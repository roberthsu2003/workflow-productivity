# Browser、Web Search 與 Computer Use

| 能力 | 適合用途 | 注意事項 |
|---|---|---|
| Web Search | 查公開且可能更新的資料 | 要求附來源與日期 |
| Browser | 開頁、點擊、填表、檢查 UI | 使用者帳號權限仍然生效 |
| Browser extension | 使用指定瀏覽器分頁 | 只授權必要頁面 |
| Computer Use | 操作瀏覽器或原生 app | 高影響動作前核對目標 |

課堂先在測試網站做「搜尋、填寫但不送出」，確認 Codex 能描述狀態並停在送出前，再進入真實流程。
