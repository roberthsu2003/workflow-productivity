# Codex 工作空間

Claude 的 Cowork / Code 概念，在 OpenAI 中分散於 Desktop、CLI、IDE、local/worktree/cloud environments 與 task coordination。

- Desktop：多 task、diff、終端機、browser 與成果預覽。
- CLI：終端機導向工作、腳本與遠端主機。
- IDE extension：在編輯器內理解與修改程式碼。
- Cloud：可重現的遠端執行、背景工作與跨裝置交辦。

互不相依的目標放到不同 task；Git repository 優先使用不同 worktree。一次性複雜成果可用 goal，週期性工作用 automation。
