# 工業級儲能系統（BESS）安全技術標準摘要

> ⚠️ **教學用虛構資料。** 條號、數值與機關名稱均為虛構，**不得作為實際工程或法遵依據**。

> 本檔案的用途是練習「跨文件法規查核」，不是提供真實標準。

**文件編號**：TFL-DOC-STD-2026-011（內部彙整）
**彙整日期**：2026-08-15
**彙整單位**：潮汐物流 工務處
**用途**：園區儲能建置案的內部初審依據

---

## 一、適用範圍

本摘要適用於**裝置容量 100 kWh 以上、2,000 kWh 以下**之工業級鋰電池儲能系統（BESS），設置於物流園區之室內或半戶外空間。

**不適用**：
- 裝置容量超過 2,000 kWh（需另依大型儲能規範）
- 設置於住宅區或人員密集場所
- 移動式儲能設備

---

## 二、選址與空間

| 條號 | 要求 | 數值 |
| :--- | :--- | :--- |
| S-1 | 與建築物外牆最小間距 | **≥ 3.0 公尺** |
| S-2 | 與可燃物堆置區最小間距 | **≥ 5.0 公尺** |
| S-3 | 與逃生出口最小間距 | ≥ 3.0 公尺 |
| S-4 | 電池櫃間最小間距 | ≥ 1.0 公尺 |
| S-5 | 維修通道最小寬度 | ≥ 1.2 公尺 |
| S-6 | 設置點淹水潛勢 | 不得位於 50 年重現期淹水潛勢區 |

---

## 三、防火與滅火

| 條號 | 要求 |
| :--- | :--- |
| F-1 | 電池室之防火時效 **≥ 2 小時** |
| F-2 | 須設置**氣體式**自動滅火系統（不得僅以水系統為主要滅火設施） |
| F-3 | 須設置獨立之火警偵測系統，含**煙感與溫感雙重偵測** |
| F-4 | 須設置可燃氣體偵測器，偵測氫氣濃度 |
| F-5 | 氫氣濃度達 **1.0%（LEL 的 25%）** 時須自動啟動強制排氣 |
| F-6 | 滅火系統動作後須自動切離電池與電網之連接 |

---

## 四、通風

| 條號 | 要求 | 數值 |
| :--- | :--- | :--- |
| V-1 | 常時換氣次數 | **≥ 6 次／小時** |
| V-2 | 緊急排氣換氣次數 | **≥ 12 次／小時** |
| V-3 | 排氣口設置高度 | 天花板下 0.3 公尺內 |
| V-4 | 進排氣口最小間距 | ≥ 3.0 公尺 |

---

## 五、電池管理系統（BMS）

| 條號 | 要求 |
| :--- | :--- |
| B-1 | 須具備單一電芯層級之電壓與溫度監控 |
| B-2 | 過充保護動作電壓：依電芯規格書設定，且須有**二階段保護** |
| B-3 | 溫度異常告警門檻 **≤ 55°C**，強制斷開門檻 **≤ 65°C** |
| B-4 | 須具備熱失控早期預警功能 |
| B-5 | 監控資料須保存 **≥ 12 個月** |
| B-6 | 須能與園區之集中監控系統整合 |

---

## 六、電氣安全

| 條號 | 要求 |
| :--- | :--- |
| E-1 | 直流側須設置獨立之隔離開關 |
| E-2 | 接地電阻 **≤ 10 歐姆** |
| E-3 | 須設置突波保護裝置（SPD） |
| E-4 | 電纜須採用低煙無鹵（LSZH）材質 |
| E-5 | 併網須符合台電併聯技術要點（另案審查） |

---

## 七、維運與人員

| 條號 | 要求 |
| :--- | :--- |
| M-1 | 每 **6 個月**執行一次定期檢查並留存紀錄 |
| M-2 | 每 **12 個月**執行一次滅火系統功能測試 |
| M-3 | 操作人員須完成儲能系統安全訓練，訓練紀錄保存 3 年 |
| M-4 | 須訂定緊急應變計畫並每年演練一次 |
| M-5 | 現場須備置適用於鋰電池火災之滅火器材 |
