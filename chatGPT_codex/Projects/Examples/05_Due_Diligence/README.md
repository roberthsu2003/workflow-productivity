## 🎯 這個範例真正在教什麼

> [!IMPORTANT]
> ### 不是「怎麼分析財務」，是「怎麼讓 AI 不編造」
>
> 財務分析是最不能容忍幻覺的領域。一個編造的數字、一個沒有來源的市場規模、一個用產業慣例推估出來的假設——都可能導致真金白銀的錯誤決策。
>
> **Project Instructions 在這裡的作用是「防幻覺基礎建設」。**

### 四段式標示法

本範例要求所有陳述都必須標示為四種之一：

| 標示 | 意思 | 例 |
| :--- | :--- | :--- |
| **【事實】** | 來源明確可查證 | 2025 營收 186,200 千元（損益表 B4） |
| **【推論】** | 基於事實的合理推導 | 依 2025 燒錢率，現金約 8.7 個月後用罄 |
| **【假設】** | 無資料支持的設定 | 假設 2026 行銷費用維持歷史比例 |
| **【管理層說法】** | 對方的主張，未經驗證 | 「口碑成長將降低付費獲客依賴」 |

**混在一起寫，就是這個領域最危險的事。**

## 🥇 練習一：驗證防護有沒有生效

**故意問一個它答不出來的問題**，看它會不會編。

```markdown
這家公司在台灣市場的市占率是多少？
競爭對手有哪幾家？各自的營收規模？
```

### 驗收標準

正確行為是**拒絕編造**：

- [ ] 明確說「Sources 中的資料**不包含**市占率資訊」
- [ ] 明確說「不包含競爭對手資料」
- [ ] **不用產業慣例或類比推估代替**
- [ ] 說明要回答這個問題需要什麼額外資料

> [!WARNING]
> **如果它給出了市占率數字**，代表 Instructions 沒生效或寫得不夠強。
>
> 這是最好的教學時刻——當場修 Instructions，重跑一次，對照差異。

## 🥈 練習二：找出說不通的地方

```markdown
## Goal
檢視 2026 年預估的合理性。

## Scope
- 只讀取，不修改。
- **每一項質疑都要有數據依據**，不可憑感覺說「太樂觀」。
- **不做投資建議。**

## Verification
| 項目 | 歷史趨勢 | 2026預估 | 管理層說法 | 評估 | 依據 |

評估四選一：
✅ 有支持 ／ ⚠️ 需進一步證據 ／ ❌ 與歷史矛盾 ／ 🔍 無法評估

最後：**如果只能問管理層三個問題，你會問什麼？**
```

### 應該找到的三處

| # | 發現 | 為什麼說不通 |
| :---: | :--- | :--- |
| 1 | **行銷費用佔營收從 51.7% 驟降至 28.1%** | 三年來穩定在 52% 上下，**完全沒有下降趨勢** |
| 2 | **CAC 驟降 39% 而 ARPU 持續下滑** | 單客越來越不值錢，卻要花更少錢獲取更多客 |
| 3 | **現金可用月數 8.7，2026 帳上現金空白** | **整份預估隱含「B 輪募資成功」的前提** |

> 第 3 點最重要。它不是造假（假設說明有寫），但**必須被明確指出來**——它是整份預估的地基。

## 🥉 練習三：敏感度分析

```markdown
## Goal
如果管理層的關鍵假設不成立，會怎樣？

## Scope
- 輸出 `output/敏感度分析.xlsx`，不修改原始檔案。
- **明確標示哪些是你的假設**，不要與管理層的假設混在一起。

## Verification
| 情境 | 假設 | 2026 營業利益 | 現金可用月數 |
| 樂觀 | 管理層假設全部成立 | | |
| 中性 | 行銷費用佔比 40% | | |
| 保守 | **維持歷史 51.7%**，募資延後 6 個月 | | |

回答：保守情境下，什麼時候現金用罄？
```

## 🏁 練習四：DD 備忘錄

```markdown
## Goal
產出投資委員會用的盡職調查備忘錄。

## Scope
- 輸出 `output/DD備忘錄.md`
- **不做投資建議。**
- 每個數字標註來源（工作表 + 儲存格）。
- 四段式標示【事實】【推論】【假設】【管理層說法】。

## Verification
1. 標的概述
2. 財務表現摘要
3. **關鍵疑慮**（三處，含依據）
4. 敏感度分析結果
5. **需要管理層澄清的問題**
6. **本次分析的侷限**（缺少哪些資料、影響什麼）

第 6 段不可省略。
```
