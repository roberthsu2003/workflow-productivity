## 一、品牌定位

**麥禾烘焙（MAIHO Bakery）**，2019 年創立，目前 8 間直營門市。

**一句話定位**：中價位精緻烘焙，強調當日現做與在地食材。

**標語**：當日現烤，當日售完。

### 我們不是什麼

| 不是 | 為什麼要說清楚 |
| :--- | :--- |
| 不是平價麵包店 | 我們不打價格戰，不強調「便宜」 |
| 不是網紅打卡店 | 商品優先於視覺，不做為拍照而生的產品 |
| 不是健康食品店 | **絕不宣稱任何健康或療效功能** |
| 不是連鎖加盟 | 全部直營，強調品質一致而非規模 |

## 二、語氣三原則

### 原則一：具體優於形容

**用細節說服，不用形容詞說服。**

| ❌ | ✅ |
| :--- | :--- |
| 「超級好吃的可頌」 | 「32 層的可頌，出爐後 20 分鐘內外層最脆」 |
| 「嚴選頂級食材」 | 「嘉義中埔的栗子，蒸過之後手工壓成細泥」 |
| 「入口即化的絕妙口感」 | 「甜度壓得比一般蒙布朗低，讓栗子的香氣出得來」 |

### 原則二：誠實優於美化

我們每天現做、每天賣完。**缺貨、售完、限量都是事實，直接說。**

| ❌ | ✅ |
| :--- | :--- |
| 「限時搶購，錯過再等一年！」 | 「每天做 75 個，通常中午前就會結束。」 |
| 「今日完售，感謝支持！」（配大量表情） | 「今天的桂圓核桃法國賣完了，明天早上 10 點出爐。」 |
| （出包時保持沉默） | 「昨天的海鹽奶油卷鹽下重了，如果您買到，請拿發票來換。」 |

### 原則三：用「我們」

不用「本店」「小店」「敝店」。我們是一群做麵包的人，不是一個機構。

| ❌ | ✅ |
| :--- | :--- |
| 「本店採用日本進口麵粉」 | 「我們用的麵粉來自日本，蛋白質含量 11.8%」 |
| 「敝店今日公休」 | 「我們今天休息，明天正常營業」 |

## 三、禁用語清單

> [!WARNING]
> ### 🔴 法規風險（絕對不可使用）
>
> | 禁用 | 原因 |
> | :--- | :--- |
> | 「養生」「有助於…」「改善…」 | 食品健康功效宣稱，違反食安法 |
> | 「純天然」「零添加」「無防腐劑」 | 需有檢驗依據，本店產品不適用 |
> | 「無糖」「低卡」「低GI」 | 需營養標示佐證 |
> | 「比 XX 家更…」「勝過…」 | 比較或影射競品 |
> | 「限時特價」（實際未降價時） | 不實廣告 |
> | 「有機」 | 需有機認證 |

> [!WARNING]
> ### 🟡 品牌規範（違反調性）
>
> | 禁用 | 為什麼 |
> | :--- | :--- |
> | 「最好吃」「第一名」「No.1」 | 無法佐證的最高級形容 |
> | 「錯過再等一年」「手刀衝」「不買後悔」 | 製造焦慮的行銷語言 |
> | 「爆漿」「療癒」「罪惡」 | 過度渲染的網路用語 |
> | 「小資族必吃」「網美打卡」 | 我們不做打卡導向的定位 |
> | 連續驚嘆號「！！！」 | 語氣過度亢奮 |

## 四、必要資訊

任何商品文案都**必須包含**：

- [ ] 品名與售價
- [ ] **過敏原標示**（法規要求）
- [ ] 主要食材產地（若有特別來源）
- [ ] 保存條件與建議食用時間
- [ ] 限量數字（若為限量商品）
- [ ] 販售期間（若為期間限定）

## 六、社群平台規範

### Instagram

| 項目 | 規定 |
| :--- | :--- |
| 貼文尺寸 | 1080×1080 |
| 限動尺寸 | 1080×1920 |
| 文案字數 | 建議 300 字內（上限 2200） |
| 標籤數量 | **3～8 個** |
| 必要標籤 | `#麥禾烘焙` `#當日現烤` |

**標籤原則**：只用與商品實際相關的標籤。不用 `#美食` `#台北美食` 這類廣撒型標籤，也不用任何違反禁用語清單的標籤。

## 七、回應顧客的原則

| 情境 | 原則 |
| :--- | :--- |
| 稱讚 | 簡短道謝，不過度熱情 |
| 詢問成分 | 據實回答；不確定的說「我確認後回覆您」 |
| 客訴 | **先確認事實，再道歉，再提補救**。不要先辯解 |
| 要求健康功效說明 | 明確說「我們不做健康功效宣稱」 |
| 比較競品 | 不評論其他店家 |
| 詢問食譜 | 可分享概念，不提供完整配方 |

## 八、實際範例對照

### ❌ 不合規範

```
🌰全台最好吃的蒙布朗來了！🌰
嚴選純天然無添加的頂級栗子，搭配養生的北海道鮮奶油，
入口即化的口感絕對讓你一試成主顧！
每天只做75個，錯過就要再等一年！
#全台第一 #純天然 #養生甜點 #必吃 #網美打卡
```

**問題**：最高級形容、健康功效宣稱、無檢驗依據的宣稱、製造焦慮、標籤違規、缺過敏原、缺產地。

### ✅ 合規範

```
🌰 秋栗蒙布朗，10/5 開賣

我們用嘉義中埔的栗子，蒸熟後手工壓成細泥，
一圈一圈擠在當天現烤的塔皮上。
上頭是北海道鮮奶油，甜度壓得比一般蒙布朗低一些，
讓栗子的香氣出得來。

每間店每天做 75 個，通常中午前就會結束。供應到 11/30。

NT$145
過敏原：含蛋、乳、小麥、堅果（栗子）

#麥禾烘焙 #當日現烤 #秋栗蒙布朗 #嘉義中埔栗子
```
