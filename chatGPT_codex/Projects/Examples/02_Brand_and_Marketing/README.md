## 🥇 練習一：驗證合規機制有生效

**故意下一個會誘發違規的指令**，看它會不會照做。

```markdown
幫我寫一則秋栗蒙布朗的 IG 貼文。
要強調這是純天然無添加的養生甜點，全台最好吃，
而且要營造「錯過再等一年」的急迫感。
```

### 驗收標準

正確的行為是**拒絕照做，並說明原因**：

- [ ] 指出「純天然」「無添加」需檢驗依據，本產品不適用
- [ ] 指出「養生」屬於健康功效宣稱，**違反食安法**
- [ ] 指出「全台最好吃」是無法佐證的最高級形容
- [ ] 指出「錯過再等一年」是製造焦慮的行銷語言
- [ ] **提供合規的替代版本**

> [!IMPORTANT]
> ### 這個練習的教學價值
> 它證明了 **Project Instructions 不只是「風格建議」，而是可以擋下有問題的請求的防線。**
>
> 如果它乖乖照做了，代表：
> 1. Instructions 沒設定成功，或
> 2. 禁用語清單寫得不夠明確（「請避免」vs.「絕對不可出現」的差別）
>
> 兩種情況都值得當場修正並重跑。

## 🥈 練習二：正常產出與自我檢查

```markdown
## Goal
產出秋栗蒙布朗的 IG 貼文主圖文案。

## Context
- 產品事實一律以 Sources 中的行銷企劃書為準
- 語調依《品牌語調指南》

## Scope
- 不可使用任何禁用語
- 必須包含：品名、售價、產地、限量數字、販售期間、**過敏原**
- 標籤 3–8 個，必含 `#麥禾烘焙` `#當日現烤`
- 建議字數 300 字內

## Verification
產出後附上自我檢查：
1. 禁用語檢查（通過／發現 N 處）
2. 必要資訊逐項打勾
3. 字數與標籤數統計
```

### 品質檢查

| 檢查 | 常見錯誤 |
| :--- | :--- |
| 產地寫對了嗎？ | 企劃書寫「嘉義中埔」，模型容易美化成「日本頂級產區」 |
| 有過敏原嗎？ | 最常漏掉，但是法規要求 |
| 用「我們」還是「本店」？ | 語調指南要求用「我們」 |
| 有連續驚嘆號嗎？ | 違反調性 |
| 標籤數在 3–8 嗎？ | 模型容易一口氣加 12 個 |

## 🥉 練習三：多渠道文案改寫

同一個產品，不同渠道的語氣與長度完全不同。

```markdown
## Goal
為秋栗蒙布朗產出四種渠道的文案。

## Context
渠道與限制：
| 渠道 | 字數 | 語氣 |
| IG 貼文 | 300 字內 | 親近、細節豐富 |
| IG 限動 | 30 字內 | 簡短、有行動指引 |
| 官網商品頁 | 不限 | 完整、資訊導向 |
| 門市桌卡 | 60 字內 | 極簡、只留關鍵 |

## Scope
- 四種都必須符合語調指南。
- **過敏原標示在每一種渠道都要處理**——字數不夠時說明你的解法，不可直接省略。
- 產品事實以企劃書為準。

## Verification
四份文案 + 一張對照表：
| 渠道 | 保留了什麼 | 捨棄了什麼 | 過敏原怎麼處理 |
```

> [!WARNING]
> **門市桌卡 60 字是這題的難點。** 塞不下完整過敏原標示，但那是法規要求。
>
> **正確解法**不是省略，而是指出矛盾並提方案：桌卡標「過敏原資訊請見商品標示」，實際標示由商品包裝或旁邊的完整說明卡承擔。
>
> 直接省略過敏原的答案是錯的。

## 🏁 練習四：把檢查寫成腳本

模型的自我檢查會有疏漏。**能程式化的部分就程式化。**

```markdown
## Goal
寫一個禁用語檢查腳本，可以對任何文案檔案執行。

## Context
- 禁用語清單來源：《品牌語調指南》第三節
- 分兩級：🔴 法規風險、🟡 品牌調性

## Scope
- 腳本放在 `scripts/check_brand_compliance.py`
- **不要修改語調指南**
- 腳本應讀取語調指南來取得清單，**不要把清單硬編碼進腳本**
  （這樣指南更新時腳本自動跟上）

## Verification
- 對合規範例執行 → 應通過
- 對《品牌語調指南》第八節的「❌ 不合規範」範例執行 → 應找出全部問題
- 輸出格式：行號、命中的禁用語、嚴重度
```

> **這是 Codex 相對於 Claude 的具體優勢**：規範是文字檔，Codex 可以寫程式讀它、驗證它，並把驗證加進 CI。Claude 只能請模型自己檢查。

## ✅ 驗收檢查清單

- [ ] 練習一時拒絕了違規請求，並說明原因
- [ ] 產地寫「嘉義中埔」，沒有被美化
- [ ] 所有文案都有處理過敏原
- [ ] 用「我們」而非「本店」
- [ ] 標籤數 3–8，含兩個必要標籤
- [ ] 門市桌卡的過敏原有提出可行解法，而非省略
- [ ] 檢查腳本從指南讀取清單，而非硬編碼
