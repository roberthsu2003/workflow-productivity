# 範例 04：個人學習教練

> 🟢 **方案需求**：Free。

**情境**：你想在三個月內把 Python 資料分析學到「能獨立完成公司報表自動化」的程度。你需要的不是課程，是**一個會記得你進度、會誠實指出你哪裡沒學好的教練**。

> **這個範例練的是「長期關係」的 project 設計**——與前三個範例（一次性任務）本質不同。

## 🏗️ 課前設定

**這個範例建議用 Local project**，因為學習紀錄需要累積成檔案。

```bash
mkdir -p ~/codex-lab/python-learning/{progress,exercises,notes}
cd ~/codex-lab/python-learning
git init
cp <講義路徑>/sample_files/學習目標與現況.md notes/
git add . && git commit -m "init: 學習計畫"
```

---

## ⚠️ 這個範例最重要的設計

> [!WARNING]
> ### AI 教練最大的失敗模式是「太好相處」
>
> 預設行為下，它會：
> - 說「你做得很好！」即使你的程式碼有明顯問題
> - 你說「我懂了」就往下走，不驗證你真的懂了
> - 你卡住時直接給答案，而不是讓你想
>
> **這三件事都會讓你學不會。** Instructions 必須明確要求相反的行為。

## 🥇 練習一：建立誠實的評估基準

```markdown
## Goal
評估我目前的 Python 程度，建立一個誠實的起點。

## Context
- 我的自述在 `notes/學習目標與現況.md`
- **自述可能高估或低估自己**，請用實作驗證

## Scope
- **不要相信我的自我評估，用題目驗證。**
- 出 5 題，難度遞增，涵蓋：基本語法、資料結構、檔案處理、pandas、錯誤處理
- **一次出一題**，我答完再出下一題
- 不要給提示，除非我明確要求

## Verification
五題結束後：
1. 我實際的程度（不是我自述的）
2. **我以為我會但其實不會的地方**
3. 我以為我不會但其實會的地方
4. 據此調整的學習計畫
```

> **第 2 點是這個練習的核心價值。** 學習最大的浪費是「以為自己會了」——那會讓你跳過該練的東西。

## 🥈 練習二：每週複習（有累積的對話）

**每週固定跑一次。** 這是 project 的價值所在——它記得你上週做了什麼。

```markdown
本週複習。

## 我這週做的
（貼上你的 exercises/ 或描述）

## 我覺得卡住的地方
（誠實寫）

## 請你做
1. 檢視我的程式碼，指出問題（**不要客套，直接說**）
2. 對照 `notes/學習目標與現況.md` 的計畫，我的進度落後還是超前？
3. 出 3 題**針對我這週弱點**的練習
4. 更新 `progress/YYYY-WW.md` 記錄本週狀況

## 限制
- **不要說「你做得很好」除非我真的做得很好。**
- 指出問題時要說明「為什麼這樣不好」，不只是「應該這樣寫」
- 我卡住時**先給提示，不要直接給答案**
```

## 🥉 練習三：從練習到真實專案

學習的終點是**能解決真實問題**。

```markdown
## Goal
把我學到的東西用在真實任務上：自動化公司的月報產出。

## Context
- 真實資料：`data/配送績效_2026Q1.csv`（見商業情報範例）
- 我目前的程度：（依練習一的評估）

## Scope
- **這次由我寫，你只做 code review。**
- 我卡住超過 20 分鐘才給提示。
- **不要幫我寫程式碼。**

## Verification
我寫完後，請你：
1. 指出問題（分：會出錯 / 不好維護 / 風格建議）
2. **問我三個問題**，確認我理解自己寫的東西
3. 如果我答不出來，指出我該回頭補哪個觀念
```

> [!IMPORTANT]
> **「不要幫我寫程式碼」是這一題的關鍵限制。**
>
> Codex 的預設行為就是寫程式碼——它很擅長。但**你請它幫你學習時，它幫你寫就等於幫你作弊。**
>
> 這也是 Codex 用於學習時最需要注意的地方：**它太能幹了。**

## 🏁 練習四：三個月回顧

```markdown
## Goal
回顧三個月的學習，誠實評估達成度。

## Context
- 原始目標：`notes/學習目標與現況.md`
- 每週紀錄：`progress/` 底下所有檔案

## Scope
- **不要粉飾。** 沒達成就說沒達成。
- 用具體證據（哪一週的哪個練習）支持你的評估。

## Verification
1. 原始目標的逐項達成度
2. **實際花的時間 vs. 原本預估**
3. 哪些學習方法有效、哪些浪費時間（用紀錄佐證）
4. 我現在**能獨立做到什麼、還不能做到什麼**
5. 下一階段建議
```

## 🔄 與其他範例的差異

| | 範例 01–03 | **範例 04** |
| :--- | :--- | :--- |
| 時間跨度 | 單次任務 | **三個月** |
| Sources | 參考資料 | **目標與現況（會更新）** |
| 產出 | 交付物 | **累積的學習紀錄** |
| 對 AI 的要求 | 準確、有效率 | **誠實、不要幫太多** |
| 成功的定義 | 任務完成 | **我學會了** |
