# Meeting Action Plan

## 流程
1. 讀取會議紀錄或逐字稿。
2. 標記所有「要做的事」。
3. 對每一項判斷三欄：**做什麼 / 誰做 / 什麼時候前**。
4. **三欄齊全** → 「行動計畫」工作表。
   **任一欄缺少** → 「待確認事項」工作表，並註明缺什麼、該問誰。
5. 判斷「相依於誰」——這一項要別人先完成才能動嗎？
6. 讀取 `templates/action-plan-template.xlsx`，填入後產出到 `output/`。

## 期限的處理
| 原文 | 怎麼記 |
| :--- | :--- |
| 「這週給我」 | 換算日期，標註「（依會議日推算）」 |
| 「月底前」 | 該月最後工作日 + 推算依據 |
| **「盡快」** | **不換算** → 待確認 |
| 未提及 | **不補** → 待確認 |

## 限制
- **不得補造未出現的負責人或期限。**
- **「你講得有道理」「嗯可以考慮」不是決議**，不列為行動項目。
- 每一項都要填「出處」，引用紀錄中的原文片段。
- 不修改範本檔；產出不覆蓋既有檔案。

## 輸出
1. 產出檔路徑
2. 行動項目 N 項、待確認 M 項
3. **你歸類為「不是行動項目」的內容**（讓使用者確認沒漏掉）
