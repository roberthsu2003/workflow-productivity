## 講師用：這份逐字稿的教學點

### 1. 「應該不會」的處理（最重要）

`[00:18:50]` 林維倫對客戶說「**應該不會**」影響上市。

這是**語意模糊的承諾**。緊接著 `[00:20:00]` 陳柏宇就出面澄清了。

| ❌ 錯誤記錄 | ✅ 正確記錄 |
| :--- | :--- |
| 已承諾：不會影響 10/5 上市 | 語意模糊，需確認。業務處表示「應該不會」影響上市，
但營運處隨後澄清為「北中區確定、南區待確認」。**以澄清版本為準。** |

> 客戶會議的承諾有合約意義。把「應該不會」寫成「承諾不會」，日後出事就是糾紛。

### 2. 已決議 vs. 待確認

| 項目 | 狀態 | 依據 |
| :--- | :--- | :--- |
| 北中區六間可配合 | ✅ **已決議** | `[00:20:30]` 陳柏宇明確確定 |
| 以 900 盒量能規劃 | ✅ **已決議** | `[00:05:00]` 陳柏宇拍板 |
| 提供溫度記錄報告 | ✅ **已決議** | `[00:24:35]` 林維倫確認 |
| 南區配送時段 | ⏳ **待確認** | 陳柏宇週四回覆 |
| 合約形式（加購 or 另簽） | ⏳ **待確認** | 王詩涵週五回覆 |
| 冷鏈車輛是否足夠 | 🔶 **討論中未定案** | 採購進度不明，無結論 |

### 3. 部分出席

吳建志 `[00:15:20]` 才加入。**出席欄應標示「列席，10:45 加入」**，不可寫成全程出席。
