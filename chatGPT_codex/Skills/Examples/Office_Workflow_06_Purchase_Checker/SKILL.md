# Purchase Checker

## 流程
1. 讀取所有報價資料（可為圖片、PDF、文字）。
2. 讀取 `references/採購作業規範.md`。
3. **檢查比價門檻**：依採購總額判斷需要幾家報價。**不足即標示不合規。**
4. **逐筆檢查報價資格**（6 項，見規範第二節）。缺任一項 → 該筆**不得列入比較**。
5. **檢查規格對等性**——保固、交期、規格有差異時必須標示，不可只比單價。
6. 產出比價表到 `output/`。

## 限制
- **一律以 `references/採購作業規範.md` 為準**，不可自行放寬。
- **不得以未經驗證的規格等同性進行比價。**
- 提出建議廠商時，若非最低價，**必須引用規範第三節的可接受理由**。
- **「品質比較好」「合作比較久」不是可接受的理由。**
- 不推測承辦動機。只陳述「不符規範第 X 節」。
- 不修改範本；產出不覆蓋既有檔案。

## 輸出
1. **合規檢查結果**（家數是否足夠、各筆報價資格是否齊全）
2. 比價表（含規格差異標示）
3. 建議廠商 + 理由（引用規範條次）
4. **不合規項目清單**——這一段在前，比價表在後
