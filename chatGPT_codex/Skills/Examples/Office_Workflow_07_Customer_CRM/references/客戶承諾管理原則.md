# 潮汐物流 客戶承諾管理原則

> ⚠️ 教學用虛構資料。

## 一、什麼算「承諾」

| 表述 | 是承諾嗎 | 處理 |
| :--- | :---: | :--- |
| 「我們會在 X 日前完成」 | ✅ **是** | 記錄，含期限 |
| 「7 個工作天內回覆」 | ✅ **是** | 記錄，換算實際日期 |
| 「這個沒問題」 | ✅ **是**（對前述請求的同意） | 記錄，需釐清範圍 |
| **「我們盡量」** | ⚠️ **語意模糊** | **標示「需確認是否構成承諾」** |
| **「應該可以」** | ⚠️ **語意模糊** | 同上 |
| 「我再確認後回覆你」 | ⚠️ 這是承諾「回覆」，不是承諾「做到」 | 記錄為「承諾回覆」 |
| 「我了解你的需求」 | ❌ 否 | 不記錄為承諾 |

> [!WARNING]
> **語意模糊的表述必須標示，不可自行判定為「是」或「不是」承諾。**
> 這類表述在爭議時是雙方各執一詞的來源，需要人來判斷。

## 二、承諾記錄原則

- **引用原文，不可改寫或美化。**
  ❌「已承諾協助處理」　✅「原文：『這個我們禮拜三之前給你答覆』」
- 記錄承諾的**管道與時間**（郵件？電話？當面？）
- 電話或當面的承諾，**須在紀錄中標示「無書面依據」**

## 三、逾期承諾的處理

| 逾期天數 | 風險等級 | 必要動作 |
| :--- | :---: | :--- |
| 1–3 天 | 🟡 | 主動告知客戶延遲原因與新時程 |
| 4–7 天 | 🟠 | 同上 + 主管知悉 |
| **> 7 天** | 🔴 | 同上 + **書面說明** + 評估補償 |
| **客戶已催 2 次以上** | 🔴 | **一律升級主管處理** |

## 四、禁止事項

- 不得記錄未經授權的承諾
- 不得因為客戶施壓而追加承諾
- **不得推測客戶的動機或情緒**（「客戶只是想凹折扣」）
- 客訴紀錄中不寫對客戶的評價

## 五、升級判準

符合任一即應升級主管：
- [ ] 客戶明示要終止合約或申訴
- [ ] 承諾逾期超過 7 天
- [ ] 客戶已催 2 次以上
- [ ] 涉及金額超過 NT$20,000
- [ ] 涉及法規或合約爭議
