# Leave Handover

## 流程
1. 讀取請假單（可為圖片），取得：請假人、期間、代理人、核准狀態。
   **未核准的請假不產出交接清單**——先確認。
2. 讀取 `references/職務代理規範.md`，確認代理權限上限。
3. 盤點交接事項，**分成兩類**：
   - **現況**：目前的工作狀態
   - **期間內需處理**：請假期間會發生的事
4. 對每項判定急迫度（🔴 / 🟡 / 🟢）。
5. **檢查三項常見疏漏**（見規範第五節）：
   - 期間內會到期的事項
   - 他人在等你回覆的事項
   - **代理人權限不足的事項**
6. 讀取 `templates/leave-handover-template.xlsx` 產出到 `output/`。

## 限制
- **代理權限一律以 `references/職務代理規範.md` 為準**，不可自行放寬。
- 超出代理權限的事項，**必須單獨列出並註明「須由部門主管處理」**。
- 不得補造請假單上沒有的資訊。
- 使用者未提供的交接事項，**不要憑空生成**——問他。
- 不修改範本；產出不覆蓋既有檔案。

## 輸出
1. 產出檔路徑
2. 🔴 項目清單（最需要注意的）
3. **超出代理權限的事項清單**
4. 你發現的疏漏風險（依規範第五節）
