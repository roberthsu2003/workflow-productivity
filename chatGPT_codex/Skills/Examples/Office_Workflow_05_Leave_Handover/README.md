## 📝 預期結果

### 🔴 期間內必須處理（至少 2 項）

| 事項 | 為什麼是 🔴 |
| :--- | :--- |
| **麥禾報價 9/26 到期** | **請假期間（9/21–9/30）內就會過期** |
| 元昇報價（客戶已催兩次） | 他人在等，且已延遲 |

### ⚠️ 超出代理權限（關鍵發現）

| 事項 | 問題 |
| :--- | :--- |
| **冷鏈車採購案** | 授權書明確寫「**NOT authorized: purchase approval**」——代理人林維倫**不能核決採購**。若期間內供應商回覆需決策，會卡住。 |

### 三項疏漏檢查

- [x] 期間內會到期 → 麥禾報價 9/26
- [x] 他人在等回覆 → 元昇報價、鼎和賠償案
- [x] **代理權限不足** → 採購核決

---

## ✅ 驗收

> [!IMPORTANT]
> ### 最重要的一項：有沒有抓到「採購核決」的權限問題
>
> 交接清單看起來寫得再完整，**如果代理人根本沒有權限處理其中一項，那一項就是會卡住。**
>
> 這是 `references/` 的價值——**skill 不只填表格，它拿規範去比對並發現問題。**

- [ ] 讀懂請假單圖片（期間 9/21–9/30、代理人林維倫）
- [ ] **抓到採購核決超出代理權限**
- [ ] 麥禾報價 9/26 到期被標 🔴
- [ ] 元昇報價（客戶已催）被標 🔴 或 🟡
- [ ] 車輛保養排程被合理歸為 🟡 或 🟢
- [ ] **沒有憑空生成我沒提到的交接事項**
- [ ] 範本未被修改
