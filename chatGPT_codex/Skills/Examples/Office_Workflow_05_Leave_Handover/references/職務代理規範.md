# 潮汐物流 職務代理規範（摘要）

> ⚠️ 教學用虛構資料。

## 一、代理人指派

- 請假 **3 個工作天以上**須指定職務代理人。
- 代理人須為**同部門或相關部門**且職級不低於請假人一級以下。
- 代理期間須完成**書面交接**並經部門主管核可。

## 二、代理權限上限

| 項目 | 代理人可否決行 | 上限 | 超過時 |
| :--- | :---: | :--- | :--- |
| 日常請款 | ✅ 可 | **NT$10,000** | 需請示部門主管 |
| 採購核決 | ❌ 否 | — | 一律由部門主管處理 |
| 對外正式函文 | ❌ 否 | — | 一律由部門主管處理 |
| 客訴回覆 | ⚠️ 限草稿 | — | 須客服主管確認後發出 |
| 人事異動 | ❌ 否 | — | — |
| 合約簽署 | ❌ 否 | — | — |

## 三、交接清單必要欄位

- [ ] 交接事項與現況
- [ ] **請假期間內需處理的事項**（與「現況」分開列）
- [ ] 急迫度分級
- [ ] 各事項的聯絡窗口
- [ ] **代理人權限範圍**（引用本規範）

## 四、急迫度分級

| 級別 | 定義 |
| :---: | :--- |
| 🔴 | 請假期間內**必須**處理，逾期有實質後果 |
| 🟡 | 可延後但需在回任後一週內處理 |
| 🟢 | 回任後再處理即可 |

## 五、常見疏漏

> [!WARNING]
> 依過往稽核，交接最常漏掉的三項：
> 1. **期間內會到期的事項**（合約、報價有效期、法定期限）
> 2. **他人在等你回覆的事項**（對方不知道你請假）
> 3. **代理人權限不足的事項**（沒事先安排，到時卡住）
