# 延伸練習 02：待辦事項擷取（第一階：模仿者）

> 🟢 **方案需求**：Free。

從一段雜亂的文字（郵件、訊息、筆記）中，抓出「誰要做什麼、什麼時候前」。

---

## 🛠️ 建立

```bash
mkdir -p ~/.agents/skills/task-extractor
cat > ~/.agents/skills/task-extractor/SKILL.md <<'EOF'
---
name: task-extractor
description: 從郵件、訊息或會議筆記中擷取待辦事項，輸出負責人與期限。適用於已存在的文字紀錄；不要用於撰寫新的工作計畫、排定優先順序，或在沒有原始文字時憑空產生待辦。
---

# Task Extractor

## 流程
1. 通讀全文，標記所有「要做的事」。
2. 對每一項判斷三個欄位：**做什麼 / 誰做 / 什麼時候前**。
3. 三個欄位齊全 → 列入「行動項目」。
4. **任一欄位缺少 → 列入「待確認」，不要補。**

## 期限的處理
| 原文說法 | 怎麼記 |
| 「這週給我」 | 換算成日期，標註「（依來文日推算）」 |
| 「月底前」 | 該月最後工作日，標註推算依據 |
| **「盡快」「有空的時候」** | **不換算**。記為「未定期限」→ 待確認 |
| 沒提到期限 | **不要補**。→ 待確認 |

## 限制
- **不得補造未出現的負責人或期限。**
- 「我們應該要…」「或許可以…」是**討論**，不是待辦。
- 以暱稱或代稱出現的人，**保留原稱呼**。
- 疑問句不是待辦（「要不要順便做 X？」）。

## 輸出
1. **行動項目**表格：項目 / 負責人 / 期限 / 出處（引用原文片段）
2. **待確認**：缺什麼、該問誰
3. **我判斷不是待辦的內容**（讓你確認我沒漏掉）
EOF
```

---

## ▶️ 測試素材

```text
$task-extractor

以下是 Slack 討論，請擷取待辦：

小李：東區那個 SOP 我這週會給草稿
主管：好。另外冷鏈車的事情要不要順便查一下？
小王：我可以查，但不確定什麼時候有空
主管：盡快
小李：對了，鼎和那個案子法務還在看
主管：這個要優先，慧玲你追一下，禮拜五前給我進度
小王：我們應該要建立一個追蹤表
主管：嗯可以考慮
```

### 📝 預期結果

**行動項目**（2 項）：

| 項目 | 負責人 | 期限 |
| :--- | :--- | :--- |
| 東區 SOP 草稿 | 小李 | 本週（依來文日推算） |
| 鼎和案進度追蹤 | 慧玲 | 週五前 |

**待確認**（1 項）：
- 查冷鏈車 — 小王 — **期限「盡快」，未定**

**不是待辦**（2 項）：
- 「我們應該要建立追蹤表」+ 主管回「嗯可以考慮」→ **討論，未拍板**
- 「要不要順便查一下」是疑問句，但小王承接了 → 所以它變成待辦（列在待確認）

> [!WARNING]
> **「盡快」是這個 skill 最重要的測試。**
> 把它轉成「三天內」或任何具體日期都是捏造。
>
