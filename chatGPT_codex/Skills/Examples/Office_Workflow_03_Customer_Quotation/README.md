## ▶️ 測試一：資訊不全（應該被擋下）

```text
$customer-quotation

幫麥禾烘焙做一張冷鏈配送報價單，每天 600 盒，8 間門市。
```

### 驗收

- [ ] **它應該停下來問**，不是直接產出
- [ ] 應該問到：聯絡人、單價、付款方式、有效期限
- [ ] **沒有自行填入預設值**（例如「付款方式：月結 30 天」）

> [!IMPORTANT]
> **這是第二階最重要的測試。** 有了範本，模型會很想把每一格填滿——
> 而填滿的最快方式就是編造。
>
> `SKILL.md` 裡「缺任一項 → 停止並詢問」那一行就是在對抗這個傾向。

---

## ▶️ 測試二：資訊齊全

```text
$customer-quotation

客戶：麥禾烘焙股份有限公司
聯絡人：王詩涵
項目：
- 冷藏配送服務（0-4°C），8 間門市，每日一趟，單價 NT$1,800/趟/店
- 溫度記錄報告，每月一次，單價 NT$3,000/月
數量：配送 240 趟/月（8店×30天）、報告 1 次/月
折讓：長約優惠 NT$20,000/月
付款方式：月結 30 天
有效期限：2026-10-31
```

### 驗收

- [ ] 小計 = 240×1,800 + 1×3,000 = **435,000**
- [ ] 總計 = 435,000 − 20,000 = **415,000**
- [ ] 產出在 `output/`，**範本未被修改**
- [ ] 有附上計算過程供核對
