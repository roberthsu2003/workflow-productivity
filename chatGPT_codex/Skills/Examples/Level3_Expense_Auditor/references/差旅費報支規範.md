# 潮汐物流 差旅費報支規範

> ⚠️ 教學用虛構資料。
>
> **文件編號**：TFL-FIN-2026-002 ｜ **版本**：v5.3 ｜ **生效日**：2026-01-01

---

## 一、適用範圍

本規範適用於因公出差所生之交通、住宿、膳食與雜支費用。

**不適用**：客戶招待費（另依 TFL-FIN-2026-005）、教育訓練費、搬遷費。

---

## 二、費用上限

### 2.1 交通費

| 交通方式 | 上限 | 單據要求 |
| :--- | :--- | :--- |
| 高鐵 | 標準車廂實支 | 票根或電子票證明細 |
| 台鐵 | 實支 | 票根 |
| 客運 | 實支 | 票根 |
| 計程車 | **單趟 NT$500** | 收據（須含日期、金額、車行） |
| 網約車 | **單趟 NT$500** | App 行程明細截圖 |
| 自用車 | 每公里 NT$8 | 里程紀錄表 |
| 停車費 | 單日 NT$300 | 收據 |
| 飛機 | 需事前簽核 | 登機證 + 電子機票 |

> [!IMPORTANT]
> **計程車與網約車單趟超過 NT$500**：超出部分需檢附「事由說明」並經直屬主管核可。
> 常見可接受事由：末班車後、攜帶大型設備、行動不便、緊急事故。
> **不可接受事由**：「比較方便」「時間比較快」「當時沒想那麼多」。

### 2.2 住宿費

| 地區 | 每晚上限 |
| :--- | ---: |
| 台北市、新北市 | NT$3,500 |
| 其他直轄市 | NT$2,800 |
| 其他縣市 | NT$2,200 |
| 離島 | NT$3,000 |

**單據要求**：住宿發票（須含住宿人姓名與日期）。

### 2.3 膳食費

| 項目 | 上限 |
| :--- | ---: |
| 每人每日膳食 | NT$600 |
| 單餐 | NT$300 |

**單據要求**：
- 單筆 **NT$100 以下**：可免附單據，但需列明日期、地點、金額
- 單筆 **NT$100 以上**：須附發票或收據

> [!WARNING]
> ### 商務餐敘（有客戶或外部人員參與）
> **不適用膳食費上限**，改依「客戶招待費」規範（TFL-FIN-2026-005）。
> 須於單據上註明：**參與人員姓名、所屬單位、餐敘目的**。
> 未註明者一律**退件**，不得事後補填。

### 2.4 雜支

| 項目 | 上限 | 說明 |
| :--- | ---: | :--- |
| 網路／通訊 | 每日 NT$200 | 需說明用途 |
| 影印／文具 | 實支 | 收據 |
| 行李寄放 | 實支 | 收據 |

**不可報支**：個人物品、酒類、菸品、洗衣費、迷你吧、私人行程之交通費、罰單。

## 三、單據規範

### 3.1 必要欄位

所有單據須清楚可辨識：

- [ ] **日期**
- [ ] **金額**
- [ ] **品項或服務內容**
- [ ] **開立單位**（店名／車行／飯店名）

缺任一項 → **退件**。

### 3.2 不受理的單據

| 情況 | 處理 |
| :--- | :--- |
| 影本（除非正本已交主管機關並附證明） | 退件 |
| 手寫收據無統一編號且金額 > NT$1,000 | 退件 |
| 日期在出差期間之外 | 退件 |
| 金額經塗改 | 退件 |
| 模糊無法辨識 | 退件，可重新提供 |

### 3.3 報支期限

**出差結束後 30 日內**。逾期需附遲延說明並經處級主管核可。

## 四、審核判定

審核結果分四類：

| 判定 | 意義 | 後續 |
| :--- | :--- | :--- |
| ✅ **通過** | 完全符合規範 | 送出納 |
| ⚠️ **部分核准** | 超出上限，核准至上限金額 | 通知報支人差額自負 |
| 📋 **待補件** | 缺少必要說明或單據 | 通知補正，**不退件** |
| ❌ **退件** | 不符規範且無法補正 | 退回報支人 |

> [!IMPORTANT]
> ### 「待補件」與「退件」的差別
> - **待補件**：問題可以透過補充資料解決（例：計程車超額但未附事由說明）
> - **退件**：問題無法補救（例：報支酒類、單據日期在出差期間外）
>
> **審核時不可把「待補件」誤判為「退件」**——那會讓同仁白白損失可正當報支的費用。

## 五、模糊地帶的處理原則

> [!WARNING]
> **以下情況一律標示「待人工判斷」，不可由自動化流程逕行判定。**

| 情況 | 為什麼需要人工 |
| :--- | :--- |
| 事由說明的合理性 | 「末班車後」是否屬實需查證班次時間 |
| 商務餐敘的目的正當性 | 涉及業務判斷 |
| 逾期報支的遲延理由 | 涉及個別情況 |
| 單據金額與品項明顯不相稱 | 可能是誤植，也可能是問題 |
| 同一日多筆計程車費 | 可能合理（多點拜訪），也可能重複報支 |
