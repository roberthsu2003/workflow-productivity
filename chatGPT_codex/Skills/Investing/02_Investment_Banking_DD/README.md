# 投資 02. 財務盡職調查

> 🔵 **方案需求**：Investment Banking plugin 需 Plus 起。讀 xlsx 分析 🟢 Free 亦可。

**情境**：一家 SaaS 新創正在募 B 輪，給了你一份財務摘要。你的工作**不是驗算加減乘除**，而是**找出說不通的地方**。

---

## 📂 示範資料

[`受評標的_財務摘要_2023-2026E.xlsx`](./sample_files/受評標的_財務摘要_2023-2026E.xlsx)

| 工作表 | 內容 |
| :--- | :--- |
| 損益表 | 2023–2025 實績 + 2026 預估 |
| 關鍵指標 | 成長率、毛利率、燒錢率、CAC、ARPU、現金可用月數 |
| 假設說明 | **管理層對 2026 預估的說法** |

---

## 🥇 練習一：先讀懂，不要下判斷

```markdown
## Goal
盤點這份財務摘要提供了什麼、缺了什麼。

## Scope
- **只讀取，不要修改檔案。**
- **這一輪不要做評價，也不要下投資判斷。**

## Verification
1. 三個工作表各自提供什麼資訊
2. **哪些是實績、哪些是預估？**（分清楚 2025 與 2026E）
3. 做盡職調查通常會看、但這份資料**沒有**的項目
4. 「假設說明」中的每一條，屬於【事實】【推論】還是【管理層說法】？
```

### 缺少的關鍵項目（參考）

現金流量表、資產負債表、客戶集中度、流失率（churn）、遞延收入、股權結構、關係人交易、應收帳款帳齡、員工人數與人均產出。

> **教學重點**：盡職調查的第一步是**知道自己看不到什麼**。只看損益表就下判斷，是最常見的錯誤。

---

## 🥈 練習二：找出說不通的地方（核心練習）

```markdown
## Goal
檢視 2026 年預估的合理性，找出無法從歷史數據或假設說明得到支持的部分。

## Scope
- 只讀取，不修改。
- **每一項質疑都要有數據依據**，不可憑感覺說「太樂觀」。
- **不做投資建議。** 只呈現分析。

## Verification
輸出：
| 項目 | 歷史趨勢 | 2026 預估 | 管理層說法 | 我的評估 | 依據 |

評估只能是四種：
- ✅ **有支持**（歷史趨勢或假設說明能解釋）
- ⚠️ **需要進一步證據**（可能成立，但目前資料不足）
- ❌ **與歷史數據矛盾**
- 🔍 **無法評估**（缺少必要資料）

最後：**如果只能問管理層三個問題，你會問什麼？**
```

### 📝 應該找到的三處（講師用）

| # | 發現 | 歷史 | 2026E | 問題 |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **行銷費用佔營收** | 三年穩定在 **52.3% / 52.6% / 51.7%** | **驟降至 28.1%** | 管理層說「口碑成長降低付費獲客依賴」，但**三年來完全沒有這個趨勢**。從 51.7% 一年砍到 28.1% 沒有任何歷史支持。 |
| **2** | **CAC 與 ARPU 同時反向** | CAC 18.1→16.3→15.0（緩降）<br>ARPU 34.5→31.0→29.0（**持續下降**） | CAC **驟降至 9.2**<br>ARPU 續降至 28.0 | CAC 三年只降 17%，卻要在一年內再降 39%。同時 ARPU 一直在跌——**單客越來越不值錢，卻要花更少錢獲取更多客**。 |
| **3** | **現金可用月數 8.7** | 2025 年底現金 96,000 千元 | 2026 帳上現金**空白** | 依 2025 燒錢率，**8.7 個月後（約 2026 年 9 月）現金用罄**。假設說明寫「B 輪募資進行中」——**這份預估的前提是募資成功**。募資失敗則整份預估不成立。 |

### 三個該問的問題

1. 行銷費用要砍掉近一半，具體的執行計畫是什麼？有沒有先導測試的數據？
2. ARPU 連續三年下滑的原因是什麼？2026 預估仍在下滑，成長要從哪裡來？
3. **B 輪募資目前的進度？如果沒有完成，2026 的計畫怎麼調整？**

> [!WARNING]
> ### 第 3 點是整個練習最重要的
> **「現金可用月數 8.7」與「帳上現金空白」擺在一起，是一個訊號**：這份預估**隱含地假設募資會成功**。
>
> 這不是造假——假設說明有寫。但它必須被**明確指出來**，因為它是整份財務預估的地基。
>
> 很多分析會逐項檢查營收、毛利、費用，卻漏掉「這一切的前提是什麼」。

## 🥉 練習三：敏感度分析

```markdown
## Goal
建立敏感度分析：如果管理層的關鍵假設不成立，會怎樣？

## Context
三個關鍵假設：
- A：行銷費用佔比降至 28.1%
- B：CAC 降至 9.2
- C：B 輪募資於 2026 Q1 完成

## Scope
- 輸出 `output/敏感度分析.xlsx`，**不要修改原始檔案**。
- **明確標示哪些是你的假設**，不要與管理層的假設混在一起。

## Verification
三種情境：
| 情境 | 假設 | 2026 營業利益 | 現金可用月數 | 說明 |
| 樂觀 | 管理層假設全部成立 | | | |
| 中性 | 行銷費用佔比維持 40% | | | |
| 保守 | **維持歷史的 51.7%**，且募資延後 6 個月 | | | |

最後回答：**在保守情境下，這家公司什麼時候會現金用罄？**
```

## 🏁 練習四：產出盡職調查備忘錄

```markdown
## Goal
產出投資委員會用的 DD 備忘錄。

## Scope
- 輸出 `output/DD備忘錄_受評標的.md`
- **不做投資建議**（不寫「建議投資／不建議投資」）。
- 每個數字標註來源（工作表 + 儲存格）。
- 嚴格標示【事實】【推論】【假設】【管理層說法】。

## Verification
結構：
1. 標的概述【事實】
2. 財務表現摘要【事實】
3. **關鍵疑慮**（三處，含依據）
4. 敏感度分析結果【推論】
5. **需要管理層澄清的問題**
6. **本次分析的侷限**（缺少哪些資料、影響什麼）

第 6 段不可省略。
```
