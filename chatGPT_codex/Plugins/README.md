# Codex Plugins

Plugin 是可安裝的擴充套件，可組合 Skills、MCP server 與選用 UI。

| 需求 | 選擇 |
|---|---|
| 固定 SOP、規則、範本 | Skill |
| 連接自有 API 或資料庫 | MCP server |
| 打包多個 skills、MCP 與 UI | Plugin |
| 已有官方或策展整合 | 優先使用現成 Plugin |

安裝前檢查發布者、權限、依賴與資料去向；第一次先做唯讀測試，定期移除不再使用的 plugin。

官方入口：[OpenAI Plugins documentation](https://developers.openai.com/plugins)
