# Apps、Connectors 與外部資料

Codex 可透過 app/plugin 使用 Google Drive、Gmail、GitHub、Canva 等服務；可用項目依帳號、組織政策與安裝狀態而異。

1. 在設定中查看 Apps / Plugins。
2. 閱讀 OAuth 權限，只授與必要範圍。
3. 在 task 指出資料來源與動作。
4. 寫入、寄送或發佈前核對目標與內容。
