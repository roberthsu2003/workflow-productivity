# 01. Google Workspace 實戰

> 🔵 **方案需求**：Plus 起。需在 `Settings` → `Apps / Plugins` 安裝並授權 Google 相關 app。

用 **潮汐物流（TideFlow Logistics）** 的營運情境，練習 Drive、Gmail 與 Calendar 三種最常見的整合。

---

## 🎯 這一章要練的三件事

| 次章節 | 情境 | 核心能力 |
| :--- | :--- | :--- |
| [01. Drive 跨檔分析](./01_Drive_Analysis/README.md) | 從 Drive 讀取全年配送績效，找出真正的異常 | **唯讀分析**、區分「異常」與「離群」、處理缺漏值 |
| [02. Gmail 摘要與草稿](./02_Gmail_Automation/README.md) | 彙整客戶來信，產出回覆草稿 | **產草稿不寄出**、抗提示詞注入 |
| [03. Calendar 排程調配](./03_Calendar_Scheduling/README.md) | 偵測會議衝突並提出調整方案 | **不直接改行事曆**、衝突偵測 |

---

## 🔐 授權範圍建議

課堂練習請用測試帳號，並採最小權限：

| App | 建議範圍 | 為什麼 |
| :--- | :--- | :--- |
| Google Drive | `drive.file`（僅你明確選取的檔案） | 避免整個雲端硬碟曝光 |
| Gmail | `gmail.readonly` + `gmail.compose` | 可讀信、可建草稿，**但不能寄出** |
| Calendar | `calendar.readonly` | 只偵測衝突，不動行事曆 |

> [!WARNING]
> **`gmail.send` 在課堂上一律不要授權。** 練習的目標是產出草稿讓人複核，寄不寄出是人的決定。

## 📁 示範資料

各次章節的 `sample_files/` 內含可直接上傳到 Drive 測試的檔案：

| 檔案 | 用於 | 內容 |
| :--- | :--- | :--- |
| `潮汐物流_2026全年配送績效與客訴分析表.csv` | 01 | 48 列，含 4 區 ×12 月的量化資料 |
| `潮汐物流_2026年度跨境物流擴張策略備忘錄.md` | 01 | 質化策略文件，供跨檔交叉比對 |
| `模擬客戶郵件資料集.md` | 02 | 8 封客戶來信，含 1 封注入攻擊測試 |
| `模擬行事曆日程資料集.md` | 03 | 一週日程，含 3 組刻意設計的衝突 |

> [!IMPORTANT]
> ### 資料裡有教學用的「埋伏」
> CSV 中刻意植入三種狀況，用來訓練學員**不要照單全收模型的結論**：
> 1. **真異常**：東區 8 月準時率崩到 81.3%（有颱風備註佐證）
> 2. **假異常**：南區 11 月單量暴增 2.3 倍（雙 11 檔期，是真的不是錯誤）
> 3. **資料缺漏**：中區 6 月整列空白（系統移轉未落帳，**不可用 0 代替**）
>
> 好的分析要能區分這三者。這是本章最重要的教學點。

## 🔄 與 Claude Connectors 的操作差異

| 步驟 | Claude | Codex |
| :--- | :--- | :--- |
| 授權 | Settings → Connectors | `Settings` → `Apps / Plugins` |
| 指定資料 | 對話中選取 Connector | task 中寫明來源路徑與檔名 |
| 分析結果 | 留在對話中 | **可直接寫成本機檔案** |
| 產檔 | 下載 | 寫進 workspace，可 `git diff` |
