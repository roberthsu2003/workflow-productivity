# Google Workspace 實戰

## 練習一：Drive 跨檔分析

連線 Google Drive 後，要求 Codex 找出指定資料夾中的營運 CSV 與策略備忘錄，交叉整理 KPI、策略落差與三項行動。先列出實際讀取的檔名；找不到資料時不得猜測。

## 練習二：Gmail 草稿

```text
根據指定客戶郵件整理問題、承諾與期限，產生一封繁體中文回覆草稿。
不要寄出；未在郵件中出現的承諾請標成「待確認」。
```

## 練習三：Calendar 衝突檢查

要求讀取指定日期範圍、找出衝突並提出兩個替代時段。只有在使用者確認後才新增或修改活動。

無法連線時，可用 [`sample_files`](./sample_files/) 進行離線演練。
