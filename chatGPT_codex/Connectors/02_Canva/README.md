# 02. Canva 設計自動化

> 🔵 **方案需求**：Plus 起。需安裝並授權 Canva app（或含 Canva 的 **Creative production** plugin）。

用 **麥禾烘焙（MAIHO Bakery）** 的秋季新品上市情境，練習「文案 → 版面 → 品牌合規」的完整流程。

> [!IMPORTANT]
> ### 規範裡有三個刻意設計的「陷阱」
> 這一章的教學價值不在「做出漂亮的圖」，而在**教模型讀懂並遵守規範**：
>
> 1. **`wheat_gold #C8912F` 不可作為內文色** — 它在 cream 背景上的對比度低於 WCAG AA 4.5:1。但它是主品牌色，模型很容易直覺拿來用。
> 2. **`chestnut #8B5E3C` 有效期只到 2026-11-30** — 秋季限定，不可用於常態商品素材。
> 3. **禁用語清單含法規風險** — 「養生」「純天然」「無添加」涉及食品法規，不只是風格問題。
>
> 好的產出要能**主動指出**「你要求的做法違反了規範第 X 條」，而不是照做。

## 🔐 授權範圍建議

| App | 建議範圍 | 為什麼 |
| :--- | :--- | :--- |
| Canva | 讀取範本 + 建立新設計 | 課堂只產出草稿 |
| Canva | ❌ 不要授權「發佈／分享」 | 避免誤發到公開連結 |

> 課堂請用個人 Canva 帳號，不要用有真實品牌資產的公司帳號。

## 🔄 與 Claude Canva Connector 的差異

| 面向 | Claude | Codex |
| :--- | :--- | :--- |
| 整合方式 | Canva Connector | Canva app，或 **Creative production plugin**（含 Figma、Shutterstock、Picsart、Fal） |
| 規範來源 | 上傳到對話或 Project | **直接讀 workspace 內的 JSON 規範檔** |
| 產出落點 | Canva 中的設計 | Canva 設計 + **本機的規格檢查報告** |
| 合規檢查 | 需人工比對 | 可**程式化比對**（讀 JSON、算對比度） |

> **Codex 的優勢在這裡**：品牌規範是一個 JSON 檔，Codex 可以**逐條讀取並實際計算**對比度，而不是憑印象判斷。這一章會示範怎麼做。
