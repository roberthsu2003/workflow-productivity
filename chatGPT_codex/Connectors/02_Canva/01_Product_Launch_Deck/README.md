# 02-1. 新品上市簡報與海報

> 🔵 **方案需求**：Plus 起，需授權 Canva app。

**情境**：麥禾烘焙的秋季新品「秋栗蒙布朗」10/5 上市。行銷部給了你一份企劃書，你要在一週內產出 9 件素材，橫跨門市、社群、官網與電子報。

## 🥇 練習一：規格萃取（先不要做設計）

> **這一步不能跳過。** 直接叫 Codex「做海報」，它會憑印象選色選字，然後你要花更多時間抓錯。

```markdown
## Goal
從兩份規範文件中，萃取出製作秋季新品素材時**必須遵守的所有硬性規定**，整理成一份可逐項核對的檢查表。

## Context
- 企劃書：`麥禾烘焙_2026秋季新品行銷企劃與視覺規格書.md`
- 品牌規範：`麥禾烘焙_品牌視覺規範與色彩配置表.json`

## Scope
- **只讀取，這一輪不要產生任何設計。**
- 不要修改這兩份文件。

## Verification
輸出一張檢查表，分五類：
1. **色彩**（哪些可用、哪些禁用、哪些有使用條件）
2. **字體**（字級下限、層級上限、中英混排規則）
3. **文案**（必須包含的資訊、禁用語）
4. **攝影**（風格、禁止事項）
5. **無障礙**（對比度要求）

每一條都要標註**來源**（哪份文件的哪一節）。

最後另列一段：**「有使用條件」的規定**——哪些色彩／元素不是無條件可用的？
```

### 📝 解答對照（講師用）

最後那段應該抓到至少三條：

| 規定 | 條件 |
| :--- | :--- |
| `chestnut #8B5E3C` | 僅限 2026 秋季檔期，**有效期至 2026-11-30**，不可用於常態商品 |
| `wheat_gold #C8912F` | **不可作為內文色**（對比度不足），只能用於 logo、≥24px 大標、按鈕底色 |
| `#FFFFFF` 純白 | 只能用於 logo 留白區與 CTA 文字，**不可作為大面積背景** |

> **教學重點**：這三條都不是「禁止」，而是「有條件允許」。模型最容易在這裡出錯——看到「主品牌色」就拿來當內文色。

## 🥈 練習二：產出主視覺海報

```markdown
## Goal
產出 A-01 主視覺海報（A2, 420×594mm），供門市張貼。

## Context
- 商品：秋栗蒙布朗，NT$145，10/05–11/30 限期供應，每店每日限量 75 個
- 食材：嘉義中埔栗子、北海道鮮奶油、自製塔皮
- 依練習一產出的檢查表製作。

## Scope
- 嚴格遵守品牌規範，**不可自行發揮**。
- 必須包含：食材產地、每日限量數字、販售期間、過敏原標示。
- **不可使用禁用語清單中的任何用語。**
- 不要發佈或分享設計，只建立草稿。

## Verification
產出後，逐條回報你如何滿足檢查表中的每一項：
| 檢查項 | 你的做法 | 符合？ |

**若有任何一項無法滿足，明說並解釋原因，不要假裝符合。**
```

### 品質檢查

| 檢查 | 常見錯誤 |
| :--- | :--- |
| 內文用了 `wheat_gold` 嗎？ | ⚠️ 最常見的違規 |
| 背景用了純白嗎？ | 應該用 cream `#F7F1E6` |
| 有標過敏原嗎？ | 常被漏掉，但這是法規要求 |
| 字體層級超過 3 級嗎？ | 資訊多的時候容易失控 |
| 有沒有出現「純天然」「養生」？ | 法規風險 |

## 🥉 練習三：多尺寸一致性

素材清單有 9 件，橫跨 A2 海報到 60×20mm 貼條。**同一套視覺在不同尺寸下要保持識別度。**

```markdown
## Goal
依 A-01 主視覺，衍生出其餘 8 件素材。

## Context
素材清單（見企劃書第三節）：
- A-02 桌卡 A5 直式
- A-03 價目貼條 60×20mm
- B-01 IG 主圖 1080×1080
- B-02 IG 限動 1080×1920
- B-03 IG 輪播 4 張 1080×1080（說明食材來源）
- C-01 官網 banner 1920×640
- C-02 行動版 banner 750×900
- D-01 電子報主圖 600×400

## Scope
- 保持與 A-01 的視覺一致性。
- **依尺寸調整資訊密度**——A-03 貼條只有 60×20mm，塞不下全部資訊。
- 品牌規範的字級下限（內文 14px）在所有尺寸都適用。
- 不要發佈或分享。

## Verification
產出一張對照表：
| 素材 | 保留了哪些資訊 | 捨棄了哪些 | 為什麼 |

**A-03 貼條特別說明**：在 60×20mm 內，你選擇保留什麼？過敏原標示放不下時怎麼處理？
```

> [!IMPORTANT]
> **A-03 是這個練習的關鍵。** 60×20mm 塞不下過敏原標示，但那是法規要求。
>
> **正確的處理**不是硬塞或省略，而是**指出這個矛盾並提出方案**：貼條只放品名與價格，過敏原標示由旁邊的桌卡（A-02）或既有的商品標示承擔。
>
> 會直接省略過敏原、或把字縮到 4pt 硬塞的模型，就是需要被糾正的地方。

## 🏁 練習四：交付清單與外包說明

```markdown
## Goal
產出一份給設計外包窗口的交付說明。

## Scope
- 寫入 `deliverables/2026Q3_秋季新品素材交付說明.md`。
- 不要修改品牌規範或企劃書。

## Verification
說明應包含：
1. 素材清單與交付期限（見企劃書）
2. **必須遵守的品牌規範摘要**（不要叫外包自己去讀 JSON）
3. 特別提醒事項（`wheat_gold` 不可作內文、`chestnut` 有效期）
4. 驗收標準（外包交件時你會檢查什麼）
5. **常見錯誤清單**——根據你剛才製作時遇到的問題整理
```
