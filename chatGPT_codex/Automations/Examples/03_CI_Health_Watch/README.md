# 排程範例 03：CI 健康度與 PR 審查

> 🔵 **方案需求**：Plus 起。**事件觸發僅在 ChatGPT 網頁版與行動版可建立**，桌面版與 CLI 不支援。Business / Enterprise 需管理員開啟 **Allow event-triggered scheduled tasks**。

**類型**：事件觸發（GitHub）＋ 時間排程
**授權**：唯讀 + 留言

---

## 🔀 兩個排程，不要混在一起

| 排程 | 觸發 | 做什麼 | 通知誰 |
| :--- | :--- | :--- | :--- |
| **A. PR 自動審查** | PR opened（事件） | 依 `AGENTS.md` 的 code review rules 逐條檢查 | PR 作者 |
| **B. CI 健康度巡檢** | 每日 09:00（時間） | 統計失敗率，區分真失敗與 flaky | 維護者 |

分開的理由：**觸發條件與通知對象都不同**。

---

## ⚙️ 排程 A：PR 自動審查

```text
當 tideflow-portal 有新的 PR 開啟時，依 AGENTS.md 的 code review rules 審查。

## 檢查
逐條檢查 B-1 ~ B-8、W-1 ~ W-6、S-1 ~ S-3，
以及特別區域規則（src/legacy/、services/payments/、migrations/）。

## 意見格式
每條意見包含五要素：
1. 規則編號　2. 檔案與行號　3. 問題描述（一句話）
4. **具體的修法建議**（不可寫「請改善」）　5. 嚴重度

## 🚫 絕對紅線
- **不要 approve、不要 merge、不要關閉 PR。**
- **不要修改 PR 中的任何程式碼。**
- 不要 push 到任何分支。

## 通知
- 未發現問題 → **不要留言、不要通知。**
- 發現 🔴 阻擋級 → 留下審查意見並通知我。
- 只有 🟡 / 🟢 → 留下意見，不通知我。
```

> [!WARNING]
> **「未發現問題就不要留言」很重要。** 一個每次都留「LGTM 👍」的機器人，會讓真正的審查意見被淹沒。

規則內容見 [PR 自動審查章節](../../../Connectors/03_GitHub/02_PR_Review/README.md)。

## ⚙️ 排程 B：CI 健康度巡檢

```text
每天上午 9:00（Asia/Taipei）檢視 tideflow-portal 過去 24 小時的 CI 執行結果。

## 統計
- 總執行次數、成功／失敗數、失敗率
- 依 job 分類的失敗分布
- **區分兩種失敗**（見下方判準）

## 失敗分類判準
- **可能是 flaky**：逾時、runner 中斷、網路錯誤、
  **同一個 commit 重跑後通過**
- **真失敗**：測試斷言失敗、編譯錯誤、型別錯誤、
  **同一個 commit 重跑仍失敗**

判斷不出來的一律歸入「需人工確認」，**不要猜**。

## 限制
- **只讀取，不要重跑 CI、不要修改 workflow 設定。**
- 不要在 PR 或 Issue 留言。
- 不要修改任何程式碼。

## 通知
- 失敗率 < 10% 且無真失敗 → **不通知。**
- 出現真失敗、或失敗率 ≥ 10% → 通知，附：
  失敗的 job、commit、錯誤摘要、你的分類與依據。
```

---

## 🎯 教學重點：flaky vs. 真失敗

> [!IMPORTANT]
> **這是 CI 監控最有價值、也最容易做錯的判斷。**
>
> | 誤判 | 後果 |
> | :--- | :--- |
> | 真失敗 → 判成 flaky | 壞掉的程式碼被放行 |
> | flaky → 判成真失敗 | 每天被假警報打擾，最後乾脆關掉監控 |
>
> **最可靠的判準是「同一個 commit 重跑的結果」**——這是事實，不是推測。
>
> 所以 prompt 刻意要求：判斷不出來的歸入「需人工確認」。
> **允許模型說「我不知道」，比逼它給答案安全得多。**

---

## 🚫 為什麼不讓它自動重跑 CI

| 情況 | 自動重跑合理嗎 |
| :--- | :---: |
| 明確的 runner 中斷 | ⚠️ 勉強可以，但要限制次數 |
| 逾時 | ⚠️ 可能是真的變慢了，重跑會掩蓋問題 |
| 測試斷言失敗 | ❌ 只是浪費 CI 額度 |
| 判斷不出來 | ❌ |

> **自動重跑會掩蓋真正的問題。** 一個 flaky 測試被自動重跑一百次，就沒有人會去修它。
>
> 課堂建議：**只監控、只通知，不自動重跑。**
