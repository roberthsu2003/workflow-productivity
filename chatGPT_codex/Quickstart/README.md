# Codex 快速開始

1. 在 Codex 加入或選取 saved project（本機資料夾或 Git repository）。
2. 建立 task，說明結果、可修改範圍與驗收方式。
3. 讓 Codex 檢查檔案、修改內容並執行驗證。
4. 完成後檢查摘要、測試結果與 diff。

```text
請先閱讀這個專案的 README 與 AGENTS.md，整理用途、啟動方式和目錄結構。
不要修改檔案。請指出資訊缺口，並提出三個最值得補強的文件項目。
```

```text
請替 README 新增「快速開始」段落。先確認實際可用的安裝與啟動命令，
只修改 README，完成後檢查連結與命令是否一致，並摘要變更。
```

CLI 與桌面版共用核心代理概念，但 UI、登入和部分功能不同。請以 [官方 Codex CLI 文件](https://learn.chatgpt.com/docs/codex-cli) 為準。
