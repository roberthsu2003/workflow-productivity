# 實戰範例 01：便利超商門市人力排班素材檢核表

本檢核表供教師或學員在進行「超商門市排班人機協商工作流」前，自我核對排班素材是否備齊。

---

## 檢核項目清單

### 1. 門市基本營運資訊
- [x] 門市名稱與營運型態（24 小時全年無休、捷運站前門市）
- [x] 排班週期（以週為單位，範例設定為 7 天：10/12～10/18）
- [x] 班別定義明確：
  - 早班 (D)：07:00 – 15:00（通勤與早餐咖啡尖峰）
  - 晚班 (E)：15:00 – 23:00（下班與包裹取貨高峰）
  - 大夜班 (N)：23:00 – 07:00（冷藏物流進貨、清洗、盤點）

### 2. 員工人力名冊與個別限制
- [x] 員工身分區分（正職幹部、專職大夜、計時工讀生、假日兼職）
- [x] 每位員工的每週工時上限（正職 40H、工讀生 24H、假日兼職 16H）
- [x] 員工排班特殊限制與預排請假（如：專職大夜週五特休、大三工讀生平日補習不可排、假日兼職僅限週末）
- [x] 大夜值班資格註記（僅正職幹部或經認證人員可獨立留守大夜）

### 3. 法規與營運硬性規則
- [x] **輪班間隔（勞基法）**：更換班次間隔至少 11 小時（嚴禁晚班接早班）
- [x] **一例一休（勞基法）**：每 7 天至少 1 天例假與 1 天休息日，連續出勤不超過 6 天
- [x] **24 小時大夜守護**：每天大夜班不可開天窗，專職大夜休假時須由正職幹部替補
- [x] **通勤與下班尖峰雙人制**：平日早班、每日晚班至少 2 人當值

## 課堂練習引導提問

教師可於課堂引導學生思考：
1. **為什麼勞基法規定輪班要隔 11 小時？**（若超商讓員工上晚班到 23:00，隔天 07:00 上早班，扣除通勤與洗漱，員工睡眠往往不足 5 小時，極易因精神不濟發生職災或收銀短溢款）。
2. **為什麼不直接手刻 RTCCF 提示詞？**（真實職場資料繁瑣，先給 AI 偽素材，再用「白話發想 Prompt」讓 AI 自動提煉結構，速度快 10 倍，且不易遺漏法規細節）。
3. **Canvas 畫布在排班微調時的優勢是什麼？**（排班常有臨時突發請假，直接在畫布上「圈選反白換人」，不必整張重排重印，效率極高）。
