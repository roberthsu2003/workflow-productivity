申報檔產生工具（營業稅進銷項檔、各類所得申報檔、補充保費明細申報檔）
================================================================
本資料夾的工具會讀取「無紙化流程_素材總表.xlsx」，依官方格式產生可匯入申報系統的檔案。
請在只有您控管的電腦執行；薪資資料已加密時，執行時會要求輸入通關密語。

〈事前設定（一次）〉
 1. 打開素材總表的「申報設定」工作表，把範例值改成公司實際資料：統一編號、營業人稅籍編號（9碼）、扣繳單位稅籍編號、
    稽徵機關代號（3碼，例 A06）、申報單位名稱與地址、扣繳義務人、聯絡人、電話、電子郵件、房屋稅籍編號、健保投保單位代號。
    範例值（全為 0 或含「範例」）沒改的話，工具會拒絕產檔。
 2. 「薪資發放月份」：當月發薪填 0，次月發薪填 1。所得以給付日認列年度，次月發薪時 12 月薪資會歸入次年。
 3. 在「流程1_請假申請」右側員工名單補上每位員工的證號別與戶籍地址（所得申報檔必填）。
 4. 安裝套件（一次）：pip install openpyxl cryptography

〈一、營業稅進銷項檔（每期申報）〉
 資料來源：「流程2_報銷申請」（進項）與「營業稅_銷項登記」（銷項）。
 進項須填：憑證種類、憑證日期、賣方統一編號、發票字軌號碼（例 AB12345678）、扣抵類別、課稅別，且「買受人為本公司統編」須為「是」。
 執行（Windows，可雙擊 run_vat.bat，或在命令列）：
     python vat_export.py --xlsx 無紙化流程_素材總表.xlsx --from 2026-11-01 --to 2026-12-31 --out 輸出資料夾
 產出：
     統一編號.TXT                    進銷項資料檔（每筆81字元，格式依營業稅電子資料申報繳稅作業要點附件五）
     營業稅進銷項明細_YYYYMM-YYYYMM.xlsx   進項明細表、銷項明細表、未入檔與提醒、摘要
 說明：不得扣抵、收據、免用發票、買受人統編不符的憑證不會入檔，會列在「未入檔與提醒」；匯入後請把已申報的列標成「已申報」。
 匯入前請先用財政部「營業稅網路申報程式」前端審核。

〈二、各類所得與補充保費申報檔（每年一月）〉
 資料來源：data 資料夾內該年度各月「薪資_YYYYMM.xlsx」（可為加密的 .enc）。
 執行（可雙擊 run_tax.bat，或在命令列）：
     python tax_export.py --data data --year 2026 --out 輸出資料夾
 產出：
     統編.民國年.U8                 各類所得扣繳暨免扣繳憑單申報檔（UTF-8、分隔符號格式；含所得資料、各類所得申報書資料、申報單位基本資料）
     DPR統編申報日期序號.csv        補充保險費明細申報檔（獎金類別62／兼職類別63，Big5 編碼，健保署CSV格式）
     申報核對報告.txt               筆數、金額與需確認事項（身分證字號、地址、補充保費金額差異等）
 匯入前請先用國稅局申報程式檢核所得檔、用健保署「媒體檢核程式」檢核補充保費檔。
 申報期限：所得資料原則上次年1月31日前（遇連續3日以上國定假日順延）；補充保費給付日次月底前繳納，年度明細依健保署規定申報。

〈注意事項〉
 - 本工具只涵蓋員工薪資所得（格式50）與其補充保費；顧問費、執行業務、租金等其他所得需另行申報。
 - 免稅伙食費上限與免稅加班費為簡化判斷，請會計確認；憑單填發方式預設為「免填發」，若仍要發憑單請在申報設定改成 2 或 3。
 - 官方格式依作業要點整理（營業稅進銷項檔：106/2/1生效之附件五；所得資料：112/12/11 修正之電子申報作業要點；補充保費：健保署114/7/24 更新之格式），
   若主管機關日後改版，請以官方最新格式為準。本工具已用範例資料驗證欄位數與長度，尚未經官方系統實際上傳驗證，請務必先檢核再申報。
 - 身分證字號、地址等個資請妥善保管，產出的申報檔上傳後請加密保存或依規定銷毀。
