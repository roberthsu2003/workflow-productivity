## 🛠️ 實作步驟 1-A：自然語言發想 ➔ 建立第 1 個工作流（RTCCF_v1.md）

請開啟您偏好的 **AI Agent 平台**（如 Claude / ChatGPT / Gemini 等支援多模態圖像理解之對話視窗），先上傳抽牌照片，發送以下指令：

```text
我平時有每日抽一張塔羅牌自我覺察的習慣。我不希望死背牌義或聽信宿命論恐嚇，我想要一套能長期陪伴我成長、具備心理學洞察的身心靈解讀系統。

【任務：建立每日塔羅多模態解讀與視覺指引之工作流規格書】
請先不要產出今日的占卜報告，也不要進行個人化算命。我現在要建立的是一套「可供未來每日抽牌重複調用」的標準工作流程規格。
請依據所附素材與工作流指引，幫我產出【RTCCF 工作流規格書】：

1. Role（角色）：擁有深厚榮格心理學（Carl Jung）與現代象徵學背景的資深身心靈占卜導師兼現代生活視覺設計師。
2. Task（任務）：定義輸入任一張牌卡照片與當日心境時，標準的解碼作業鏈路（多模態視覺識別 ➔ 符號色彩解碼 ➔ 心理投射診斷 ➔ 減法生活行動 ➔ 現代卡片排版）。
3. Context（背景）：定義適用的資料結構（多模態牌卡圖像或牌名、當日一句話真實心情脈絡），適用於未來每天自我探索。
4. Constraints（限制條件）：鎖定嚴格諮商底線（拒絕宿命論、禁止恐嚇或絕對化預言、聚焦內在覺察與落地行動、排版卡片化）。
5. Format（輸出格式）：規範未來解牌後應產出的結構化卡片段落。

請將這套通用的工作流程規則，【務必儲存為獨立的 Markdown 檔案：RTCCF_v1.md】交付給我！
只要產出這份 .md 規格書即可，不需要輸出特定解牌結果。後續關卡完成後，我們都會直接更新這份 RTCCF_v1.md，讓工作流愈變愈長！
```

## 🔍 人工檢核（人機協作點 1）：檢查 `RTCCF_v1.md`

AI 產出並儲存 `RTCCF_v1.md` 後，請開啟該檔案檢閱：
- [ ] **是否為純工作流程規格**？（未寫死特定牌卡名稱如愚人或死神，未來 78 張牌皆通用）
- [ ] **多模態影像識別要求是否明確**？（包含牌名、正位/逆位、核心色彩與人物神態辨識）
- [ ] **反宿命論底線是否確立**？（嚴禁「你今天會大難臨頭」等負面恐嚇言語）
- [ ] 檢核無誤後，保存這份 **`RTCCF_v1.md`** 作為我們指揮 AI 工作的基石。

## 🚀 實作步驟 1-B：叫 AI 開始依據這個工作流工作！

工作流規格確認後，請在同一個對話中發送執行指令，**真正叫 AI 依據工作流開始幹活**：

```text
這份 RTCCF_v1.md 工作流規格書我確認沒問題！

現在請你嚴格依據剛剛建立的【RTCCF_v1.md】工作流規格：
1. 辨識我所上傳的牌卡照片（或指定牌名：權杖七 逆位）。
2. 解碼牌卡核心視覺要素：
   - 牌名、所屬組別（小阿爾克那／權杖火元素）與正逆位狀態。
   - 核心色彩寓意（如背景黃色象徵意識與理智、紅色羽毛象徵意志與熱情）。
   - 人物姿態與環境符號（手持權杖站在懸崖邊抵抗下方六根權杖，逆位代表防禦過度或力不從心）。
3. 輸出第一階段完整的【牌卡視覺多模態解碼清冊】讓我驗收！
```

## 🔍 人工驗收（人機協作點 2）：核對多模態辨識成果

- [ ] **牌卡名稱與正逆位精確**：是否正確識別出牌面上下方向？（正位與逆位不可顛倒）
- [ ] **視覺符號捕捉細膩**：是否觀察到畫面中的細節意象（懸崖、鞋子、權杖方向）？
- [ ] **非死記牌義**：解釋是否生動自然、回歸視覺符號本質，而非照抄教科書死板條目？
