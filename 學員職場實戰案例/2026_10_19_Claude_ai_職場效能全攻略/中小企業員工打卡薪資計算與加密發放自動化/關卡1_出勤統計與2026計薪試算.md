## 🛠️ 實作步驟 1-A：口語化發想 ➔ 建立第 1 個工作流規格書（RTCCF_v1.md）

> 💡 **核心教學心法：為什麼都要儲存為 `.md` 檔案？**  
> 不論是工作流規格書 `RTCCF_v1.md`，還是後續產出的 `員工薪資試算月結表.md`，**一律強制要求 AI 存為 `.md` 檔案，目的就是為了「方便人機協作」**！  
> * Markdown 是通用純文字結構，AI 讀寫最精準、極度省 Token，且不會像 Excel 破壞格式或被公式鎖死。  
> * 人類隨時能用編輯器開啟檢視、修改確認；確認後，AI 下一步又能無縫讀取該檔案繼續擴充（切傳票、產薪資單），達成最高效率的人機協作！

請開啟您偏好的 **AI Agent 平台**（如 Claude Projects / ChatGPT / Gemini 等）：
1. 確保已將 `固定資料表/` 內的 3 個 Markdown 檔放入專案知識庫（Project Knowledge）。
2. 在對話視窗上傳 **`員工資料範本_202610_上課工作流專用.xlsx`**。
3. 發送以下**條例式、口語化**的自然語言發想指令：

```text
你好，我是公司的人資主管。我們公司每個月都要算員工薪水，我現在想請你幫我設計一套標準的發薪工作流程規格。

【先不要算特定月份的薪水，我要的是通用規格書】：
請先不要去計算任何特定月份的數字，也不要輸出報表。我要的是一份可以讓未來每個月（10月、11月、12月...）都能重複調用的標準工作流規格書。

請依據我上傳的 Excel 結構（員工名冊、出勤紀錄、本月人工項目）與專案知識庫裡的參數，幫我建立一份【RTCCF 規格書】：
1. 你的角色（Role）：請扮演精通台灣勞基法與 2026 最新費率的薪資核算專家。
2. 你的任務（Task）：定義一套標準的算薪作業鏈路（從打卡工時統計 ➔ 請假遲到折算 ➔ 加班費階梯計算 ➔ 勞健保代扣 ➔ 算出實發薪資）。
3. 你的目標（Context）：這套規格書未來每個月被調用執行時，最終都要能為公司產出一份結構完整的【員工薪資試算月結表.md】純文字檔案！
4. 規則約束（Constraints）：請鎖定嚴格法規底線（平日加班前 2 小時 1.34、後 2 小時 1.67 階梯倍率；2026 勞保 12.5% 自付 20%、健保 5.17% 自付 30% 且眷屬上限 3 口；伙食費 3,000 元/月納入時薪計算基礎）。
5. 交付格式（Format）：請把這整套通用規格，【務必儲存為獨立的 Markdown 檔案：RTCCF_v1.md】交付給我！

只要產出這份 RTCCF_v1.md 規格書即可，不需要輸出其他試算內容。後續關卡完成後，我們都會直接更新這份檔案，讓工作流愈變愈長！
```

## 🚀 實作步驟 1-B：叫 AI 開始依據工作流執行 10 月份算薪！

工作流規格確認後，請在同一個對話中，用**口語化、條例式**的指令正式叫 AI 幹活，**產出第 1 個業務成果 `.md` 檔**：

```text
這份 RTCCF_v1.md 規格書我剛才看過了，寫得很完整！

現在請你正式當我的算薪助理，嚴格依照【RTCCF_v1.md】這套標準流程幹活：
1. 請讀取我剛才上傳的「員工資料範本_202610_上課工作流專用.xlsx」（員工名冊、出勤紀錄、本月人工項目），並對照知識庫裡的「01_流程1_參數.md」。

3. 成果交付要求：請依照規格書約定，把第一階段算出來的成果，正式儲存為獨立的 Markdown 檔案：【員工薪資試算月結表.md】交付給我驗收！
```

## 🔍 人工驗收（人機協作點 2）：核對算薪成果（員工薪資試算月結表.md）
