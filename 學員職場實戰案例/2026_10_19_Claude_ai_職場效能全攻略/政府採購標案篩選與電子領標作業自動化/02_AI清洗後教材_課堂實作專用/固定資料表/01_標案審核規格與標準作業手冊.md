## 一、標案九大關卡審核合格標準表

| 審核關卡 | 合格標準 | 負責人員 | 未通過之處理方式 |
| :--- | :--- | :---: | :--- |
| **1. 查詢需求確認** | 關鍵字及限制條件明確，需求版本有效 | 技術部窗口 | 補充或修正需求參數 |
| **2. 查詢完整性** | 所有有效關鍵字均已完整查詢，無結果亦記錄 | 管理部承辦 | 立即補查缺漏關鍵字 |
| **3. 標案適用性** | 屬勞務類、尚在等標期內，符合部門查詢條件 | 管理部承辦 | 排除或加註特殊例外理由 |
| **4. 重複與版本確認** | 同一機關＋案號＋招標次別不重複列案；更正公告保留版本 | 管理部承辦 | 合併舊案或更新版本紀錄 |
| **5. 技術部決策審查** | 分類勾選明確（爭取/參考/不採用）、有確認人，爭取案指派專屬承辦人 | 技術部主管 | 退回技術部列為「待確認」 |
| **6. 領標授權審核** | 具備完整領標指示，電子領標費用符合公司財務授權額度 | 授權主管 | 補齊內部授權單據 |
| **7. 領標結果檢驗** | 機關名稱與標案代號正確，電子憑據（.tkn）及招標文件齊全可正常開啟 | 管理部複核 | 重新下載或排除憑據異常 |
| **8. 編號與歸檔查核** | 配號號段正確（爭取3000系/參考6000系）、編號唯一、五合一資料夾結構無誤 | 管理部複核 | 修正目錄結構後交付技術部 |
| **9. 交付與異動追蹤** | 資料夾連結正常可讀，技術部完成接收；後續更正公告即時更新並通知 | 管理部/技術部 | 補正檔案連結並重新發送通知 |

## 二、標案各階段最終產品交付清單

| 最終產品名稱 | 主要交付內容 | 建議載體形式 | 交付時點 |
| :--- | :--- | :---: | :--- |
| **關鍵字需求表** | 各部門關鍵字清單、同義詞、排除詞、地區/預算限制及有效版本 | Markdown / Excel | 首次建立及需求變更時 |
| **標案篩選清單** | 標案基本資料、命中關鍵字、截止投標時間、技術部勾選欄 | Markdown / 表格 | 每週二、五定期產出 |
| **標案管理總表** | 技術部決策、領標狀態、四碼計畫編號、資料夾連結及最新異動期限 | Excel / 線上共用表 | 隨各階段作業動態更新 |
| **爭取標案資料包** | 3001～6000 編號、招標公告、領標憑據、原始招標文件及內部評估表 | 五合一標準目錄 | 領標複核完成後立即交付 |
| **參考標案資料包** | 6001～9999 編號、招標公告、領標憑據及招標規範文件 | 五合一標準目錄 | 領標複核完成後封存歸檔 |
| **領標完成通知單** | 標案編號、標案名稱、截止時間、資料夾連結及投標注意事項 | 即時通訊 / Email | 歸檔完成時即刻發出 |
| **標案異動追蹤表** | 更正公告、等標期延長、規格釋疑補件及澄清文件記錄 | 總表附頁 / 異動清單 | 發現機關發布更正時隨時記錄 |
