# 政府採購標案篩選與電子領標管理自動化技能

本技能提供標準化、符合台灣《政府採購法》招標投標作業法規之標案篩選、評估配號、電子領標憑據檢核與五合一標準目錄自動歸檔閉環工作流。

## 🎯 核心能力

1. **標案查詢需求過濾與排重**：
   - 依關鍵字、同義詞、排除詞、地區與預算條件篩選採購網等標期內勞務標案。
   - 依「機關代碼＋案號＋次別」進行精準排重。
   - 距截止投標不足 3 個工作天自動觸發【🚨 急件】警示。
2. **技術決策矩陣與領標指示授權**：
   - 支援四分法決策（爭取／參考／待確認／不採用），爭取案強制指派負責工程師與領標指示，不採用案記錄原因結案。
3. **電子領標防重查核與憑據合格性審查**：
   - 查核既有紀錄防範重複刷卡付費領標。
   - 強制核驗 `.tkn` 電子憑據真實性與招標文件解壓縮可讀性，缺憑據直接阻斷。
4. **單一編號台帳配號與五合一目錄歸檔**：
   - 單一編號台帳嚴格配號（爭取 `3001～6000`、參考 `6001～9999`），號碼終身累加不重置、作廢不回收。
   - 自動在個案目錄下建立標準五大子資料夾（`01_公告`、`02_領標憑據及付款`、`03_原始招標文件`、`04_更正及補充`、`05_內部評估`）。
5. **更正異動版本管理與交付通知**：
   - 追蹤更正公告與截標展延，保留原始文件版本並動態更新「標案管理總表」與發布交付通知。

## 🛠️ 標準調用指令（RTCCF 規格）

當使用者提供標案資訊、關鍵字或領標檔案時，請嚴格依照 [**`6-2_AI產出之RTCCF審查與結構化提示詞.md`**](../../6-2_AI產出之RTCCF審查與結構化提示詞.md) 中規範之終極 RTCCF 規則執行。

可直接調用 Python 腳本建立標準專案五合一目錄：
```bash
python scripts/init_tender_folder.py --id 3043 --category target --name "水利署115年度水資源智慧監控委託技術服務案"
```
