> 🎯 **本關核心邏輯**：  
> 1. 先用白話自然語言請 AI 串聯前四關產出，維護「標案管理總表」、發布「領標完成交付通知」，並處理等標期內的更正公告與截標展延。  
> 2. 人工驗收總表閉環與異動版本無誤後 ➔ **最終整合五大模組，收斂為【終極生產級 `RTCCF_v1.md`】！**  
> 3. （選修進階）將這套閉環工作流封裝為可重複調用之 **AI Agent Skill 套件**。

## 🛠️ 實作步驟 5-A：自然語言執行總表串聯、交付通知與更正追蹤

在同一個 AI Agent 對話視窗中，模擬專案交付與招標機關發布更正公告的情境，發送以下指令：

```text
管理部已完成案件 A（3043，水利署水資源智慧監控案）與案件 B（6089，道路巡查影像案）之配號與五合一歸檔。現在要辦理總表串聯、交付通知與異動追蹤：

【情境與後續異動資料】：
1. 專案交付作業：
   - 案件 A 負責工程師為「張簡工程師」，需立即發出領標完成交付通知。
   - 建立並更新全公司之【標案管理總表】。

2. 等標期更正公告異動：
   - 經濟部水利署於 2026-11-03 上午對案件 A 發布更正公告：
     • 修正需求說明書第 12 頁之通訊協定規範。
     • 截止投標時間由原本 2026-11-04 17:00 展延至 2026-11-08 17:00！
     • 下載取得更正附件：`WRA115001_v2_clarification.pdf`

【任務：總表維護、交付通知與異動追蹤閉環】
請執行以下三項作業：
1. 【版本另存防呆與歸檔】：依內控規定將更正文件歸戶至 `3043/04_更正及補充/`，說明為什麼嚴禁直接覆蓋 `03_原始招標文件`。
2. 【標案管理總表動態更新】：產出完整的【標案管理總表】，串聯：計畫編號、分類、案名、機關、預算、承辦人、領標狀態、最新截止投標時間、剩餘工作天（展延後剩餘 5 天，自動解除急件警示）、雲端資料夾連結與異動紀錄。
3. 【領標完成與異動交付通知公版】：產出正式的通知信（文字/郵件版），包含編號、標案名稱、最新截標時限、雲端資料夾連結、本次更正重點與備標注意事項。
```

## 🔍 人工驗收（人機協作點 1）：核對總表與通知成果

AI 輸出後，請核對以下細節：
- [ ] **版本可追溯性**：更正檔案是否妥善收納於 `04_更正及補充`，原始招標文件未遭任何篡改？
- [ ] **總表時限精準更新**：截止時間是否更新為 `2026-11-08 17:00`，急件警報狀態依最新天數自動刷新？
- [ ] **通知信專業完整**：通知內容是否明確提醒張簡工程師「感測器通訊規範已更正，請以 04 目錄最新澄清表為準」？

驗收無誤後，請指示 AI 將五道關卡的所有規則（篩選清洗、評估授權、領標查核、台帳歸檔、總表異動）進行全面整合收斂，產出**終極完稿版工作流**：

```text
異動追蹤機制、交付通知與標案管理總表核對完全正確！

現在請執行【終極完稿整合】：
請將前面五個關卡所驗收通過的所有業務規則、法規限制與產出格式：
1. 模組 1：標案查詢需求與等標期排重清洗（含不足3日急件標籤）
2. 模組 2：技術部四分法評估決策矩陣與承辦人指派授權
3. 模組 3：電子領標防重付款查核與 .tkn 憑據真實性阻斷防呆

5. 模組 5：更正公告版本另存、標案管理總表動態更新與交付通知閉環

全數整合收斂為一份最完整、生產級的【RTCCF_v1.md】規格書！
請直接將這份終極工作流檔案儲存交付給我！

```

## ⭐ 選修進階（Optional）：將 RTCCF_v1 工作流封裝為「AI Agent Skill」

當這套工作流打磨成熟後，建議依據官方 Agent Skill 規範，將其封裝為獨立的技能資料夾，方便團隊跨電腦、跨專案一鍵掛載調用：

### 1. 標準 Skill 目錄結構
```text
skills/government-tender-automation/
├── SKILL.md            # 必要：包含 YAML frontmatter (name, description) 的完整作業規格
└── scripts/            # 選用：自動化建置資料夾與比對之 Python 輔助腳本
    └── init_tender_folder.py
```

### 2. 封裝指令（發送給 AI）
```text
請依據官方 Agent Skill 規範，將我們剛剛完稿的終極 RTCCF_v1.md 工作流：
1. 封裝為標準技能檔案：skills/government-tender-automation/SKILL.md（必須包含合法之 YAML frontmatter：name 與 description）。
2. 在 scripts/ 目錄下產出一個實用的 Python 輔助腳本 init_tender_folder.py，能傳入「計畫編號」與「標案名稱」，自動在指定路徑建立符合規範的五合一標準子目錄結構！
```
