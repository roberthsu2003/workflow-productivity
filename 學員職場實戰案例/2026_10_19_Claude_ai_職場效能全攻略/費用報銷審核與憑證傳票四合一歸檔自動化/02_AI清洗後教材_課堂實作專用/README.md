## 🎯 使用指南

1. **建立專案時（一次性）**：將 `固定資料表/` 內的 3 個 Markdown 檔案上傳至您的 **Claude Project 知識庫（Project Knowledge）** 作為固定知識。
2. **上課建立工作流時（關卡 1~4）**：上傳 `使用者提供/費用報銷申請明細_202610_上課工作流專用.xlsx`，依步驟發想並生成通用規格書 `RTCCF_v1.md`，完成請款萃取、傳票關聯、目錄書籤與四合一歸檔。
3. **驗證工作流通用性時（即調即用）**：上傳 `使用者提供/費用報銷申請明細_202611_偽資料.xlsx`，直接調用剛才生成的 `RTCCF_v1.md`，立即驗證 AI 是否能不改任何規則、全自動完成全新月份的歸檔作業！
