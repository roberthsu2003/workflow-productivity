# 費用報銷與憑證傳票四合一歸檔自動化技能

本技能提供標準化、符合商業會計法電子憑證保存規範的費用報銷四合一自動封裝流程。

## 🎯 核心能力

1. **請款數據與簽核軌跡萃取**：自動從 Excel 解析請款資訊與 @trail 主管審批歷程，動態繪製不可篡改之軌跡頁。
2. **會計科目與傳票勾稽**：借貸科目精準對齊，金額 100% 勾稽比對，阻斷異常或缺漏發票案件。
3. **動態目錄與頁次自適應**：依據發票附件頁數動態計算總頁數，繪製封面目錄（Table of Contents）。
4. **PDF 階層書籤注入**：建立包含目錄、傳票、請款單、簽核歷程與附件的完整書籤樹，支援繁體中文 Unicode。
5. **四合一實體批次合併**：依標準順序合併，頁尾中央壓印「單據編號 ｜ 第 x 頁 / 共 y 頁」流水號。

## 🛠️ 標準調用指令（RTCCF 規格）

當使用者提供請款資料表、傳票與發票附件時，請嚴格依照 [**`2-2_AI產出之RTCCF審查與結構化提示詞.md`**](../../2-2_AI產出之RTCCF審查與結構化提示詞.md) 中規範之終極 RTCCF 規則執行。

可直接執行封裝腳本：
```bash
python scripts/packet.py
```
