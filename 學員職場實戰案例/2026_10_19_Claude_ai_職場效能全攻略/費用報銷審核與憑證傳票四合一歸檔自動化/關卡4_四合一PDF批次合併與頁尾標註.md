## 🛠️ 實作步驟 4-A：自然語言執行任務（批次合併與頁尾標註）

在同一個 AI Agent 對話視窗中，發送以下指令：

```text
前三關的萃取、勾稽與目錄書籤機制均已完善！現在我們要產出最終的生產級批次封裝程式碼，將所有模組整合為一體。

請完成以下封裝與整合任務：
1. 【批次四合一 PDF 實體合併】：
   - 依照固定順序拼裝單一報銷案件之完整檔案：
     [封面目錄] ➔ [1. 會計傳票] ➔ [2. 已簽核請款單] ➔ [3. 簽核歷程] ➔ [4. 發票/憑證圖檔與附件]
   - 支援將圖片格式（PNG / JPG / HEIC）自動轉換並等比例縮放適應 A4 頁面。
2. 【全文件頁尾浮水印與頁碼標註】：
   - 在合併後的每頁正中央頁尾，自動壓印雙層識別碼：
     「請款單號：EXP-202610-001 ｜ 第 x 頁 / 共 y 頁」
   - 確保頁尾文字不遮蔽原始發票上之發票字軌或統編金額。
3. 【整合產出 Python 封裝程式碼（packet.py）】：
   - 採用 pypdf 與 ReportLab，具備命令列參數輸入與批次資料夾掃描能力。
   - 產出檔案自動依「單號_申請人_報銷歸檔.pdf」規則命名存檔。

請為我輸出完整的 Python 封裝腳本與批次執行報告！
```

## 🔍 人工驗收（人機協作點 1）：核對最終歸檔本

- [ ] **四合一順序正確**：目錄 ➔ 傳票 ➔ 請款單 ➔ 簽核歷程 ➔ 發票附件，無任何缺漏頁。
- [ ] **頁尾標籤清晰**：每頁底部均有「單號 第 x / y 頁」，查帳時即便單頁抽印也能追溯歸屬。
- [ ] **發票縮放適中**：手機隨手拍下的收據圖片是否已自動旋轉、等比例縮放至 A4 版面內，未裁切關鍵資訊。
