## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜憑證稅額檢核與不得扣抵過濾（`RTCCF_step1.md`）**
   * 檢查買受人統編、拆算 `÷1.05` 稅額並標示不可扣抵項目，產出檢核表 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜4 碼會計科目與借貸平衡傳票（`RTCCF_step2.md`）**
   * 依科目對照表編製每筆單據借貸平衡分錄（差額 = 0），產出 `.md` 後封存 `step2`。
4. **Step 4｜關卡 3｜四層簽核鏈稽核與目錄頁碼規劃（`RTCCF_step3.md`）**
   * 驗證 `申請人 ➔ 會計 ➔ CFO ➔ CEO` 四關完整性（只增不減），產出目錄規劃 `.md` 後封存 `step3`。
5. **Step 5｜關卡 4｜四合一書籤 PDF 合成與總控組裝（`RTCCF_step4.md` ＋ `RTCCF_main.md`）**
   * 調用 Python 合併五段頁面並注入左側 Outline 書籤與統一頁尾，封存 `step4` 並組裝 `RTCCF_main.md`。
6. **Step 6｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`費用報銷申請明細_202611_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/費用報銷申請明細_202611_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **不得扣抵稅額併入費用**：交際費（5155）、自用小客車、收據不得列入可扣抵進項稅額。
2. **傳票強制借貸平衡**：每筆傳票借方總額必須 100% 等於貸方總額。
3. **簽核鏈完整與只增不減**：退回重送須新增列紀錄，未走完四關者不得直接放行歸檔。
4. **PDF 書籤與統一頁尾**：須包含左側階層書籤跳轉與頁尾「`單據編號 第 x / y 頁`」。
