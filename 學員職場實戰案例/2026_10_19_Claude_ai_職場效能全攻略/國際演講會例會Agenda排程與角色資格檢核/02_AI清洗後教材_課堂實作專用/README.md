# 02_AI清洗後教材_課堂實作專用

本目錄為專門提供給 AI Agent（如 Claude Projects、ChatGPT、Gemini 等）進行課堂實作的極致省 Token 清洗後教材。

---

## 📁 目錄結構說明

```text
02_AI清洗後教材_課堂實作專用/
├── README.md                      # 本說明文件
├── 固定資料表/                     # 【常駐】請全部放入 AI 專案知識庫（Project Knowledge）
│   ├── 01_排課核心業務規則與角色資格標準.md
│   ├── 02_會員演講進度與資格對照表.md
│   └── 03_排課SOP說明與規則.md
└── 使用者提供/                     # 【純輸入 Excel】依實作進度上傳對話框
    ├── 例會排程報名表_第183次例會_上課工作流專用.xlsx   # 關卡 1~4 實作工作流專用
    └── 例會排程報名表_第184次例會_偽資料.xlsx         # 關卡 4 全部完成後，最後全流程一鍵驗證專用
```

---

## 🚀 課堂使用指引

1. **專案知識庫設置**：  
   請將 `固定資料表/` 內的 3 個 Markdown 檔案直接上傳至 AI Agent 的專案知識庫中。
2. **對話視窗上傳**：  
   關卡 1 開始時，僅需在對話視窗上傳 `使用者提供/例會排程報名表_第183次例會_上課工作流專用.xlsx` 即可開始建立並執行工作流程！
3. **最後全流程一鍵驗證**：  
   在關卡 4 完成最終收斂後，換上 `使用者提供/例會排程報名表_第184次例會_偽資料.xlsx`，一鍵驗收所有例會排程與議程表！
