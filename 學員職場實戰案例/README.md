# 🎯 學員職場實戰案例庫

> 本專區收錄學員於真實職場中面臨的高頻、高耗時日常業務痛點。透過**人機協同發想**、**RTCCF 結構化提示詞工程**、**多模態處理**與**漸進式積木優化（Progressive Modular Refinement）**工作流，將複雜的人工作業轉化為一般同仁皆可無門檻調用的企業級 AI 自動化落地實戰成果！



---

## 🧭 核心主軸：[成為「AI工作流架構師」實戰指南](./00_AI工作流架構師實戰指南/README.md)

> 💡 **終極目標：讓每位學員成為能獨立拆解業務的「AI工作流架構師」！**  
> 告別「課堂會照著跑、回職場不會自己規劃」的斷層痛點。回到公司面對雜亂的 Excel、PDF 規章、白板照片與主管口頭需求時，透過以下 **架構師三步法**，即可將複雜業務轉化為可重複調用的自動化工作流（點擊上方標題進入專區取得完整提示詞與 7 大實作包）：

### 1️⃣ 第一步：盤點手邊「四大原料」
開工前先不急著寫 Prompt，將手邊零散素材歸納為 4 個項目（支援上傳後由 AI 自動辨識）：
* **① 工作流程說明**（痛點與步驟）
* **② 工作流參考檔案**（不變的規章與對照表 ➔ 抽離為獨立 `.md` 常駐知識庫，極致省 Token）
* **③ 未來動態輸入檔**（每週／每月變動的流水帳或照片）
* **④ 預期輸出成品檔**（過去簽核合格的 Excel / Word / PPT / PDF 樣版，防止 AI 瞎猜排版）

### 2️⃣ 第二步：挑選「雙路線引擎」規劃規格
依業務複雜度與個人習慣，任選一條路線啟動：
* **🔍 路線 A（先體檢再拆積木）**：適合複雜多表勾稽或不確定資料是否齊全。由 AI 先產出《可行性評估與關卡規劃報告.md》抓出缺漏紅黃燈、提煉固定規則 `.md` 檔，再依藍圖進入關卡。
* **💬 路線 B（一問一答建積木）**：適合想邊聊邊建規格。由 AI 先給工作流建議名稱與首版規格，每次只問 1 題引導補齊細節（並先問再拆固定 `.md` 檔）。

### 3️⃣ 第三步：以「漸進式積木優化」落地執行與跨期驗證
複雜業務**切忌一次輸入所有任務，也切忌將所有關卡塞進同一個巨型檔案**！依任務規模採取積木式組裝：
* **🟢 單一任務（1 關閉環）**：只需產出一份通用規格書 **`RTCCF.md`**，確認後直接執行產出成品。
* **🔵 多關卡任務（2~4 關）**：遵循**一次一關、一關一積木、最後總組裝**
  1. **逐關建立並封存積木**：第 1 關產出 **`RTCCF_step1.md`** 並執行產出 `.md` 資料成果（人工驗收通過後，`RTCCF_step1.md` 即定版封存，後續不再更動！）。
  2. **後續關卡獨立封裝**：後續關卡先以自然語言執行新任務並驗收 `.md` 資料成果，通過後各自**獨立儲存為 `RTCCF_step2.md`、`RTCCF_step3.md`...**（一關一檔、不回頭重寫前關，省 Token 又避免改後忘前）。
  3. **最終總組裝與換批驗證**：在最後一關結束時，建立輕量總控檔 **`RTCCF_main.md`** 串聯所有 `RTCCF_step1~N.md`；接著換上第二批全新偽資料，直接呼叫 `RTCCF_main.md` 一鍵驗證跨期通用性！
