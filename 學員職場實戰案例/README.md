# 🎯 學員職場實戰案例庫

> 本專區收錄學員於真實職場中面臨的高頻、高耗時日常業務痛點。透過**人機協同發想**、**RTCCF 結構化提示詞工程**、**多模態處理**與**漸進式優化（Progressive Refinement）**工作流，將複雜的人工作業轉化為一般同仁皆可無門檻調用的企業級 AI 自動化落地實戰成果！

---

## 💡 全系列核心方法論與架構原則

全體案例皆貫穿兩大現代 AI 智慧辦公的實戰核心支柱：

### 1. 漸進式優化（Progressive Refinement）
複雜的企業級業務**切忌一次輸入所有任務**！所有案例均嚴格遵循「一次一個任務、做一步驗一步」的漸進式優化路徑：
1. **第 1 個產出是規格書**：白話口語發想，產出通用工作流規格書 **`RTCCF_v1.md`**（純規格、不執行特定計算，存為 `.md` 純文字以便人機協作）。
2. **叫 AI 依據工作流開始工作**：人工確認規格無誤後，正式指示 AI 依據規格執行第一階段任務。
3. **後續關卡用自然語言執行新任務**：依序在各關卡丟出新任務（資料比對、格式轉譯、合規防呆、版面排版）。
4. **完成後更新寫回同一個工作流**：每道關卡驗收無誤後，指示 AI 將新規則追加寫回 **`RTCCF_v1.md`**。**關卡推進，工作流就會愈長、功能愈強大！**
5. **最終收斂完稿與換批一鍵驗證**：在最後關卡收斂為終極生產級 SOP，並換上第二批全新偽資料，一鍵測試全流程跨期/跨月份通用性！

### 2. 前置資料清洗（Pre-Data Cleansing，極致省 Token）
為避免直接上傳多工作表肥大檔案導致免費版對話迅速耗盡 Token，本案例庫全數落實前置資料解耦：
* 📁 **固定資料表/**：常駐專案知識庫之規則手冊與參數表（純 Markdown 格式，Token 節省 85%~90% 以上）。
* 📁 **使用者提供/**：僅保留實作必備之輸入資料（課堂練習 1 份、換批驗證 1 份，部分含進階規模）。
* 📊 **實測成果_偽資料/**：提供完整實測交付檔案（Excel、Word、PPT、PDF、Markdown 報表等），供學生對照標準答案。
* 📦 **課堂實作下載包.zip**：一鍵打包精簡教材，免除手動整理負擔。

### 📝 三大必備要素詳細說明（學員準備概念）

為了讓 AI 能精確理解並為您量身打造工作流，請務必掌握「**有進、有出、有規則**」的核心思維：

| 交付項目 | 核心作用 | 內容要點與準備原則 |
| :--- | :--- | :--- |
| 📄 **需求說明書** | 讓 AI 與講師釐清邏輯 | 1. **業務痛點**：目前這項工作每月/每週需耗費多少人工時間？最容易出錯的地方在哪？<br>2. **業務規則與公式**：各欄位的計算方式（例如「加班費乘數」、「營業稅 5% 四捨五入」）、比對條件（如以統一編號或員工編號勾稽）。<br>3. **例外與防呆狀況**：遇到缺漏值、負數、異常格式時該如何處置？ |
| 📁 **01_來源檔案 (Input)** | 提供 AI 分析的原料 | 1. 平常您從 ERP/POS/打卡機/表單下載下來的**原始未加工資料**。<br>2. 請提供 1~2 份具代表性的範例資料（一份供課堂分析驗證、一份供換批測試）。 |
| 📁 **02_需要產出的檔案 (Output)** | 定義交付終點標準 | 1. 您目前「手動辛苦做出來」的成品，或是**主管/客戶期望看到的最終報表**。<br>2. 包含 Excel 統計樞紐表、Word 正式會簽單、PPT 簡報、PDF 或符合特定格式的純文字檔。 |

### 📋 《需求說明書》快速範本（可複製填寫）

學員可直接複製以下結構填寫後存為 `需求說明書.md` 一併放入資料夾中：

```markdown
# 專案名稱：【學員姓名】客訴工單自動分類與週報產出

## 1. 提案人資訊
- 學員姓名：王小明
- 任職部門 / 職稱：營運客服部 / 資深專員
- 聯絡 Email / Line：example@mail.com

## 2. 目前作業現況與痛點
- 作業頻率：每週一上午產出前週週報
- 人工耗時：每次需手動篩選 500+ 筆客服留言，耗時約 3.5 小時
- 最大痛點：客服分類標準不一，無法快速歸納出「系統異常」或「物流延誤」，主管難以即時決策。

## 3. 輸入資料說明（放於 01_來源檔案/）
- 檔案 1：`202610_客服系統留言原始匯出.xlsx`（包含留言時間、會員編號、留言文字內容、滿意度星等）。

## 4. 期望產出成果（放於 02_需要產出的檔案/）
- 產出 1：`每週客訴戰情報告.xlsx`（包含「問題類別統計樞紐」、「TOP 5 高頻異常關鍵字」、「嚴重客訴預警名單」）。
- 產出 2：`客訴改善週報摘要.md`（供週會報告直接投影或貼至 Slack / Teams 的 500 字簡報摘要）。

## 5. 核心業務邏輯與判斷規則
- 若星等 <= 2 星，一律強制標記為「🚨 需急迫追蹤」。
- 包含關鍵字「退款」、「重複扣款」、「刷卡失敗」，自動歸類至「財務扣款問題」。
- 重複提出相同問題超過 3 次的會員，需獨立列入「高風險流失用戶」。
```

## 🛡️ 企業實務資安部署建議（個資不上雲端）

中小企業導入 AI 最常擔心的就是：**「真實商業機密、客戶名單、員工身分證與薪資，真的能上傳給外部雲端 AI 嗎？」**

本系列案例全數貫徹**「脫敏研發 ➔ 本機離線執行」**雙軌機制：
1. **脫敏研發（在 AI Agent 平台上）**：
   使用各專案提供的去識別化虛擬範例資料，在 AI Agent 平台上完成所有邏輯發想、提示詞微調、人機協商驗收與工作流規格（`RTCCF_v1.md`）產出。
2. **本機離線執行（在公司內部）**：
   當流程驗證無誤後，將產出的規格或自動化 Python 腳本下載至內部電腦執行。由本機直接讀取公司內部真實資料，**真實機敏資訊 100% 留在本機，完全不流經任何外部雲端**，兼顧極致效率與最高資安隱私合規！
