# 📋 學員《User Story 提案卡》填寫樣版

> 💡 **產品經理人心態（Mindset Shift）**：  
> 不要急著丟「幫我寫程式」或「幫我算薪水」這種模糊的願望。優秀的 AI 產品經理人，永遠從**「誰（Who）、在什麼情境（When/Where）、遇到什麼阻礙（Problem）、需要達成什麼價值（Value）」**出發！  
> 
> 請直接複製以下空白模板填寫，完成後即可搭配 [02_AI產品顧問一問一答訪談提示詞.md](./02_AI產品顧問一問一答訪談提示詞.md) 交由 AI 進行深度訪談！

## 📝 《User Story 提案卡》空白模板（請複製填寫）

```markdown
# 專案提案：【學員姓名】專案主題名稱

## 1. 提案人基本資訊
* 學員姓名：[請填寫您的姓名]
* 任職部門 / 職稱：[例如：財務部 / 資深會計專員]
* 業務類別：[例如：薪資計算 / 發票核銷 / 訂單沖帳 / 社群素材 / 標案篩選]

## 2. 核心使用者故事 (User Story)
* **As a（身為...的角色）**：[例如：每個月底要處理全公司 50 位同仁考勤的薪酬專員]
* **I want（我想要自動化完成什麼功能）**：[例如：自動計算平日與假日階梯加班費、遲到扣款與法定勞健保代扣，並產出每位同仁的加密薪資單]
* **So that（以便於達到什麼商業價值 / 解決什麼痛苦）**：[例如：將原本需要連續加班 2 天的人工核算縮短至 30 分鐘內完成，且完全避免勞資糾紛與算錯薪資的風險]

## 3. 現狀業務痛點與時間成本
* 作業頻率：[例如：每個月 1 次 / 每週一上午 1 次 / 每天下午 5 點]
* 人工耗時：[例如：每次需手動核對 3 小時，月底更是要花整整 2 天]
* 最大痛點：[例如：打卡記錄有許多忘打卡、跨日加班，手動拉 Excel 公式常常漏掉 11 小時輪班間隔，容易被勞檢開罰]

## 4. 輸入原料說明 (Input Data)
* 平常我會拿到哪些原始檔案？（請準備 1~2 份範本檔案）：
  - 檔案 1：`打卡機原始明細.xlsx`（包含打卡日期、工號、姓名、上下班刷卡時間戳記）
  - 檔案 2：`員工本薪與職級參數表.xlsx`（包含本薪、職務加給、固定津貼）

## 5. 期望產出成果 (Expected Output)
* 主管或客戶期望看到的最終成果是什麼？（請準備期望成果範本）：
  - 產出 1：`全公司出勤與薪資統計總表.xlsx`（包含每位員工的應發工資、各項扣款、實發薪資）
  - 產出 2：每位同仁獨立的 `加密薪資明細單.pdf`（開啟密碼為身分證字號）

## 6. 已知核心規則與防呆條件（初步想法）
* [例如：平日加班前 2 小時乘以 1.34，第 3 小時起乘以 1.67]
* [例如：遲到未滿 15 分鐘不扣款，超過 15 分鐘扣半小時薪資]
* [例如：實發金額如果小於 0 元，必須立刻標記紅色警示]
```

## 🌟 填寫示範 1：【人資薪酬領域】員工出勤打卡與階梯薪資核算

```markdown
# 專案提案：【陳美玲】中小企業員工打卡薪資計算與加密發放自動化

## 1. 提案人基本資訊
* 學員姓名：陳美玲
* 任職部門 / 職稱：人資行政部 / 人資專員
* 業務類別：薪酬出勤

## 2. 核心使用者故事 (User Story)
* **As a**：每個月初要結算 80 位員工薪資的人資專員
* **I want**：自動清洗打卡鐘匯出的不規則打卡資料，精準計算平日/休息日/例假日階梯加班費、請假扣款與 2026 法定代扣，並產出個別加密 PDF 薪資條
* **So that**：能在每月 5 號發薪日前從容核算完成，徹底根絕人工算錯薪資與違反勞基法的風險

## 3. 現狀業務痛點與時間成本
* 作業頻率：每月一次（每月 1~3 號）
* 人工耗時：每次耗費 16 小時（需 2 位同仁重複核對 1 整天）
* 最大痛點：員工常有忘記打卡或補打卡，加班倍率計算繁瑣，且發薪時手動寄紙本薪資條極易洩漏薪資機密。

## 4. 輸入原料說明 (Input Data)
* 檔案 1：`打卡記錄_202610.csv`（打卡機原始記錄，含分鐘級打卡時間）
* 檔案 2：`請假申請清單_202610.xlsx`（主管已核准之假別與請假日數）
* 檔案 3：`員工基本資料與投保級距表.xlsx`（包含員工身分證號、本薪、勞健保級距）

## 5. 期望產出成果 (Expected Output)
* 產出 1：`薪資月結彙總表.xlsx`（含所有欄位勾稽平帳公式）
* 產出 2：`批次加密員工薪資單/`（每人一份 AES-256 加密 PDF，密碼為身分證號）

## 6. 已知核心規則與防呆條件
* 平日加班 2 小時內 1.34 倍、第 3 小時起 1.67 倍；休息日依勞基法規定核算。
* 輪班間隔未滿 11 小時需在總表標註異常警示。
* 身分證字號與薪資機敏資訊嚴格不得流經外部雲端，需支援本地離線執行。
```

## 🌟 填寫示範 2：【財務會計領域】費用報銷多模態審核與四合一歸檔

```markdown
# 專案提案：【李俊宏】費用報銷多模態審核與四合一電子歸檔

## 1. 提案人基本資訊
* 學員姓名：李俊宏
* 任職部門 / 職稱：會計部 / 主辦會計
* 業務類別：費用審核與傳票憑證管理

## 2. 核心使用者故事 (User Story)
* **As a**：每月需審核全公司 50 筆差旅與交際費用的會計人員
* **I want**：AI 能自動讀取同仁上傳的發票照片，自動辨識統編、稅額與金額，並與請款單、傳票進行三方比對，最後依內控順序自動拼合成自帶目錄與書籤的歸檔 PDF
* **So that**：能節省 80% 的人工黏貼憑證與影印時間，且查帳時點擊書籤即可秒級跳轉至發票影像

## 3. 現狀業務痛點與時間成本
* 作業頻率：每月 2 次（5 號與 15 號結算付款）
* 人工耗時：每月花費 8 小時在影印、黏貼發票與核對金額
* 最大痛點：同仁常常發票沒打公司統編、或是請款金額跟發票含稅金額對不起來；國稅局查帳時需翻閱厚重紙本憑證本，費時費力。

## 4. 輸入原料說明 (Input Data)
* 檔案 1：`費用報銷申請明細.xlsx`（線上表單登錄資料）
* 檔案 2：`單據附件/` 資料夾（內含請款單 PDF、會計傳票 PDF、同仁手機拍下的發票收據照片 PNG/JPG）

## 5. 期望產出成果 (Expected Output)
* 產出 1：`傳票與單據比對表.md`（三方金額勾稽確認表，差額必須為 0 元）
* 產出 2：`四合一歸檔本.pdf`（依序拼裝：目錄 ➔ 傳票 ➔ 請款單 ➔ 簽核 ➔ 發票，附書籤樹與頁尾流水號）

## 6. 已知核心規則與防呆條件
* 發票買方統編必須為本公司統編（70845354），否則一律標示不可扣抵。
* 請款金額 ＝ 發票金額 ＝ 傳票借貸金額，任何 1 元差額皆需中斷流程警示。
```

## 🌟 填寫示範 3：【數位行銷領域】跨平台廣告數據整合與異常歸因週報

```markdown
# 專案提案：【張雅婷】跨平台成效數據交叉分析與異常診斷自動化

## 1. 提案人基本資訊
* 學員姓名：張雅婷
* 任職部門 / 職稱：數位行銷部 / 廣告投放副理
* 業務類別：成效分析與預算配置

## 2. 核心使用者故事 (User Story)
* **As a**：負責管理 Google、Meta 與 LINE 廣告成效的行銷副理
* **I want**：自動整合三通路的每日花費、點擊率 (CTR)、轉換數 (CV) 與 GA4 實際訂單營收，自動計算各平台 ROAS，並對異常指標標記歸因原因
* **So that**：在每週一上午 9 點前自動產出主管週會戰報，並及時調配預算給投報率最高的通路

## 3. 現狀業務痛點與時間成本
* 作業頻率：每週一上午一次
* 人工耗時：每次耗時 3.5 小時手動下載三平台報表、匯入 Excel 做 VLOOKUP 整理
* 最大痛點：各平台命名標準不一（Meta 叫 Amount Spent，Google 叫 Cost）；遇到 ROAS 突然驟降時，往往來不及查明是點擊成本上漲還是著陸頁跳離率過高。

## 4. 輸入原料說明 (Input Data)
* 檔案 1：`Google_Ads_Export.csv`（Google 原始匯出）
* 檔案 2：`Meta_Campaign_Export.xlsx`（Meta 原始匯出）
* 檔案 3：`GA4_Purchase_Event.csv`（GA4 實際轉換營收）

## 5. 期望產出成果 (Expected Output)
* 產出 1：`跨平台週成效總表.xlsx`（包含通路橫向對齊、動態計算 CPA 與 ROAS）
* 產出 2：`成效異常診斷與預算配置建議.md`（包含各通路異常指標診斷與下週預算增減百分比）

## 6. 已知核心規則與防呆條件
* ROAS < 2.5 即觸發「⚠️ 成效未達標預警」；ROAS > 4.5 觸發「🚀 建議加碼 20% 預算」。
* 日期格式須自動標準化為 YYYY-MM-DD，幣別非 TWD 時自動依固定匯率換算。
```
