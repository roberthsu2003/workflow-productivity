# 📽️ 範例 05：【實體簡報 ➔ PPTX】觀光飯店訂房月報動態生成

> 📖 **這個業務在做什麼？（非旅宿業新手先看這段）**  
> 飯店營運人員每月初要把 PMS 訂房流水帳算成住房率（OCC）、平均房價（ADR）、每房收益（RevPAR）與年增率（YoY），並製作 16:9 簡報向總經理報告各分館表現與 OTA／官網／旅行社通路結構。  
> 👉 **不熟飯店營運指標與加權 ADR 陷阱？** 請先看 1 分鐘白話導讀：[**`00_業務背景與專業術語導讀.md`**](./00_業務背景與專業術語導讀.md)

> 🚦 **診斷狀態**：🟢 **綠燈**（流水帳數據、加權指標公式與 PPTX 範本齊全）  
> 🧱 **建議關卡規劃**：**2 道關卡**，產出 `RTCCF_step1~2.md` ＋ 最後組裝 `RTCCF_main.md`

## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini）。
   * 依需求套用 [**路線 A：體檢評估提示詞**](../../01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1：加權營運指標精算與摘要（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，用 Python 計算 OCC、加權 ADR、RevPAR、YoY 與三大通路佔比，產出純文字摘要 `.md` 人工核對後封存 `step1`。
3. **Step 3｜關卡 2：16:9 原生圖表簡報生成與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已核對的摘要 `.md`，調用 Python `python-pptx` 生成 3 頁式 16:9 實體簡報 `.pptx`，最後封存 `step2` 並組裝 `RTCCF_main.md`。

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **加權平均 ADR 鐵則**：合併多館別或跨月計算 ADR 時，**必須「總營收 ÷ 總售出房晚」**，嚴禁將各列 ADR 直接算術平均。
2. **兩關中斷先驗數字再做簡報**：關卡 1 必須先產出 `.md` 指標摘要表，核對總房晚、總營收與 YoY 無誤後，關卡 2 才繪製 PPTX。
3. **分母為 0 顯示 N/A**：若某館房晚為 0、缺去年同期營收或缺目標值，指標應顯示 `N/A`（且不計算跨館整體目標達成率）。
4. **3 頁簡報母片與原生圖表**：需包含 ①KPI 卡片與各館對比、②兩期趨勢與三大通路佔比圖表、③各館實際 vs. 目標 ADR 檢核，且文字不可重疊遮擋。
