## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini）。
   * 依需求套用 [**路線 A：體檢評估提示詞**](../../01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1：發票稅額與不得扣抵檢核（`RTCCF_step1.md`）**
   * 驗算 `÷ 1.05` 稅額並區分可扣抵／不得扣抵進項，產出檢核表 `.md` 人工確認後封存 `step1`。
3. **Step 3｜關卡 2：4 碼會計科目與借貸平衡傳票（`RTCCF_step2.md`）**
   * 讀取前關結果編製借貸傳票（驗證借貸差額 = 0），產出傳票表 `.md` 後封存 `step2`。
4. **Step 4｜關卡 3：四層簽核鏈稽核與目錄規劃（`RTCCF_step3.md`）**
   * 檢查 `申請人 ➔ 會計 ➔ CFO ➔ CEO` 簽核鏈完整性並規劃 PDF 頁碼目錄，產出 `.md` 後封存 `step3`。
5. **Step 5｜關卡 4：四合一書籤 PDF 合成與總控組裝（`RTCCF_step4.md` ＋ `RTCCF_main.md`）**
   * 調用 Python 產出含左側階層書籤與頁尾流水號的 `.pdf`，最後封存 `step4` 並組裝 `RTCCF_main.md`。

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **不得扣抵進項之稅額須併入費用**：交際費（`5155`）、自用小客車與收據的 5% 稅額不得申報進項扣抵，必須併入費用科目入帳。
2. **每筆傳票強制借貸平衡**：關卡 2 必須驗證 `借方總額 ＝ 貸方總額`，且嚴禁漏列任何分錄。
3. **簽核軌跡只增不減（不可篡改）**：退件或重送時只能新增紀錄列，嚴禁覆蓋修改過去的時間戳記與簽核紀錄。
4. **PDF 書籤與統一頁尾規格**：最終 PDF 須具備左側可點擊跳轉的 Outline 書籤，以及每頁頁尾「`單據編號 第 x / y 頁`」。
