# 🔴 範例 03：【真實痛點・紅燈補齊 ➔ 法定 TXT】營業稅電子申報媒體檔

> 📖 **這個業務在做什麼？（非財會新手先看這段）**  
> 公司每兩個月要向國稅局申報營業稅，把進項與銷項發票轉成財政部規定「每行精準 81 個字元」的 `.TXT` 媒體檔，並剔除交際費、小客車等不得扣抵憑證。本範例刻意設計**「先缺漏亮紅燈 ➔ 再用 `補齊/` 素材轉綠燈」**雙階段演練！  
> 👉 **不熟稅務申報術語與 81 字元規則？** 請先看 1 分鐘白話導讀：[**`00_業務背景與專業術語導讀.md`**](./00_業務背景與專業術語導讀.md)

> 🚦 **診斷狀態**：🔴 **紅燈阻斷警告 ➔ 🟢 使用 `補齊/` 資料夾素材後轉綠燈通關**  
> 🧱 **建議關卡規劃**：補齊轉綠燈後規劃 **2 道關卡**，產出 `RTCCF_step1~2.md` ＋ 最後組裝 `RTCCF_main.md`  
> 📦 **獨立實作專案**：本資料夾即為完整獨立專案，紅燈初始原料與 `補齊/` 綠燈素材皆已打包進同一個實作包，無需跳轉其他專案。

## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜先傳外層初始原料，體驗紅燈阻斷**
   * 將外層 2 份初始原料（`.txt` ＋ 缺漏 `.xlsx`）上傳至 AI，套用 [**路線 A：體檢評估提示詞**](../../01_路線A_AI工作流架構師評估提示詞.md)。
   * **重點**：確認 AI 亮起 🔴 **紅燈**拒絕產出 TXT，並正確點出缺少統編、格式代號與 81 字元規則。
2. **Step 2｜上傳 `補齊/` 資料夾素材，轉為綠燈**
   * 將 **`補齊/`** 內的規則 `.md`、已補代碼 `.xlsx`、補齊說明 `.txt` 與成品 `.TXT` 上傳給同一個對話補齊（亦可用 `補齊/` 素材直接走 [**路線 B 一問一答提示詞**](../../02_路線B_互動式漸進生成RTCCF提示詞.md)），看 AI 轉為 🟢 **綠燈**。
3. **Step 3｜分 2 關產出並驗收 81 字元 TXT**
   * **關卡 1（`RTCCF_step1.md`）**：剔除不得扣抵進項、驗算 5% 稅額，產出檢核清冊 `.md` 人工確認。
   * **關卡 2（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**：由 Python 精準補零補空白產出 `.TXT` 並檢查每行長度皆等於 81 字元。

---

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **紅燈階段嚴禁幻覺硬產**：未傳入 `補齊/` 素材前，AI 必須阻斷開工，絕不能自己亂編統一編號或格式位置。
2. **營業稅法第 19 條不得扣抵防呆**：補齊後執行關卡 1 時，必須正確剔除「交際費」、「免用統一發票收據」、「自用小客車保養」。
3. **統編方向與消費者留白**：進項買方是本公司（`70845354`），銷項賣方是本公司；開給一般消費者（無統編）時買受人統編應填 8 個空白。
4. **必須用 Python 驗證 81 字元**：不可讓 AI 直接在對話框「手排」定長文字，須用程式格式化並驗證 `len(line) == 81`。
