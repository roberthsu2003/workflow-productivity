# 工程監造白板照片辨識｜課堂實作導覽

**學習目標**：從素材整理開始，建立可跨批使用的 RTCCF 工作流，逐關產出、檢查並擴充規格，再以第二批偽資料驗證。

## 關卡快速連結

- [關卡 0：建立工作流規格](./關卡0_建立工作流規格.md)
- [關卡 1：白板資訊核對](./關卡1_白板資訊核對.md)
- [關卡 2：查驗紀錄](./關卡2_查驗紀錄.md)

- [最終關卡：收斂完整工作流](./最終關卡_收斂完整工作流.md)

## 課前準備

1. 閱讀 [前置資料清洗說明](./00_前置資料清洗說明.md)，了解原始素材與虛構練習的差異。
2. 建立 AI 專案，將 [案例固定規則](./固定資料表/01_案例規則.md) 與 [輸入欄位及清洗檢查](./固定資料表/02_輸入欄位與清洗檢查.md) 放入專案知識庫；沒有知識庫功能時，在對話貼上全文。
3. 開啟新對話，上傳 [第一批偽資料](./使用者提供/01_課堂練習_偽資料.md)。使用可讀檔與產檔的 AI；若不支援產檔，先將回覆另存為文字檔。
4. 辨識圖片時，可另上傳 [模擬白板 01](./使用者提供/模擬白板_01.svg)；換批上傳 [模擬白板 02](./使用者提供/模擬白板_02.svg)。這是示意圖而非現場照片；平台不支援 SVG 時，使用者可截圖轉成 PNG。
5. 每個程式或檔案操作均先檢查結果；不能因 AI 自稱正確就直接發布。

## 關卡 0：建立工作流規格

**輸入**：固定規則、第一批偽資料。**產出**：`RTCCF_v1.md`（只建立規格，先不執行業務任務）。

```text
我要把「工程監造白板照片辨識」變成每批都能重用的工作流。請先閱讀固定規則及我提供的資料，列出輸入欄位、缺值與需要確認的地方；不要自行補值。請以 Role、Task、Context、Constraints、Format 建立 RTCCF_v1.md，規則與本批資料分開，不寫死本批名稱或數字。只產出規格，不執行業務任務。
```

**驗收**：五要素齊全；輸入和輸出明確；不明資料列為待確認；換一批資料仍可使用。可對照 [RTCCF 關卡 0 參考](./RTCCF_v1_關卡0參考.md)。

## 關卡 1：白板資訊核對

**輸入**：固定規則、本批資料、已確認的 RTCCF 規格。
**產出**：`白板辨識.md`。

```text
請依已確認的 RTCCF_v1.md 執行「白板資訊核對」。依 P01、P02 分欄，記錄來源與不清楚欄位。所有結果需可對照來源；缺漏與無法計算項目請標示原因，不得編造。請先交付 白板辨識.md 供我核對。
```

**驗收**：先檢查資料筆數、欄位和結果是否可追溯；逐項核對本關任務與例外，修正後才進下一關。老師可用[教師驗收參考](./教師驗收參考.md)抽查。

**驗收通過後，請再貼上：**

```text
這一關我已核對。請將剛才確認的處理規則、例外處理、驗收條件和交付格式追加到 RTCCF_v1.md，保留原有規則，不寫死本批資料；如有衝突先列出。
```

## 關卡 2：查驗紀錄

**輸入**：固定規則、本批資料、已確認的 RTCCF 規格與上一關確認成果。
**產出**：`施工查驗紀錄.docx`。

```text
請依已確認的 RTCCF_v1.md 執行「查驗紀錄」。僅使用核准資訊製作 Word，保留照片佔位與結果待確認。所有結果需可對照來源；缺漏與無法計算項目請標示原因，不得編造。請先交付 施工查驗紀錄.docx 供我核對。
```

**驗收**：先檢查資料筆數、欄位和結果是否可追溯；逐項核對本關任務與例外，修正後才進下一關。老師可用[教師驗收參考](./教師驗收參考.md)抽查。

**驗收通過後，請再貼上：**

```text
這一關我已核對。請將剛才確認的處理規則、例外處理、驗收條件和交付格式追加到 RTCCF_v1.md，保留原有規則，不寫死本批資料；如有衝突先列出。
```

## 進階練習：多圖白板查驗

請依 [多圖白板查驗進階關卡](./進階關卡_多圖白板查驗.md) 逐圖辨識、比對、製作 Word 並收斂工作流，再換第二組示意圖驗證。

## 最終關卡：收斂完整工作流

完成後可使用 [教師參考：完整工作流](./教師參考_完整工作流.md) 對照所有關卡是否齊全；先自行完成再查看。

所有關卡通過後，開啟 [最終關卡：收斂完整工作流](./最終關卡_收斂完整工作流.md)，請 AI 把各關規則整合成同一份 `RTCCF_v1.md`，並下載保存。接著才進行換批驗證。

## 最後驗證：換批重跑

上傳 [第二批偽資料](./使用者提供/02_換批驗證_偽資料.md)，保留固定規則與已擴充的 RTCCF，逐關執行。

```text
請使用新的偽資料和已確認的 RTCCF_v1.md 執行整個工作流。每關先列出結果和例外供我驗收；不可沿用上一批的資料。遇到缺漏時標待確認，不得自行補值。
```

**驗收**：抽查新資料、各關輸出與例外；規格無須因批次改寫。 可參考 [兩批試算與對照](./教師用_兩批試算對照.md)。已知參考答案見[教師驗收參考](./教師驗收參考.md)。

本包提供基礎與進階的虛構練習；已完成的本地實測成果及適用限制請見[專案首頁](../README.md)。
