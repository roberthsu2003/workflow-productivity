## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜營收核對、MoM/YoY 計算與排名（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，依唯一代號鍵核對 39 家營收與來源，計算月增率與年增率（缺值標 `N/A`），產出排名與檢核表 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜四工作表競業矩陣 Excel 產出與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已確認的 `.md` 分析表，調用 Python `openpyxl` 生成含摘要、比較、排名與來源查證的四工作表 `.xlsx`，封存 `step2` 並組裝 `RTCCF_main.md`。
4. **Step 4｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`02_換批驗證_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **零幻覺來源查證**：每筆營收必須保留資料出處與基數，不可自行捏造未公告月份數字。
2. **缺值與零分母標 `N/A`**：數據缺漏或分母為 0 時標為 `N/A` 並註明原因，嚴禁當成 `0` 算入增率。
3. **排行榜公平納入原則**：僅納入可計算出有效增率之公司，同率時依公司代號排序。
4. **四工作表結構完整**：Excel 須完整包含摘要、營收比較、排名榜與來源查證四個工作表。
