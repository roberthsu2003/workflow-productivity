# ⚠️ AI 評估與實作注意事項指南

> 💡 **為什麼這份文件只列注意事項？**  
> 因為不同 AI 模型（Claude / ChatGPT / Gemini）每次產生的評估報告措辭、關卡說明與 Prompt 都不一樣！實作時**不需要追求字面完全相同**，只要確認您的 AI 有抓到以下核心注意事項與驗收標準，就代表這套工作流規劃過關。

---

## 一、資料健檢與防呆注意事項（Gap Analysis 重點）

本專案屬於 **🟢 綠燈（實際原料與測試偽資料齊全，可直接開工）**，請確認 AI 有掌握以下關鍵規則：

| 檢查項目 | 業務背景重點 | AI 應做出的防呆反應（注意事項） |
|---|---|---|
| **1. MoM（月增率）** | Month-over-Month，這個月營收跟「上個月」比成長幾 % | `(本月 － 上月) ÷ 上月` |
| **2. YoY（年增率）** | Year-over-Year，這個月營收跟「去年同一個月」比成長幾 % | `(本月 － 去年同月) ÷ 去年同月`（可排除季節淡旺季干擾） |
| **3. N/A（缺值或零分母處理）** | 資料沒公布或去年同期營收為 0 時的標記方式 | **不可當作 `0` 填入**，須標記 `N/A` 並說明原因，且不納入增率排行榜 |
| **4. 四工作表產業矩陣** | 將分析濃縮成：摘要、營收比較、排名榜、來源查證四個工作表 | 讓高層先看摘要排名，又能一秒追查每筆數字的出處 |

## 二、資料分離與關卡規劃注意事項

* **固定知識庫（常駐 Project Knowledge）**：
    * [`01_案例規則.md`](02_AI清洗後教材_課堂實作專用/固定資料表/01_案例規則.md)（基礎 MoM/YoY 與防幻覺規則）
    * [`02_輸入欄位與清洗檢查.md`](02_AI清洗後教材_課堂實作專用/固定資料表/02_輸入欄位與清洗檢查.md)（輸入欄位與清洗檢查）
    * [`03_進階_同業營收規則.md`](02_AI清洗後教材_課堂實作專用/固定資料表/03_進階_同業營收規則.md)（進階 39 家同業營收矩陣規則）
* **動態輸入（每期換批上傳）**：
  * 第 1 批練習原料：`02_AI清洗後教材_課堂實作專用/使用者提供/01_課堂練習_偽資料.xlsx`
  * 第 2 批換批測試：`02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx`
* **建議關卡架構（2 道關卡：產出 `RTCCF_step1~2.md` ＋ 最後組裝 `RTCCF_main.md`）**：
  1. **關卡 1｜營收核對、MoM/YoY 計算與排名（`RTCCF_step1.md`）**：先產出 `RTCCF_step1.md`，依唯一代號鍵核對 39 家營收與來源，計算月增率與年增率（缺值標 `N/A`），產出排名與檢核表 `.md` 後封存 `step1`。
  2. **關卡 2｜四工作表競業矩陣 Excel 產出與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**：讀取已確認的 `.md` 分析表，調用 Python `openpyxl` 生成含摘要、比較、排名與來源查證的四工作表 `.xlsx`，封存 `step2` 並組裝 `RTCCF_main.md`。

## 三、執行與驗收注意事項（Checklist）

不論您用哪一套 AI 工具產出規格與成品，驗收時請務必核對以下項目：

- [ ] 全部同業代號與本月／上月／去年同月基數是否與輸入資料 100% 一致？
- [ ] MoM 與 YoY 公式計算無誤，且缺漏或分母為 0 者均標為 `N/A` 而非填入 0？
- [ ] 排行榜是否排除 `N/A` 者並正確由高至低（同率依代號）排序？
- [ ] 產出的 `.xlsx` 四工作表數值與關卡 1 `.md` 完全吻合，且附來源查證頁？
- [ ] 使用第 2 批同業資料執行 `RTCCF_main.md` 時，是否能自動重新排名並產出新報表？
