## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜資料異常篩檢與持分特徵計算（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，用 Python 檢查重複編號與分母異常，計算持分面積、坪數與單價，分離住宅／道路候選／大宗候選，產出清洗檢核 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜四合一戰情 Excel 生成與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已核對的檢核表 `.md`，透過 `openpyxl` 生成四合一戰情分析活頁簿 `.xlsx`，封存 `step2` 並組裝 `RTCCF_main.md`。
4. **Step 4｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`02_換批驗證_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **異常筆數先剔除再計算**：交易編號重複、面積 ≤ 0、持分分母 ≤ 0 或分子 > 分母者，須標記異常且不計算衍生指標。
2. **住宅與道路用地嚴格分離**：使用分區含「道路」者獨立標記為「道路候選」，絕不混入住宅區平均單價計算。
3. **坪數換算係數精準鎖定**：固定使用 `1 坪 = 3.305785 m²`，持分坪數 ≥ 100 標記「大宗」。
4. **兩關中斷人工確認**：關卡 1 必須先產出 `.md` 核對有效／異常筆數與區域統計，確認後才生成戰情 Excel。
