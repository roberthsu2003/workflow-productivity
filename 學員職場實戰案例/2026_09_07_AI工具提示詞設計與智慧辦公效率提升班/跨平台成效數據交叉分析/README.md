## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜跨通路指標標準化與計算（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，核對各平台曝光、點擊、轉換、費用或營收口徑，正確計算比率與增減幅度（缺比較期標 `N/A`、零轉換防除以零），產出檢核表 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜異常歸因、決策建議與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已核對數據，標記異常變動、提煉行銷事件對照與下期預算建議，輸出完整分析報告 `.md`，封存 `step2` 並組裝 `RTCCF_main.md`。
4. **Step 4｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`02_換批驗證_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **嚴禁跨平台人數直接加總**：官網工作階段、FB 觸及、IG 曝光不可加總宣稱為「不重複總人數」。
2. **缺上期或分母為 0 誠實標 `N/A`**：首月無前月資料時月增率標 `N/A`；轉換數為 0 時不出現除以零錯誤。
3. **異常判讀與事實分離**：僅依數據指出明顯波動與行銷檔期對照，不無端腦補因果關係。
4. **輸出格式清晰可驗算**：保留百分比小數 2 位、原始總額與計算公式說明。
