# 輸入欄位與清洗檢查

本表描述課堂偽資料的欄位；實際資料的欄位、單位與使用權限應另行確認。

| 欄位 | 清洗及確認方式 |
| :--- | :--- |
| 日期 | 確認日期或期間與報表一致，保留來源文字。 |
| 早班需求 | 確認計量單位與正負號；缺值與零分開。 |
| 晚班需求 | 確認計量單位與正負號；缺值與零分開。 |
| 小安可上 | 保留原值並確認格式；空白列為待確認。 |
| 小文可上 | 保留原值並確認格式；空白列為待確認。 |
| 小林可上 | 保留原值並確認格式；空白列為待確認。 |

## 清洗後檢查

- 保留來源資料與處理後版本，以便逐筆追溯。
- 檢查筆數、重複、空白與格式；不得把空白自動轉為零。
- 換批後重新檢查欄位、單位與例外，再進入關卡。
