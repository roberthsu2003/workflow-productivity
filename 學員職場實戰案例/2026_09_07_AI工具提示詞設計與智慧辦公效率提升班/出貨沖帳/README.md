# 📦 進銷存出貨沖帳與四欄平帳自動化

> 📖 **這個業務在做什麼？（非本科新手先看這段）**  
> 倉儲與會計在核對「進貨、退貨、POS 銷貨、結清」四欄數量時，常遇到缺漏結帳單或銷貨單號、導致數量對不起來的呆帳問題。本工作流依品號精準補號並彙總四欄數量，加總為零才標記沖帳完成（V）。

## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜單號補齊檢查與四欄彙總（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，依品號找唯一進貨候選補號（多組或零組列待確認），加總四欄數量判斷是否標 `V`，產出純文字檢核表 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜沖帳結果 Excel 套表與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已人工核對的 `.md` 檢核表，透過 Python `openpyxl` 生成三工作表沖帳結果 `.xlsx`，封存 `step2` 並組裝 `RTCCF_main.md`。
4. **Step 4｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`02_換批驗證_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **單一候選補號鐵則**：同品號進貨數 > 0 且單號完整者「恰有一組」才能補號，零組或多組皆列待確認。
2. **四欄合計為零才標 `V`**：分別加總進貨、退貨、POS 銷貨、結清四欄，總和為 0 標 `V`，不等於 0 列出差額。
3. **空白數量防呆**：缺少數量欄位不得默認為 0，須標示待確認避免掩蓋帳務差異。
4. **數量平帳與單號例外分開紀錄**：四欄加總為 0 不代表該品號的單號問題已解決，兩者須獨立驗收。
