# 輸入欄位與清洗檢查

本表描述課堂偽資料的欄位；實際資料的欄位、單位與使用權限應另行確認。

| 欄位 | 清洗及確認方式 |
| :--- | :--- |
| 品號 | 以文字保留完整字元；檢查缺值和重複，勿推測。 |
| 結帳單 | 保留原值並確認格式；空白列為待確認。 |
| 銷貨單 | 保留原值並確認格式；空白列為待確認。 |
| 進貨數 | 確認計量單位與正負號；缺值與零分開。 |
| 退貨數 | 確認計量單位與正負號；缺值與零分開。 |
| POS銷貨數 | 確認計量單位與正負號；缺值與零分開。 |
| 結清數量 | 確認計量單位與正負號；缺值與零分開。 |

## 清洗後檢查

- 保留來源資料與處理後版本，以便逐筆追溯。
- 檢查筆數、重複、空白與格式；不得把空白自動轉為零。
- 換批後重新檢查欄位、單位與例外，再進入關卡。
