# 步驟三：生成出貨沖帳完成 Excel 發布檔提示詞

> 💡 **教學情境**：在 ChatGPT Canvas 畫布中微調與審核核銷資料無誤後，進入財務落地發布階段。本步驟指導 AI 使用 Python 程式庫（openpyxl / pandas），將完成單號填補、沖帳驗算後的資料，直接輸出為具備企業級美觀版面的 `.xlsx` 活頁簿，方便直接存檔、歸檔或呈報主管！  
> 🛠️ **適用平台**：ChatGPT（具備進階資料分析 / Code Interpreter 能力之對話視窗）或支援 Python 執行的 AI 代理。

---

## 📋 提示詞複製專區

請將下方內容直接複製貼入剛才完成核銷檢核的 ChatGPT 對話框中：

```markdown
## Role

你是一位專精於 Excel 資料工程與財務自動化的 Python 專家，擅長使用 `openpyxl` 產出排版專業、具備動態公式與條件式格式化的企業級試算表。

## Task

請根據剛才核銷確認無誤的「出貨沖帳資料」，編寫並執行 Python 程式碼，直接生成一份可供直接下載的 Excel 活頁簿檔案（檔名：`出貨沖帳_已完成沖帳.xlsx`）。

## Structure & Requirements

這份 Excel 活頁簿必須具備以下架構與專業細節：

1. **多工作表（Sheet）架構**：
   - **工作表 1【出貨沖帳明細表】**：
     * 工作表名稱：`出貨沖帳明細表`
     * 內容：保留原表 23 欄完整架構。
     * 單號補齊：將先前空白之 23 列結帳單與銷貨單填入正確單號，並將這些被 AI 補齊的儲存格加上「柔和淺綠底色（#E2EFDA）」，方便主管快速核對變更。
     * 異常標記：針對全表查無進貨單號之品號（如 `816466`、`816481`），在單號欄位填入「`⚠️待確認單號`」並以淺黃底色標註。
     * 沖完狀態：若該品號總和已平帳（進貨 + 退貨 + POS + 結清 = 0），在「巳沖完」欄位填入粗體綠色「`V`」。
   - **工作表 2【品號沖帳彙總表】**：
     * 工作表名稱：`品號沖帳彙總表`
     * 欄位：`品號`、`品名`、`總進貨數`、`總退貨數`、`總POS銷售`、`總結清數量`、`沖帳餘額(Net)`、`沖帳狀態`。
     * 計算方式：`沖帳餘額 = 總進貨數 + 總退貨數 + 總POS銷售 + 總結清數量`。
     * 狀態標註：若餘額 $= 0$ 顯示「`✅ 已沖完(V)`」；若餘額 $\neq 0$ 顯示「`⚠️ 尚有餘額`」，一目了然！
   - **工作表 3【異常待確認品號】**：
     * 工作表名稱：`異常待確認品號`
     * 內容：專門列出表中無任何進貨單號可供對照的品號明細，提供會計人員向採購/業務部門進一步確認。

2. **視覺與排版美化規範**：
   - 表頭標題列：使用沈穩海軍深藍色底（#1F4E79）搭配白色粗體字，列高設定為 28。
   - 資料儲存格：文字靠左置中、日期與單號置中、金額與數量數值靠右對齊並設定千分位格式（`#,##0` 或 `#,##0.0`）。
   - 外框格線：全表套用細灰色格線（Thin Borders），表頭套用雙線底框。
   - 自動欄寬：所有欄位依文字長度自動計算適當欄寬（Auto-fit width，額外保留 3~4 字元空間），確保文字不被截斷、絕不出現 `###`。

請直接執行 Python 程式產出 `.xlsx` 檔案，並在回覆中提供該檔案的直接下載連結！
```

## 💡 教學引導亮點

* **高亮變更儲存格（Audit Trail）**：在正式財務作業中，自動填補單號最忌諱「改了什麼看不出來」。要求 AI 將補填儲存格套上淺綠底色，正是資深會計主管最讚賞的專業防呆細節！
* **雙層檢驗（明細 ＋ 彙總）**：除了原本的明細表之外，自動生成「品號沖帳彙總表」，能讓主管在 3 秒鐘之內看清 60 個品號各自的沖銷餘額，極大提升溝通效率。
