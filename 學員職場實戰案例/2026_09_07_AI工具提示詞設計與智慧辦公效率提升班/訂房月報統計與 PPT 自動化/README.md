## 🚀 獨立專案實作流程（不限 AI 平台，掌握注意事項即可）

1. **Step 1｜啟動架構師體檢或互動建置**
   * 將「原料 1～4」上傳至您使用的 AI（Claude / ChatGPT / Gemini），依需求套用 [**路線 A：體檢評估提示詞**](../../00_AI工作流架構師實戰指南/01_路線A_AI工作流架構師評估提示詞.md) 或 [**路線 B：一問一答提示詞**](../../00_AI工作流架構師實戰指南/02_路線B_互動式漸進生成RTCCF提示詞.md)。
2. **Step 2｜關卡 1｜加權指標精算與洞察提煉（`RTCCF_step1.md`）**
   * 先產出 `RTCCF_step1.md`，檢核鍵值重複與負數，依加權口徑計算房晚、營收、ADR、目標達成率與 YoY，產出指標摘要 `.md` 後封存 `step1`。
3. **Step 3｜關卡 2｜16:9 原生圖表簡報生成與總控組裝（`RTCCF_step2.md` ＋ `RTCCF_main.md`）**
   * 讀取已核對的指標 `.md`，調用 Python `python-pptx` 生成 3 頁式 16:9 簡報 `.pptx`，封存 `step2` 並組裝 `RTCCF_main.md`。
4. **Step 4｜用第 2 批測試資料進行換批驗證**
   * 開新對話呼叫 `RTCCF_main.md`，上傳 [`02_換批驗證_偽資料.xlsx`](02_AI清洗後教材_課堂實作專用/使用者提供/02_換批驗證_偽資料.xlsx)，驗證工作流是否能全自動跨期通用產出第 2 批成果！

## ⚠️ 關鍵注意事項（每個 AI 產出不同，請抓準這 4 點）

1. **加權 ADR 不可妥協**：跨館／跨月合併房價必須用 `營收總和 ÷ 房晚總和`，嚴禁算術平均。
2. **零分母與缺值防呆**：房晚為 0 時 ADR 標 `N/A`；缺去年同期時 YoY 標 `N/A`。
3. **目標表精準對位**：依「年月＋館別」對齊目標 ADR，且不計算跨館整體目標達成率。
4. **PPTX 版面與圖表核對**：簡報圖表數值須與 `.md` 摘要 100% 一致，且文字無重疊遮擋。
