# 輸入欄位與清洗檢查

本表描述課堂偽資料的欄位；實際資料的欄位、單位與使用權限應另行確認。

| 欄位 | 清洗及確認方式 |
| :--- | :--- |
| 員工 | 保留原值並確認格式；空白列為待確認。 |
| 出勤日 | 保留原值並確認格式；空白列為待確認。 |
| 每日正常時數 | 確認計量單位與正負號；缺值與零分開。 |
| 每日加班時數 | 確認計量單位與正負號；缺值與零分開。 |
| 保費 | 確認單位及數值格式；缺值不得視為零。 |
| 預支 | 確認單位及數值格式；缺值不得視為零。 |

## 清洗後檢查

- 保留來源資料與處理後版本，以便逐筆追溯。
- 檢查筆數、重複、空白與格式；不得把空白自動轉為零。
- 換批後重新檢查欄位、單位與例外，再進入關卡。
