# 廣告指標與預算規則

## 1. 指標公式（固定）
- CTR = 點擊 ÷ 曝光（小數 2 位百分比）
- CPC = 費用 ÷ 點擊（新台幣元，小數 1 位）
- CPA = 費用 ÷ 轉換（轉換 = 0 時顯示「無轉換」）
- ROAS = 轉換價值 ÷ 費用（倍數，小數 2 位）

## 2. 異常門檻（待主管確認後填入）
- 規則 A：費用 > 20,000 元 且 ROAS < 2.0 → 🔴 高風險
- 規則 B：CPC 較上期增加 30% 以上 → 🟠 CPC 暴增
- 規則 C：費用 > 0 且轉換 = 0 → 🟠 花費無效

## 3. 預算調整原則（待主管確認後填入）
- 下週總預算：與本週相同（或依主管指定總額）
- 單一平台單週調整上限：±20%
- 各平台保底預算：最低 2,000 元
- 調整方向：ROAS 高者加碼、觸發規則 A 者減碼
