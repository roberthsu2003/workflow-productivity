# 🌿 工研院綠能所專屬 Skill 實戰（第一階：模仿者篇）

> **模組名稱**：工研院公文、研發簽呈與產學合作回覆信函修飾專家（ITRI GEL Official Comms Expert）  
> **所屬階段**：🟢 **第一階：模仿者 (Imitator)** —— 單獨建立高標準之 `SKILL.md`  
> **適用對象**：工研院綠能所各組研究員、計畫主持人、專案工程師與行政秘書。  
> **輸出成果**：符合行政機關與財團法人規範之正式公文、內部簽呈、產學合作洽詢回覆函與營業秘密保護宣告。  

---

## 💡 為什麼第一階（模仿者）對工研院綠能所同仁極為重要？

在工研院等國家級科研機構中，研究人員日常需要應對來自各界的繁重溝通：
1. **公文程式嚴謹性**：往來經濟部能源署、環境部、國科會或台電的函文，需嚴格遵循「主旨、說明、辦法」三段式架構，用詞精確得體。
2. **科技法人分寸拿捏**：面對民間能源廠商、開發商的技術合作洽詢，既要熱情展現工研院綠能研發能量，又絕不能在信件中過度承諾（如避免保證絕對發電量或零故障），並須守護關鍵核心智財權（主動引導簽署 NDA）。
3. **消除雜亂口語**：研究員常忙於實驗室與風場場勘，手邊只有手機隨手打下的簡略碎片字句，需要一鍵轉化為院內簽呈或正式函稿。

---

## 📁 本自訂 Skill 結構

本範例為最經典的 **第一階：模仿者** 架構，僅需單一 `SKILL.md` 即可建立專屬數位秘書：

```text
ITRI_Imitator/
├── README.md   # 本教學導引與測試指引
└── SKILL.md    # 核心技能定義檔（定義 Role、Task、法人分寸原則與輸出模板）
```

### ✍️ 方式 B：手動在 Claude 網頁介面建立（推薦課堂實作）

1. 登入 [Claude.ai](https://claude.ai)，點選左下角個人頭像 ➔ 前往 **Customize** ➔ **Skills**。
2. 點擊右上角 `+` ➔ **Create skill** ➔ 選擇 **Write skill instructions**。
3. 依據以下欄位輸入：
   - **Skill name**：
     ```text
     工研院綠能所公文與產學信函專家
     ```
   - **Description**：
     ```text
     將綠能所雜亂口語工作筆記，轉換為符合公文程式條例與智財保護之正式公文、簽呈與產學合作回函。
     ```
   - **Instructions**：直接複製並貼上 [**SKILL.md**](./SKILL.md) 的完整內文。
4. 點擊 **Create** 按鈕儲存。確認清單中出現該 Skill 即代表安裝成功！

### 📝 測試案例 1：公文回覆（對接台電進度詢問）

**自然語言測試輸入（直接複製測試）：**

```markdown
台電發公文問我們離岸風機那邊監測系統什麼時候裝好，說他們長官在催進度。
跟他們說我們現在感測器晶片卡關，下個月才會到貨，
預計最快 11 月底前去現場試裝，請他們別急。
```

```markdown
## Role
你是一名任職於工研院綠能所的**資深公文修飾專家兼主任秘書**。

## Task

- 原始口語筆記：
  「台電發公文問我們離岸風機那邊監測系統什麼時候裝好，說他們長官在催進度。
  跟他們說我們現在感測器晶片卡關，下個月才會到貨，
  預計最快 11 月底前去現場試裝，請他們別急。」

## Context
- 發文單位：**工業技術研究院 綠能與環境研究所**
- 受文單位：**台灣電力股份有限公司**
- 規範依據：公文程式條例、院內對外函稿格式標準

## Constraint
- 化解口語與負面詞彙（如「卡關、別急」），改以專業工程語言（如「因應特殊規格出廠耐環境校驗」）。
- 嚴禁過度承諾，清楚說明預計現地整合時程。
- 使用**繁體中文**輸出。

## Format
產出標準兩大部分：
1. **正式公文函稿**（含：發文機關、受文者、主旨、說明）
2. **秘書室溫馨提示**（關鍵術語替換對照表、附件與行政呈核提醒）
```

</details>

**預期效果：**
- 自動生成標準公文三段式架構（主旨、說明）。
- 自動化解「卡關、別急」等非正式字眼，改以「因應抗鹽霧及 Class T 耐颱特殊規格，現正配合原廠進行出廠耐環境校驗」展現專業嚴謹。
- 附帶「秘書室溫馨提示」，提醒附件整備與公文擬核注意事項。

### 📝 測試案例 2：產學研發洽詢回函（對接民間儲能開發商）

**自然語言測試輸入（直接複製測試）：**

```markdown
某個民間儲能系統廠寄信來問說，想請我們幫忙測他們的電池櫃會不會爆炸，
還想跟我們要綠能所最新那套熱失控預警演算法的原始碼。
回覆跟他說我們實驗室排程很滿，但如果他們願意出產學研究費可以排在明年初，
至於演算法不能直接給，要先簽 NDA 才能聊。
```

```markdown
## Role
你是一名工研院綠能所的**智財法務專家兼產學合作研發秘書**。

## Task
請依據以下研究員的口語草稿，撰寫一封兼具產學合作熱忱與嚴密法規護城河的**正式商務合作回覆信函**：
- 原始口語筆記：
  「某個民間儲能系統廠寄信來問說，想請我們幫忙測他們的電池櫃會不會爆炸，
  還想跟我們要綠能所最新那套熱失控預警演算法的原始碼。
  回覆跟他說我們實驗室排程很滿，但如果他們願意出產學研究費可以排在明年初，
  至於演算法不能直接給，要先簽 NDA 才能聊。」

## Context
- 洽詢對象：民間儲能系統設備開發商
- 涉及技術：儲能櫃大型燃燒防阻測試、電池熱失控預警演算法
- 法務依據：工研院產學研發合約規範、營業秘密法

## Constraint
- 將口語「會不會爆炸」優雅替換為專業法規用語（如「依據 CNS 62933-5-2 與 UL 9540A 規範進行大型燃燒與熱失控延燒防阻測試」）。
- 嚴格守護專利演算法原始碼，明訂「涉及本所核心專利技術，建議簽署保密協定 (NDA) 後進一步交流」。
- 使用**繁體中文**輸出。

## Format
請產出高規格產學商務回函：
1. **正式產學合作回覆信函**（稱謂、感謝來函、驗證排程建議、智財保密協議程序、正式署名）
2. **秘書室溫馨提示**（專利保護守則、產學委託合約範本檢附提醒）
```

</details>

**預期效果：**
- 輸出高規格商務產學合作回函，展現工研院輔導產業之熱忱，同時明確建立智財與法規護城河。
- 將「會不會爆炸」優雅替換為「依據 CNS 62933-5-2 與 UL 9540A 規範進行大型燃燒與熱失控延燒防阻測試」。
- 清楚劃定專利界限，主動提供標準產學委託合約與 NDA 簽署標準程序。
