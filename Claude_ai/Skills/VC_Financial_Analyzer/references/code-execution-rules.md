# 🎨 背景 Code Execution 數據計算與圖表視覺化規範指南 (Code Execution Rules)

在 `VC_Financial_Analyzer` 中，背景數據運算與圖表繪製由 Claude 的 Analysis Tool 自動處理。本文件提供自然語言級別的視覺與運算原則指引，**學員無需編寫任何程式碼**。

---

## 1. 數據計算與格式規範 (Data Guidelines)

1. **多工作表 (Multi-Sheet) 自動解析**：
   - 指示 Claude 於背景自動掃描 Excel 中的所有工作表（如「損益表」、「現金流」、「KPIs」），無需手動分割檔案。
2. **數字格式化呈現**：
   - 金額數據輸出時統一格式化為千分位，如 `$1,250,000` 或 `NT$ 4,500,000`。
   - 所有成長率與毛利率百分比保留小數點後 1 位，如 `78.5%`。

---

## 2. 創投 IC 委員會圖表美感規範 (Chart Aesthetics)

為符合創投高階視覺要求，指示 Claude 在背景繪圖時遵守以下風格：

1. **配色方案 (Color Palette)**：
   - 主數據（營收 / 期末現金）：採用濃郁海軍藍 (`#1F4E79`) 或 深青綠 (`#008080`)。
   - 次數據（成本 / 費用）：採用中性鐵灰 (`#808080`)。
   - 警訊數據（燒錢 / 虧損 / 警戒線）：採用警告紅 (`#C00000` / `#E53E3E`)。
   - 正向數據（盈利 / 成長）：採用翠綠 (`#2E7D32`)。
2. **圖表清晰度與標籤**：
   - 設置 Data Labels（數據標籤），讓讀者能一眼看清具體數值。
   - 清晰標示 X 軸（月份/時間）與 Y 軸（金額/月數）單位。
   - 在中文字體顯示上保持簡潔清晰無亂碼。

---

## 3. 圖表樣式設計說明 (Chart Design Guidance)

### 📈 1. 營收 vs. 費用消長趨勢圖 (Revenue & Expense Trend)
- **設計邏輯**：使用柱狀圖呈現「總營收」與「總營業費用」的消長，並疊加「淨損益/EBITDA」折線圖，直觀展現公司是否接近損益平衡點。

### 📉 2. 期末現金餘額與 Cash Runway 趨勢圖
- **設計邏輯**：使用面積填充圖展現「期末現金餘額」的消耗趨勢，並在圖中特別劃設 **6 個月安全警戒線 (Safety Limit)**，方便投資委員會判斷現金流斷裂點。
