# 工研院綠能所 研發專案技術成熟度 (TRL) 與效益評核標準指引

本規章為工研院綠能與環境研究所（ITRI GEL）內部執行政府科研計畫（經濟部能源署、國科會）與產業前瞻合作之技術評核標準。

---

## 1. 綠能技術成熟度 (Technology Readiness Levels, TRL 1~9)

| TRL 層級 | 階段定義 | 綠能所代表性研發產出指標 | 查核驗收重點 |
| :---: | :--- | :--- | :--- |
| **TRL 1~2** | 基本原理發現與概念形成 | 綠能新材料（如固態電解質、新型碳捕捉吸附劑）之文獻探索與分子模擬。 | 產出學術論文或技術探索白皮書。 |
| **TRL 3~4** | 實驗室可行性概念驗證 (PoC) | 扣式電池充放電測試、微型風洞葉片氣動縮比模型測試（<1 kW）。 | 實驗室環境數據重現性、基礎專利申請。 |
| **TRL 5~6** | 次系統於模擬環境之整合驗證 | 100 kW 儲能貨櫃次系統整合、無人機自動巡檢 4K 影像微裂紋辨識演算法驗證。 | 通過 IEC/CNS 基本安規、完成工廠端整合測試 (FAT)。 |
| **TRL 7~8** | 真實示範場域之全系統原型運轉 | 陸域 4~6 MW / 離岸 14~16 MW 風場現地實測、MW 級電網端儲能即時調頻（E-dReg）。 | 連續併網運轉測試逾 1,000 小時、取得第三方驗證認證。 |
| **TRL 9** | 商業化量產與全面技術移轉 (Tech Transfer) | 技術授權國內外系統整合廠（SI）或製造商，建立完整國產化供應鏈。 | 簽訂技術移轉授權合約、達成產業化營運實績。 |

## 2. 綠能科研關鍵績效指標 (KPI) 評核維度

綠能所專案報告必須量化呈現以下四大維度：

1. **能源效率與發電性能 (Efficiency & Performance)**：
   - 風力發電：機組可用率（Availability $\ge 97\%$）、容量因數（Capacity Factor $\ge 42\%$）、切入/額定/切出風速響應。
   - 儲能系統：充放電往返效率（Round-Trip Efficiency, RTE $\ge 86\%$）、系統反應時間（Response Time $< 200\text{ ms}$）。
   - 氫能與燃料電池：水電解產氫能耗（$< 4.5\text{ kWh/Nm}^3$）、電堆耐久度（降解率 $< 1\% / 1,000\text{ hr}$）。
2. **減碳效益與綠色影響力 (Decarbonization Impact)**：
   - 每年預估發電量（MWh / GWh）。
   - 依據經濟部最新公告電力排碳係數（例如 $0.495\text{ kg CO}_2\text{e/kWh}$）換算年度總減碳當量（噸 $\text{CO}_2\text{e/年}$）。
3. **智財布局與專利實力 (IP & Patent Portfolio)**：
   - 區分「發明專利（Invention Patent）」與「新型專利（Utility Model）」。
   - 標註抗颱減震、熱失控阻隔、動態偏航控制等核心國際專利（台、美、歐、日）。
4. **經濟與產業帶動效益 (Economic Feasibility)**：
   - 平準化度電成本（LCOE, NTD/kWh）改善幅度。
   - 預估帶動民間投資額與技術移轉權利金收益。
