# 📊 實戰 2：Google Sheets 敏捷任務追蹤表與自動試算

> **所屬章節**：[Google Workspace Skills 實戰](../README.md) ➔ **練習 2**  
> **運作模式**：💬 **一般對話模式（Chat Prompts）**  
> **預計實作時間**：10 分鐘  
> **所需 Skill / 工具**：🔹 **Google Sheets Skill**（或 Google Workspace 連接器）  
> **前置要求**：開啟 `Code execution and file creation` 並授權 Google Drive

---

## 🎯 任務目標

學習如何將零散交辦的多部門待辦事項，先於 Claude Artifacts 中組織為具備截止日排序、優先級判定與狀態標籤的結構化試算表草案；經使用者審核後，自動於雲端建立正式 Google Sheets 試算表，並存檔於 Google Drive「上課用」資料夾。

## 📋 複製貼上 RTCCF Prompt（直接執行）

本範例採用 **RTCCF 模型** 組織提示詞結構（其中 **R、C、C、F 為 Optional 選填**，學員可依需求調整；`Task` 為核心必要項目）。

打開 Claude [一般對話視窗](https://claude.ai)，點擊右上角一鍵複製貼入：

```markdown
## Role (Optional)
你是一位行政效率顧問，
擅長運用 Google Sheets 建立標準敏捷任務追蹤表，並能運用 Google Workspace 工具管理雲端檔案。

## Task
請將我提供的待辦任務清單，整理成一份專業的任務追蹤表：
1. 先於 Claude Artifacts 中以 Markdown 表格呈現草稿與欄位規劃。
2. 待我確認無誤後，再調用 Google Sheets 工具在我的雲端硬碟建立試算表，並歸檔至「上課用」資料夾。

## Context (Optional)
待辦任務清單：
- 採購 3 台 27 吋高解析設計螢幕
  （負責人：王小明，截止：2026-06-20，優先級：P1，備註：已送簽核）
- 更新員工手冊 2026 年度修訂版
  （負責人：李小華，截止：2026-06-30，優先級：P2，備註：法規與人資審閱中）
- 安排 Q2 部門實體聚餐與場地預約
  （負責人：陳小美，截止：2026-06-15，優先級：P2，備註：預算已核准）
- 整理 Q1 全球經銷商合約正本歸檔
  （負責人：王小明，截止：2026-07-05，優先級：P3，備註：等待海外快遞回傳）
- 中南部競品定價分析簡報彙整
  （負責人：李小華，截止：2026-06-22，優先級：P0，備註：供 6/23 晨會報告用）

## Constraint (Optional)
- 語言：繁體中文
- 欄位規劃：任務編號、任務名稱、負責人、截止日期、優先級、目前狀態（預設：待處理）、備註說明
- 排序邏輯：依照「截止日期」由近到遠自動遞增排序（6/15 聚餐排第一，7/05 合約排最後）
- 試算表命名：「2026-06 專案任務追蹤表」
- **四階段工作流程限制（Human-in-the-Loop）**：
  1. 第一步（草稿產出）：請先使用 Claude Artifacts 呈現排序後的表格預覽。
  2. 第二步（停頓確認）：在此步驟**不要**呼叫 Google Sheets 工具！詢問我是否需要增修欄位。
  3. 第三步（建立試算表）：待我明確回覆「可以建立」後，才呼叫 Google Sheets 工具建立線上檔案。
  4. 第四步（資料夾歸檔）：將該試算表存放在 Google Drive 根目錄下的 **「上課用」** 資料夾中（若不存在請自動建立）。

## Format (Optional)
- 建立 Google Sheets 試算表
- 完成後回傳線上編輯連結，並列出已建立的欄位清單與列數
```

---

## 🚦 課堂互動推進指令

1. **第一輪**：貼上 Prompt ➔ Claude 於 Artifacts 呈現按截止日排序之表格草稿，主動停下詢問。
2. **第二輪（通關推進）**：在對話框輸入：
   ```text
   確認無誤，可以建立！
   ```
3. Claude 將調用工具生成 Google Sheets 檔案並存入「上課用」資料夾，回傳直達線上試算表連結。
