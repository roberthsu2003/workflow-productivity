> **預計實作時間**：10 分鐘

> **前置要求**：完成 Gmail 授權

## 🎯 任務目標

學習如何輸入採購發包與時限要求，引導 Claude 先於 Artifacts 呈現具備商務禮儀與專業威嚴的信件草稿；確認無誤後，調用 Gmail 工具在您的真實 Gmail 中建立郵件草稿（Draft），並自動套用名為「**上課用**」的標籤分類（Label），確保不會誤發郵件。

## 📋 複製貼上 RTCCF Prompt（直接執行）

本範例採用 **RTCCF 模型** 組織提示詞結構（其中 **R、C、C、F 為 Optional 選填**，學員可依需求調整；`Task` 為核心必要項目）。

打開 Claude [一般對話視窗](https://claude.ai)，點擊右上角一鍵複製貼入：

```markdown
## Role (Optional)
你是一位資深的商業採購與供應鏈管理顧問，
擅長依照採購要點草擬專業、嚴謹且有禮貌的商務郵件，並能運用 Gmail 工具管理雲端郵件與標籤。

## Task
請依我提供的採購資訊，先於 Claude Artifacts 中規劃一封正式的交期確認信草稿；
待我討論確認後，再調用 Gmail 工具在我的 Gmail 中建立草稿，並為該郵件套用「上課用」分類標籤。

## Context (Optional)
採購發包資訊：
- 收件人：台灣聯動電氣科技 業務窗口 <supplier@example.com>
- 採購單號：PO-2026-0609
- 下單日期：2026 年 6 月 9 日
- 核心溝通重點：
  1. 我方已於 6/9 在系統發出 PO-2026-0609 採購單，請廠商協助確認接單。
  2. 請業務窗口於 24 小時內回覆工廠預計出貨日期（ETA）。
  3. 為配合沙崙示範園區現場組裝，我方總部庫房最晚需在 6 月 20 日前收到全部貨品。
  4. 若有晶片短缺或航運延誤等異常，請務必提前來信或來電告知，以便協調調配。
  5. 語調：商務正式、講求時效、禮貌且尊重長期夥伴關係。

## Constraint (Optional)
- 語言：繁體中文
- 結尾簽名檔：
  王小明｜星橋科技 採購部專員
  電話：(02) 2700-1234 分機 1234
  Email: ming.wang@bridge-tech.example.com
- **四階段工作流程限制（Human-in-the-Loop）**：
  1. 第一步（草稿產出）：請先使用 Claude Artifacts 功能，呈現完整郵件草稿（含收件人、主旨、內文、簽名檔）。
  2. 第二步（停頓確認）：在此步驟**嚴禁**呼叫 Gmail 工具建立或寄出郵件！向我詢問語氣或條件是否需要調整。
  3. 第三步（建立草稿）：待我明確輸入「草稿確認，建立信件」後，呼叫 Gmail 工具將此信件建立於 Gmail「草稿匣（Drafts）」，**嚴禁直接發送**！
  4. 第四步（套用標籤）：請為該郵件草稿套用名稱為 **「上課用」** 的標籤（若標籤不存在請自動建立）。

## Format (Optional)
- 在 Artifacts 視窗呈現完整信件草稿
- 我確認後呼叫 Gmail 工具建立草稿，並回傳操作結果與「已套用『上課用』標籤」的確認資訊
```

## 🚦 課堂互動推進指令

1. **第一輪**：送出 Prompt ➔ Claude 於 Artifacts 呈現正式雙方商務回函草稿，主動停止輸出並詢問。
2. **第二輪（確認建立）**：在對話框輸入：
   ```text
   草稿確認，建立信件
   ```
3. Claude 將調用 Gmail 工具建立草稿，並打上「上課用」標籤，回傳操作成功訊息。

## ✅ 成果驗收點

- [ ] **安全煞車生效**：第一輪未直接存檔，主動停下由使用者把關內容。
- [ ] **高情商商務措辭**：信件既表達出「6/20 必須入庫」的堅定時限，又保持合作夥伴之禮節。
- [ ] **信件僅存於草稿匣**：登入 Gmail 檢查「草稿匣（Drafts）」，信件已完整建立，未誤發給外部。
- [ ] **「上課用」標籤正確標記**：信件左上方或側邊欄標註有名稱為「上課用」之彩色標籤。

## 💡 常見問題與除錯

* **Q：信件會不會自動寄給 supplier@example.com？**  
  * **解答**：**絕對不會！** 系統工具僅調用「Create Draft（建立草稿）」API，真正的發送按鈕必須由您親自在 Gmail 介面點擊「傳送」，安全無虞。
* **Q：如果信箱中沒有「上課用」標籤會出錯嗎？**  
  * **解答**：不會！Claude 會先檢查現有標籤清單，若不存在會自動調用 API 建立標籤後再掛載到該郵件上。
