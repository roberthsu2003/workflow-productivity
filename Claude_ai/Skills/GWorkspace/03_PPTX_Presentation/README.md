## 📋 複製貼上 RTCCF Prompt（直接執行）

打開 Claude [一般對話視窗](https://claude.ai)，點擊右上角一鍵複製貼入：

```markdown
## Role
你是一位頂尖的簡報視覺指導與商業演講顧問，擅長將要點精煉為結構清晰的簡報大綱，並能調用內建 PPTX Skill 產出實體 PowerPoint 簡報檔案。

## Task
請依我提供的業務成果要點，先規劃一份 5 頁投影片結構與大綱，在 Claude Artifacts 中呈現與我討論；待我確認無誤後，再調用內建 PPTX Skill 將其製作成 PowerPoint 簡報檔案 (.pptx) 供我下載。

## Context
簡報資訊：
- 主題：2026 Q2 業務成果與策略報告
- 對象：部門主管與經營管理層
- 核心要點：
  - Q2 業績達成率達 94%，超越原定目標 4%
  - 全季新簽約客戶 5 家，集中於北部高科技製造業
  - 下半年策略方針：深耕現有大客戶 (Upselling) 並開拓中南部經銷合作通道
  - Q3 展望目標：設定營收季增長 15%

## Constraint
- 語言：繁體中文
- 簡報設計配色：指定使用「Midnight Executive」配色方案（深藍 `#1E2761` / 冰藍 `#CADCFC` / 純白 `#FFFFFF`）。
- 固定 5 頁投影片架構：封面 → 本期成果 → 重點發現 → 下半年策略 → 結語與目標。
- 每頁重點條目不超過 4 條，文字需俐落精準。
- **三階段工作流程限制（Human-in-the-Loop）**：
  1. **第一步（大綱草稿）**：請先使用 Claude Artifacts 功能，呈現每頁投影片的標題、版面配置建議與大綱草稿。
  2. **第二步（停頓確認）**：在此步驟**嚴禁**呼叫 PPTX 產生工具！主動向我確認大綱與配色是否核准。
  3. **第三步（實體匯出）**：待我明確輸入「大綱核可，製作簡報」後，調用內建 PPTX Skill 產生實體 .pptx 檔案並提供下載按鈕。

## Format
- 套用指定配色，匯出可下載的實體 PowerPoint 簡報檔案 (.pptx)
- 完成後回傳檔案下載連結，並簡短摘要每頁投影片之核心論點
```

---

## 🚦 課堂互動推進指令

1. **第一輪**：送出 Prompt ➔ Claude 於右側 Artifacts 視窗展開 5 頁投影片草稿，主動停止輸出等待審核。
2. **第二輪（確認生成）**：在對話框輸入：
   ```text
   大綱核可，製作簡報
   ```
3. Claude 將調用 Python 環境的 PPTX Skill 動態渲染並封裝檔案，輸出可點擊直接下載的 `.pptx` 連結！

---

## ✅ 成果驗收點

- [ ] **Artifacts 討論閘門**：第一階段未自動輸出二進制檔案，乖乖停下等待指示。
- [ ] **實體 PPTX 下載連結**：第二階段執行完畢後，對話框出現實體 `.pptx` 下載按鈕。
- [ ] **5 頁標準架構完整**：下載並打開檔案後，5 頁投影片標題與文字精準對位。
- [ ] **Midnight Executive 配色生效**：投影片背景與標題正確套用深藍、冰藍與白色。

## 💡 常見問題與除錯

* **Q：點擊下載後打開 PPTX 會跑版嗎？**  
  * **解答**：Anthropic 官方 PPTX Skill 採用標準 16:9 寬螢幕規格與跨平台通用字型，相容於 Microsoft PowerPoint、Google Slides、Keynote 與 LibreOffice。
* **Q：可以放入圖片嗎？**  
  * **解答**：可以！若在對話中上傳剛才提供的 `2026_業務增長趨勢與成果視覺圖.png`，Claude 可在產生 PPTX 時將該圖片置入投影片中。
