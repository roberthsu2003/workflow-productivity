## ❓ 常見問題排查（FAQ）

### Q1：Claude 回應「I don't have direct access to PowerPoint export」或僅給出 Markdown 程式碼而沒有產出檔案？
- **原因**：目前使用的對話沒有啟動 Code Execution 工具，或您使用的是免費版 Claude。
- **解決方式**：請確認前往 Settings ➔ Capabilities 開啟「**Code execution and file creation**」。只要此開關開啟，Claude 官方內建的 PPTX Skill 即會自動生效並提供實體 .pptx 下載按鈕。

### Q2：如何將 `sample_files/` 內的大型風機工程示意圖插入投影片中？
- **操作方式**：
  1. 將 `大型陸域與離岸風力發電運維工程示意圖.jpg` 作為附件上傳至 Claude 對話視窗。
  2. 在 Prompt 加上指令：「請在第 3 頁或第 4 頁右側保留 4.5 吋寬之圖形區塊，並在調用 PPTX Skill 產出簡報時將此圖片嵌入對應頁面中」。
