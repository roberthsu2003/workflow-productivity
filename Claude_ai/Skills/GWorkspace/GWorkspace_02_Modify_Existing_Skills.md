# 實作範例 2：修改現有的 Skill（打造個人與公司工作流）

> 🟢 **方案需求**：Free（需先在 Settings 開啟 Skills 與程式碼執行）  
> 🎯 **學習目標**：學會編輯現有 `SKILL.md`，為 Docs、Sheets、Slides 與 Gmail 加上**公司 Logo、品牌名稱、警示規則與固定簽名檔**，打造符合企業規範的自動化助理。

本練習與 [練習 1：使用現有的 Skill](./GWorkspace_00_Use_Existing_Skills.md) 的 A、B、C1、C2、D 完美對照。我們將學習如何透過修改 Skill 的操作指引（`SKILL.md`），讓 Claude 產出的所有文件與郵件都符合特定的公司規範，而不需要每次都在 Prompt 裡重複說明。

---

## 🛠️ 修改 Skill 的通用步驟

1. 點擊 Claude 左下角個人頭像，前往 **Settings** → **Skills**。
2. 找到目標 Skill（例如 Google Docs），點擊其右側的 **「Edit」** 按鈕。
3. 編輯器會開啟該 Skill 的 `SKILL.md` 檔案。
4. 找到對應的區塊（通常是 `## Constraint` 或 `## Format`），將修改內容貼在最下方，然後點擊 **Save**。
5. 開啟新對話，呼叫該 Skill 測試修改是否生效。

## 練習 2-A：修改 Docs Skill 建立公司專屬會議紀錄

### 📖 修改目標
讓 Claude 建立的每份會議紀錄，第一行都必須包含**公司 Logo** 與**公司名稱**（創新科技股份有限公司），並使用正式的表格抬頭。

### ✍️ 如何修改 `SKILL.md`
請打開您的 **Google Docs Skill** 的 `SKILL.md`，在 `## Format` 區塊的最末尾加入：

```markdown
所有的會議紀錄文件，開頭必須嚴格遵守以下格式：
1. 第一行置中放置公司 Logo 圖片：![創新科技 Logo](https://picsum.photos/200/50)
2. 第二行置中放置粗體公司名稱：**🚀 創新科技股份有限公司 — 會議紀錄**
3. 隨後才是日期、與會人員與會議內容。
```

### 📋 測試用 RTCCF Prompt

```markdown
## Role
你是辦公室行政助手，擅長整理會議紀錄，並能運用已修改的 Google Docs Skill 管理雲端檔案。

## Task
請將我提供的會議要點，整理成一份正式的會議紀錄。請先與我討論確認大綱，確認後再呼叫已修改的 Google Docs Skill 建立文件，並儲存至 Google Drive 中名為「上課用」的資料夾。

## Context
會議資訊：
- 會議名稱：2026 年第二季業務檢討會
- 日期：2026-06-09
- 與會人員：王小明（主持）、李小華、陳小美
- 討論要點：
  - Q1 業績達成率 87%，Q2 目標上調 10%
  - 新客戶開發：本季新增 3 家，需加強中南部區域
  - 下次會議排定 6/23，小華負責準備競品分析

## Constraint
- 語言：繁體中文
- 文件結構：會議基本資訊 → 討論摘要 → 決議事項 → 行動清單（含負責人與期限）
- **工作流程限制**：
  1. **第一步**：請先使用 Claude Artifacts 功能，以 Markdown 格式呈現會議紀錄草稿（需包含我修改設定的公司 Logo 與抬頭）。
  2. **第二步**：詢問我是否需要修改。在此時**不要**建立文件。
  3. **第三步**：待我確認「可以建立」後，呼叫 Google Docs Skill 建立文件。
  4. **第四步**：將該會議紀錄存放在 Google Drive 的 **「上課用」** 資料夾中。

## Format
- 建立 Google Docs 文件，命名為「{日期} {會議名稱} 會議紀錄」
- 完成後回傳 Google Docs 的文件連結
```

## 練習 2-B：修改 Sheets Skill 建立具狀態警示的任務表

### 📖 修改目標
讓 Claude 建立任務追蹤表時，只要任務狀態為「逾期」，自動在備註欄填入「⚠️ 請儘速處理」，並在表格最底部自動加上一個「小計欄」顯示未完成的任務總數。

### ✍️ 如何修改 `SKILL.md`
請打開您的 **Google Sheets Skill** 的 `SKILL.md`，在 `## Constraint` 區塊的最末尾加入：

```markdown
試算表欄位填寫規則：
1. 檢查「截止日」與「狀態」。如果任務已超過截止日且狀態非「完成」，請自動在該列的「備註」欄位寫入「⚠️ 逾期，請儘速處理」。
2. 表格最後一列必須加上一行「未完成任務小計」，並在下方填入統計公式或未完成任務的加總數值。
```

### 📋 測試用 RTCCF Prompt

```markdown
## Role
你是辦公室行政助手，擅長使用 Google Sheets 建立任務追蹤表，並能運用已修改的 Google Sheets Skill 管理雲端檔案。

## Task
請將我提供的任務清單，整理成一份任務追蹤表。請先與我討論確認結構，確認後再呼叫已修改的 Google Sheets Skill 將其建立並儲存至 Google Drive 中名為「上課用」的資料夾。

## Context
任務清單：
- 採購 3 台 27 吋螢幕（負責人：王小明，截止：2026-06-05，狀態：待處理）-> 已過期！
- 更新員工手冊 2026 版（負責人：李小華，截止：2026-06-30，狀態：進行中）
- 安排 Q2 部門聚餐（負責人：陳小美，截止：2026-06-15，狀態：待處理）
- 整理客戶合約歸檔（負責人：王小明，截止：2026-07-05，狀態：待處理）

## Constraint
- 語言：繁體中文
- 欄位：任務名稱、負責人、截止日、狀態、備註
- 依截止日由近到遠排序
- 試算表名稱：「2026-06 任務追蹤表」
- **工作流程限制**：
  1. **第一步**：請先使用 Claude Artifacts 功能，以 Markdown 表格呈現任務追蹤表草稿（需套用我修改設定的「逾期警告」與「未完成小計」規則）。
  2. **第二步**：詢問我是否需要修改。在此時**不要**呼叫 Skill 建立檔案。
  3. **第三步**：待我確認「可以建立」後，呼叫 Google Sheets Skill 建立檔案並歸檔至 **「上課用」** 資料夾中。

## Format
- 建立 Google Sheets 試算表
- 完成後回傳連結，並說明已套用的警示規則
```

## 練習 2-C1：修改 PPTX Skill 套用公司標準色與版權聲明

### 📖 修改目標
限制簡報 Skill 只能使用公司的官方標準配色（Ocean Gradient），且投影片第一頁必須標示「**© 2026 創新科技股份有限公司 版權所有**」。

### ✍️ 如何修改 `SKILL.md`
請打開您的 **PPTX Skill** 的 `SKILL.md`，在 `## Constraint` 區塊的末尾加入：

```markdown
簡報視覺與版權規範：
1. 簡報配色：強制指定使用「Ocean Gradient」配色方案（深藍/湖水藍/子夜藍），不得使用其他顏色。
2. 簡報封面頁（第一頁）的底部，必須以小字包含以下版權聲明：
   「© 2026 創新科技股份有限公司 版權所有 | 內部機密文件」
```

### 📋 測試用 RTCCF Prompt

```markdown
## Role
你是簡報設計助手，擅長將要點轉化為結構清晰的簡報大綱，並能運用已修改的 PPTX Skill 產生符合公司規範的 PowerPoint 簡報檔案。

## Task
請依我提供的主題與要點，規劃一份簡報大綱與投影片結構，先與我討論確認後，再使用已修改的 PPTX Skill 將其製作成 PowerPoint 簡報檔案 (.pptx) 供我下載。

## Context
簡報資訊：
- 主題：2026 Q2 業務成果報告
- 對象：部門主管
- 要點：
  - Q2 業績達成率 94%，超越目標 4%
  - 新客戶 5 家，集中在北部科技業
  - 下半年策略：深耕現有客戶 + 開拓中南部市場
  - 預計 Q3 目標：業績成長 15%

## Constraint
- 語言：繁體中文
- 固定 5 頁結構：封面 → 本期成果 → 重點發現 → 下半年策略 → 結語與目標
- 每頁要點不超過 4 條
- **工作流程限制**：
  1. **第一步**：請先使用 Claude Artifacts 功能，呈現每頁投影片的標題、大綱與配色計畫（需符合「Ocean Gradient」配色與封面版權規定）。
  2. **第二步**：詢問我是否需要修改。在此時**不要**呼叫 PPTX 產生工具。
  3. **第三步**：待我確認大綱「可以製作」後，呼叫已修改的 PPTX Skill 將此大綱內容製作成實體 PPTX 簡報檔案。

## Format
- 使用已修改的 PPTX Skill 建立並匯出 PowerPoint 簡報檔案 (.pptx)
- 完成後提供簡報檔案下載連結，並列出每頁的標題與大綱摘要
```

## 練習 2-C2：修改 Canva Connector 簡報格式

### 📖 修改目標
讓 Claude 呼叫 Canva Connector 時，自動將建立的簡報副標題設定為「創新科技 2026 專屬報告」，並為所有投影片名稱加上 `[創新科技]` 前綴。

### ✍️ 如何修改 `SKILL.md`
請打開您的 **Canva Connector Skill** 的 `SKILL.md`，在 `## Format` 區塊最下方加入：

```markdown
Canva 簡報命名與標題規範：
1. 簡報封面標題若有副標題，一律預設為：「創新科技 2026 專屬報告」。
2. 傳送給 Canva 建立的檔案名稱，必須統一使用「[創新科技] {原定簡報名稱}」格式。
```

### 📋 測試用 RTCCF Prompt

```markdown
## Role
你是簡報設計助手，擅長將要點轉化為結構清晰的簡報大綱，並能運用 Canva Connector 製作符合公司格式的簡報。

## Task
請依我提供的主題與要點，規劃一份簡報大綱與投影片結構，先與我討論確認後，再使用已修改的 Canva Connector 將其製作成簡報檔案。

## Context
簡報資訊：
- 主題：2026 Q2 業務成果報告
- 對象：部門主管
- 要點：
  - Q2 業績達成率 94%，超越目標 4%
  - 新客戶 5 家，集中在北部科技業
  - 下半年策略：深耕現有客戶 + 開拓中南部市場
  - 預計 Q3 目標：業績成長 15%

## Constraint
- 語言：繁體中文
- 固定 5 頁結構：封面 → 本期成果 → 重點發現 → 下半年策略 → 結語與目標
- 每頁要點不超過 4 條
- **工作流程限制**：
  1. **第一步**：請先使用 Claude Artifacts 功能，呈現每頁投影片的標題與大綱草稿。
  2. **第二步**：詢問我是否需要修改。在此時**不要**呼叫 Canva Connector。
  3. **第三步**：待我確認大綱「可以製作」後，呼叫已修改的 Canva Connector 將此大綱內容製作成 Canva 簡報。

## Format
- 使用 Canva 建立簡報檔案，套用公司專屬副標與命名格式
- 完成後回傳 Canva 簡報連結，並列出每頁的標題與大綱摘要
```

## 練習 2-D：修改 Gmail Skill 自動帶入部門簽名檔

### 📖 修改目標
強迫 Claude 透過 Gmail Skill 產出的所有郵件草稿，其結尾都必須自動附加統一格式的部門簽名檔。

### ✍️ 如何修改 `SKILL.md`
請打開您的 **Gmail Skill** 的 `SKILL.md`，在 `## Format` 區塊末尾加入：

```markdown
郵件結尾必須附上以下簽名（固定格式，請勿更動括號外的文字）：

---
{您的姓名}
{您的職稱} ｜ 行政管理部
聯絡分機：{您的分機號碼}
聯絡信箱：{您的 Email 地址}
```

### 📋 測試用 RTCCF Prompt

```markdown
## Role
你是商業郵件撰寫助手，擅長依照重點草擬專業且有禮貌的 Gmail 郵件，並使用已修改的 Gmail Skill 管理郵件。

## Task
請依我提供的資訊，規劃一封郵件草稿，先與我討論確認後，再使用已修改的 Gmail Skill 建立草稿，並套用「上課用」標籤（Tag）。

## Context
郵件資訊：
- 收件人：supplier@example.com（廠商業務）
- 主旨：確認採購訂單 PO-2026-0609 交期
- 溝通重點：
  - 我方已於 6/9 下訂，訂單編號 PO-2026-0609
  - 請廠商確認預計出貨日期
  - 我方最晚需在 6/20 收到貨品
  - 語氣：正式且友善

## Constraint
- 語言：繁體中文
- **工作流程限制**：
  1. **第一步**：請先使用 Claude Artifacts 功能，以 Markdown 格式呈現完整郵件草稿（需包含我修改設定的「行政管理部」自動簽名檔）。
  2. **第二步**：詢問我是否需要修改。在此時**不要**呼叫 Gmail Skill 建立郵件。
  3. **第三步**：待我確認「可以建立」後，呼叫 Gmail Skill 建立郵件草稿，並套用 **「上課用」** 標籤。

## Format
- 先在對話中呈現草稿
- 我確認後呼叫 Gmail Skill 建立草稿，並回傳操作結果與套用標籤的確認資訊
```
