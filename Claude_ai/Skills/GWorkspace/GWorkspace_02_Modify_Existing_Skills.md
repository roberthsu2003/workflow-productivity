# 實作範例 2：修改現有的 Skill

> 🟢 **方案需求**：Free（需先在 Settings 開啟 Skills 與程式碼執行）  
> 🎯 **學習目標**：學會編輯現有 `SKILL.md`，針對個人或團隊需求調整角色、規則與輸出格式，掌握自訂 Skill 的核心技巧。

在熟悉如何使用現有 Skill 之後，下一步是學會「客製化」。透過修改現有 Skill，您可以將公司格式、部門簽名、特殊檢查邏輯等內建到 AI 的工作指引中，打造專屬的工作流。

---

## 🛠️ 修改 Skill 的通用步驟

1. 點擊 Claude 左下角個人頭像，前往 **Settings** → **Skills**。
2. 在已安裝的 Skills 清單中，找到您想客製化的 Skill，點擊其右側的 **「Edit」** 按鈕。
3. 編輯器會開啟該 Skill 的 `SKILL.md` 檔案。
4. 找到需要調整的區塊（通常是 `Role`、`Constraint` 或 `Format`），進行增刪與修補後點擊 **Save**。
5. 在新的對話中呼叫該 Skill，測試修改後的行為是否符合預期。

## 💡 Google Workspace 客製化修改建議

您可以參考下表，為您的工作流加上特定限制或欄位：

| 客製化目標 | 原始 Skill 設定 | 建議修改方式 |
| :--- | :--- | :--- |
| **Google Docs**<br>會議紀錄改成符合公司格式 | 通用標題與段落結構 | 在 `## Format` 區塊中，限制必須加入公司抬頭、部門、與會人員等特定表格欄位。 |

| **Google Slides**<br>簡報大綱改成固定頁數結構 | 依內容長度自由發揮 | 在 `## Format` 區塊中，限制簡報必須固定為：封面、問題、解法、數據、結論共 5 頁結構。 |
| **Gmail**<br>草稿自動套用部門專屬簽名檔 | 通用信件結尾 | 在 `## Format` 區塊中，加入固定的部門簽名檔格式與資訊。 |

## 📝 實戰演練：為 Gmail Skill 加入部門簽名檔

以下我們以 Gmail 寫信 Skill 為例，教您如何為其加上固定簽名檔。

### 第一步：修改 `SKILL.md`
開啟 Gmail Skill 的編輯介面，並在其 `## Format` 區塊的末尾，加上以下指示：

```markdown
## Format
...（保留原本的格式規定）

郵件結尾必須附上以下簽名（固定格式，請勿更動括號外的文字）：

---
{您的中文姓名}
{您的專業職稱} ｜ 行政管理部
聯絡分機：{您的分機號碼}
聯絡信箱：{您的 Email 地址}
```

### 第二步：儲存並測試
1. 點擊 **Save** 儲存修改。
2. 開啟一個新的 Claude 對話視窗。
3. 輸入測試指令：
   > 「`/gmail 幫我寫一封詢問採購進度的信給小明，語氣正式且友善`」
4. 確認產出的郵件草稿結尾，是否已自動為您套用並帶入剛才設定的「行政管理部」簽名檔格式。
