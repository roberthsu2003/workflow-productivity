# 延伸練習 2：主管交辦事項整理員（第一階：模仿者）

> 實際測試-無誤

這是第一階的延伸實作練習。本階段的重點是學會如何透過介面建立最基礎的自訂 Skill。

## 📖 範例說明
這個 Skill 會把零散訊息整理成可追蹤的待辦清單，適合處理主管口頭交辦、會議後訊息或團隊聊天紀錄。

## 🛠️ 建立方式（使用 Write skill instructions）
請依照以下步驟在 Claude 介面中手動新增：

1. 點擊 Claude 左下角頭像前往 **Customize** ➔ **Skills**。
2. 點擊右上角的 `+` ➔ **Create skill** ➔ 選擇 **Write skill instructions**。
3. 依照以下內容填寫欄位：
   - **Skill name**: `Task Extractor`
   - **Description**: `從主管交辦或團隊對話中整理待辦、負責人、期限與優先級。`
   - **Instructions** (複製並貼上以下內容)：
     ```text
     你是一位細心的專案助理，擅長把混亂訊息整理成可執行任務。

     ## 任務
     當使用者貼上主管交辦、會議紀錄或聊天紀錄時，請整理成待辦清單。

     ## 輸出格式
     請整理為表格，包含以下欄位：
     | 任務 | 負責人 | 期限 | 優先級 | 缺漏資訊 |

     ## 判斷規則
     - 如果出現「今天、明天、下週」等相對日期，請保留原文並提醒需確認實際日期。
     - 如果沒有負責人，標記為「未指定」。
     - 優先級分為高、中、低。
     - 最後列出「建議追問主管的問題」。
     ```
4. 點擊 **Create** 按鈕完成建立。確認 Skills 列表中是否已成功出現「Task Extractor」這個新 Skill。


### 💡 方式 B：在終端機中部署（適用於 Claude Code / 終端機代理）
1. 在您的專案或 CLI 系統的 `/mnt/skills/user/` 目錄下建立一個自訂技能資料夾（名稱例如 `task-extractor`）。
2. 在該資料夾內建立 `SKILL.md` 檔案。
3. 複製下方「一鍵複製區 (SKILL.md)」中的所有內容並貼入 `SKILL.md` 存檔即可。

## 🧪 測試與驗證

確認 Skill 建立成功後，您可以開啟新對話並使用以下範例 Prompt 來測試其效果：

**測試 Prompt：**
```text
請幫我整理交辦事項：
「明天早上先把 A 客戶報價整理好，B 專案風險也要有人追，週五前給我簡報初稿。」
```

**預期效果：**
Claude 將會自動啟用該 Skill，並依據規範將上述交辦文字整理為一個包含任務、負責人、期限、優先級與缺漏資訊的結構化表格。
