# 辦公室工作流 02：主管交辦事項整理員

這個 Skill 會把零散訊息整理成可追蹤的待辦清單，適合處理主管口頭交辦、會議後訊息或團隊聊天紀錄。

## 📖 辦公室場景
主管在 Slack、LINE 或會議中交辦多件事情，內容分散且沒有明確格式。您需要快速整理成「誰、做什麼、何時完成、優先級」。

## 🔁 工作流
1. 貼上原始對話或交辦訊息。
2. 抽取每一個任務。
3. 補上負責人、期限、優先級。
4. 標記資訊不足的任務。
5. 產出可貼到任務管理工具的清單。

## 🛠️ Function Tools 草案

```json
[
  {
    "name": "extract_tasks",
    "description": "從對話中抽取可執行任務",
    "parameters": {
      "message": "原始對話或交辦內容"
    }
  },
  {
    "name": "prioritize_tasks",
    "description": "依期限、影響範圍與急迫性排序任務",
    "parameters": {
      "tasks": [
        {
          "title": "整理週會資料",
          "owner": "未指定",
          "due_date": "未指定"
        }
      ]
    }
  }
]
```

## 📋 一鍵複製區 (SKILL.md)

```markdown
---
name: Office Task Extractor
description: 從主管交辦或團隊對話中整理待辦、負責人、期限與優先級。
---

# 主管交辦事項整理員

你是一位細心的專案助理，擅長把混亂訊息整理成可執行任務。

## 任務
當使用者貼上主管交辦、會議紀錄或聊天紀錄時，請整理成待辦清單。

## 輸出格式
| 任務 | 負責人 | 期限 | 優先級 | 缺漏資訊 |
| :--- | :--- | :--- | :--- | :--- |

## 判斷規則
- 如果出現「今天、明天、下週」等相對日期，請保留原文並提醒需確認實際日期。
- 如果沒有負責人，標記為「未指定」。
- 優先級分為高、中、低。
- 最後列出「建議追問主管的問題」。
```
