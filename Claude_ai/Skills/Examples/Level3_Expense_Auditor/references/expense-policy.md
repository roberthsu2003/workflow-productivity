# 📋 企業差旅與公務費用報銷規範手冊 (v2.4)

本規範適用於全體同仁申報差旅、公務交際及日常辦公雜項支出。凡不符合本手冊規範之報銷申請，財務部得逕行退件或要求補件。

---

## 一、 基本憑證與申報原則

1. **統一編號與買受人**：
   - 台灣境內取得之統一發票或電子發票，買受人統一編號必須填寫公司統編：`88888888`。
   - 二聯式發票若未打統編、手開二聯式收據未蓋免用統一發票專用章者，**一律不予核銷**。
2. **品項明細**：
   - 發票上若僅標註「文具一批」或「餐飲」，須檢附品項銷售明細單或點餐單據。
3. **報銷時效**：
   - 費用發生日起 **30 天內** 須完成申報，逾期需經一級主管特簽。

---

## 二、 費用類別與上限規範

### 1. 市區交通費 (市區計程車 / Uber)
- **報銷上限**：單趟以 **NT$ 500** 為上限。
- **合規條件**：
  - 須具備急迫公務事由（如：攜帶大型樣品展示設備、外訪多個客戶且轉乘不便、跨區會議趕場）。
  - 若為深夜（22:00 後）因公加班返家，得全額報銷，須註明「因公加班返家」。
  - **違規標記**：無公務事由說明、單趟超額且未檢附主管核准說明者，標記為 `⚠️ 需補事由` 或 `❌ 超額需自付差額`。

### 2. 長途差旅 (高鐵 / 臺鐵)
- **報銷上限**：高鐵限報銷**標準車廂**對號座票價；若搭乘商務車廂，超額差價由個人負擔。
- **憑證要求**：須檢附實體乘車票根或高鐵 App 購票證明（含載明扣款金額之 T-Ex 購票證明）。

### 3. 公務餐費與業務交際 (公務餐費)
- **日常公務用餐上限**：每人每餐以 **NT$ 600** 為限（例如 3 人用餐上限為 NT$ 1,800）。
- **外部客戶宴客交際**：每人每餐以 **NT$ 1,500** 為限，申報時必須載明「拜訪客戶名稱、客戶職稱與人數」。
- **違規標記**：單人超額部分列為「超標自負」，不予全額給付。

### 4. 辦公用品與雜項 (辦公文具 / 耗材)
- 單筆採購金額 **NT$ 3,000 以下**：同仁可先行墊付後報銷。
- 單筆採購金額 **超過 NT$ 3,000**：須於採購前提出採購請購單（PR），未經事前簽核逕行購買者不予受理。

## 三、 稽核狀態判斷標準（供審核員判斷）

| 狀態代碼 | 狀態文字 | 判定條件 |
| :--- | :--- | :--- |
| **COMPLIANT** | `✅ 合規` | 發票統編正確、金額在限額內、公務事由完整 |
| **WARNING** | `⚠️ 需補件` | 金額合規但缺事由說明（如計程車）、或品項未明細 |
| **OVER_BUDGET**| `❌ 超標` | 超過報銷額度上限（如單人餐費 > NT$ 600、計程車 > NT$ 500） |
| **REJECTED** | `⛔ 退件` | 統編錯誤、逾期未特簽、私人消費無關公務 |
