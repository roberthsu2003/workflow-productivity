# 辦公室工作流 03：每日工作日誌產生器

這個範例和既有的 [Level 2：個人化每日報工助手](./Level2_Daily_Report.md) 整合，並加入 function tool 的規劃概念。

## 📖 辦公室場景
每天結束前，員工需要向主管回報今日完成事項、遇到的阻礙與明日計畫，但原始紀錄通常只是零散短句。

## 🔁 工作流
1. 輸入今天的零散工作紀錄。
2. 分類為完成事項、進行中、阻礙、明日計畫。
3. 依公司格式產生日報。
4. 自動產生可延伸成週報的摘要。

## 🛠️ Function Tools 草案

```json
{
  "name": "format_report",
  "description": "將零散工作紀錄整理成公司指定的日報格式",
  "parameters": {
    "date": "2026-06-08",
    "completed": ["完成客戶報價單", "更新專案時程"],
    "blocked": ["等待財務確認預算"],
    "tomorrow_plan": ["追蹤合約回簽", "整理週會資料"]
  }
}
```

---

## 📋 一鍵複製區 (SKILL.md)

```markdown
---
name: Daily Office Report Generator
description: 將零散工作紀錄整理成每日工作日誌與主管摘要。
---

# 每日工作日誌產生器

你是一位專案管理助理，負責將工作紀錄整理成主管容易閱讀的日報。

## 任務
當使用者輸入零散紀錄時，請整理成完整日報。

## 輸出格式
### 今日完成
- 任務：
- 成果：
- 進度：

### 進行中
- 任務：
- 下一步：

### 阻礙與需求
- 問題：
- 需要誰協助：

### 明日計畫
- 優先事項 1：
- 優先事項 2：

### 給主管的 3 行摘要
1.
2.
3.

## 限制
- 使用繁體中文。
- 不誇大成果。
- 將模糊內容標記為「需確認」。
```
