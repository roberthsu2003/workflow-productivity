# 創投 (VC) 商業與財務評估框架指南

本文件供 Claude 於評估新創公司財務健全度與生成投資備忘錄 (Investment Memo) 時作為對照標準。

## 📊 1. SaaS 與訂閱制關鍵財務指標 (Key Metrics)

| 指標名稱 | 英文全名 | 創投健康基準 (Benchmark) | 評估意義與說明 |
| :--- | :--- | :--- | :--- |
| **ARR / MRR** | Annual/Monthly Recurring Revenue | 年經常性收入 / 月經常性收入 | 衡量 SaaS 業務穩定營收的基礎指標。 |
| **LTV / CAC** | Life-Time Value / Customer Acquisition Cost | **> 3.0** (優秀為 > 5.0) | 客戶終身價值 vs 獲客成本。> 3 表示獲客效率健全。 |
| **CAC Payback Period** | 獲客成本回收期 | **< 12 個月** (早期新創 < 18 個月) | 新創收回單一客戶獲客成本所需月數。 |
| **NDR / NRR** | Net Dollar Retention | **> 110%** (Enterprise SaaS > 120%) | 扣除流失後，現有客戶的淨營收成長率。 |
| **Gross Margin** | 毛利率 | **> 70% ~ 80%** | 軟體/SaaS 應具備高毛利；硬體/DeepTech 則介於 40%~60%。 |
| **Rule of 40** | 40 法則 | **Revenue Growth Rate + Profit Margin ≥ 40%** | 衡量成長率與獲利能力平衡度的黃金法則。 |
| **Burn Multiple** | 燒錢倍數 | **< 1.5** (優秀為 < 1.0) | Net Burn / Net New ARR。每增加 $1 ARR 需要燒掉多少現金。 |

## 🎯 2. TAM / SAM / SOM 市場規模估算框架

- **TAM (Total Addressable Market，總可即市場)**：若全球無競爭對手，該產品能達到的最大市場潛能。
- **SAM (Serviceable Addressable Market，可服務市場)**：受限於產品功能、語言、地理分佈後，目標產品能切入的市場。
- **SOM (Serviceable Obtainable Market，可取得市場)**：未來 3-5 年內，憑藉團隊現有資源與通路預計能拿下的真實市場份額。

## 🛡️ 3. 創投評估防禦壁壘 (Moats) 分類

1. **網路效應 (Network Effects)**：用戶越多，平台價值越高（如 Marketplace、社群平台）。
2. **切換成本 (Switching Costs)**：客戶更換系統的代價極高（如 ERP、核心銀行系統）。
3. **規模經濟 (Economies of Scale)**：規模越大，邊際成本越低（如 雲端基礎設施）。
4. **專利與技術壁壘 (Proprietary Tech / Patents)**：DeepTech/醫療 AI 之核心演算法與專利佈局。
5. **品牌與信任壁壘 (Brand / Trust)**：金融、醫療或資安領域的品牌認可。
