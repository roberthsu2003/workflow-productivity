# 📦 庫存巡檢與安全庫存補貨 SOP 規章 (Safety Stock Rules)

## 1. 安全庫存可支撐天數 (Days of Inventory - DOI) 計算公式
$$\text{DOI (天)} = \frac{\text{當前庫存數}}{\text{日平均消耗數}}$$

## 2. 補貨預警警戒線判讀標準
- 🔴 **紅色警戒 (極度缺貨風險)**：
  - 條件：$\text{DOI (天)} \le \text{供應商交期 (天)} + 2$ 天。
  - 代表庫存已無法涵蓋進貨等待期，隨時面臨斷貨！
- 🟡 **黃色預警 (應準備採購)**：
  - 條件：$\text{DOI (天)} \le \text{供應商交期 (天)} \times 2$。
  - 代表庫存接近低水位，應通知採購發發 Request。
- 🟢 **綠色正常**：
  - 條件：$\text{DOI (天)} > \text{供應商交期 (天)} \times 2$。
