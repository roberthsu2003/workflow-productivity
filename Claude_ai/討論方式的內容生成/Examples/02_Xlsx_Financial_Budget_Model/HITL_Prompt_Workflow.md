## 階段一：口語協商 RTCCF 規格（對齊財務指標與維度）

### 提示詞 1-1：請 AI 扮演資深財務長 (CFO) 梳理架構
請將以下內容貼入 Claude 對話框：

```text
我們公司是一間企業級 AI 軟體公司，現在要編制 2026 年度的「全通路營運預算與動態損益模型 (P&L)」。
我們有三種訂閱版本（Pro 年費 4,800、Team 年費 28,000、Enterprise 平均 180,000）以及顧問和 API 收入；支出包含研發薪酬、雲端算力（COGS）、行銷發表會、廣告、業務佣金與管理費用。
最後需要產出一份正式的 Excel 檔案（.xlsx）給董事會審查。
請先不要直接產出 Excel，請扮演資深財務長顧問，幫我整理出 RTCCF (Role, Task, Context, Constraint, Format) 提示詞，並在 Format 中要求先在 Markdown 表格中逐項確認 4 個工作表的欄位與連鎖公式邏輯。
```

## 階段二：純文字多輪局部打磨（核對跨表連鎖公式與情境）

### 提示詞 2-1：貼上定稿的 RTCCF 產出 Markdown 初稿
```markdown
## Role
你是一位具備 15 年經驗的矽谷級資深財務總監 (CFO) 與財務建模 (Financial Modeling) 專家。

## Task
建立一份專業的「星橋科技 2026 年度營運預算與動態損益試算表 (P&L)」財務模型架構。

## Context
- 營業收入：包含 Pro 個人版、Team 團隊版、Enterprise 企業版、顧問服務與 API 額度。
- 營業支出：研發薪資、雲端算力 (COGS)、發表會費用、數位行銷、業務人事、行政租金。
- 關鍵指標：營收合計、毛利、毛利率、OPEX、營業淨利、EBITDA。

## Constraint
- 拒絕單一工作表通篇寫死，必須規劃 4 個分工明確的工作表。
- 公式嚴謹：毛利必須等於營收減成本，跨工作表必須使用精準 Excel 引用公式。

## Format
- 請先以 Markdown 表格條列呈現 4 個工作表的欄位名稱、假定數字與公式連鎖關係（可於 Artifacts 呈現），供我們逐項校對。
```

### 提示詞 2-2：標題座標法微調（修正 COGS 歸屬與 EBITDA 公式）
```text
財務結構很清晰！請保持其他部分不變，專門針對【工作表 3：綜合損益試算表】的計算邏輯微調：
請確認將「雲端算力與 API 呼叫費」準確歸列為營業成本 (COGS)，使營業毛利 (Gross Profit) 的計算公式為營業收入減去雲端算力；營業費用 (OPEX) 則扣除算力後加總其餘費用；文末加入一列「EBITDA」試算。請只更新損益表的公式對照。
```

### 提示詞 2-3：追加情境敏感度分析工作表
```text
很好！董事會需要評估市場風險：
請追加規劃【工作表 4：情境敏感度分析】，設定三種情境：
1. 保守情境：付費轉換率 1.8%，營收為基準之 75%，支出為 85%。
2. 基準情境：付費轉換率 2.8%，完全連鎖損益表。
3. 樂觀情境：付費轉換率 4.5%，營收為基準之 135%，支出為 110%。
請以 Markdown 表格呈現各情境之預估 ARR、支出、EBITDA 與損益兩平時點預估。
```

## 階段三：定稿一鍵編譯正式 Excel (.xlsx) 交付

### 提示詞 3-1：一鍵轉出正式 XLSX 檔案
```text
這份財務模型的結構、科目與跨表連鎖公式已經過我們討論定稿，完全正確無誤！
請啟用 Python 程式碼執行（openpyxl），將上述規劃直接編譯為一份具備高階財務質感的真實 Excel 活頁簿（.xlsx）供我下載：
1. 建立 4 個獨立工作表：1_營收與訂閱預測、2_營業費用與行銷預算、3_綜合損益試算表 (P&L)、4_情境敏感度分析。
2. 表頭使用深海軍藍（#1E3A8A）或深石板灰（#334155）底色配白色粗體字。
3. 所有金額欄位套用貨幣千分位格式（$#,##0），比率欄位套用百分比格式（0.0%）。
4. 全面寫入真實動態公式（=SUM, 跨工作表引用如 ='1_營收與訂閱預測'!C10 等），不得全部填寫死數據！
5. 各工作表開啟網格線（Gridlines），自動調整最適合欄寬，合計列加入頂部細線與底部雙底線（Accounting Underline）。
```
