## 📖 情境故事

在金管會與國際供應鏈對 ESG 要求日益嚴苛的背景下，星橋科技永續長正與第三方獨立公證檢驗機構（如 SGS、TUV 認可查證員）進行年度溫室氣體盤查查證。

在法律責任層面，查驗宣告書一旦蓋章發出，內容若有數據缺漏或格式瑕疵，將直接影響企業永續評比與國際客戶下單資格：
- 很多新手叫 AI 直接生成 PDF，往往遇到中文字體變成豆腐方塊、表格線條位移跑版，或者漏掉了關鍵免責聲明。
- 在二進位 PDF 檔案上，人類根本無法反白即時修訂數據。

永續長運用 **Human-in-the-Loop** 心法：
1. **法規標準對齊**：與 Claude 首席稽核長口語協商，確認 ISO 14064-1:2018 與「合理確信等級 (Reasonable Assurance)」的法定宣告要素。
2. **純文字嚴謹核查**：在 Markdown 階段逐條檢查範疇一（18.45 tCO2e）、範疇二（312.80 tCO2e）與範疇三（119.50 tCO2e）的計算依據，並補強綠電採購 (CPPA) 改善建議。
3. **一鍵編譯成檔**：經雙方逐字推敲定稿後，一鍵啟用 Python 編譯，產出具備國際公證機構專用格式、深墨綠色（#047857）標題帶、清晰中文字型與雙方法定簽章用印區的不可竄改 `.pdf` 正式公文！

## 🛠️ Step-by-Step 人機協作流程

### 第一步：口語協商 RTCCF（法規標準對齊）
1. 打開 Claude 對話框，輸入以下口語指令：
   ```text
   我們公司是一間高科技軟體公司，剛完成 2025 年度的溫室氣體盤查，現正由外部獨立查驗機構執行查驗。
   盤查結果包含範疇一 18.45 tCO2e、範疇二 312.80 tCO2e、範疇三 119.50 tCO2e，總計 450.75 tCO2e。
   我們需要產出一份正式的、具備法律確信效力的「ESG 溫室氣體盤查查驗宣告書」PDF 檔案（.pdf）。
   請先不要直接產出 PDF，請扮演國際資深主任稽核員 (Lead Auditor)，幫我梳理出 RTCCF (Role, Task, Context, Constraint, Format) 提示詞，並在 Format 中要求先以 Markdown 格式逐項對齊 ISO 14064-1 條文要求與簽章欄位。
   ```

### 第二步：純文字多輪打磨（核對排放數據與改善建議）
1. 貼上 RTCCF 產出宣告書初稿。
2. **標題座標法微調改善建議**：
   ```text
   宣告書結構非常合規！請保持其他段落不變，專門針對【三、 查驗改善建議事項與後續追蹤】微調：
   請明確點出兩大具體行動：
   1. 要求範疇三雲端算力服務商（AWS/GCP）於 2026 年提供按小時即時碳排 API，對接歐盟 CBAM 標準。
   2. 針對佔比近 70% 的範疇二電力，具體建議採購至少 150 張太陽能綠電憑證 (T-REC)，朝 RE50 邁進。請只更新該小節。
   ```
3. **核實雙簽核欄位**：確認文末具備受查驗機構代表人與第三方主任稽核員的完整雙欄簽章資訊。

### 第三步：定稿一鍵編譯為法律效力 PDF (.pdf)
核查數據無誤後，輸入一鍵編譯指令：
```text
這份 ESG 查驗宣告書的內容與數據已經核實定稿，完全符合 ISO 國際規範！
請啟用 Python 程式碼執行（reportlab），將上述 Markdown 內容直接編譯為一份具備高階防偽、公信力強大的正式宣告書 PDF 檔案（.pdf）供我下載：
1. 版面設定為 A4 規格，邊距 36pt，上下左右對齊。
2. 標題與重點色採用專業深墨綠（#047857 / #065F46）搭配科技深藍黑（#0F172A）。
3. 繁體中文請指定使用系統支援之字型（如 Arial Unicode 或相容中文字型），確保字體清晰美觀、零跑版、無亂碼。
4. 數據表格表頭採用深墨綠色底、白色字，總計列加入高亮淡綠色底色；文末設計雙欄對齊之簽章與公司用印方塊。
```
點擊下載產生的檔案，即可獲得與 [星橋科技_2026年度ESG永續發展查驗宣告書.pdf](./sample_files/星橋科技_2026年度ESG永續發展查驗宣告書.pdf) 完全一致的高階正式宣告書！
