## 📖 情境故事

星橋科技創辦人志偉即將在矽谷進行 Series A 輪 500 萬美元的路演（Pitch）。他面對的是看過上千份 Pitch Deck 的頂級創投合夥人。

一般人叫 AI 做簡報，產出來的簡報往往慘不忍睹：
- 每頁塞了 300 到 500 字，滿滿的條列清單，觀眾根本不知道重點在哪。
- 沒有講者備忘稿，講者上台只能跟著螢幕上的字照本宣科，毫無說服力。
- 比例還是舊時代的 4:3，或者顏色土氣死板。

志偉透過 **Human-in-the-Loop** 方式協作：
1. **分鏡協商**：要求 AI 擔任矽谷 Pitch 教練，先規劃 16:9 寬螢幕下「每頁單一觀點 (One Message per Slide)」的分鏡結構。
2. **純文字打磨**：在 Markdown 階段反覆推敲演講備忘稿 (Speaker Notes) 的字字句句，並確認卡片式視覺排版（三欄痛點、三步解法、四張大字報數據）。
3. **一鍵編譯成檔**：定稿後啟動 Python 引擎原生輸出，產出具有深邃科技藍黑背景（#0F172A）、圓角卡片邊框、而且在 PowerPoint「簡報者檢視畫面」中完整呈現演講備忘稿的商業級 `.pptx`！

## 🛠️ Step-by-Step 人機協作流程

### 第一步：口語協商 RTCCF（分鏡與節奏規劃）
1. 打開 Claude 對話框，輸入以下口語指令：
   ```text
   我們公司是一間專注於 Human-in-the-Loop 人機協同生產力平台的軟體公司，目前正在進行 Series A 輪 500 萬美元融資。
   過去 12 個月我們達成 ARR $2.4M、NRR 138%、LTV/CAC 4.8x，已有 180 家企業客戶。
   我們需要產出一份 16:9 寬螢幕、極簡卡片風的高質感 PowerPoint 簡報（.pptx）給矽谷創投合夥人。
   請先不要直接做簡報檔案，請扮演頂級創投簡報教練，幫我梳理出 RTCCF (Role, Task, Context, Constraint, Format) 提示詞，並在 Format 中要求先以 Markdown 條列每一頁的「單一核心訊息」、卡片視覺佈局與講者演講備忘稿 (Speaker Notes)。
   ```

### 第二步：純文字多輪打磨（精修單頁核心訊息與 Notes）
1. 貼上 RTCCF 產出分鏡初稿。
2. **標題座標法微調職場痛點**：
   ```text
   簡報大綱節奏很好！請保持其他頁面不變，專門針對【投影片 2：職場痛點】進行微調：
   請將痛點提煉為「黑箱猜測，改一處整篇重寫」、「Token 浪費，越聊越貴越遲鈍」、「格式孤島，無法融入正式交付」三張卡片；並在講者備忘稿中補充一句針對投資人質疑『為什麼不直接用 ChatGPT』的強烈反擊。請只更新第二頁的內容。
   ```
3. **確認數據大字報與資金分配**：確認投影片 4 採用大字報指標呈現 ARR 與 NRR，投影片 5 採用三欄資金分配。

### 第三步：定稿一鍵編譯為 16:9 寬螢幕 PPTX (.pptx)
確認分鏡文字後，輸入一鍵編譯指令：
```text
這份融資簡報的分鏡架構、卡片內容與講者備忘稿已經討論定稿，非常震撼！
請啟用 Python 程式碼執行（python-pptx），將上述分鏡直接編譯為一份專業的 16:9 商業簡報（.pptx）供我下載：
1. 尺寸設定為 16:9 寬螢幕（13.333 x 7.5 英吋）。
2. 配色主題採用科技深邃暗色系：背景深深藍色（#0F172A）、卡片深石板灰（#1E293B）、強調色為活力藍（#3B82F6）與翡翠綠（#10B981）。
3. 採用現代卡片式（Rounded Rectangle Card）佈局，標題大氣、字距舒適。
4. 最關鍵：每一頁投影片必須寫入真實的講者備忘稿（slide.notes_slide.notes_text_frame），讓我上台報告時能看著講者檢視畫面流暢演說！
```
點擊下載產生的檔案，即可獲得與 [星橋科技_Series_A商業融資計畫書.pptx](./sample_files/星橋科技_Series_A商業融資計畫書.pptx) 完全一致的高階 Pitch Deck！

## 🧪 學生實測三部曲成果驗收

### 成果驗收檢核表
- [ ] **16:9 寬螢幕比例**：打開投影片是否為現代標準的 16:9 寬螢幕比例，完全無兩側黑邊？
- [ ] **現代卡片視覺美學**：投影片是否摒棄了條列流水帳，採用深色科技背景搭配乾淨俐落的資訊卡片？
- [ ] **真實講者備忘稿**：切換至 PowerPoint「簡報者檢視畫面（Presenter View）」或檢視備忘稿區塊，每一頁下方是否都包含完整的演講逐字提示詞？
