## 階段一：口語協商 RTCCF 規格（對齊 16:9 商業分鏡）

### 提示詞 1-1：請 AI 扮演頂級創投募資簡報顧問
請將以下內容貼入 Claude 對話框：

```text
我們公司是一間專注於 Human-in-the-Loop 人機協同生產力平台的軟體公司，目前正在進行 Series A 輪 500 萬美元融資。
過去 12 個月我們達成 ARR $2.4M、NRR 138%、LTV/CAC 4.8x，已有 180 家企業客戶。
我們需要產出一份 16:9 寬螢幕、極簡卡片風的高質感 PowerPoint 簡報（.pptx）給矽谷創投合夥人。
請先不要直接做簡報檔案，請扮演頂級創投簡報教練，幫我梳理出 RTCCF (Role, Task, Context, Constraint, Format) 提示詞，並在 Format 中要求先以 Markdown 條列每一頁的「單一核心訊息」、卡片視覺佈局與講者演講備忘稿 (Speaker Notes)。
```

## 階段二：純文字多輪局部打磨（打磨 One Message per Slide 與 Notes）

### 提示詞 2-1：貼上定稿的 RTCCF 產出 Markdown 初稿
```markdown
## Role
你是一位曾協助多家矽谷獨角獸完成數千萬美元融資的頂級 Pitch Deck 商業簡報總監與視覺設計教練。

## Task
規劃「星橋科技 Series A 輪 500 萬美元商業融資計畫書」的簡報分鏡架構。

## Context
- 痛點：AI 單向黑箱生成導致「修改成本極高」、「Token 浪費」與「格式無法交付」。
- 解法：OmniFlow 三階段人機協同工作流引擎。
- 數據：ARR $2.4M (YoY +210%)、NRR 138%、180 家企業客戶。
- 募資：$5M，用於研發 (50%)、市場拓展 (30%)、資安合規 (20%)。

## Constraint
- 嚴格遵守「One Message Per Slide」：每頁只傳達一個震撼觀點，禁止滿版小字抄書。
- 每一頁必須自帶講者演講備忘稿 (Speaker Notes)。

## Format
- 請先以 Markdown 條列每一頁的標題、副標題、三欄/卡片結構內容與完整演講備忘稿，供我們在畫布上逐頁推敲打磨。
```

### 提示詞 2-2：標題座標法微調（強化痛點三欄對比）
```text
簡報大綱節奏很好！請保持其他頁面不變，專門針對【投影片 2：職場痛點】進行微調：
請將痛點提煉為「黑箱猜測，改一處整篇重寫」、「Token 浪費，越聊越貴越遲鈍」、「格式孤島，無法融入正式交付」三張卡片；並在講者備忘稿中補充一句針對投資人質疑『為什麼不直接用 ChatGPT』的強烈反擊。請只更新第二頁的內容。
```

### 提示詞 2-3：深化商業數據與資金分配卡片
```text
很好！請確認【投影片 4：商業數據】使用 4 張大字報指標呈現（$2.4M ARR, 138% NRR, 4.8x LTV/CAC, 78% 跨格式導出使用率）；並在【投影片 5：本輪募資】明確列出 50% 研發、30% 海外拓銷、20% 資安合規的三欄卡片結構。
```

## 階段三：定稿一鍵編譯正式 PowerPoint (.pptx) 交付

### 提示詞 3-1：一鍵轉出正式 PPTX 檔案
```text
這份融資簡報的分鏡架構、卡片內容與講者備忘稿已經討論定稿，非常震撼！
請啟用 Python 程式碼執行（python-pptx），將上述分鏡直接編譯為一份專業的 16:9 商業簡報（.pptx）供我下載：
1. 尺寸設定為 16:9 寬螢幕（13.333 x 7.5 英吋）。
2. 配色主題採用科技深邃暗色系：背景深深藍色（#0F172A）、卡片深石板灰（#1E293B）、強調色為活力藍（#3B82F6）與翡翠綠（#10B981）。
3. 採用現代卡片式（Rounded Rectangle Card）佈局，標題大氣、字距舒適。
4. 最關鍵：每一頁投影片必須寫入真實的講者備忘稿（slide.notes_slide.notes_text_frame），讓我上台報告時能看著講者檢視畫面流暢演說！
```
