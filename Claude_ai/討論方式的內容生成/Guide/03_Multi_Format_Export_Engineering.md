# 03. 四大格式（DOCX, XLSX, PPTX, PDF）Prompt 驅動導出工程學與程式碼執行解析

> 💡 **學習目標**：理解 Claude 如何利用後台 Python 沙盒環境將 Markdown 編譯為專業二進位檔案；掌握如何撰寫「定稿導出 Prompt」，讓產出的 Word、Excel、PowerPoint、PDF 具備大廠出版品般的視覺質感。

---

## ⚙️ 底層原理：Claude 程式碼執行沙盒 (Code Execution)

當你在對話框中說「請幫我產出可下載的 .docx / .xlsx / .pptx / .pdf」時，Claude 內部並非直接吐出二進位位元組，而是：
1. **將 Markdown 數據模型化**：解析你已經在對話中打磨好的標題、段落、表格與清單。
2. **自動撰寫 Python 代碼**：調用後台內建的標準庫（如 `python-docx`、`openpyxl`、`python-pptx`、`reportlab` 等）。
3. **在沙盒中執行並生成檔案**：將執行完成的二進位檔案打包為可點擊下載的 URL 連結呈現給使用者。

這也是為什麼**「先打磨純文字 Markdown」是成功的關鍵**——因為如果你的 Markdown 結構混亂、邏輯矛盾，Python 腳本就只能基於混亂的資料去繪製圖表或表格，產出的檔案自然容易崩潰或跑版。

> 🚨 **不可逆協作定律**：  
> 一旦 Python 沙盒將檔案編譯打包為 `.docx`、`.xlsx`、`.pptx` 或 `.pdf`，這份二進位檔案就**脫離了人機協作生命週期**！  
> 你**無法**要求 Claude「直接修改剛剛那個 docx 的第 3 頁」。若要修改，唯一正確的做法是：**「在原來的 .md 檔案中繼續人機討論打磨，打磨定稿後再執行一次導出指令」**！

## 🛠️ 四大格式導出指令設計規範

### 1. Word (.docx) 導出提示詞要點
- **配色主題**：指定企業主色（如沉穩海軍藍 `#1E3A8A`、深石板灰 `#334155`）。
- **表格樣式**：要求表頭具備背景底色與白字粗體，交替列加入斑馬紋底色（Zebra striping），儲存格設定上下邊距。
- **頁首頁尾**：要求加入機密等級標籤、文件版本與頁碼。
- **重點引言**：要求將核心原則或注意須知包裝在帶底色與左側邊線的 Callout Box 中。

### 2. Excel (.xlsx) 導出提示詞要點
- **多工作表架構**：嚴禁所有數據塞在同一頁，要求明確分成多個命名工作表（如 `1_營收預測`、`2_營業費用`、`3_損益表`）。
- **真實動態公式**：明確要求寫入真實 Excel 公式（如 `=SUM(...)`、`='工作表名稱'!單元格`），嚴禁填入寫死數字。
- **會計數字格式**：金額套用貨幣千分位格式（`$#,##0`），比率套用百分比格式（`0.0%`）。
- **視覺規範**：合計列套用會計專用雙底線（Accounting Double Underline），各表顯示網格線（Gridlines）並自動最佳化欄寬。

### 3. PowerPoint (.pptx) 導出提示詞要點
- **寬螢幕比例**：明確指定 `16:9` 寬螢幕尺寸（寬 13.333 英吋，高 7.5 英吋），絕不用過時的 4:3。
- **視覺卡片化**：拒絕流水帳，要求使用現代卡片佈局（Rounded Rectangle Card），搭配深色高對比主題。
- **演講備忘稿 (Notes)**：要求將打磨好的演講台詞寫入 `slide.notes_slide`，確保在簡報者檢視畫面下隨時可讀。

### 4. PDF (.pdf) 導出提示詞要點
- **中文字型指定**：在 Python ReportLab 中要求註冊系統中文字型（如 Arial Unicode 或蘋方字型），確保零缺字、無亂碼。
- **企業防偽版面**：加入正式文件編號（Document ID）、宣告資訊邊框與深色色帶。
- **雙方簽章欄位**：在文末規劃結構嚴謹的雙欄法定用印與簽名方塊，建立無可撼動的法律效力感。
