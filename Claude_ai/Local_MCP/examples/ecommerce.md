# 電商與零售實務範例：Playwright MCP 爬蟲、競品比價與登入互動

> 🛒 **產業應用**：電子商務、零售通路、市場調研、行銷比價  
> 🛠️ **核心工具**：Claude Desktop + `playwright` Local MCP Server  
> 📌 **適用情境**：公開牌告查詢、動態電商商品比價、競品規格矩陣分析、需會員登入之受保護頁面存取  

---

## 💡 電商實務背景與價值

在電商與零售運營中，定期監控同業定價、匯率波動與促銷活動是維持競爭力的核心。然而多數電商平台（如 momo、PChome、蝦皮）擁有複雜的前端 JavaScript 渲染與防爬蟲機制，雲端 AI 爬蟲往往會被阻擋。

透過 **Claude Desktop 本地 Playwright MCP**：
- **動態模擬人類瀏覽**：自動在搜尋框輸入關鍵字、觸發搜尋事件、解析商品列表。
- **支援人機協作登入**：遇到需要帳號密碼或 2FA 驗證的頁面，可由人手動在彈出的視窗完成登入，再交由 Claude 接續抓取後台訂單或會員專屬優惠。

## 📝 實作演練範例

### 🔹 範例一：單純公開資訊爬取（台灣銀行牌告匯率）

**實作目標**：驗證 Playwright 能正確開啟公開金融網站，解析表格數據並整理成標準格式。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright 開啟台灣銀行牌告匯率網頁（https://rate.bot.com.tw）：
1. 查詢今日美金 (USD)、日圓 (JPY) 與歐元 (EUR) 對新台幣的『現鈔買入』與『現鈔賣出』匯率。
2. 將結果整理成 Markdown 表格輸出。
```

---

### 🔹 範例二：動態搜尋與商品比價（momo 購物網）

**實作目標**：驅動瀏覽器在搜尋框中輸入商品名稱，解析動態載入的商品清單與價格。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright 開啟 momo 購物網（https://www.momoshop.com.tw）：
1. 在搜尋框中輸入『毛寶洗碗精』並進行搜尋。
2. 幫我收集搜尋結果前 5 筆商品的『商品名稱』與『促銷價格』。
3. 將結果整理成 Markdown 表格輸出。
```

---

### 🔹 範例三：競品市場調查與交叉對比分析

**實作目標**：先查詢自營商品資訊，接著搜尋競品，由 Claude 自動計算並產出競品交叉分析矩陣。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright 開啟 momo 購物網（https://www.momoshop.com.tw）：
1. 在搜尋框中輸入『毛寶 小蘇打洗碗精 無香精』並搜尋，記錄我方產品的促銷價格與規格。
2. 接著重新搜尋『小蘇打洗碗精』，尋找其他競品（例如橘子工坊、茶籽堂、淨毒五郎等）。
3. 收集前 5 筆競品商品的『品牌名稱』、『商品名稱』、『容量』與『促銷價格』。
4. 將我方產品與這 5 筆競品進行交叉對比，整理成 Markdown 比較表格，並針對價格競爭力提供簡單對比建議。
```

---

### 🔹 範例四：登入型網站操作（人機協作半自動登入）

**實作目標**：處理需要會員帳號密碼或手機 SMS 雙重驗證（2FA）的網站。

> ⚠️ **關鍵設定提示**：
> 必須保持預設的**有頭模式（Headed Mode）**，絕對不能在 `claude_desktop_config.json` 加入 `"--headless"`，否則瀏覽器不會顯示在螢幕上，導致無法手動輸入帳密。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright 開啟 momo 購物網登入頁（https://www.momoshop.com.tw/member/Login.jsp）：
1. 請開啟頁面後停在登入畫面，提示我進行手動登入。
2. 當我在對話框回覆「我已完成登入」後，請幫我前往『會員中心 -> 訂單查詢』。
3. 幫我收集最近 3 筆訂單的『訂單編號』、『訂購日期』與『訂單金額』，整理成 Markdown 表格輸出。
```

**操作流程說明：**
1. 下達指令後，Claude 會呼叫 Playwright 開啟實體瀏覽器視窗並前往登入頁。
2. 您直接在彈出的瀏覽器視窗中手動輸入帳號、密碼或驗證碼並登入。
3. 登入成功後，在 Claude 對話框輸入：「我已完成登入，請繼續」。
4. Claude 便會沿用該 Session 已登入的 Cookie 狀態，繼續接手執行分頁切換與資料擷取。

---

## 💡 實務注意事項

1. **大量爬取建議**：Playwright MCP 適合「互動式探索、驗證邏輯與即時調研」；若要每日定期大量爬取，建議請 Claude 協助產出獨立的 Python/Node.js Playwright 腳本並以 Cron 排程運行。
2. **遵守網站使用規範**：請遵守各電商平台的 robots.txt 與服務條款，避免高頻頻率請求造成伺服器負擔。
