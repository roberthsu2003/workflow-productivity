# 創投（VC）實務範例：Playwright MCP 本地自動化爬蟲與動態調研

> 💼 **產業應用**：創投（Venture Capital）、投資研究、標的評估（Deal Sourcing / Due Diligence）  
> 🛠️ **核心工具**：Claude Desktop + `playwright` Local MCP Server  
> 📌 **適用情境**：突破雲端白名單限制、抓取無公開 API 的新創官網、動態 JS 渲染網頁截圖、半導體與關鍵技術情報蒐集  

---

## 💡 創投實務背景與價值

創投機構在進行早期投資評估（Deal Sourcing）與盡職調查（Due Diligence, DD）時，經常需要面對以下挑戰：
1. **新創官網無公開 API**：早期團隊官網通常僅有展示頁面，或大量使用 Webflow、React、Vue 等前端框架動態渲染內容，傳統靜態網頁擷取工具無法抓取完整文字。
2. **雲端網路白名單限制**：雲端 AI 網頁版受限於官方伺服器網路白名單政策，常被目標網站的防爬機制阻擋（如 Cloudflare 等）。
3. **網頁即時存證**：投資經理需要保留新創公司當前的產品文案、定價、團隊名單與宣傳標語作為歷史紀錄。

透過 **Claude Desktop 本地 Playwright MCP**，Claude 能直接調用您電腦本機的真實瀏覽器（Chromium/Firefox/WebKit），自動滾動頁面確保動態內容渲染完全、擷取關鍵文字，並執行視覺截圖存檔。

---

## 📝 實作驗證任務

請確認本機已安裝並啟動 `playwright` MCP 伺服器，開啟 **Claude Desktop** 對話視窗，直接複製以下 Prompt 貼入測試：

### 🔹 任務選項 A：動態網站資料爬取與重點整理（公開資訊 / 產業新聞）

**實作目標**：針對特定科技賽道（如半導體先進封裝、CPO 矽光子），快速從科技新聞網站彙整最新動態與市場情報。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 幫我開啟科技新報（https://technews.tw）或公開新聞網頁：
1. 搜尋過去一週關於『半導體封裝』或『CPO 矽光子』的新聞報導
2. 擷取前 3 筆資料的『標題』、『發布日期』與『摘要重點』
3. 將結果整理成 Markdown 表格輸出，並給出 2 點投資人關注重點分析
```

---

### 🔹 任務選項 B：新創標的網站動態網頁截圖與產品分析

**實作目標**：針對剛接觸的新創公司官網，模擬投資分析師進行第一階段初篩（Screening），自動滾動網頁載入內容、進行視覺截圖保存，並提煉投資關注維度。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 開啟指定的新創公司官網（或科技新聞頁面）：
1. 開啟網頁並滾動頁面確保動態 JS 內容完全載入
2. 讀取頁面文字並對首頁重要區塊進行截圖保存
3. 提煉出該公司的『核心產品/技術』、『應用市場』與『團隊優勢』
4. 依據上述資訊，列出 3 個若要進行訪談時建議詢問創辦團隊的 DD 關鍵問題
```

---

### 🔹 任務選項 C：雙標的競品快速交叉對比（Due Diligence 初階比對）

**實作目標**：同時瀏覽兩家同賽道競爭對手的官方網站，擷取其商業模式與技術訴求，產出投資比對矩陣。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 分別造訪以下兩家新創官方網站：
- 標的 A 官網：[請貼入標的 A 網址，如 https://example-startup-a.com]
- 標的 B 官網：[請貼入標的 B 網址，如 https://example-startup-b.com]

任務要求：
1. 分別擷取兩家公司的「核心產品訴求」、「目標客群（2B / 2C / 企業端）」與「定價/商業模式」。
2. 製作一個 Markdown 橫向對比表格。
3. 從創投角度，點評兩者在市場定位上的差異與潛在競爭壁壘。
```

---

## ✅ 實作驗證檢核清單（Checklist）

完成實作時，請核對以下項目：

- [ ] **MCP 服務連線正常**：在 Claude Desktop 設定（Settings -> Developer）中確認 `playwright` 狀態顯示為綠色或藍色 Running。
- [ ] **本機瀏覽器自動喚起**：下達指令後，Claude Desktop 能自動驅動本機 Playwright 瀏覽器視窗彈出並執行導航動作。
- [ ] **突破雲端白名單限制**：能成功存取並解析包含動態 JavaScript 渲染的公開新聞網站或新創首頁。
- [ ] **視覺截圖與動態渲染**：Playwright 成功滾動網頁，並產出頁面重點截圖存證。
- [ ] **結構化報告輸出**：成功將爬取到的文字與數據彙整成清晰的 Markdown 摘要表格或投資分析建議。

## 💡 創投實務操作小技巧

1. **有頭模式（Headed Mode）的優勢**：
   - 預設模式下瀏覽器視窗會彈出，投資人可以親眼確認 Claude 正在檢視的畫面，避免 AI 產生幻覺（Hallucination）。
2. **遇到 Cloudflare 或驗證碼時**：
   - 由於視窗看得見，若出現機器人驗證或登入畫面，可手動在彈出的瀏覽器視窗點擊完成驗證，再於 Claude 輸入「我已通過驗證，請繼續」，AI 即可接續作業。
3. **搭配進階 Skill 模組**：
   - 若需結合更深度的台灣深科技標的（如無人機國家隊、矽光子與邊緣 AI 晶片），可參考 [VC Playwright 台灣在地實戰專章](../../Skills/VC_Playwright/README.md)。
