# 工研院綠能與環境研究所實務範例：Playwright MCP 本地自動化爬蟲與動態情報調研

> 🌿 **產業應用**：綠能科技、環境永續、電力系統研發、淨零碳排政策追蹤、儲能與再生能源評估  
> 🛠️ **核心工具**：Claude Desktop + `playwright` Local MCP Server  
> 📌 **適用情境**：台電即時電力資訊爬取、經濟部能源署/氣候變遷署動態公告、無 API 綠能網站儀表板截圖存證  

---

## 💡 為什麼綠能所研究員使用 Playwright MCP「特別有感」？

工研院綠能所的研發與政策幕僚同仁在進行產業情資蒐集、電網監控與法規研究時，傳統工具（如靜態 Python 爬蟲、Curl 或雲端 AI 網頁版）經常面臨四大痛點：

```text
傳統工具困境                                    Playwright 本地 MCP 解決方案
┌─────────────────────────────────┐           ┌─────────────────────────────────┐
│ 1. 動態 JS/圖表只抓到空白骨架     │           │ 1. 真實 Chromium 完整渲染 JS 與圖表│
│ 2. 雲端 AI 被政府/電力網站阻擋   │   ──────► │ 2. 本機 IP 連線，突破雲端白名單限制 │
│ 3. 缺乏視覺存證，無法向長官證明 │           │ 3. 自動滾動 + 即時截圖，眼見為憑 │
│ 4. 寫爬蟲程式碼門檻高、維護不易 │           │ 4. 自然語言下達指令，5 秒產出報告 │
└─────────────────────────────────┘           └─────────────────────────────────┘
```

1. **突破「動態渲染」限制，告別空白網頁**：
   - 現代能源與電力平台（如台電即時電力負載圖、再生能源即時發電量）大量使用 Vue、React 或 Highcharts/ECharts 動態繪製。
   - 雲端 AI 僅能抓取靜態 HTML，往往只看到 `<div id="chart-loading"></div>`；Playwright 則是在您本機啟動真實瀏覽器，等待圖表與數據完全計算渲染完畢才讀取，保證資料抓得到！
2. **突破「雲端網路白名單」限制**：
   - 官方雲端網頁版（claude.ai）受限於海外雲端伺服器 IP 與資安白名單，連線國內特定政府網站時極易被 WAF 防火牆阻擋。
   - Playwright MCP 使用您辦公室電腦的真實本機網路發出請求，只要您的 Chrome 開得起來，Claude 就能操作！
3. **有頭模式（Headed Mode）視覺存證**：
   - 即時備轉容量、瞬時風光發電出力瞬息萬變。Playwright 可彈出瀏覽器視窗，自動滾動並精準對關鍵儀表板進行「視覺截圖存證」，直接作為技術評估報告的佐證圖表。
4. **零程式門檻，直覺語言操作**：
   - 不必寫任何一條 Selenium 或 Puppeteer 程式碼，研究員只需在 Claude Desktop 對話框輸入業務需求，Claude 就會自動操作瀏覽器完成導航、滾動、解析與整理。

## 📝 實作演練任務（綠能所專屬情境）

請確認本機已安裝並啟動 `playwright` MCP 伺服器，開啟 **Claude Desktop** 對話視窗，複製以下 Prompt 進行實測：

### 🔹 任務選項 A：台電即時電力供需與再生能源發電佔比動態監控

**實作目標**：自動瀏覽台灣電力公司官網，等待即時 JavaScript 儀表板渲染完畢，擷取今日即時用電量、最大供電能力、備轉容量率燈號與太陽能/風力發電出力。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 幫我造訪台灣電力公司「今日電力資訊」網頁（https://www.taipower.com.tw）：
1. 開啟頁面並等待動態負載與發電數據完全載入。
2. 擷取以下關鍵電力指標：
   - 目前用電量 (MW) 與 預估最高用電量 (MW)
   - 目前最大供電能力 (MW)
   - 目前備轉容量率 (%) 與 供電充裕燈號狀態
   - 再生能源（太陽能與風力）目前的即時發電量與佔比估算
3. 將結果整理成清晰的「今日即時電力供需狀況報告」Markdown 表格，並依據綠能所專業角度，提出 2 點電網調度與儲能應對觀察。
```

---

### 🔹 任務選項 B：主管機關淨零政策與碳費法規情報追蹤

**實作目標**：針對淨零碳排、碳費徵收機制與最新儲能補助要點，從主管機關公開網站自動搜尋、摘要並產出研發因應對策。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 造訪環境部氣候變遷署（https://cca.moenv.gov.tw）或經濟部能源署（https://www.moeaea.gov.tw）最新消息區：
1. 搜尋近一個月內關於「碳費徵收機制」、「儲能系統示範」或「地熱發電獎勵」的最新公告。
2. 擷取最新 3 筆關鍵公告的『發布日期』、『主管機關/政策名稱』與『核心條文/補助要點』。
3. 請製作 Markdown 摘要表格，並針對每一項公告，列出：
   - 對國內能源/排碳產業之機會與衝擊
   - 工研院綠能所技術研發端之因應行動建議（條列 3 點）
```

---

### 🔹 任務選項 C：國內外綠能/儲能新創標的官網動態調研與規格解析

**實作目標**：評估國內外儲能系統或新能源新創技術時，由 Playwright 深入官網滾動載入規格表，截圖關鍵技術結構，提煉電池循環壽命、C-rate 與安全認證。

**在 Claude Desktop 中輸入 Prompt：**
```text
請使用 Playwright MCP 造訪指定的新能源/儲能系統技術官網（例如特定儲能或電芯廠商官網）：
1. 開啟產品介紹頁面，向下滾動確保動態 JS 渲染的規格參數表（Datasheet）完全載入。
2. 對產品外觀與核心規格區塊進行網頁截圖保存。
3. 提煉該系統的核心技術參數：
   - 電池技術類型（LFP / NMC / 全固態 / 釩液流等）
   - 額定容量、充放電倍率 (C-rate) 與 預期循環壽命
   - 通過的國際安全規範（如 UL9540、UL9540A、IEC 62619 等）
4. 依工研院技術審查標準，產出一份「儲能技術初步審查速報」。
```

## ✅ 實作驗證檢核清單（Checklist）

完成綠能所演練時，請逐一核對以下項目：

- [ ] **MCP 服務連線正常**：在 Claude Desktop 設定（Settings -> Developer）中確認 `playwright` 狀態顯示為綠色或藍色 Running。
- [ ] **真實瀏覽器視窗彈出**：下達指令後，電腦桌面上能看見真實 Chromium 視窗啟動並自動前往電力/政府網站。
- [ ] **動態圖表成功解析**：成功等待 JavaScript 動態資料加載完成，沒有出現資料空白或載入失敗情形。
- [ ] **視覺截圖與動態渲染**：Playwright 成功自動滾動視窗，並產出關鍵圖表或規格截圖。
- [ ] **結構化專業報告產出**：Claude 成功將爬取之電力負載或政策數據整理為 Markdown 專業報告，並附帶綠能技術建議。

## 💡 綠能所研究員實務操作小技巧

1. **彈出視窗的重要性（避免數據幻覺）**：
   - 預設保持有頭模式（Headed Mode），研究員可以在視窗中親眼看見台電當前即時數據，確保 AI 擷取的數據與畫面完全一致，符合科研嚴謹性要求。
2. **遇政府網站驗證碼或公文系統登入**：
   - 由於瀏覽器看得見，若網站跳出驗證碼或需公文憑證登入，可直接用手動在彈出視窗完成輸入，再於 Claude 輸入「我已登入完成，請繼續抓取資料」，AI 即可順暢接手後續分析。
3. **延伸銜接綠能專用 Skill**：
   - 爬取到的技術與法規資料，可進一步丟給 [綠能專案技術摘要與規格評核專家](../../Skills/ITRI_Creator/README.md) 產出制式規格評審報告，或透過 [風電技術評估 PPTX Skill](../../Skills/GWorkspace/05_ITRI_Green_Energy_PPTX/README.md) 一鍵生成主管匯報簡報！
