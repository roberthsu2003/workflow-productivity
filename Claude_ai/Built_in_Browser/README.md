# 🌐 內建瀏覽器（Built-in Browser）：Claude 自己開網頁幫你做事

> 🔵 **方案需求**：**Pro / Max / Ultra**；**Team / Enterprise** 預設可用（管理員可關閉）。Free 方案不支援。
> 💻 **環境**：**Claude Desktop**（macOS、Windows、Linux Beta）。網頁版或手機交辦的任務也能用，但那台電腦的 Claude Desktop 必須**開著且連網**。
> 📖 官方參考：[Use the built-in browser](https://support.claude.com/en/articles/16607400-use-the-built-in-browser-in-claude-cowork)

---

## 💡 這是什麼？

**內建瀏覽器**是 Claude Desktop 裡面自帶的一個瀏覽器。當任務需要用到網站時，它會在**側邊面板**打開，你可以**看著 Claude 自己開網頁、閱讀、點按鈕、輸入文字、填表單**。

- **免安裝**：不用裝任何擴充功能，Claude Desktop 打開就有。
- **和你的瀏覽器分開**：Claude 不會碰到你 Chrome 裡的登入狀態，除非你主動匯入。
- **自動出現**：只要任務需要上網操作，就會自動開啟。

---

## 🆚 內建瀏覽器 vs Claude in Chrome

| | 🌐 內建瀏覽器 | 🧩 [Claude in Chrome](../claude_in_chrome/README.md) |
| :--- | :--- | :--- |
| 在哪裡執行 | Claude Desktop 側邊面板中的獨立瀏覽器 | 你自己的 Chrome（透過擴充功能） |
| 安裝 | 不用安裝 | 要裝 Chrome 擴充功能 |
| 登入帳號 | 獨立的，除非你匯入登入資料 | 直接使用你 Chrome 已登入的帳號 |
| 最適合 | **把任務中「上網那一段」整個交給 Claude** | **在你已經打開的網頁上請 Claude 幫忙** |

> ⚙️ **設定預設瀏覽器**：到 **Settings** 的 **Preferred browser** 選擇要用哪一個。如果你原本就在用 Claude in Chrome，它會維持是預設值。想臨時換一個，直接在 Prompt 中說「請用內建瀏覽器」即可。

---

## 🔑 登入網站：兩種方式

1. **匯入登入資料（Cookies）**：第一次使用時可以從其他瀏覽器匯入，並**勾選要匯入哪些網站**（預設全選，請把不需要的取消）。
   - macOS / Linux：支援 Chrome、Edge、Brave、Chromium、Firefox
   - Windows：支援 Firefox
   - ❌ 不支援 Safari
2. **直接在內建瀏覽器登入**：Claude 會在這台電腦上記住登入狀態，之後的任務都能用。

> ⚠️ **只登入需要的網站**。登入狀態會保留給之後的任務使用，涉及金錢或個資的網站請特別小心。

## 🎯 使用情境

| 情境 | 說明 |
| :--- | :--- |
| 🔎 **比價與市場調查** | 打開多個購物網站，整理價格、規格、評價成比較表 |
| 📰 **新聞與競品追蹤** | 逐一打開新聞網站閱讀全文，整理成晨報（可搭配[排程](../Scheduled/README.md)） |
| 📝 **重複填表** | 把 Excel 名單逐筆填到網頁表單（例如活動報名、系統登錄） |
| 📋 **網頁資料整理** | 讀取沒有 API 的網站（公告、政府開放資料頁）並整理成表格 |
| ✅ **網站檢查** | 檢查公司網站的連結是否失效、表單能不能送出 |

## 🧪 實作範例（Prompt 可直接複製）

### 範例 1｜比價小幫手　`入門`

```markdown
## Task
請用內建瀏覽器，到 3 個台灣主要購物網站搜尋「27 吋 4K 螢幕」。

## Constraint
- 每個網站取前 5 名商品
- 只看 8,000～15,000 元之間
- 記錄：品牌型號、價格、評價分數、評價數、商品連結

## Format
整理成一個比較表 Artifact，並推薦 CP 值最高的 3 款，說明理由
```

**觀察重點**：側邊面板會出現瀏覽器，你可以看到 Claude 一頁一頁打開、搜尋、閱讀。第一次操作某個網站時，Claude 會先徵求你的同意。

---

### 範例 2｜政府公告整理　`入門`

```markdown
## Task
請用內建瀏覽器打開「勞動部」官網的最新消息頁面，
整理最近 10 則與「勞工權益、薪資、工時」有關的公告。

## Format
表格欄位：公告日期、標題、重點摘要（30 字內）、對公司人資的影響、原文連結
```

---

### 範例 3｜Excel 名單批次填表　`進階`

```markdown
## Role
你是一位細心的行政助理。

## Task
我上傳了一份「研習報名名單.xlsx」（姓名、Email、單位、餐食），
請用內建瀏覽器打開以下報名表單網址，逐筆幫我填寫並送出：
[貼上表單網址]

## Constraint
- 先填第 1 筆，填好後「不要送出」，先截圖讓我確認欄位對應是否正確
- 我確認後再繼續其餘筆數
- 任何一筆出錯就停下來告訴我

## Format
完成後回報：成功筆數、失敗筆數與原因
```

> 💡 **教學重點**：重要操作請在 Prompt 中要求「**先做一筆讓我確認**」，並使用 **Manually approve** 核准模式。

### 範例 4｜搭配排程：每天早上的競品動態　`進階`

```text
請用內建瀏覽器，每個工作日早上 8 點到以下 3 個競品官網的「最新消息」頁面，
找出過去 24 小時的新公告，整理成 5 點以內的摘要，沒有新消息就寫「今日無更新」。
[競品網址 1] [競品網址 2] [競品網址 3]
```

> ⚠️ 使用內建瀏覽器的排程任務，執行當下電腦必須**開機且 Claude Desktop 開著**。

## 🛡️ 安全須知

- **第一次操作某個網站會先問你**；高風險網站會被直接封鎖。
- 每個動作都會經過安全檢查，比對是否符合你的要求。
- **提示注入（Prompt Injection）風險**：惡意網頁可能藏有想誤導 Claude 的文字。官方的防護能降低風險，但無法完全消除。
- 🚫 **官方強烈建議不要用於**：網路銀行、醫療資訊、他人個資等敏感事務。
- 從信任的網站開始練習；發現任何異常就立刻停止任務。
- Team / Enterprise 管理員可以關閉內建瀏覽器或 Cookies 匯入功能。

## ❓ 常見問題

**Q1：我在網頁版交辦任務，為什麼內建瀏覽器沒有動作？**
內建瀏覽器跑在 Claude Desktop 裡，請確認你的電腦開著，而且 Claude Desktop 已開啟並連網。

**Q2：和「網路搜尋」有什麼不同？**
網路搜尋只能「讀」搜尋結果；內建瀏覽器可以實際**打開網頁、點擊、輸入、填表**，像真人一樣操作網站。

**Q3：Free 帳號可以用嗎？**
不行，需要 Pro 以上方案。
