## 🛠️ 實戰演練 A：WeWork 跨文檔偵探審查

### 第一步：建立專案與配置 Instructions
1. 建立專案：`WeWork 創投盡調沙盒`。
2. 貼入 [Instructions_WeWork.md](./Instructions_WeWork.md) 中的指令。
3. 在 **Project Knowledge** 上傳案例 A 的 4 份練習檔案。

### 第二步：發起偵探質詢
在專案新對話中輸入：
```text
請對 WeWork 本案進行跨文檔盡調審查，抓出財務數據矛盾、創辦人利益衝突與投審會 (IC) 重大風險。
```
**✅ 成果驗收點**：
- [ ] 自動揪出「Community Adjusted EBITDA」將租金扣除的粉飾手法。
- [ ] 標記創辦人私人擁有 "We" 商標並向公司收取 590 萬美元授權費的重大公司治理暗坑。

## 🛠️ 實戰演練 B：Gogoro 台灣產發署補助與美股財報審查

### 第一步：建立專案與配置 Instructions
1. 建立專案：`Gogoro 台灣創投與補助合規沙盒`。
2. 貼入 [Instructions_Gogoro.md](./Instructions_Gogoro.md) 中的指令。
3. 在 **Project Knowledge** 上傳案例 B 的 3 份練習檔案。

### 第二步：發起合規與政策敏感度分析
在專案新對話中輸入：
```text
請評估 Gogoro 在台灣市場的政策補助依賴風險，以及美股上市財務模型是否健康？我們投審會 (IC) 應該注意什麼？
```
**✅ 成果驗收點**：
- [ ] 精算出若扣除經濟部產發署補助（每台 7,000~10,000 元），車輛硬體毛利率將驟降 35%。
- [ ] 連結產發署公文，產出保護投資人的合規切結條款建議。
