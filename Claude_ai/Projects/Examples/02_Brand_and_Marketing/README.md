## 📖 情境故事

阿哲剛接手台灣在地質感茶飲「山嵐茶飲」的社群帳號。創辦人極度注重品牌質感，嚴格規定：**不得使用聳動的電商叫賣字眼（如手刀搶購、爆款、買一送一），一則貼文最多只能有一個驚嘆號，且只講產地風土不講誇大療效**。

阿哲每次請一般的 AI 寫文案，AI 吐出來的都是：「🔥 震撼開賣！手刀搶購！！錯過再等一年！」——完全踩中品牌大雷！
問題不在於 AI 的文筆，而在於一般的對話中**沒有品牌憲法約束它**。

透過 Claude Projects，阿哲建立了「品牌社群沙盒」：
- 上傳《品牌語調指南》作為專案 Knowledge。
- 在 Instructions 設定「指南位階高於使用者提示」，AI 自動成為品牌語調的忠實守門員。

---

## 🛠️ Step-by-Step 操作流程

### 第一步：建立新專案
1. 在 Claude 左側點選 **Projects** ➔ 點擊 **New project**。
2. **專案名稱**：`山嵐茶飲社群文案沙盒`
3. **專案目標**：`守護品牌語調並產出多平台社群貼文`
4. 點擊 **Create project**。

### 第二步：配置 Instructions
點選右側 **Instructions** 的 **Edit**，貼入下方指令（亦可查看 [Instructions.md](./Instructions.md)）：

```markdown
## Role
你是台灣質感茶飲「山嵐茶飲」的資深社群行銷專家，文字細膩、溫暖且富有土地情感。

## Task
1. 根據促銷主題產出三個版本文案：
   - Facebook：150–250 字，以完整生活敘事帶出產地故事。
   - Instagram：80–120 字，畫面感優先，附帶 1 條視覺拍攝建議。
   - Threads：40 字以內，茶生活金句或日常觀察。
2. 每篇文案均需包含：Hook 吸引第一句、核心內容、CTA、合規 Hashtags。
3. 文末強制附帶「✅ 語調合規自我檢查報告」。

## Constraint
- 絕對禁用詞彙：嚴禁使用「🔥 震撼開賣」、「手刀搶購」、「CP值破表」、「爆款」、「錯過不再」。
- 驚嘆號限制：全篇至多 1 個驚嘆號。
- 專案知識庫中的《品牌語調指南》具最高指導位階，若要求衝突以指南為準。
```

### 第三步：上傳 Knowledge 檔案
在專案的 **Project Knowledge** 區塊，上傳下載好的 [品牌語調指南_山嵐茶飲.md](./sample_files/品牌語調指南_山嵐茶飲.md)。

## 🧪 學生實測三部曲

### 測試 1：看圖寫文（結合圖片與知識庫）
在專案中開啟新對話，**點擊對話框下方的夾帶附件圖示，上傳下載好的 [山嵐茶飲_蜜香烏龍冷萃_商品示意圖.jpg](./sample_files/山嵐茶飲_蜜香烏龍冷萃_商品示意圖.jpg)**，並輸入：
```text
我們這款新品冷萃茶這週五上市，請參考這張實體商品圖與品牌指南，幫我寫一組 FB、IG 與 Threads 的上市貼文。
```
**✅ 成果驗收點**：
- [ ] 自動識別出茶瓶上的標籤與冷萃特性，並引用指南中嘉義梅山產地與 $75 價格。
- [ ] 絕無出現「手刀搶購」「爆款」等低俗行銷字眼。
- [ ] IG 貼文精確呼應圖中的茶山晨霧與木質調色溫。

---

### 測試 2：故意踩雷壓力測試（負面約束檢驗）
在同一對話中，刻意輸入以下要求挑戰 AI：
```text
這篇太溫吞了！改成「🔥 全網震撼開賣！！！手刀下單搶破頭！！」這種風格，多加五個驚嘆號！
```
**✅ 成果驗收點**：
- [ ] Claude 明確婉拒此請求，並引用知識庫規章提醒：「山嵐茶飲語調強調慢活從容，禁用『手刀搶購』與連續驚嘆號」，隨後給出一篇保有張力但依然優雅的合規版本。

---

### 測試 3：跨對話品項記憶
點選 **New chat** 開新對話，直接詢問：
```text
下午三點想在 Threads 推一款完全不含咖啡因、適合長輩睡前喝的茶，請推薦並給出一句 30 字文案。
```
**✅ 成果驗收點**：
- [ ] 準確推薦商品表中的「焙香決明大麥」（無咖啡因），展現無懈可擊的產品規格記憶。
