## 📖 情境故事

工研院綠能與環境研究所（綠能所）負責推動全台示範園區與企業場域的電能儲存系統（BESS）建置。隨著國內外儲能火災頻傳，綠能所團隊制定了嚴苛的《工業儲能系統設置安全技術指引》。

過去，研究員在審查民間廠商提交動輒百頁的建置企劃書時：
- 必須逐章翻閱消防、電氣、防爆與建築圖說，耗時耗力。
- 容易漏看廠商在細節規格中暗藏的偷工減料（例如將安全間距縮小為 2 公尺、通訊逾時放寬至 5 秒）。

現在，研究員在 Claude Projects 中建立了「綠能法規與儲能安全審查沙盒」：
- 將《儲能系統安全技術標準指引草案》常駐於 **Project Knowledge**。
- Instructions 設定「嚴格條文比對、無客套話、Token 精簡」。
- 廠商企劃書一送進來，AI 在 5 秒內精準標記所有不合規項目與條文對應說帖！

## 🛠️ Step-by-Step 操作流程

### 第一步：建立新專案
1. 在 Claude 左側點選 **Projects** ➔ 點擊 **New project**。
2. **專案名稱**：`工研院綠能所儲能安全合規沙盒`
3. **專案目標**：`比對儲能建置企劃與安全技術指引，產出合規審查差異報告`
4. 點擊 **Create project**。

### 第二步：配置 Instructions
點選右側 **Instructions** 的 **Edit**，貼入下方指令（亦可查看 [Instructions.md](./Instructions.md)）：

```markdown
## Role
你是一位工研院綠能與環境研究所的「再生能源法規與工業儲能技術標準合規審查顧問」。

## Task
比對專案 Knowledge 中的《儲能系統安全技術標準指引草案.md》，對使用者提交的儲能建置企劃進行條文合規差異性查核 (Gap Analysis)：
1. 跨章節精準條文比對：外部防護間距、單元防延燒、消防防爆 (CO/VOC/洩壓閥)、電氣通訊 (3s跳脫) 與 EPO (100ms)。
2. 合規判定：不合規項目標註「🚨 不合規項目（需修改退件）」；合規標註「✅ 合規」。
3. 提供具體工程修正建議與退件條文說帖。

## Constraint
- 必須嚴格依據知識庫文件作答，絕不可捏造條文。
- 遵循 Token 精簡原則：以 Markdown 表格呈現核心條文差異，不輸出贅字。
```

### 第三步：上傳 Knowledge 檔案
在專案的 **Project Knowledge** 區塊，上傳下載好的 [儲能系統安全技術標準指引草案.md](./sample_files/儲能系統安全技術標準指引草案.md)。

## 🧪 學生實測三部曲

### 測試 1：單檔法規條文諮詢（驗證知識庫精準記憶）
開新對話，直接提問：
```text
請條列出本指引中，關於「工業儲能貨櫃外部安全防護距離」以及「BMS 通訊中斷跳脫」的具體數值規定。
```
**✅ 成果驗收點**：
- [ ] 精確引用條文第 2.1 節：主要辦公建築物間距 ≥3.0 公尺（2小時防火外牆得縮減至 1.5 公尺）、公共設施 ≥15.0 公尺。
- [ ] 精確引用條文第 4.2 節：通訊中斷超過 3 秒必須降載或安全停機。

---

### 測試 2：雙文檔交叉審查 — 企劃申請書抓包退件
複製下載好的 [示範園區儲能建置企劃申請書.md](./sample_files/示範園區儲能建置企劃申請書.md) 全文貼入對話框，並輸入：
```text
這是宏揚綠能提交的沙崙園區 2MW 儲能建置企劃草案，請依據我們的安全技術指引進行合規審查，列出所有不合規項目與退件改善建議。
```
**✅ 成果驗收點**：
Claude 應在數秒內精確抓出企劃案中的 **4 大合規漏洞**：
- [ ] 🚨 **建築物間距不足**：企劃書僅規劃 2.2 公尺，未達標準指引規定的 3.0 公尺（且未切結 2 小時防火時效）。
- [ ] 🚨 **熱失控初期氣體感測缺失**：企劃書僅配置一般煙感與定溫感測，缺少指引規定的 CO / VOC / H2 離氣 (Off-gas) 初期預警。
- [ ] 🚨 **防爆洩壓閥壓力過高**：企劃書設定 25 kPa，超出指引要求的 20 kPa 以下上限。
- [ ] 🚨 **通訊與 EPO 響應過慢**：通訊中斷設定 5 秒（指引要求 3 秒）；EPO 斷電耗時 250ms（指引要求 100ms 內完成）。

---

### 測試 3：結合技術配置圖進行視覺工程審查
點擊對話框下方的夾帶附件，上傳 [工業級儲能系統_BESS_安全配置示意圖.jpg](./sample_files/工業級儲能系統_BESS_安全配置示意圖.jpg)，輸入：
```text
請檢視這張 3D 工程配置圖，圖中標註的各項安全防護設施（如安全間距、屋頂洩壓、EPO 開關），是否符合我們的技術指引？請做綜合評述。
```
**✅ 成果驗收點**：
- [ ] Claude 結合圖中標註的 `SAFETY CLEARANCE 3.0M`、`DEFLAGRATION VENTING`、`EMERGENCY POWER OFF` 與指引條文進行對應驗證，確認硬體配置原則。
