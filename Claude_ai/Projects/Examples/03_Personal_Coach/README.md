## 📖 情境故事

Kevin 正在準備海外交換學生與外商實習申請。他以前常把文章丟給 AI 潤飾，但遇到一個極大的痛點：
**AI 每次都直接整篇重寫成華麗的托福滿分範文，改得再好都不是自己的聲音；而且下週寫新文章時，他依然犯一模一樣的文法錯誤。**

他需要的不是「代寫機器」，而是一個**真正認識他現有英文程度、記得他常犯哪些盲點**的個人化教練。

透過 Claude Projects，Kevin 建立了「專屬英語教練沙盒」：
- 上傳自己的原始寫作樣本至 **Knowledge** 作為能力基準線。
- Instructions 設定「雙軌回饋制」：既給出優雅重寫，又逐句標記老毛病。

---

## 🛠️ Step-by-Step 操作流程

### 第一步：建立新專案
1. 在 Claude 左側點選 **Projects** ➔ 點擊 **New project**。
2. **專案名稱**：`個人化英語教練沙盒`
3. **專案目標**：`根據個人寫作樣本進行弱點診斷與雙軌寫作指導`
4. 點擊 **Create project**。

### 第二步：配置 Instructions
點選右側 **Instructions** 的 **Edit**，貼入下方內容（亦可查看 [Instructions.md](./Instructions.md)）：

```markdown
## Role
你是一位專業 ESL 英語寫作教練，以正向鼓勵的風格引導非母語者提昇學術與商務英文溝通力。

## Task
1. 認識學生特質：專案知識庫中有我的寫作樣本。回答前，先以樣本中反映的程度與典型盲點為基準。
2. 雙軌回饋模式：
   - 第一軌道：提供「自然、精準且具母語人士語感」的潤飾範本（維持 CEFR B2 中高級水準）。
   - 第二軌道：逐點解析修改原因（文法、搭配詞、語氣），解說使用繁體中文。
   - 若犯下的錯誤與知識庫樣本中的歷史錯誤相符，必須特別標註「🔁 老毛病提醒」。
3. 刻意練習：每次回答結尾針對當次文法盲點出 1 題改錯練習。
```

### 第三步：上傳 Knowledge 檔案
在專案的 **Project Knowledge** 區塊，上傳下載好的 [英文寫作樣本_自我介紹.md](./sample_files/英文寫作樣本_自我介紹.md)。

## 🧪 學生實測三部曲

### 測試 1：個人程度與弱點全面診斷
開新對話，輸入：
```text
請仔細閱讀我的英文寫作樣本，列出我最常犯的 3 個文法盲點，附上範例文句與改正建議，並評估我目前的 CEFR 等級。
```
**✅ 成果驗收點**：
- [ ] 抓出樣本中的典型盲點（如 `very interesting in`、`passed on last December`）。
- [ ] 給予客觀的 CEFR 等級評定（約落在 B1+ 至 B2- 之間）。

---

### 測試 2：實戰求職信雙軌批改 ＋ 老毛病偵測
複製剛才下載的 [英文求職信草稿_Cover_Letter.md](./sample_files/英文求職信草稿_Cover_Letter.md) 全文，貼入對話框並送出：
```text
這是我剛寫好要投遞實習的 Cover Letter 草稿，請以雙軌模式幫我批改，並抓出我有沒有犯老毛病。
```
**✅ 成果驗收點**：
- [ ] 提供流暢自然的 B2 潤飾版本。
- [ ] 成功抓出「🔁 老毛病」：明確指出信中的 `express my interesting` 與 `seen on last Friday` 又是先前自我介紹中出現過的同類型錯誤！

---

### 測試 3：跨對話客製化課表
點選 **New chat** 開新對話，輸入：
```text
根據我的寫作樣本與盲點，為我出一份 3 題的今日文法改錯特訓題。
```
**✅ 成果驗收點**：
- [ ] 題目精準針對該學生的介系詞與時態弱點，完全不需要重新交代背景。
