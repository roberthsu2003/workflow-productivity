# 範例 4：個人第二大腦（成長型知識庫）🧠

> **難度**：⭐⭐⭐　|　**所需時間**：約 30 分鐘　|　**用到的模擬檔案**：無——這個專案**從零開始**，知識庫是你自己一張一張養大的

## 📖 情境故事

宗翰每天都在「學東西」：看文章、上課、看 YouTube、跟人聊天得到的啟發……但這些收穫散落在 LINE 記事本、手機截圖和瀏覽器書籤裡，**一週後就再也找不到了**。

前面三個範例都是「先上傳檔案，AI 才變聰明」。但如果一開始**根本沒有累積好的檔案**呢？

這個範例示範相反的方向：**用專案裡的 Prompt + Artifacts，把每天的新收穫變成標準化的「知識卡片」，回存到 Knowledge**——專案的大腦，是你一張卡片一張卡片餵大的。

## 🎯 你將學到

- 設計「收錄／查詢／回顧」三種模式的專案 Prompt
- 用 **Artifacts** 產出格式固定的 Markdown 知識卡片
- 核心循環：**對話產出 → 下載卡片 → 上傳 Knowledge → 大腦長大**

```mermaid
graph LR
    A["💬 對話中學到東西"] -->|收錄：| B["📇 Artifact 知識卡片"]
    B -->|下載 + 上傳| C["📂 Knowledge"]
    C -->|查詢：| D["🧠 任何新對話都能取用"]
    D --> A
```

## 🛠️ 動手做

### Step 1：建立專案

- Projects → **New project**，在「Create a project」視窗中：
  - **What are you working on?**：`我的第二大腦`
  - **What are you trying to achieve?**：`累積個人知識卡片，隨時查詢與回顧`

### Step 2：貼入 Instructions

```text
你是我的「第二大腦」知識管理員。這個專案的 Knowledge 會隨時間不斷成長，
你的任務是把我零散的輸入變成結構化的知識卡片，並在我需要時準確取用。

【收錄模式】當我的訊息以「收錄：」開頭（後面可能是文章、上課筆記、心得）：
1. 整理成一張「知識卡片」，以 Artifact 輸出單一 Markdown 檔，格式固定：
   # 卡片標題（15 字內）
   - 日期：（今天日期）
   - 標籤：2–4 個 #標籤
   - 來源：（我提供的出處，沒有就寫「口述」）
   ## 三句話摘要
   ## 值得記住的金句或關鍵數據
   ## 與舊卡片的關聯（比對 Knowledge 中已有的卡片，指出可連結的卡片標題；
      若目前沒有相關卡片，寫「暫無」）
2. 輸出後提醒我：「請下載這張卡片並上傳到專案 Knowledge，讓大腦長大。」

【查詢模式】當我的訊息以「查詢：」開頭：
只根據 Knowledge 中的知識卡片回答，並在結尾列出引用的卡片標題。
知識庫中沒有的內容，直接回答「大腦裡還沒有這方面的記憶」，絕不編造。

【回顧模式】當我輸入「每週回顧」：
彙整 Knowledge 中的所有卡片，以 Artifact 產出一張「週回顧卡片」，包含：
本週卡片清單、跨卡片的共同主題、一個值得我深入研究的問題。
週回顧卡片同樣提醒我回存 Knowledge。
```

### Step 3：不用上傳任何檔案

對，**Knowledge 現在是空的**——接下來親手把它養大。

---

## 🧪 養腦四部曲

### 對話 1：收錄第一張卡片

開新對話，貼入：

```text
收錄：今天讀到「費曼學習法」——想真正搞懂一個概念，就試著用最簡單的話
把它解釋給完全不懂的人聽。解釋卡住的地方，就是你其實沒懂的地方。
回去重讀，再解釋一次，直到能講得又簡單又清楚。
來源：《費曼學習法》書摘
```

**✅ 驗證點**：
- [ ] Claude 以 **Artifact** 輸出一張格式完整的知識卡片
- [ ] 「與舊卡片的關聯」寫「暫無」（因為大腦還是空的）
- [ ] 結尾提醒你下載並上傳

**🔑 關鍵動作**：下載卡片（或複製另存 .md），**上傳到專案 Knowledge**。恭喜，大腦有第一個記憶了。

### 對話 2：收錄第二張——觀察「關聯」出現

再開新對話，收錄一個你**這門課才學到**的東西：

```text
收錄：學到 RTCCF 提示詞框架——寫 Prompt 時包含五要素：
Role（角色）、Task（任務）、Context（背景）、Constraint（限制）、Format（格式），
AI 的回答品質會大幅提升。老師說「會提問的人，AI 才會變聰明」。
來源：Claude 工作流課程
```

**✅ 驗證點**：這次「與舊卡片的關聯」**不再是暫無**——Claude 讀到了 Knowledge 裡的費曼卡片，可能會連結「教別人」與「問 AI」都是靠輸出檢驗理解。照樣下載、上傳。

### 對話 3：查詢——大腦開始回報你

**開一個全新對話**，輸入：

```text
查詢：我學過哪些提升學習效率的方法？
```

**✅ 驗證點**：Claude 根據兩張卡片回答，結尾列出引用的卡片標題。

再測**防幻覺**：

```text
查詢：我有收錄過關於投資理財的卡片嗎？
```

**✅ 驗證點**：回答「大腦裡還沒有這方面的記憶」——**不編造**，這是可信賴知識庫的底線。

### 對話 4：每週回顧——讓大腦自己長出洞察

新對話輸入 `每週回顧`。

**✅ 驗證點**：產出週回顧卡片（Artifact），指出兩張卡片的共同主題，並拋出一個值得深入的問題。**把週回顧卡片也回存 Knowledge**——連「回顧」本身都成為大腦的一部分。

---

## 💪 挑戰題

1. **30 天養腦計畫**：每天收錄一張卡片，30 天後問「查詢：這個月我最常關注什麼主題？我自己有發現嗎？」
2. **索引卡**：當卡片超過 10 張，請 Claude 產出一張「總索引卡」（依標籤分類的卡片地圖）並回存，之後查詢會更精準。
3. **接上 Connectors**：為專案開啟 Google Drive，把知識卡片存在 Drive 資料夾，請 Claude 直接讀取——省去手動上傳的步驟。
