# 範例 4：商業數據分析庫（會自動進化的圖表）📊

> **難度**：⭐⭐⭐　|　**所需時間**：約 20 分鐘　|　**用到的模擬檔案**：請於本頁複製模擬數據

## 📖 情境故事

小美是星橋科技的營運主管。她每季都需要向總經理報告銷售趨勢，並附上精美的數據圖表。

以前，她必須手動將 Q1 和 Q2 的 Excel 資料表貼給 AI，或者每次都要手動組合多份 CSV 檔案才能讓 AI 畫出完整的趨勢圖。如果下一季數據出來了，她又得重新把三個季度的檔案再上傳一次。

現在，小美利用 Claude Projects 建立了「商業數據分析庫」：
* 她只要把每季的數據檔案**丟進專案 Knowledge**（或直接關聯 Google Drive）。
* 之後不論開幾個新對話，她只需要輸入一模一樣的指令：`繪製銷售趨勢圖`。
* Claude 就會自動掃描 Knowledge 裡所有的資料表，**自動合併它們**，並畫出最新、最完整的趨勢圖。
* **資料愈多，同一個指令生出來的圖表就愈完整！**

## 🎯 你將學到

- 撰寫一個能自動識別並合併多資料表的專案 Instructions
- 見證「不更改 Prompt，僅更新 Knowledge，新對話圖表便自動进化」的過程
- 瞭解多種將資料更新至 Knowledge 的商業管道（如 Google Drive 自動同步）

## 🛠️ 動手做

### Step 1：建立專案

1. 在 Claude 左側欄點選 **Projects** → **New project**
2. **What are you working on?**（專案名稱）輸入：`商業數據分析沙盒`
3. **What are you trying to achieve?**（目標描述）輸入：`自動合併多季銷售數據並繪製趨勢圖表`

### Step 2：貼入 Instructions

在專案右側的 **Instructions** 區塊，貼入以下指令：

```text
你是星橋科技的「資深商業數據分析師 (BI Analyst)」。
你的任務是讀取專案 Knowledge 中所有銷售數據檔案（可能是 Markdown、CSV 或 TXT 格式）。

當我要求「分析銷售趨勢並繪製圖表」時，請執行以下步驟：
1. 自動掃描 Knowledge 中所有包含銷售數據的檔案。
2. 將所有不同季度/月份的數據按時間順序（由遠到近）進行合併。如果有重複或重疊的月份，以最新上傳的檔案為準。
3. 計算合併後的關鍵指標：
   - 總銷售額 (Total Revenue)
   - 平均月銷售額 (Monthly Average)
   - 成長率最顯著的月份
4. 使用 Artifact 建立一個互動式圖表（以 HTML + Chart.js，或 React + Recharts 呈現），繪製折線圖或柱狀圖，呈現完整的銷售金額趨勢變化。請勿使用 Mermaid 語法，因為介面無法正確渲染。
5. 附上簡短的商業洞察（2-3 點）。
```

---

## 🧪 圖表進化兩部曲

請準備好以下兩份模擬數據（您可以在電腦上分別將它們儲存為 `sales_Q1.md` 和 `sales_Q2.md`，或者直接複製內容另存新檔）：

### 模擬數據 A：`sales_Q1.md`
```markdown
# 星橋科技 2026 第一季銷售數據
| 月份 | 產品線 | 銷量 (台) | 銷售金額 (萬新台幣) |
|---|---|---|---|
| 1月 | 智慧客服系統 | 120 | 240 |
| 2月 | 智慧客服系統 | 150 | 300 |
| 3月 | 智慧客服系統 | 180 | 360 |
```

### 模擬數據 B：`sales_Q2.md`
```markdown
# 星橋科技 2026 第二季銷售數據
| 月份 | 產品線 | 銷量 (台) | 銷售金額 (萬新台幣) |
|---|---|---|---|
| 4月 | 智慧客服系統 | 210 | 420 |
| 5月 | 智慧客服系統 | 250 | 500 |
| 6月 | 智慧客服系統 | 300 | 600 |
```

---

### 第一階段：僅有第一季數據時

1. 在專案的 **Knowledge** 區塊中，上傳 `sales_Q1.md`。
2. 在專案中開啟一個**全新對話**，輸入以下指令：

```text
分析銷售趨勢並繪製圖表
```

**✅ 觀察結果**：
* Claude 讀取了 Knowledge 中的 `sales_Q1.md`。
* 輸出第一季的總銷售額（900 萬），並用 Mermaid 畫出一張包含 **1月、2月、3月** 的銷售趨勢折線圖。

---

### 第二階段：加入第二季數據，見證自動進化

小美拿到了最新的第二季報表，她想更新專案的記憶。

1. **上傳新數據**：在專案的 **Knowledge** 區塊中，加碼上傳 `sales_Q2.md`。（此時 Knowledge 中同時存有 `sales_Q1.md` 與 `sales_Q2.md` 兩份檔案）。
2. **開啟一個全新的對話**（這非常重要，這能確保對話不受前一次對話的記憶干擾，完全依賴最新 Knowledge）。
3. 輸入**一模一樣的指令**：

```text
分析銷售趨勢並繪製圖表
```

**✅ 觀察結果**：
* Claude 這次自動掃描並**合併**了兩份檔案。
* 輸出的總銷售額更新為第一季與第二季的總和（2420 萬）。
* Mermaid 圖表自動延伸，畫出一張橫跨 **1月到6月**、呈現持續增長趨勢的全新折線圖！
* **你的 Prompt 一個字都沒變，但產出的圖表內容已經不一樣了！**

## 💡 商業實務：如何透過多種方式增加與更新 Knowledge？

在真實的企業應用中，手動下載並上傳檔案依然有點繁瑣。Claude Projects 提供了多種靈活的資料同步管道：

### 1. Google Drive / Microsoft OneDrive 連接器（自動同步）
* **做法**：在 Project 的 **Capabilities** 中開啟 Google Drive 連接器，並授權連結一個名為 `星橋科技營運數據` 的雲端硬碟資料夾。
* **優勢**：您或您的團隊成員只需要在電腦上把每個月的 CSV/Excel 檔案存入該 Google Drive 資料夾。Claude Project 會在背景自動同步。當您在 Claude 裡開新對話問同一個問題時，圖表就會自動抓取最新上傳的檔案。

### 2. GitHub 連接器（適合技術團隊）
* **做法**：將專案連接到特定的 GitHub Repository。
* **優勢**：當研發團隊將最新的 API 規格書或程式代碼 `git push` 到 GitHub 後，專案的 Knowledge 便會同步更新。產品經理詢問「目前的 API 接口規範」時，不需重新上傳，答案就會自動更新為最新版本。

### 3. 直接在對話中貼上，並請 AI 更新 Knowledge（雙向互動）
* **做法**：在對話中直接貼上一段雜亂的數據，輸入：「幫我把這段數據整理成 CSV 格式，並用 Artifacts 輸出，提醒我下載回存到 Knowledge 中。」
* **優勢**：當你手邊只有零星文字時，可以讓 AI 幫你格式化後再手動回存，達到「邊聊邊養大腦」的效果。
