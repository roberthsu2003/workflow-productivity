# 📬 實戰 2：Gmail 緊迫客訴摘要與高情商雙語回信草稿

> **所屬章節**：[Google Workspace 連接器實戰](../README.md) ➔ **練習 2**  
> **運作模式**：💬 **一般對話模式（Chat Prompts）**  
> **預計實作時間**：10 分鐘  
> **所需連接器**：🔹 **Gmail**（讀取與草稿建立權限）

---

## 🎯 任務目標

學習如何讓 Claude 調用 Gmail 連接器，即時檢索指定客訴郵件，快速提煉故障現象、受影響層級與緊急時限，並以資深客戶成功經理（CSM）的口吻在 **Gmail 草稿匣（Drafts）** 中起草高情商的日語與繁體中文雙語回信，落實 Human-in-the-Loop 安全規範。

---

## 📥 專屬測試偽資料與雙軌實測機制

本練習提供專屬的客戶郵件資料集：[**模擬客戶郵件資料集.md**](./sample_files/模擬客戶郵件資料集.md)。

學生可依個人狀況自由選擇以下任一途徑完成實作：

| 實測途徑 | 適用對象 | 操作方式 |
| :--- | :--- | :--- |
| **方案 A：真機 Gmail 直連** | 欲體驗 Claude 真實連線個人信箱並建立草稿者 | 複製下方測試郵件寄給自己的 Gmail，再由 Claude 檢索 |
| **方案 B：免寄信快速模擬** | 不想動用個人信箱、追求 10 秒立即驗證者 | 直接使用下方方案 B 內建 Context 的 Prompt 執行 |

### ✉️ 方案 A 測試郵件素材（寄給自己的 Gmail 信箱）

點擊右上角複製，寄一封信給自己的測試 Gmail：

```text
收件人：(您的 Gmail 信箱)
主旨：【緊急】九州熊本半導體示範廠 BridgeGrid-X Modbus 通訊中斷回報
內文：
星橋科技 團隊您好：

我是東京菱光商事的佐藤。
今早 8:30 九州熊本示範園區回報，現場 3 台 BridgeGrid-X 微電網網關在進行高負載測試時，突然出現 Modbus 輪詢逾時錯誤（Error Code: MB-408），導致中央 SCADA 系統無法即時讀取日照逆變器數據。
由於客戶下週二即將帶同日本經濟產業省官員前來參觀，請貴司技術團隊務必在今天下班前（台北時間 17:00 前）提供初步分析報告或遠端更新 Patch。

感謝協助。
東京菱光商事 海外事業推進部 佐藤健太郎
```

## 📋 複製貼上 Prompt

打開 Claude [一般對話視窗](https://claude.ai)，依您選擇的方案複製貼入：

### 若使用【方案 A：真機 Gmail 直連】
```markdown
## Role
你是一位具備跨國商務談判經驗的客戶成功經理（CSM）。

## Task
請透過 Gmail 連接器檢視我的收件匣中近期來自「佐藤」或主旨包含「緊急」或「BridgeGrid-X」的郵件：
1. 摘要該客訴的核心故障現象、受影響之客戶層級與緊急時限。
2. 幫我在 Gmail 草稿匣中擬妥一封專業、嚴謹且展現誠意的回覆郵件（日文正式商務體與繁體中文對照版）。

## Constraints
- 信中必須提及技術團隊正在分析 Modbus 逾時問題（MB-408），並承諾於今天下午 16:30 前提供初步處置說明。
- 嚴格遵守 Human-in-the-Loop 原則：僅將回信儲存於 Gmail「草稿匣（Drafts）」，嚴禁直接自動寄出！
```

### 若使用【方案 B：免寄信快速模擬】
```markdown
## Role
你是一位具備跨國商務談判經驗的客戶成功經理（CSM）。

## Context（模擬收到的緊急客訴郵件）
寄件人：佐藤 健太郎 <k-sato@ryoko-shoji.co.jp>
主旨：【緊急】九州熊本半導體示範廠 BridgeGrid-X Modbus 通訊中斷回報
內文：今早 8:30 九州熊本示範園區現場 3 台 BridgeGrid-X 微電網網關出現 Modbus 輪詢逾時錯誤（Error Code: MB-408），導致 SCADA 無法讀取逆變器數據。下週二經產省官員即將參訪，請於今日台北時間 17:00 前提供分析報告或遠端 Patch。

## Task
1. 摘要此客訴的核心故障現象、受影響之客戶層級與時效限制。
2. 起草一封專業商務回信草稿（日文正式商務體與繁體中文對照）。
3. 承諾於今日 16:30 前提供初步處置說明，文字需體現誠意與進度掌握感。
```

---

## ✅ 成果驗收點

- [ ] **高壓關鍵字提煉**：精準捕捉「九州熊本示範廠」、「經產省官員參訪（高層客戶）」、「今日 17:00 前」三大要素。
- [ ] **商務日語禮儀到位**：包含標準日商信件開頭「平素は大変お世話になっております」與結尾禮辭。
- [ ] **安全界線守護**：承諾在 16:30 前更新，並嚴格聲明僅將信件儲存於「草稿匣」，絕無越權擅自發送信件。

---

## 💡 常見問題與除錯

* **Q：Claude 會真的把信件發送給客戶嗎？**  
  * **解答**：不會！在設計中特別限定僅建立為 Drafts（草稿），最終審核與「點擊發送」按鈕永遠掌握在人類手中。
* **Q：方案 A 提示找不到信件？**  
  * **解法**：確認寄件後，於 Prompt 加上具體的主旨關鍵字（例如：搜尋主旨包含 `九州熊本` 的信件），或直接改用方案 B 進行無痛驗證。
