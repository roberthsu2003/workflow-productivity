# 分享（Share）、權限與複製再利用 SOP

> 2026/9/16 改版後，**Artifact 預設是私人的**，要你主動分享別人才看得到。分享時可以選擇「誰能開」以及「能做什麼」（檢視／留言／編輯）。舊版的 **Publish** 只保留給改版前的舊版 Artifact。
>
> 📖 官方來源：[Share artifacts](https://support.claude.com/en/articles/9547008-share-artifacts)

---

## 🔗 新版分享步驟

1. 打開 Artifact ➔ 點右上角 **Share**
2. 選擇**誰可以開啟**（見下表）
3. 選擇**權限**：Can view／Commenter／Can edit
4. 複製連結，或輸入 Email 邀請特定的人

### 誰可以開啟？

| 選項 | 說明 | 方案 |
| :--- | :--- | :---: |
| **Only you** | 只有自己（預設） | 全部 |
| **Anyone with the link** | 拿到連結就能開，多數情況**不需要 Claude 帳號** | 全部（Team / Enterprise 需管理員開放對外分享） |
| **Email 邀請（Beta）** | 只有被邀請的人能開，對方要用該 Email 登入 Claude | 🔵 Pro 以上 |
| **Anyone at [公司名稱]** | 公司內所有成員 | 🟣 Team / Enterprise |
| **群組** | 分享給指定群組 | 🟣 Enterprise |

### 能做什麼？

| 權限 | 看成品 | 看留言 | 留言 | 下載成品提供的檔案 | 直接修改 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Can view** | ✓ | ✓ | | | |
| **Commenter** | ✓ | ✓ | ✓ | ✓ | |
| **Can edit** | ✓ | ✓ | ✓ | ✓ | ✓ |

### Email 邀請的規則
- 每個 Artifact 最多邀請 **50 位**組織外的人
- 邀請 **30 天**內沒接受就會失效
- 外部受邀者即使有 Can edit 權限，也**不能刪除** Artifact
- 連接其他網站的 Artifact，或上傳檔案還沒通過檢查的 Artifact，無法用 Email 邀請

## ⚠️ 連結訪客看得到什麼？

用「Anyone with the link」分享時，沒登入或不在你組織內的訪客：

| 可以 | 不行 |
| :--- | :--- |
| ✓ 看到成品、操作按鈕與圖表 | ✗ 看留言、新增留言 |
| | ✗ 使用 Artifact 裡「呼叫 Claude」的功能 |
| | ✗ 使用 Artifact 裡「連接 App」的功能 |

另外，**會連接其他網站的 Artifact 不能使用「Anyone with the link」**。登入的使用者使用連接 App 的功能時，用的是**他們自己的連線**，不是你的帳號。

> 💡 **選擇建議**：只是要給大家看 ➔ 連結分享；要大家一起填資料、使用 AI 功能或留言 ➔ Email 邀請或組織內分享。

## 🖥️ 開會展示技巧

- **Slides**：直接按 **Present** 全螢幕播放，用方向鍵翻頁。
- **互動工具／儀表板**：分享連結後在會議室電腦打開，全螢幕演示；也可以把連結貼到 LINE / Teams 群組，讓與會者用手機一起操作。
- **會後收意見**：分享時給主管 **Commenter** 權限，主管可以直接在成品上留言，不用另外寄信。
- **改完不用重新發連結**：新版 Artifact 修改後，同一個連結就會看到最新內容。

## 🔄 想用別人的成品改成自己的版本？

| 情況 | 做法 |
| :--- | :--- |
| 對方給你 **Can edit** 權限 | 直接修改（會改到對方的原始成品，請先溝通） |
| 舊版發布的 Artifact | 登入後可以 **複製並儲存（copy and save）**一份到自己帳號，用量算在自己的方案上 |
| 只有檢視權限 | 請 Claude 參考成品重做：「這是同事做的工具，請做一個類似的版本，並改成綠色主題、加上列印按鈕」 |

## 🗄️ 舊版 Artifact 的 Publish（2026/9/16 以前的作品）

舊版 Artifact 仍然使用 **Publish** 按鈕：

- **Free / Pro / Max**：按 **Publish** 會產生公開連結，任何人都可以不登入直接開啟；也可以設定允許的網域，把 Artifact 嵌入到其他網站。
- **Team / Enterprise**：顯示為 **Share & copy link**，只有組織成員（或在開放對外分享時，拿到連結的人）可以開。

> 🚨 **取消發布前請三思**：舊版 Artifact 一旦 **Unpublish**，連結會失效、**無法再次發布**，而且**儲存的資料會永久刪除**。如果要重新分享，只能重做一個新的 Artifact。
>
> 新版 Artifact 只要把權限改回 **Only you** 或 **Only people invited** 就能停止分享，資料不會被刪除。

## 🔒 分享前檢查清單

- [ ] 內容沒有密碼、API 金鑰、身分證字號、未公開財報等敏感資訊
- [ ] 確認儲存方式：共用儲存的資料，所有人都看得到
- [ ] 選對分享對象：公開連結 vs Email 邀請 vs 組織內
- [ ] 選對權限：不需要修改的人，不要給 Can edit
