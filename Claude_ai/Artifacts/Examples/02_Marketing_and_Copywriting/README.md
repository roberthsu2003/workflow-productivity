# 範例二：行銷文案守門人 —— 產品銷售頁文案與受眾切換 (Markdown)

> 🟢 **難易度**：Level 1 入門實戰  
> 🎯 **產出格式**：結構化 Markdown 文件 Artifact  
> 👥 **適合對象**：行銷企劃、電商運營、社群小編、品牌主管  

---

## 📌 任務背景

行銷經理需要為一款旗艦智慧手錶撰寫產品銷售頁（Landing Page）文案。產出必須具備引人入勝的標題、條理分明的五大核心賣點與規格對比，並能隨長官意見在「年輕科技風」與「商務沉穩風」之間快速切換版本。

---

## 📋 RTCCF Prompt（複製後直接貼給 Claude）

```markdown
## Role
你是一位擅長科技消費產品行銷的資深文案撰寫專家。

## Task
為一款旗艦智慧手錶撰寫一份結構清晰、說服力強的產品銷售頁文案，以 **Markdown 格式的 Artifact** 產出。

## Context
- 產品名稱：Chronos Ultra 智慧運動手錶
- 目標受眾：注重健康監測的都會上班族與戶外運動愛好者
- 核心規格：雙頻 GPS、14 天超長續航、全天候心率與血氧偵測、50米防水、藍寶石鏡面

## Constraint
- 語言：繁體中文；口吻專業、積極、具現代感
- 結構必須包含：主標題、副標題、一段 100 字情境簡介、5 大核心亮點（附粗體小標與生動描述）、以及與競品比較的優勢總結
- 未確認數據請標記為 [TBD]，嚴禁捏造規格

## Format
- 產出為 **Markdown 格式的 Artifact**，便於在側欄獨立檢視與匯出
```

---

## 🔄 實戰演練：長官反饋與風格切換

### 步驟 1：長官提出「風格切換」要求（V2 迭代）
```markdown
長官看過後覺得文字偏向休閒，希望調整為更嚴謹、面向高階商務主管的風格：
1. 請將標題與亮點調整為突出「高階商務菁英的時間管理與健康守護」。
2. 底部增加一個 Markdown 表格，整理「商務版」與「標準版」的規格對比。
請直接在同一個 Artifact 畫布上更新版本。
```

> 🎯 **成果觀察**：  
> 右側面板無縫升級為 Version 2，隨時可切換回 Version 1 進行風格 A/B Test 對比。
