# 範例四：數據分析師戰情室 —— 雙軸動態營運圖表 (React / Recharts)

> 🟡 **難易度**：Level 3 高階分析  
> 🎯 **產出格式**：React 元件互動圖表 Artifact (Recharts)  
> 👥 **適合對象**：數據分析師、營運主管、商業智慧 (BI) 專案人員  

---

## 📌 任務背景

季度營運會議上，分析師需要將四個季度的銷售額（柱狀圖）與利潤率（折線圖）整合在同一個畫面上，讓長官一眼看出兩者之間的關聯。不需安裝專業 BI 工具，透過 React Artifact 即可在瀏覽器中即時渲染與懸停互動。

---

## 📋 RTCCF Prompt（複製後直接貼給 Claude）

```markdown
## Role
你是一位擅長商業數據視覺化的前端分析師，精通 React 與 Recharts 圖表庫。

## Task
使用 **Recharts** 建立一個雙 Y 軸（Dual-Axis）動態圖表 React Artifact：左軸顯示各季度銷售量（台），右軸顯示淨利潤率（%），X 軸為季度時間。

## Context
- 季度數據：
  - Q1：銷售量 150,000 台，利潤率 20%
  - Q2：銷售量 220,000 台，利潤率 22%
  - Q3：銷售量 180,000 台，利潤率 21%
  - Q4：銷售量 280,000 台，利潤率 25%

## Constraint
- 使用 Recharts 的 `ComposedChart` 實作；柱狀圖採用企業藍，折線圖採用活力綠
- 加入互動式 Tooltip（懸停提示視窗）與圖例（Legend）
- 圖表設定合適的 margin，避免軸標籤與數值被邊界裁切
- 數據直接內嵌於元件代碼中

## Format
- 產出為 **React Artifact**，可在右側側欄直接進行互動與滑鼠懸停測試
```

---

## 🔄 實戰演練：長官開會反饋修訂（V2 迭代）與展示

```markdown
長官檢視後希望：
1. 為每個柱狀圖頂部標註實際銷售數字標籤（Label）。
2. 在圖表下方新增一個「各季度數據摘要卡片」，列出全年度總銷售量與平均利潤率。
請在原 Artifact 畫布上更新。
```

> 🎯 **開會應用**：  
> 點擊右上角 **Publish**，開會時直接將網址投影在會議室大螢幕上，滑鼠滑過每個季度柱狀圖時即時浮現詳細數值！
