# 範例一：辦公行政小工具 —— 會議室借用與請假規則查詢 (HTML)

> 🟢 **難易度**：Level 1 入門實戰  
> 🎯 **產出格式**：單一 HTML 互動網頁 (HTML + CSS + JavaScript)  
> 👥 **適合對象**：行政同仁、總務人員、專案管理、HR  

---

## 📌 任務背景

總務想先做一個可供同仁點選、查閱的簡易網頁原型，顯示內部會議室借用規定、時段表以及請假流程常見問答。此小工具在開會時可直接向長官演示，確認架構無誤後再行推廣，不需架設任何資料庫。

---

## 📋 RTCCF Prompt（複製後直接貼給 Claude）

```markdown
## Role
你是一位擅長前端原型的行政／總務承辦人員。

## Task
建立一個**單一 HTML Artifact**（內嵌 CSS 與 JavaScript）：主題為「內部會議室借用與請假流程快速查詢」。頁面需具備清楚標題、Tab 分頁切換（會議室規則／請假流程）、以及一個可展開收合的「常見問題（FAQ）」摺疊清單。

## Context
- 使用對象：機關／公司全體同仁
- 會議室規定：開放時段為平日 08:30~17:30，需提前 3 天於系統預約；大型會議室需主管簽核。
- 請假規定：事假需提前 1 天申請，病假可於上班後 2 小時內補假單；年度特休依勞基法規定。

## Constraint
- 語言：繁體中文；版面清楚俐落、字級適中利於閱讀
- 不連接真實後端資料庫；所有切換皆以純 JavaScript 在本地完成
- 配色簡潔商務，按鈕具備滑鼠懸停（hover）微動畫效果

## Format
- 產出為 **Artifact**，格式為 **HTML**，可於右側側欄即時操作預覽
```

---

## 🔄 實戰演練：長官反饋修訂 ➔ 版本切換 ➔ 開會 HTML 連結展示

完成 V1 初版後，真實職場流程通常如下：

### 步驟 1：長官檢視後提出修改要求，下達 V2 迭代 Prompt
將長官的意見原話貼回對話框：
```markdown
長官看過初版後，提出以下兩點修改要求：
1. 請在頂部新增一個「關鍵字快速搜尋框」，同仁輸入關鍵字（例如：投影機、事假、補休）時，下方的 FAQ 能即時自動過濾。
2. 標題與按鈕字體請放大一號，主色系改為專業的沉穩深藍色（#1E3A8A）。
請直接在原本同一個 Artifact 畫布上更新版本。
```

> 🎯 **成果觀察**：  
> Claude 會在右側原畫布直接推進為 **Version 2**。點擊右下角的歷史版本下拉選單，可在 `v1` 與 `v2` 之間自由切換與比對。

---

### 步驟 2：開會展示 —— 一鍵發布 HTML 分享連結（Publish & Share Link）

1. 點擊右側 Artifact 面板右上角的 **「Publish」** 按鈕。
2. 複製生成的專屬展示網址（例如 `https://claude.site/artifacts/...`）。
3. **開會應用**：
   - **投影全螢幕演示**：會議室電腦直接點開網址全螢幕展示，不需準備隨身碟或轉接線。
   - **群組同步操作**：將連結貼到會議通訊群組，與會主管用手機點開即可直接點擊互動體驗。
