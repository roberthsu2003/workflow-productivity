# 範例五：產品經理的互動原型 —— 團隊排程行事曆 (React UI)

> 🟡 **難易度**：Level 3 高階分析  
> 🎯 **產出格式**：可點擊彈窗的完整 React 應用原型 Artifact  
> 👥 **適合對象**：產品經理 (PM)、UI/UX 設計師、專案主管  

---

## 📌 任務背景

產品經理在向主管與開發團隊提報全新「團隊排程行事曆」功能前，需要一個能真實點擊、彈出 Modal、輸入排程並即時顯示於日期格中的前端原型，用於在會議上演示 UX 流程與收集團隊回饋。

---

## 📋 RTCCF Prompt（複製後直接貼給 Claude）

```markdown
## Role
你是一位擅長 React 前端互動原型設計的高級產品經理。

## Task
建立一個**月曆排程行事曆 React Artifact**。功能包含：月份日曆網格顯示（自動對齊星期）、點擊任一日期格彈出 Modal 新增排程（含任務標題輸入與部門下拉選單）、儲存後排程即時標記在對應日期格內。

## Context
- 適用團隊：行銷、研發、營運等跨部門專案排程
- 預設顯示月份：當前月份或 2026 年 10 月
- 部門標籤色：行銷（紫色）、研發（藍色）、營運（橘色）

## Constraint
- 使用 React `useState` 管理排程資料狀態；不連接後端資料庫
- 彈跳視窗需具備「儲存」與「取消」按鈕，關閉後日曆不被遮擋
- 介面排版精緻現代，支援週六日以淡灰色標示

## Format
- 產出為 **React Artifact**，可於側欄直接點選日期與新增任務
```

---

## 🔄 實戰演練：結合持久化儲存 (localStorage) 的進階迭代

```markdown
長官試用後很滿意，但希望：
1. 請加入 `localStorage` 持久化儲存，讓剛剛新增的排程在重新整理頁面後依然保留。
2. 點擊已排程的卡片時，支援「刪除」該筆排程。
請在原 Artifact 畫布上更新版本。
```

> 🎯 **成果觀察**：  
> 程式碼升級為包含持久化邏輯的 Version 2，點擊 Publish 分享給團隊，每個人在自己手機/電腦上測試都能記住自己的排程！
