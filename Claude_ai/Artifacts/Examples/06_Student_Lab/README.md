# 範例六：學生實作工作坊 —— 五大多格式體驗與挑戰任務

> 🟢 **難易度**：Level 1 ~ Level 2 綜合練習  
> 🎯 **產出格式**：涵蓋 HTML、Mermaid、Markdown、React 表格與 SVG 向量圖  
> 👥 **適合對象**：課堂學生、AI 新手學員、各領域跨界工作者  

---

## 📌 實作說明

每位學員可依興趣選擇以下**任一種情境**動手實作，親身體驗 Artifact 的多元形態；完成後，所有人皆須完成文末的兩大必修挑戰（版本迭代與多檔案管理）。

---

### 練習一：英文單字學習小工具 (HTML 互動網頁)
- **Prompt**：
  ```markdown
  ## Role: 前端工程師與英文名師
  ## Task: 建立一個單一 HTML 格式的英文單字四選一測驗小工具 Artifact。
  ## Context: 題庫包含 apple, banana, cherry, date, elderberry。
  ## Constraint: 點選後即時給予對錯反饋與中文例句說明；介面活潑清晰。
  ## Format: HTML Artifact，可於側欄操作。
  ```

### 練習二：光合作用生物學機制圖 (Mermaid 流程圖)
- **Prompt**：
  ```markdown
  ## Role: 生物科視覺化教學設計師
  ## Task: 使用 Mermaid 語法繪製植物「光合作用」流程圖 Artifact。
  ## Context: 呈現光反應（類囊體膜）與暗反應（基質）的能量載體循環（ATP/NADPH）。
  ## Constraint: 節點清晰，以不同形狀與色系區分輸入物、產物與反應階段。
  ## Format: Mermaid 圖表 Artifact，側欄即時渲染。
  ```

### 練習三：小組討論會議紀錄 (Markdown 結構化文件)
- **Prompt**：
  ```markdown
  ## Role: 效率專案秘書
  ## Task: 將零散的討論對話整理成一份專業的 Markdown 會議紀錄 Artifact。
  ## Context: 包含主題、與會人員、核心討論整理、決議事項表與明確的待辦清單（含負責人與截止日）。
  ## Constraint: 待辦事項必須用 Markdown 表格呈現。
  ## Format: Markdown 文件 Artifact。
  ```

### 練習四：園遊會擺攤預算記帳表 (動態計算表格)
- **Prompt**：
  ```markdown
  ## Role: 精通財務與試算表規劃的班級總務股長
  ## Task: 建立一個園遊會擺攤預算記帳表格 Artifact。
  ## Context: 包含紅茶、熱狗、雞蛋糕的單價、預估銷量、單位成本。
  ## Constraint: 必須自動計算各品項營收與利潤，並在底部加總總成本與總獲利。
  ## Format: HTML / React 表格 Artifact。
  ```

### 練習五：班級專屬班徽標誌 (SVG 向量圖)
- **Prompt**：
  ```markdown
  ## Role: 簡約風格平面設計師
  ## Task: 使用純 SVG 程式碼設計一款扁平化班徽標誌 Artifact。
  ## Context: 包含書本圖案（知識）與盾牌外框（團結），主色為經典海軍藍。
  ## Constraint: 純 SVG 格式，設定適當 viewBox，確保縮放不失真。
  ## Format: SVG 向量圖 Artifact。
  ```

---

## 🎯 必修兩大挑戰任務

1. **挑戰 A：體驗「版本更新（同一檔案迭代）」**
   - 對 Claude 說：「*太棒了！請幫我把主要文字字級放大 15%，背景色改為米黃色。*」
   - 觀察右側同一個 Artifact 是否更新為 Version 2？點選右下角歷史紀錄切回 Version 1。
2. **挑戰 B：體驗「一次對話產出多個檔案（多檔案管理）」**
   - 接著輸入：「*請根據剛剛產出的成果，另外幫我寫一份給家長/長官看的 150 字說明書，做成第二個獨立的 Markdown Artifact。*」
   - 觀察對話中是否出現第二個獨立的 Artifact？兩個檔案能否分開查看與發布連結？
