# 05. Advanced Data Analysis（免寫程式！辦公室數據分析與文件自動產出）

> 🟢 **適用方案**：Free（每日提供基礎額度） / Plus / Team / Enterprise 全方案適用

很多人以為「數據分析」一定要學寫 Python 或熟練複雜的 Excel 巨集公式。但在 ChatGPT 的圖形化介面中，**一般人完全不需要寫任何程式碼**！

ChatGPT 內建了強大的雲端數據運算能力（原名 Code Interpreter）。你只需要把日常的 Excel 表格、CSV 或報表直接**拖曳上傳**，用一般白話中文告訴它你想看什麼，ChatGPT 就會在背景自動幫你算好數據、畫出專業商務圖表，甚至直接生成 **可下載的 Excel 報表、Word 文件與 PowerPoint 簡報**！

---

## 🖱️ 一般人如何操作？只要三步驟！

```text
┌─────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│   步驟 1：上傳檔案  │ ───> │  步驟 2：用日常白話提問   │ ───> │  步驟 3：一鍵下載成果   │
│ 拖曳 Excel/CSV 檔 │      │ 「幫我算出各區銷售總額」 │      │ 下載圖表、Excel 或 Word  │
└─────────────────┘      └─────────────────────────┘      └─────────────────────────┘
```

1. **點擊上傳**：在 ChatGPT 輸入框左側點擊 **「+」**（或迴紋針圖示），從電腦選取你的 Excel（`.xlsx`）、CSV、Word 或 PDF 文件。
2. **白話下指令**：用你平時跟同事說話的口吻提出分析或整理需求。
3. **下載檔案**：ChatGPT 分析完畢後，會主動提供一個藍色的**檔案下載連結**，點擊即可直接存回電腦！

## 💼 一般人必學的四大職場應用情境

### 情境 1：亂七八糟的 Excel 表格「一鍵清洗整理」
- **痛點**：下載回來的名冊資料有缺漏、姓名電話格式不一致、有重複資料、地址沒分縣市。
- **白話提問示範**：
  ```text
  這是我從系統匯出的活動報名名單（Excel 檔）：
  1. 請幫我找出是否有重複報名的手機號碼，並刪除重複項目。
  2. 把空白的「通訊地址」欄位補上「待補件」。
  3. 將整理乾淨的結果，做成一份全新的 Excel 檔案讓我下載。
  ```

### 情境 2：銷售業績數據「自動樞紐分析與洞察」
- **痛點**：主管突然要你分析這半年幾千筆訂單，你不知道怎麼拉樞紐分析表。
- **白話提問示範**：
  ```text
  這是一份本季所有門市的銷售訂單明細：
  1. 請告訴我：業績前 3 名的明星商品是哪些？分別貢獻了多少營收？
  2. 哪一個門市的退貨率最高？
  3. 請用繁體中文條列 3 個具體的經營改善建議給店長。
  ```

### 情境 3：免開軟體！直接生成高質感「商務圖表」
- **痛點**：做簡報急需圖表，但在 Excel 裡調色調半天都不好看。
- **白話提問示範**：
  ```text
  請根據這份月度營收表：
  畫一張漂亮的「每月營收趨勢折線圖」，以及一張「各產品銷售佔比圓餅圖」。
  風格請採用商務專業配色（深藍與暖橘），圖表上的標題與圖例請使用繁體中文，並提供高解析度圖檔下載連結。
  ```

### 情境 4：把對話成果「一鍵打包成 Word、Excel 或 PowerPoint 下載」
- **痛點**：ChatGPT 在畫面上產出的長篇企劃案，複製貼上到 Word 常常格式跑掉。
- **白話提問示範**：
  ```text
  請將剛剛討論完成的「2026 年度員工培訓計畫」：
  直接製作成一份正式的 Word 檔案（.docx）。
  請包含封面標題、目錄、粗體大標題，內文表格請加上邊框，完成後給我下載連結。
  ```
  *(同理：你也可以要求「製作成 Excel 活頁簿（.xlsx）」或「做出 5 頁簡報大綱的 PPT 檔（.pptx）」！)*

## 💡 一般人問答技巧：避免踩雷的小秘訣

1. **表格標題行要乾淨**：上傳 Excel 前，確認第一行是明確的欄位名稱（如：日期、部門、銷售金額、產品名），不要有跨欄置中的混亂合併儲存格。
2. **要求交代計算過程**：如果不確定 ChatGPT 算得對不對，可以加一句：*「請告訴我你的計算公式與步驟」*。此時點擊回答方塊上的「[>_] 分析（View analysis）」，就能看見它計算的邏輯證明，不需要懂代碼也能核對數字。
3. **中文亂碼問題**：如果下載的圖表中文變成方塊，只需告訴它：*「圖表上的中文字顯示異常，請使用支援 Unicode 的中文字體重新繪製一張給我」* 即可。
