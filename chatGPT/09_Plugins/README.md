# 09. Plugins（外掛程式生態與外部工具擴充）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

在 ChatGPT 側邊欄的選單中，您會看到專屬的 **「外掛程式（Plugins）」** 項目。

雖然 ChatGPT 本身擁有龐大的通用語言知識，但在面對「高精度數學工程運算」、「即時航班票價比價」或「專業學術論文即時檢索」時，透過 **外掛程式（Plugins）** 即可讓 ChatGPT 即時連線外部專業服務，瞬間化身全能工具箱！

---

## 🔌 什麼是 ChatGPT Plugins 外掛程式？

外掛程式如同為 ChatGPT 安裝各種專屬外接晶片，讓 AI 在回答問題時，能自動呼叫第三方的官方 API 取得最新、最權威的資料：

```text
┌─────────────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│ 使用者提出專業需求     │ ───> │ ChatGPT 判斷需呼叫外掛  │ ───> │ 獲取精確外部數據後      │
│ 「查詢東京下週機票票價」│      │ 連線 Expedia / Skyscanner│      │ 整理成完整比較報表回覆  │
└─────────────────────────┘      └─────────────────────────┘      └─────────────────────────┘
```

---

## 💼 職場高頻熱門外掛分類

| 應用領域 | 代表外掛 | 核心能力 |
| :--- | :--- | :--- |
| **數據計算與科學運算** | **Wolfram** | 高精度微積分、物理化學計算、即時匯率、權威地理與統計數據 |
| **商務差旅與行程規劃** | **Expedia / Kayak** | 搜尋全球航班時刻、飯店房價、比價並輸出推薦行程表 |
| **學術研究與文獻探勘** | **ScholarAI / Consensus** | 檢索數億篇同儕審查學術論文、取得摘要與真實論文 DOI 引用 |
| **工作流跨平台自動化** | **Zapier / Make** | 將對話結論直接觸發外部操作（發送 Slack 訊息、新增 Trello 卡片） |
| **視覺繪圖與心智圖** | **Show Me Diagrams** | 直接將複雜流程轉換為心智圖、架構圖或 UML 時序圖 |

## ⚙️ 如何安裝與使用外掛？

1. **進入外掛管理**：在桌面版或網頁版側邊欄點擊 **「外掛程式」**（或在設定中開啟）。
2. **瀏覽與安裝**：在市集中搜尋你需要的服務，點擊 **「安裝（Install）」**。
3. **自然對話觸發**：在對話中直接輸入日常需求，ChatGPT 會在背後自動辨識並調用對應外掛，完全不需學習生硬的 API 指令！

---

## ⚖️ Plugins vs Custom GPTs：兩者有何不同？

- **Plugins（外掛程式）**：專注於**「外接工具的能力拓展」**（讓 AI 學會使用某一項外部軟體）。
- **Custom GPTs（專屬助理）**：專注於**「整體角色的深度客製」**（打包了特定角色設定、企業內部規章知識庫 RAG 與多項工具開關）。
