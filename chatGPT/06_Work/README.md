# 06. Work（桌面版工作成果交付模式與本機檔案對接）

> 🟢 **適用方案**：Free（基礎體驗額度） / 🔵 Plus / Team / Pro（完整高用量支援）

在 2026 最新版的 ChatGPT 桌面應用程式（macOS / Windows）頂部，您會看到兩個核心分頁：**「對話」** 與 **「工作（Work）」**。

這是 OpenAI 專為商務職場打造的重大架構進化——**將「隨性聊天發想」與「動手做事的任務交付」徹底分流**。

---

## 🎯 什麼是「工作（Work）」模式？

| 比較維度 | 💬 對話（Chat）模式 | 💼 工作（Work）模式 |
| :--- | :--- | :--- |
| **核心目標** | 獲得解答、腦力激盪、快速問答 | **產出實體成果（Deliverable）並交付任務** |
| **工作環境** | 純對話泡泡視窗 | 結合檔案清單、任務進度看板與成品預覽區 |
| **檔案對接** | 每次手動點「+」上傳單一檔案 | **可直接對接電腦本機資料夾**，自動關聯內部多份檔案 |
| **執行過程** | 你問一句、它答一句 | **多步驟自主執行**（閱讀資料 ➔ 規劃草案 ➔ 數據運算 ➔ 排版產檔） |
| **終端交付** | 複製螢幕上的文字 | **直接輸出實體 Word、Excel、PowerPoint 或 PDF 檔案** |

---

## 🛠️ Work 模式三大實戰機能

### 1. 📂 本機資料夾直接對接（Local Folder Access）
- 在 Work 模式下，您可以授權 ChatGPT 存取電腦中特定的工作目錄（例如：`2026_Q4_行銷推廣案/`）。
- ChatGPT 會自動建立目錄索引，當你要求「參考規格書與過去預算表撰寫提案」時，它能自主翻閱目錄下的所有檔案，告別手動繁瑣的拖曳搬運。

### 2. 📋 任務進度條與自主多步驟排程
當交辦一個複雜任務（例如：「整理這 5 份客戶問卷，產出滿意度分析與下一季改善建議投影片」）：
- ChatGPT 會在側邊欄拆解出步驟清單：
  - [x] 1. 批次解析 5 份問卷資料
  - [x] 2. 統計滿意度評分與負評關鍵字
  - [ ] 3. 繪製樞紐分析圖
  - [ ] 4. 撰寫簡報講綱並打包為 .pptx 檔
- 您可以清晰看見任務推進進度，隨時暫停或介入補充指令。

### 3. 📦 成品交付中心（Deliverables Dashboard）
- 在 Work 視窗的右側具備專屬的交付物面板，所有產生的圖表、分析報表、文案定稿皆集中陳列，方便批次下載或直接在電腦本機軟體中開啟。

---

## 💡 職場最佳分工策略

- **用「對話」做前端發想**：概念探索、找資料、釐清問題本質、推敲文字風格。
- **用「工作」做後端落地**：當目標明確、手頭有多份參考文獻或數據，需要生成正式報告或 Office 簡報時，立刻切換至 **「工作（Work）」** 模式，享受一站式全自動交付的極致生產力！
