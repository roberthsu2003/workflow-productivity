# 13. 網站即時搜尋與 Deep Research 深度自主研究

> 🟢 **Web Search 聯網搜尋**：Free / Plus 全方案可用  
> 🟣 **Deep Research 深度研究**：付費專屬（Plus / Pro / Team / Enterprise）

一般人在做市場調查、產業競品分析或準備重大簡報時，傳統做法通常是：**打開瀏覽器搜尋關鍵字，點開 20~30 個分頁，過濾掉一堆廣告與內容農場，再手動複製貼上到 Word 裡辛苦拼湊成報告**。

ChatGPT 全面顛覆了這個耗時耗力的流程！它提供了一般人做情報探勘的兩大核心神器：
1. **Web Search（聯網即時檢索）**：秒查最新時事、法規更新與官方數據，附帶真實來源網址。
2. **Deep Research（深度自主研究代理）**：只要交辦一個題目，AI 會在背後自主規劃搜尋路徑、查閱數十個專業智庫與官方網頁、交叉驗證事實，產出一份數萬字、格式嚴謹且附帶完整引用的專業級調研報告！

---

## 🌐 一、Web Search（即時聯網搜尋）：基本查證技巧

在任何一般對話框中，點擊底部的 **「Web Search（地球圖示）」**，ChatGPT 便會連上網際網路即時檢索：

### 最佳提問範例：
```text
請幫我查詢台灣行政院最新公布的「2026 節能家電汰舊換新補助」政策：
1. 補助品項有哪些？每台補助金額上限是多少？
2. 申請截止日期為何？需要檢附哪些文件？
3. 請附上經濟部能源署或官方網站的來源連結供我查核。
```
- **核心優勢**：答案中會出現藍色的引用腳標（如 `[1]`、`[2]`），點擊即可直接跳轉到該官方網頁，確保資訊真實可靠，不怕 AI 憑空捏造。

## 🔬 二、Deep Research（深度研究）：委託專屬智庫助理

### 它是如何運作的？
Deep Research 不只是「搜尋一次」，它是一個具有**自主思考與多步探索能力**的研究員：

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. 釐清需求：你下達主題後，AI 會主動提問確認研究範圍（如：聚焦哪些國家？）│
├─────────────────────────────────────────────────────────────────────────┤
│ 2. 自主探索：AI 自動拆解成 10~20 個子問題，連續搜尋並閱讀 30~50 個網頁  │
├─────────────────────────────────────────────────────────────────────────┤
│ 3. 交叉比對：過濾矛盾資訊，整合各智庫、統計局與新聞數據                │
├─────────────────────────────────────────────────────────────────────────┤
│ 4. 交付報告：產出架構嚴謹、段落完整、附有數十個完整出處腳註的正式長文報告│
└─────────────────────────────────────────────────────────────────────────┘
```

### 如何啟動 Deep Research？
1. 在 ChatGPT 輸入框下方點選 **「Deep Research」** 圖示（或在功能選單中勾選）。
2. 輸入你想研究的課題（越具體越好）。
3. **重要步驟**：ChatGPT 會回覆 2~3 個澄清問題（例如：*「您希望這份報告著重在商業模式分析，還是政策法規審查？」*），你只要用白話簡短回覆確認。
4. 點擊開始後，你可以切換視窗去喝咖啡或處理其他工作，約 10~20 分鐘後即可回到頁面收取完整大作！

## 💼 職場一般人高頻調研 Prompt 範本

### 範例：新市場進入評估與競品調查
```markdown
請啟動 Deep Research，為我撰寫一份「台灣銀髮族智慧照護與長照居家科技產品市場調研報告」：

【調研重點】：
1. 台灣高齡化現況與政府長照 3.0 相關政策補貼方向。
2. 目前市場上主流的「智慧穿戴防跌偵測」與「居家生理監測」主要品牌、市佔狀況與定價區間。
3. 目標消費者（子女採購者 vs 長輩實際使用者）的核心顧慮與痛點。
4. 針對即將進入市場的新創品牌，提出產品定位與通路合作建議。

【產出規範】：
- 請使用繁體中文。
- 報告篇幅請力求詳盡，提供具體數據與百分比。
- 每個關鍵結論皆需標記可靠出處與資料年份。
```
