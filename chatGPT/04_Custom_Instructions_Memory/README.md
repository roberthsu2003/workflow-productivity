# 04. Custom Instructions 與 Memory（個人化設定與長期記憶）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

一般人在使用 ChatGPT 時最常遇到的困擾之一是：**每次開新對話，都要從頭向 ChatGPT 自我介紹自己的工作背景、職位，並反覆要求「請用繁體中文、語氣要專業、不要廢話」**。

ChatGPT 提供了兩大一般人必學的「記憶神隊友」功能，讓你設定一次後，它永遠記得你的偏好：
1. **Custom Instructions（自訂指示）**：主動告訴 ChatGPT 你的身分規範與期望的回覆格式。
2. **Memory（長期記憶庫）**：ChatGPT 在平常對話中自動記住你的喜好與習慣，跨對話皆可生效。

---

## 🎯 一、Custom Instructions（自訂指示）設定指引

### 如何開啟？
- **操作路徑**：點擊左下角個人頭像／名稱 → 點選 **「Custom Instructions（自訂指示）」**（部分介面顯示為「Personalize」）。

這裡只有兩個簡單的輸入框，一般人只需用清楚的白話文填寫即可：

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 區塊一：你希望 ChatGPT 了解你的哪些資訊，以便提供更貼切的回覆？          │
│ （What would you like ChatGPT to know about you to provide better responses?）│
├─────────────────────────────────────────────────────────────────────────┤
│ 💡 一般人建議填寫：                                                      │
│ 1. 你的職業與日常業務（例如：我在科技業擔任人資招募主管 / 中小企業行銷企劃）。│
│ 2. 你的目標受眾與溝通對象（例如：我的讀者大多是企業高階主管或外部客戶）。│
│ 3. 你常使用的工具或工作情境（例如：熟悉 Google 辦公套件、常用 Excel 報表）。│
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 區塊二：你希望 ChatGPT 如何回覆你？                                     │
│ （How would you like ChatGPT to respond?）                               │
├─────────────────────────────────────────────────────────────────────────┤
│ 💡 一般人建議填寫：                                                      │
│ 1. 語言規範：一律使用「台灣繁體中文（zh-TW）」回覆，使用台灣習慣商務用語。 │
│ 2. 語氣風格：專業、客觀、精煉，避免過多的客套開場白與冗長結論。             │
│ 3. 排版喜好：善用條列點（Bullet points）與清楚的粗體小標題，複雜數據請排成表格。│
│ 4. 決策支援：提出建議時，請主動附上「優點、缺點與下一步行動建議」。        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 職場一般人專用設定範本（直接複製即可使用）：

```text
【關於我】：
我是台灣企業的行政企劃主管，日常需要撰寫簽呈、跨部門會議紀錄、對外商務公文與企劃報告。溝通對象多為管理層與合作夥伴。

【回覆規範】：
1. 請一律使用台灣繁體中文回覆，符合台灣公文與商務書信慣用語。
2. 回覆風格務實、有條理，直接切入核心重點，不要贅述客套問候。
3. 長文請採用階層式標題與條列整理；若有比較內容，請優先使用 Markdown 表格呈現。
4. 當我的指令不夠具體時，請先產出一版高品質草案，並在文末主動提問 2~3 個可深入優化的關鍵方向。
```

## 🧠 二、Memory（長期記憶庫）實戰技巧

除了手動填寫的自訂指示，ChatGPT 還具備主動「記憶能力」。它會在平常聊天時，記住你提到過的人事物與偏好。

### 1. 如何讓 ChatGPT 記住重要事項？
在任何日常對話中，你只要用一般對話口吻告訴它：
- *「請記住，我們公司的標準字體是微軟正黑體，品牌主色是深海藍色（#003366）。」*
- *「請記住，我偏好把所有會議待辦事項排成『事項、負責人、截止日』三欄表格。」*
- *「請記住，我負責的產品線名稱為『SmartHome X 智慧家電』。」*

此時畫面會浮現 **「Memory updated（記憶已更新）」** 的提示，代表它已經永久儲存這項資訊。往後開任何新對話，它都會自動套用！

### 2. 如何檢查與管理記憶？
避免 ChatGPT 記住過期或錯誤的資訊，定期檢視記憶庫非常重要：
- **查看路徑**：點擊左下角頭像 → **Settings（設定）** → **Personalization（個人化）** → **Memory（記憶）** → 點選 **Manage（管理）**。
- **編輯與刪除**：你會看到一筆一筆條列的記憶紀錄。點擊右側的「垃圾桶」圖示，即可刪除不再需要的單筆記憶；也可點擊「Clear all」全部清空。

### 3. 何時不該使用記憶？
- 如果當前要處理一筆**一次性特殊專案**（風格與你平時完全不同），你可以直接在對話中說：*「這段對話不需要儲存記憶，純粹幫我評估...」*；或者直接開啟 **「Temporary Chat（臨時對話）」**。

## 📋 自我檢驗小練習

1. 打開個人帳號的 **Custom Instructions**，填入你的實際職稱與繁體中文回覆偏好，並勾選「對新對話啟用」。
2. 開啟一個全新對話，只輸入：*「幫我寫一封邀請外部講師的演講邀約信初稿。」*
3. 觀察 ChatGPT 是否**自動套用**了你的繁體中文用語與商務專業語氣，完全無需重複提醒！
