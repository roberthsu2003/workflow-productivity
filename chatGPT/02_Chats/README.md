# 02. Chats（對話、思考模型與提示詞工程）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

與 AI 對話絕非漫無目的的隨意聊天，而是透過清晰的指令結構與適當的模型選擇，精準指揮 AI 完成高品質的職場工作交付。

## 🧠 ChatGPT 兩大運算思維模式：何時切換？（不必死記頻繁更迭的版本號）

AI 模型的版本代號（從早期的 GPT-3.5、GPT-4 到後續不斷演進的各類版本）每隔幾個月就會更迭升級。但對職場使用者而言，**最核心的關鍵不是背誦型號名稱，而是掌握 ChatGPT 的「兩大運算思維模式」**：

| 運算模式 | 特性與優勢 | 適用情境 | 模式選用時機 |
| :--- | :--- | :--- | :--- |
| **通用多工模式**<br>（預設標準模式） | 速度極快、語言表達流暢自然、具備全方位多模態（即時看圖、讀檔、語音、上網搜尋）能力。 | 日常文案撰寫、郵件草擬、資料摘要、多語翻譯、圖像辨識與一般商務溝通。 | **80% 的職場日常工作首選** |
| **深度思考推理模式**<br>（Reasoning / 思考模式） | 具備「內在思考時間（Thinking Process）」，在回答前會先自主反思、多步邏輯推導，顯著降低衝動幻覺。 | 複雜多條件決策分析、財務試算邏輯、法規政策嚴謹稽核、多方利益衝突調解。 | **高難度、需要縝密邏輯與嚴謹推導的情境** |

> 💡 **模式切換黃金法則**：
> - **需要豐富創意、文筆流暢、圖片/語音多模態互動** ➔ 使用**通用多工模式**。
> - **需要嚴格邏輯推演、多步驟情境推估、法規稽核或排除矛盾** ➔ 切換至**深度思考推理模式**。
> - *註*：不論官方未來推出何種新命名，介面選單皆會標明是否具備「Thinking / Reasoning（深度思考）」能力，依照此二元原則選用即可！

## 📐 職場高階提示詞：ROSES 框架

想要獲得具備商業水準的回覆，不要只輸入「請幫我寫一封信」。推薦使用經過實戰檢驗的 **ROSES 提示詞框架**：

- **R - Role（角色設定）**：明確 AI 的專業身分與視角。
- **O - Objective（主要目標）**：這次任務的核心目的與要解決的痛點。
- **S - Scenario / Context（背景情境）**：事件經過、目標受眾（讀者是誰）、限制條件。
- **E - Expected Outcome（預期成果）**：產出的格式、語氣（專業/親切/嚴謹）、篇幅字數。
- **S - Steps / Constraints（執行步驟與限制）**：要求依序執行的階段，以及禁止發生的事項（如不可捏造事實、條列式呈現）。

## 💼 職場高頻實戰 Prompt 範本庫

### 範例 1：長篇會議紀錄轉化為行動執行計畫（Action Plan）
```markdown
【Role】你是一位具有 PMP 證照的資深專案管理顧問。
【Objective】請將我提供的零散會議逐字稿/筆記，整理成結構清晰、權責分明的專案推進摘要。
【Scenario】這是一場「Q4 跨國線上行銷專案進度週會」，參與者包含行銷經理、視覺設計師與工程主管。
【Expected Outcome】請輸出繁體中文 Markdown 格式，包含：
  1. 執行長核心決策摘要（3 點以內）
  2. 待辦任務清單矩陣（以表格呈現：任務名稱 | 負責人 | 截止日期 | 優先級 | 依賴關係）
  3. 目前潛在風險與因應措施
【Steps & Constraints】禁止猜測未在會議中提及的截止日期，若未註明請標記「待確認」。

【會議筆記內容】：
（此處貼上會議內容或上傳筆記檔案）
```

### 範例 2：公關危機危機應變聲明草擬
```markdown
【Role】你是一位擁有 15 年經驗的企業公關總監與危機處理發言人。
【Objective】針對近期發生的產品服務中斷事件，草擬一份發布給付費用戶的公開致歉與補償說明信。
【Scenario】昨日下午 14:00~16:30 因機房網路設備異常，導致核心系統離線 2.5 小時，影響約 5,000 名付費企業用戶。目前系統已全數恢復正常運作。
【Expected Outcome】語氣誠懇、專業、有擔當，絕不推諉卸責，篇幅約 500 字，段落分明。
【Steps】
  1. 表明事件現況並真誠致歉。
  2. 交代故障原因（以易懂語言說明，非生硬技術術語）與搶修成果。
  3. 提出具體補償方案（如：全體受影響客戶延長 7 天使用期）。
  4. 說明長遠防範機制，重塑客戶信心。
```

### 範例 3：跨部門提案企劃草案（1 頁紙提案書）
```markdown
【Role】數位轉型策略顧問。
【Objective】撰寫一份簡潔有力的「引進內部 AI 輔助工作流」內部簽呈提案。
【Scenario】提案對象為公司總經理與財務長，他們關注投報率（ROI）、資安風險與員工上手門檻。
【Expected Outcome】請採用「一頁紙提案（A4 規格精華版）」架構：
  - 現狀痛點與機會損失
  - 建議方案與導入路徑
  - 預期效益與 ROI 量化預估
  - 風險防範措施（資安與資料保護）
  - 預算與後續決策建議
```

## 📎 多模態輸入技巧：讓 ChatGPT 看懂你的資料

ChatGPT 不只能讀文字，更能處理多種格式的素材：

1. **直接上傳 PDF / Word 報告**：點擊對話框旁的「+」或「迴紋針」，可直接拖曳上傳多份 PDF，要求「請交叉比對 A 報告與 B 報告在營收預測上的差異」。
2. **螢幕截圖與拍照（Vision）**：
   - 拍下手寫會議白板或草圖，要求「將白板上的流程圖轉換為文字步驟與 Mermaid 語法」。
   - 上傳手機 App 的 UI 截圖，要求「指出此介面在使用者體驗（UX）上的三處可改善點」。
3. **語音輸入（Voice-to-Text）**：
   - 點擊輸入框右側的麥克風圖示（Whisper 技術），可用口語自由敘述想法，ChatGPT 會自動轉錄為結構完整的提示詞，特別適合走路或開車時紀錄靈感。

## 🔍 驗收與追問技巧（Iterative Prompting）

得到第一次產出後，不要直接放棄不滿意的回覆，善用以下「追問心法」逐步收斂：

- **反饋修改**：「第 2 點寫得太理論，請以『B2B 軟體業務』為例給出具體話術。」
- **視角轉換**：「如果從財務長的嚴格審核角度來看，這份提案最大的盲點是什麼？」
- **格式調整**：「請將上述內容壓縮成 3 條 bullet points，每條不超過 20 字，適合放進簡報投影片中。」
