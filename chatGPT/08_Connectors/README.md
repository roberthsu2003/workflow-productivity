# 08. Connectors（雲端硬碟直連：Google Drive 與 OneDrive）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

在一般企業公務環境中，大部分的文件、報表與簡報都儲存在公司或個人的 **Google Drive** 或 **Microsoft OneDrive** 雲端硬碟中。

以往如果要在 ChatGPT 中分析一份雲端檔案，往往要經歷煩瑣的「開啟雲端硬碟 ➔ 下載檔案到電腦 ➔ 打開 ChatGPT ➔ 手動上傳檔案」四大步驟，不僅浪費時間，還會在電腦的「下載」資料夾留下大量過期的暫存檔。

ChatGPT 提供的 **Connectors（已連接的雲端應用）** 功能，讓你能**直接在對話框中瀏覽並引用雲端硬碟檔案**！

---

## 🔗 如何開啟與綁定雲端硬碟？

綁定過程就像登入 Google 帳號一樣簡單安全，完全不需技術門檻：

```text
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│ 點擊輸入框「+」號選單    │ ───> │ 選擇 Google Drive/OneDrive │ ───> │ 點選「允許授權」完成綁定  │
│ 點選「Connect to Cloud」  │      │ 彈出 Google 官方登入視窗  │      │ 往後即可直接點選雲端檔案  │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
```

1. 在 ChatGPT 輸入框左側點擊 **「+」**（或迴紋針圖示）。
2. 在彈出的選單中，點選 **「Connect to Google Drive」** 或 **「Connect to Microsoft OneDrive」**。
3. 系統會開啟官方的安全授權視窗（OAuth），點選確認允許存取。
4. 綁定成功後，再次點擊「+」，就能直接看到「從 Google 雲端硬碟新增檔案」的選項！

## 💼 辦公室兩大超實用場景

### 1. 跨多份雲端試算表「一鍵交叉分析」
- **操作**：點擊「+」，從 Google Drive 同時勾選「1月份門市業績.xlsx」與「2月份門市業績.xlsx」。
- **提問**：*「請對比這兩份雲端試算表，找出二月份成長幅度最大的前 5 家門市，並總結銷售亮點。」*

### 2. 雲端文件快速摘要與轉成待辦清單
- **操作**：直接選取雲端硬碟中的「新專案會議討論手冊（Google Docs）」。
- **提問**：*「請閱讀這份雲端文件，提取出涉及我們行銷部的 3 項主要交付物與預計上線時程。」*

---

## 🔒 資安與隱私小提醒

- **免手動輸入密碼**：連線採用業界標準的 OAuth 授權，ChatGPT 不會知曉或儲存你的 Google 或 Microsoft 密碼。
- **隨時取消授權**：若不再需要連線，隨時可在 **Settings（設定）** ➔ **Connected apps（已連接應用程式）** 中點擊 **Disconnect（中斷連線）**，即可立即收回所有存取權限。
