# 07. Projects（專案空間與團隊檔案集中管理）

> 🏢 **適用方案**：Team / Enterprise（企業與團隊方案標準配備） / 部分 Plus 測試推送

在日常工作中，如果你同時經手「Q3 產品發布」、「年度預算編列」以及「客戶 A 售後服務」等多個業務，最常遇到的問題是：**左側的對話歷史堆積了幾百條，想找上個月某個討論片段像大海撈針，而且每個新對話都要重新上傳一次客戶文件**。

**ChatGPT Projects（專案空間）** 就像在 ChatGPT 裡建立獨立的「數位專案辦公室」，幫助一般工作者井然有序地管理不同業務！

---

## 🗂️ 什麼是 ChatGPT Projects？

```text
📁 你的 ChatGPT 帳號
│
├── 📂 Project 1：2026 綠色家電春季發表會
│   ├── 📎 專案參考檔案庫（產品手冊.pdf, 競品分析.xlsx, 品牌規範.docx）
│   ├── 💬 對話 1：發布會流程規劃與貴賓致詞
│   ├── 💬 對話 2：KOL 合作信件與社群文案
│   └── 💬 對話 3：現場常見問答（FAQ）整理
│
└── 📂 Project 2：第四季內部預算與績效考核
    ├── 📎 專案參考檔案庫（部門薪酬規章.pdf, 預算範本.xlsx）
    ├── 💬 對話 1：各部門差旅費試算
    └── 💬 對話 2：主管面談評語潤飾
```

## 🌟 Projects 專案空間的三大核心優勢

### 1. 跨對話檔案記憶（一次上傳，每個對話都能用）
- 在一般的單一聊天室中，一旦關閉或開啟新對話，你就得重新上傳檔案。
- 在 Project 專案空間中，你只要將參考文件（如：專案企劃書、客戶需求、產品規格 PDF）拖曳上傳到該專案的 **Files（專案檔案庫）** 中。
- **後續在這個專案內開的 10 個、20 個新對話，ChatGPT 全部自動能看見並調用這些文件**！

### 2. 專案專屬客製規範（Project Instructions）
- 每個專案可以擁有自己獨立的指示說明，不會跟你的全域個人設定打架。
- 例如：在「客戶 A 專案」設定：*「本專案一律以半導體產業專業用語回覆，所有報價單位皆為美元」*。

### 3. 團隊成員共同協作（Team Workspaces）
- 在 Team 或 Enterprise 方案中，專案空間可以邀請部門同仁加入。
- 同事能直接在同一個專案中查看過去的研究進展、共用參考文件，避免資訊孤島與重複提問。

---

## 🖱️ 如何建立與使用一個 Project？

1. **建立專案**：在 ChatGPT 左側導覽列，點擊 **「+ New Project」**（新專案）。
2. **命名與設定**：輸入專案名稱（如：*「2026 台北國際旅展籌備」*）與一句話簡介。
3. **上傳知識檔案**：點擊 **Add Files**，把跟該展覽相關的企劃簡報、場地平面圖與預算表拖曳上傳。
4. **開始新對話**：直接點擊 **New Chat in Project** 開始工作，提問時直接說：*「根據我們專案檔案庫裡的預算表，請幫我草擬一份場地搭建招標說明。」*
