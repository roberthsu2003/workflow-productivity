# 02. Personalization（個人化設定、特質微調與長期記憶）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

在日常職場協作中，一般人最常遇到的困擾就是：**每次開啟新對話，都要從頭向 ChatGPT 自我介紹工作職位，並反覆叮嚀「請用台灣繁體中文、語氣要專業、不要廢話」**。

OpenAI 全新升級了 **「個人化（Personalization）」** 系統架構，將原本單純的文字自訂指令，全面升級為涵蓋 **「基本風格與特質微調」**、**「協作夥伴設定」**、**「關於你的背景」**、**「進階功能開關」** 與 **「Memory 長期記憶庫」** 的全方位個人化中心，讓 ChatGPT 真正成為懂你習慣的專屬辦公副駕！

---

## ⚙️ 一、最新個人化（Personalization）介面設定全解析

### 📍 如何進入設定？
- **桌面版 / 網頁版**：點擊左下角頭像／名稱 → 點選 **「設定（Settings）」** → 切換至 **「個人化（Personalization）」**。
- **手機 App**：點擊側邊欄頭像 → 選擇 **「個人化（Personalization）」**。

---

### 1. 🎭 基本風格和語氣（Base Style and Tone）
- **功能說明**：設定 ChatGPT 回應時的整體基準語調（不影響模型的核心推理能力與知識庫）。
- **常用風格選取**：
  - **預設（Default）**：均衡自然的標準對話語氣。
  - **專業（Professional）**：商務正式、客觀嚴謹，適合公文、合約、跨部門提案。
  - **友善（Friendly）**：親切耐心，適合教學輔導、內訓教材或客服溝通。
  - **直率精簡（Candid / Concise）**：直奔主題、完全去除客套話，適合高速工作決策。

---

### 2. 🎚️ 細部特質（Traits）精準微調
在基礎風格之外，你可以針對四大溝通特質進行個別微調（預設、更多、更少）：

| 特質項目 | 增加（More）效果 | 減少（Less）效果 | 職場推薦設定 |
| :--- | :--- | :--- | :--- |
| **溫暖（Warmth）** | 語氣體貼溫馨、具同理心 | 語調冷靜中立、就事論事 | 日常商務選「預設」；客服接待選「更多」 |
| **熱情（Enthusiasm）** | 富有活力、激發靈感與讚揚 | 沉穩平實、低調節制 | 創意企劃選「更多」；報告稽核選「更少」 |
| **標題和列表（Headers & Lists）** | 善用粗體小標、項目符號條列 | 採用自然段落敘述長文 | **商務工作必選「更多」**（閱讀效率倍增） |
| **表情符號（Emojis）** | 穿插適度表情符號增加親切感 | 嚴禁出現任何表情符號 | 正式商業報告選「更少」；社群行銷選「更多」 |

---

### 3. 🤝 夥伴（Partner）與 👤 關於你（About You）

#### 🔹 夥伴（Partner）
- **選擇夥伴**：挑選或指定一位與你協作的角色雛型，讓 AI 保持一致的思維視角。

#### 🔹 關於你（About You）三大核心欄位
填寫一次後，ChatGPT 在任何全新對話中皆會主動將其視為默認背景，不再需要重複介紹：
1. **暱稱**：*「ChatGPT 該如何稱呼你？」*（例如：`Robert`、`經理`）。
2. **職業**：設定你的真實業務角色（例如：`中小企業數位轉型顧問與行政主管`）。
3. **更多關於你的資訊**：記錄你的核心價值觀、工具偏好或工作習慣（例如：`習慣使用 Google Docs 與 Excel、偏好數據導向決策、重視專案交付時程`）。

---

### 4. ⚡ 快速回覆（Quick Responses）開關
- **功能機制**：開啟後，當面對常識或一般知識型提問時，ChatGPT 會提供迅速且深入的解答；這些回答**不會消耗額外時間進行個人化匹配，也不會讀取你的記憶庫**，能大幅提升日常查詢的速度。

---

### 5. 🎛️ 進階功能（Advanced）啟閉控制
在個人化設定中，可依工作情境自由勾選功能開關：
- **網頁搜尋**：自動搜尋網頁以獲取最新時事與產業數據。
- **畫布（Canvas）**：自動開啟雙欄畫布協作長文與程式碼。
- **ChatGPT 語音**：啟用語音交互對話功能。
- **檔案庫搜尋**：允許自動搜尋知識檔案庫中的檔案。
- **連接器搜尋**：允許直接檢索 Google Drive、OneDrive 等連線資料來源。

## 📝 二、自訂指令（Custom Instructions）實務撰寫

在「個人化」頁面下方的 **「自訂指令（Custom Instructions）」** 欄位中，可以輸入更細緻的特定行為規範（付費版已支援高達 5,000 字上限）。

### 職場一般人必填設定範本（直接複製套用）：

```text
【回覆規範與行為喜好】：
1. 語言偏好：一律使用「台灣繁體中文（zh-TW）」回覆，使用台灣習慣商務公文與生活用語。
2. 溝通風格：務實、條理分明，直接切入核心結論，避免冗長空泛的開場白與結語。
3. 排版架構：長文一律採用階層式標題（H2/H3）、要點條列；若有比較分析，優先以 Markdown 表格呈現。
4. 專業交付：產出企劃或公文時，請符合台灣企業標準規格，必要時在文末主動提示 2~3 個可深入優化的關鍵面向。
```

## 🧠 三、Memory（長期記憶庫）運作與管理

ChatGPT 具備「跨對話主動記憶」機制。它會在平常聊天的過程中，自動記住你隨口提及的關鍵資訊。

```text
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│ 日常對話交代偏好          │ ───> │ 畫面彈出提示              │ ───> │ 未來任何新對話            │
│ 「請記住我們公司的色票號」│      │ 「Memory updated (已儲存)」│      │ 自動套用該設定，無需提醒  │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
```

### 1. 主動注入記憶的口語技巧
在任何對話中，只要用自然語言告知：
- *「請記住，我們公司的主視覺標準色是深海藍（#003366），標準字型為微軟正黑體。」*
- *「請記住，每次我要求產出待辦清單時，請排成『任務、負責人、截止日』三欄表格。」*
- *「請記住，我負責的旗艦產品品牌為『E-Green 智慧清淨機』。」*

### 2. 記憶摘要與管理（清理過期記憶）
- **管理路徑**：**設定** ➔ **個人化** ➔ **記憶** ➔ 點擊 **【管理（Manage）】**。
- **檢視與刪除**：你可以看到所有被儲存的單條記憶條目。若某個專案已結束或偏好改變，點擊右側的「垃圾桶」圖示即可單筆刪除，避免舊資訊干擾未來推論。

### 3. 何時應關閉記憶？（使用臨時對話）
如果你正在處理一個與平時完全不相關的「一次性臨時任務」或「敏感私人話題」，避免這些資訊被寫入長期記憶：
- 點擊對話介面右上角的 **「開啟臨時對話（Temporary Chat）」**。
- 在臨時對話中，ChatGPT 不會載入你的記憶庫，也不會將該對話內容寫入長期記憶，保護資訊隔離。

---

## 📋 課堂自我檢驗小練習

1. 打開個人帳號的 **「設定」➔「個人化」**，填入你的**稱呼**、**職業**，並在特質中將**「標題和列表」**設為「更多」。
2. 在**自訂指令**中填入繁體中文偏好。
3. 開啟一個新對話，輸入：*「請幫我寫一份辦公室節能減碳宣導公告的重點提綱。」*
4. 觀察產出是否自動具備結構化標題與條列，完全不用提醒！
