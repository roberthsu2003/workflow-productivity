# 03. Canvas（畫布互動協作：長文與程式碼精修）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用（現已全面開放）

傳統 AI 對話最大的痛點在於：**當你想修改一篇 3,000 字報告中的某個段落時，AI 往往會整篇重新生成一次，浪費時間又容易改動原本滿意的部分**。

OpenAI 推出的 **Canvas（畫布）** 功能正是為了解決這項痛點！Canvas 是專為「人機協同寫作」與「程式碼協作精修」打造的獨立雙欄工作區，也是對標 Claude Artifacts 的旗艦級生產力利器。

---

## 🖥️ Canvas 介面解構：雙欄協作模式

當觸發 Canvas 模式時，ChatGPT 介面會自動分為左右兩欄：
- **左欄（對話控制台）**：保持日常對話、下達宏觀指令、提出修改需求。
- **右欄（Canvas 畫布編輯區）**：顯示當前處理的文件或程式碼，學員可像在 Google Docs 或 Word 中一樣**直接手動打字修改**，或讓 AI 進行針對性精修。

```text
┌──────────────────────────────────────┬───────────────────────────────────────────┐
│           左側：對話指導區            │             右側：Canvas 畫布              │
│                                      │                                           │
│ 👤 請把第二段的語氣改得更正式，       │ 📄 2026 年度行銷策劃案                     │
│    並加上量化 KPI。                  │ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                      │ 1. 專案執行背景                           │
│ 🤖 好的！我已經直接在右側畫布上修訂  │    本專案旨在提升品牌在亞洲市場的聲量...  │
│    第二段，並補上預估數據。          │                                           │
│                                      │ 2. 核心指標（KPI） [AI 已自動劃記修訂]    │
│                                      │    - 季度活躍用戶增長：25%               │
│                                      │    - 轉換率由 1.8% 提升至 3.2%            │
└──────────────────────────────────────┴───────────────────────────────────────────┘
```

## 🚀 如何主動召喚與開啟 Canvas？

除了 ChatGPT 偵測到長文或代碼時會自動打開 Canvas 之外，你可以透過以下方式**強制開啟**：

1. **對話框手動切換**：在輸入框選擇模型時，直接選取 **「GPT-4o with canvas」**。
2. **在提示詞中明確要求**：
   ```text
   請在 Canvas 中為我撰寫一份「數位轉型專案驗收備忘錄」。
   ```
3. **將既有文字送入畫布**：在任何一段回答的右上角，點擊 **「在畫布中開啟（Open in canvas）」** 圖示。

## ✍️ 寫作場景：Canvas 五大核心協作功能

在右側 Canvas 畫布右下角，提供了一排強大的快捷編輯工具小幫手：

### 1. 劃記選取修訂（Highlight & Inline Feedback）
- **操作方式**：在右側畫布中，用滑鼠反白選取你想要調整的特定句子或段落，畫面上會立即浮現快捷對話泡泡。
- **實戰示範**：反白「我們提供優質的售後支援」，輸入指令：*「改為更具說服力的 B2B 承諾，強調 24/7 SLA 與 15 分鐘即時回應」*。AI 會**只替換該反白範圍**，其餘內容毫無損耗！

### 2. 調整長度（Adjust Length）
- 拖曳拉桿或點擊按鈕，一秒將內容從「極簡版綱要（Shortest）」展開為「詳盡企劃書（Longest）」，或將冗長會議記錄濃縮為精鍊版。

### 3. 調整閱讀層級（Reading Level）
- 自由調整目標讀者受眾的理解深度：從**小學生（Kindergarten）**、**中學生（High School）** 到 **大學與研究生（Graduate）**。
- *商務情境*：將生硬的雲端技術架構文件，一鍵轉譯為連外行客戶或高階主管都能秒懂的通俗語言。

### 4. 潤飾修整（Suggest Edits / Add Final Polish）
- 點擊「潤飾」，AI 會化身資深文字總監，自動檢查語病、修飾修辭、強化排版結構，並以底色高亮標記修改位置。

### 5. 加入表情符號（Add Emojis）
- 為生硬的公告或社群貼文注入活力，一鍵在合適的標題與小節前方加上生動的 Emoji 表情符號。

## 💻 程式協作場景：開發與數據腳本精修

若你在 Canvas 中編寫 Python、HTML、SQL 或 JavaScript，右下角的工具列會自動轉變為程式碼專屬的除錯工具箱：

| 工具功能 | 功能描述 | 職場實戰效益 |
| :--- | :--- | :--- |
| **Code Review（程式審查）** | AI 逐行檢查效能瓶頸、記憶體浪費與安全漏洞，並提出註解建議。 | 避免在生產環境中留下 SQL Injection 或效能低落的重複迴圈。 |
| **Fix Bugs（自動修復錯誤）** | 自動抓出語法錯誤（SyntaxError）或邏輯盲點，並直接在畫布上修復。 | 快速排除寫腳本時常見的縮排或變數未定義錯誤。 |
| **Add Comments（增添註釋）** | 為複雜演算法或資料清洗步驟自動加入清晰詳細的中文註解。 | 讓交接與團隊協作毫無阻礙。 |
| **Port to Language（轉譯語言）** | 一鍵將目前程式碼轉譯成其他語言（如：Python 轉 JavaScript 或 SQL）。 | 跨架構資料庫遷移時省去數小時手動改寫時間。 |

## ⏪ 版本歷程回溯（Version History）

在 Canvas 畫布的右上角，設有 **「復原／重做」** 與 **「歷史版本」** 按鈕：
- 每一次你下達指令或 AI 做出修改，系統都會自動存下一個歷史快照（Snapshot）。
- 點擊右上角的時間箭頭，可自由在「版本 1」、「版本 2」、「版本 3」之間來回切換對比。
- 就算 AI 改錯了方向，也能一鍵無損回到先前的最佳版本，徹底告別內容被覆蓋丟失的焦慮！

## 📋 本章實戰演練作業

請按照以下步驟完成一次真實的 Canvas 協同創作：

1. 發送提示詞：*「請在 Canvas 中為一家主打『永續環保咖啡豆』的新創品牌，撰寫一份 800 字的募資上線新聞發布稿。」*
2. 打開 Canvas 後，用滑鼠反白選取標題，指令要求：*「改寫為更具吸引力、能引爆社群轉發的 3 個候選標題」*。
3. 點擊右下角工具列的 **Reading Level**，將其切換為 **High School** 使語言更親民。
4. 點擊右上角的歷史箭頭，檢視修改前後的差異，最後將成品一鍵複製使用。
