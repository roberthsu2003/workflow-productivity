# 04. Chats（對話思維、提問架構與追問心法）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

與 ChatGPT 對話絕非漫無目的的隨意聊天，而是透過清晰的指令結構與適當的引導節奏，精準指揮 AI 完成高品質的職場交付。

很多初學者常覺得「AI 講話太客套、回答總是抓不到痛點」，關鍵往往不在於模型聰不聰明，而在於**提問時是否給予足夠的業務情境與輸出格式約束**。

---

## 📐 職場高階對話架構：三步驟心法

想要獲得具備商業水準的回覆，建議掌握以下三步驟：

```text
┌─────────────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│ 步驟 1：定義角色與情境   │ ───> │ 步驟 2：明確任務與限制  │ ───> │ 步驟 3：指定產出格式    │
│ 「你是一位資深人資顧問」│      │ 「針對同仁遲到撰寫提醒」│      │ 「請用繁中條列，勿說教」│
└─────────────────────────┘      └─────────────────────────┘      └─────────────────────────┘
```

1. **Role & Scenario（角色與情境）**：明確 AI 的專業視角，以及這件事發生在什麼背景下。
2. **Task & Constraints（具體任務與邊界條件）**：這次任務的核心目的，以及**絕對不能犯的禁忌**（例如：不可過度說教、不可猜測未提及的數據）。
3. **Format & Tone（格式與語氣）**：期望看到的輸出形態（Markdown 表格、要點條列、三段式信件、指定字數）。

## 💼 職場高頻對話範本庫

### 範例 1：長篇會議筆記轉化為「行動執行清單（Action Matrix）」
```text
你是一位嚴謹的專案管理顧問（PMP）。
請將我接下來貼上的零散會議筆記，整理成結構分明的追蹤矩陣：
1. 核心決策結論（3 點以內）
2. 待辦任務清單（請用表格呈現：任務名稱 | 負責人 | 預估截止日 | 優先級）
3. 潛在風險與提醒事項

【規範】：禁止捏造會議中沒提到的截止日期；若未提及請填「待確認」。
```

### 範例 2：商務公文與郵件精修（去冗詞贅字）
```text
我寫了一封準備寄給合作廠商的商務信件草稿，請幫我潤飾：
- 目標：通知因原物料上漲，下季合作報價需調整 5%，希望能約時間線上面談。
- 語氣：誠懇、尊重長期夥伴關係、有擔當，但立場堅定。
- 格式：直接提供主旨與正文，避免空泛客套，篇幅 300 字以內。
```

## 🔍 驗收與追問技巧（Iterative Prompting）

得到第一次產出後，不要因為不夠完美就直接放棄。學會用以下「追問心法」逐步收斂：

- **反饋微調**：*「第 2 點寫得太理論，請以『零售業門市主管』的角度給出具體應對話術。」*
- **視角切換檢視**：*「如果從財務長極度嚴格的角度來審核這份提案，最大的盲點會是什麼？」*
- **範例引導（Few-shot）**：*「請參考以下這段我過去寫的文案風格，將上述內容改寫成相同的筆觸：……」*
