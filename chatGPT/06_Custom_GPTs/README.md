# 06. Custom GPTs（零程式碼！打造個人與團隊專屬 AI 助理）

> 🟢 **適用方案**：Free（可自由使用市集上的 GPTs） / 🔵 Plus（可親手自建、設定與分享） / 🏢 Team（團隊內部私密共享）

在日常工作中，如果你有一套經常重複使用的標準作業程序（SOP）、專屬文案風格，或是需要經常查閱厚厚一本的「員工手冊」或「產品規格書」，每次都要重新貼給 ChatGPT 非常麻煩。

**Custom GPTs（自訂 GPT 助理）** 讓**完全不懂寫程式的普通人**，只要透過滑鼠點選與日常白話文字，就能在 10 分鐘內打造出專屬於你個人的「超級數位分身」或「部門專家助手」！

---

## 🛠️ 如何進入與打造？（只要會打字就能做）

### 1. 進入建立介面
- 在 ChatGPT 網頁版左側導覽列點選 **「Explore GPTs（探索 GPT）」**。
- 點擊右上角的綠色按鈕 **「+ Create（建立）」**。

### 2. 雙模式介面：聊天打造 vs 欄位配置

介面提供兩種方式，一般人兩種都非常容易上手：

```text
┌───────────────────────────────────────┬───────────────────────────────────────────┐
│     Create 頁籤（新手口語對話模式）    │        Configure 頁籤（專家直接設定模式）  │
├───────────────────────────────────────┼───────────────────────────────────────────┤
│ 用日常對話告訴 AI：                   │ 像填表單一樣直接輸入：                    │
│ 「我想做一個專門幫我把公文草稿改得符合 │ 1. Name（名稱）：公文合規修訂小幫手       │
│  台灣政府公文格式的秘書。」           │ 2. Description（一句話介紹）              │
│                                       │ 3. Instructions（系統核心角色與規範）     │
│ AI 會自動幫你命名、產生頭像與基本規則！│ 4. Conversation Starters（快速點選按鈕） │
│                                       │ 5. Knowledge（拖曳上傳內部手冊 PDF/Word） │

```

## 📚 打造專屬小幫手的核心關鍵：四大元件

要讓你的 Custom GPT 聰明好用，只需設定好以下四個部分：

### 1. Instructions（角色設定與行為準則）
這是小幫手的大腦核心，用清晰的繁體中文寫下：
- **它是誰**：例如「你是一家擁有 20 年歷史的連鎖餐飲品牌的公關主管」。
- **任務是什麼**：專門負責回答分店店長關於食品安全、退換貨客訴的標準應對。
- **原則與限制**：若遇重大法律糾紛，主動提醒「此案需呈報法務室處理」，不可擅自承諾賠償金額。

### 2. Knowledge（專屬知識庫：直接上傳檔案）
- 這是 Custom GPT 最厲害的地方！你可以把 **公司的員工請假辦法 (PDF)**、**產品問答手冊 (Word)**、**歷年成功新聞稿範例 (TXT)** 直接拖曳上傳。
- 當你向它提問時，它會優先檢索這些文件中的真實條款來回答你，徹底告別 AI 胡言亂語！

### 3. Conversation Starters（對話開場按鈕）
- 設定 2~4 個一鍵點選的常見問題按鈕，讓同事打開時不用思考怎麼打字：
  - *「請幫我審核一份育嬰留職停薪申請條件」*
  - *「客人反應餐點有異物，第一時間該怎麼處理？」*

### 4. Capabilities（能力勾選開關）
- **Web Search（網路搜尋）**：讓小幫手能即時上網查時事。
- **Canvas**：啟用畫布協同編輯長文。
- **Image Generation（ChatGPT Images 2.5 圖像生成）**：允許產出高品質商務圖片。
- **Code Interpreter（數據分析）**：允許解析 Excel、繪製圖表並產出 Word/Excel 檔案下載。

## 🔒 發佈與隱私分享權限

完成小幫手後，點擊右上角 **「Save / Update」**，有三種權限可選：

1. **Only me（僅自己）**：只有你的帳號看得到，適合作為私人草稿或個人工作分身。
2. **Anyone with a link（任何擁有連結的人）**：不公開在市集，但可以複製專屬網址發給部門同事或主管直接點開使用！
3. **Public（公開在 GPT Store）**：全世界的使用者都能在市集搜尋到你的作品。
