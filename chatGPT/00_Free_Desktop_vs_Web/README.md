# 00. 學生免費版通關指南：桌面版 vs 網頁版額度機制與省額心法

> 🟢 **適用方案**：Free（專為 100% 未付費學生與自學者量身打造）

在課堂中，絕大多數學生與初學者都是使用 **ChatGPT Free（免費版）**。許多同學常有的誤解是：*「免費版是不是聊幾句就會被鎖住？」*、*「桌面版跟網頁版看起來差不多，額度到底怎麼算？」*。

事實上，**ChatGPT 桌面版（Desktop App）與網頁版（Web）在免費方案下的介面設計、功能分工與額度呈現方式有著關鍵差異**。搞懂這兩者的運作規則，就算完全不花一毛錢，也能流暢運用一整個月！

## ⚖️ 桌面版 vs 網頁版：免費額度與機制全對照

| 比較項目 | 🖥️ 官方桌面版（macOS / Windows） | 🌐 瀏覽器網頁版（Web） | 學生實務建議 |

## 🔍 解密桌面版「1 個月 100% 10月11日」倒扣儀表板

打開桌面版左下角個人選單，看到這行資訊時不必慌張：

```text
┌─────────────────────────────────────────────────────────┐
│ 👤 你的姓名 (Free)                                      │
├─────────────────────────────────────────────────────────┤
│ ⏱️ 剩餘用量 ﹀                                          │
│    1 個月       100%       10月11日                     │
│    [升級為 Plus]   [深入了解]                           │
└─────────────────────────────────────────────────────────┘
```

1. **100% 代表「滿格可用」**：這是倒扣機制，數字越小代表消耗越多。100% 代表本月份的高階配額完全還沒動用。
2. **10月11日是「刷新日」**：到期當天會自動滿血復活，重新回到 100%。
3. **超額不會封鎖帳號**：即使在月底前降到 0%，**基礎純文字聊天依然永久可用**，只是無法生成新圖片或執行複雜 Python 試算表運算。

## 🚦 什麼操作會扣額度？什麼操作完全免費？

身為免費版學生，必須清楚區分這兩大類行為：

### 🟢 1. 完全不扣高階額度（100% 免費，無限次數）
- **純文字問答與討論**：詢問專案觀念、歷史典故、程式語法說明。
- **文案潤飾與改寫**：校對論文報告錯字、重寫公文信件、翻譯多國語言。
- **腦力激盪與大綱發想**：請 AI 條列報告章節架構、行銷點子。
- **文字討論式協作**：在對話中反覆打磨 Markdown 內容。

### 🔴 2. 會實質扣除高階額度（有配額上限，謹慎使用）
- **ChatGPT Images 2.5 圖像生成**：包含對話出圖、`@Sketch` 草圖轉成品圖、Comments 批註改圖。
- **檔案上傳與數據分析（點擊輸入框「+」上傳 Excel/CSV，過去稱為 Advanced Data Analysis）**：上傳試算表要求執行數據清洗、統計分析、繪製圖表或輸出新檔案。
- **實體檔案生成下載**：要求 ChatGPT 直接打包產出 `.docx`、`.xlsx`、`.pptx` 實體檔案。
- **觸發深度思考推理（Reasoning）**：當題目涉及極度繁複的邏輯數學推演，系統啟動長時間深度思考時。

## 💡 學生專屬：零花費「極致省額四神技」

### 秘技一：日常問答留在「對話」，專案交付才開「工作（Work）」
- 桌面版頂部提供了 **「對話」** 與 **「工作」** 標籤。
- 一般查資料、問問題，務必保持在 **「對話」** 模式下，絕不浪費高階額度。
- 只有當手頭有整份專案文件需要對接、或準備最終產出成果時，才切換至 **「工作」** 模式。

### 秘技二：先 Markdown 討論定稿，最後一次才產出檔案
- **反面教材（最浪費額度）**：每次只改一句話就叫 AI 產出一次 Word 檔案，不到半天就把全月額度耗盡。
- **高階心法（極致省額）**：整個修改過程**全在聊天視窗中用 Markdown 文字來回討論打磨**；直到全部章節定稿無誤後，**只在最後一步要求一次產出正式 `.docx` 或 `.pptx`**！

### 秘技三：善用「臨時對話（Temporary Chat）」
- 查課業雜題或臨時瑣事時，點擊右上角開啟「臨時對話」。
- 既不污染你的「個人化記憶（Memory）」，也不會留下多餘的歷史對話佔據版面。

### 秘技四：雙修策略（桌面版捷徑 + 網頁版多工）
- 平時寫作業、做報告時，在桌面按下 `Option + Space`（Mac）快速喚出浮動小窗，隨查隨貼。
- 需要同時對照多篇不同主題的文獻時，使用 Chrome/Edge 開啟網頁版，利用瀏覽器標籤頁平行閱讀。
