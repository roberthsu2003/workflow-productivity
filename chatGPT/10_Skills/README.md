# 10. Skills（技能機制與工作流程自動化）

> 🟢 **適用方案**：Free / Plus / Team / Enterprise 全方案適用

在現代職場中，最有效率的團隊往往不是每次重寫冗長的 Prompt，而是將成熟的工作流程封裝為標準化的 **「Skills（技能）」**。

透過 Skills 機制，ChatGPT 能像擁有專業證照的專家一樣，依照固定的 SOP、企業檢查清單與產業規範，自動化執行特定領域任務！

---

## 🧩 什麼是 ChatGPT Skills？

Skills 是由一組結構化的**專業知識、步驟規範與產出範本**所構成的模組化能力單元：

```text
┌─────────────────────────┐
│     專業 Skill 定義     │
│ 1. 觸發情境 (When to use)│ ───>  ChatGPT 自動精準執行專業 SOP，
│ 2. 執行規範 (SOP Steps) │       產出符合企業規範的成果，避免疏漏！
│ 3. 輸出範本 (Templates) │
└─────────────────────────┘
```

---

## 💼 職場必備四大實戰 Skill 範例

### 1. 📝 商務公文與正式簽呈審查 Skill
- **功能**：自動比對內部簽呈格式，檢查是否包含「主旨、說明、擬辦」，並稽核預算金額與權責主管是否符合規定。
- **效益**：大幅降低公文退件率。

### 2. 📊 財務比率診斷與異常預警 Skill
- **功能**：固定計算流動比率、速動比率、負債比率與毛利率，並以紅黃綠燈號自動標示潛在風險指標。
- **效益**：省去手動拉公式時間，數秒內輸出高階管理摘要。

### 3. 🎯 行銷文案 A/B 測試發想 Skill
- **功能**：針對同一個推廣主題，強制輸出「痛點訴求型」、「數據權威型」與「情感共鳴型」三種完全不同切入點的文案，並預設社群點擊率（CTR）假設。
- **效益**：快速豐富文案素材庫。

### 4. 🛠️ 桌面自動化與輔助技能（如 Desktop Pet）
- **功能**：在桌面版環境中調用輔助任務監控（例如桌面像素寵物孵化與狀態追蹤），讓 AI 任務執行更直觀。

---

## 🛠️ 如何在對話中自訂與調用專屬 Skill？

即使不寫程式碼，你也可以在 **自訂指令（Custom Instructions）** 或 **Projects 專案空間** 中定義你的專屬 Skill 關鍵字：

```text
【定義 Skill：法規合規檢查員 (Compliance-Checker)】
每當我輸入「#合規審查」開頭的文字時，請自動執行以下步驟：
步驟 1：檢視文案中是否包含絕對保證或誇大字眼（如：保證獲利、第一名、永不損壞）。
步驟 2：檢查是否缺少年滿 18 歲或警語警示標籤。
步驟 3：輸出「合格項目清單」與「待修正建議文字表」。
```

定義完成後，往後只要打出 `#合規審查`，ChatGPT 就會瞬間套用這套專業 SOP，大幅提升團隊生產力！
