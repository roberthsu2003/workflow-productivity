# 11. DALL·E 3（簡報配圖、社群視覺與畫筆局部修圖）

> 🟢 **適用方案**：Free（每日提供 2~3 張免費額度） / 🔵 Plus / Team（高額度日常使用）

在製作商務簡報、活動宣傳海報、內部宣導公文或社群貼文時，一般人最常遇到的困擾就是：**在免費圖庫網站翻了半天，找不到風格合適的照片，又擔心版權侵權風險**。

ChatGPT 內建了頂級的圖像生成引擎 **DALL·E 3**，讓你直接在對話中用繁體中文描述，就能一秒生成專屬的商業插圖；更具備「畫筆局部修改（Inpainting）」功能，能無痕修除畫面瑕疵或替換物件！

---

## 🎨 職場一般人圖像生成公式

想要生成符合商務質感、而不是雜亂卡通感的圖片，建議使用以下四元素結構撰寫 Prompt：

```text
【主體】+【場景與光線】+【視覺風格】+【構圖與用途】
```

### 實戰範例 1：商務簡報首頁投影片概念圖
```text
請幫我生成一張圖片：
- 主體：幾位來自不同文化背景的專業商務人士正在明亮的現代會議室中熱烈討論。
- 風景/氛圍：採光充足的玻璃帷幕大樓落地窗，窗外是現代都會天際線，晨光自然灑落。
- 風格：乾淨專業的現代商業攝影風格，色彩自然真實，高質感。
- 構圖：16:9 橫式比例，畫面右半部保留適當景深留白，適合用來當作簡報的背景底圖。
```

### 實戰範例 2：社群行銷的清新扁平插畫
```text
請生成一張「宣導員工身心健康與工作生活平衡」的圖片：
- 主體：一位上班族正在辦公桌旁伸懶腰，旁邊擺著一杯熱茶與綠色多肉植物。
- 風格：簡約溫暖的扁平向量插畫風（Flat Vector Illustration），採用柔和的莫蘭迪粉綠與暖黃配色。
- 比例：1:1 正方形，適合 Instagram 或內部公告宣傳。
```

## 🖌️ 神級功能：畫筆工具（局部修改 Inpainting）

產出一張圖片後，常常只有某個小細節不滿意（例如：人臉怪怪的、桌上多放了一杯飲料、背景想要換掉）。以前可能要整張重產，但現在可以用**畫筆直接塗抹修改**：

```text
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│ 點開產出的圖片            │ ───> │ 用畫筆塗抹「桌上的水杯」  │ ───> │ 輸入指令：「換成一台銀色  │
│ 點擊上方「選取/筆刷」圖示 │      │ 調整筆刷大小圈選範圍      │      │            筆記型電腦」   │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
```

1. 在對話中點開 ChatGPT 生成好的圖片。
2. 點擊頂部工具列的 **「畫筆（Select / Inpainting）」** 圖示。
3. 用滑鼠像橡皮擦一樣，直接塗抹塗白你想修改的那塊區域。
4. 在右下角的對話框中輸入指令：*「將塗抹區域替換為一台打開的筆記型電腦，其餘部分保持完全不變」*。
5. 送出後，ChatGPT 會精準只修改該塗抹處，保留整張圖的原汁原味！

---

## 💡 一般人常見小提醒

- **文字生成的限制**：DALL·E 3 對於生成「英文字」效果較佳，但在生成複雜「繁體中文字」時仍可能偶有筆畫不精準的狀況。建議將圖片當作純粹的視覺背景，文字標題在 PowerPoint 或 Canva 中自行後製打上，效果最完美！
