# 01. Settings（環境準備、隱私、最新桌面端設定全解析）

> 🟢 **適用方案**：Free / Plus / Team / Pro / Enterprise 全方案適用（部分進階開發與代理功能需對應桌面版本支援）

隨著 ChatGPT 桌面版（Desktop App）邁入 **Agentic AI（自主代理人）與工作流協同** 時代，設定介面（Settings）已從早期的簡單語言、主題選項，全面升級為涵蓋 **「個人（Personal）」、「整合（Integrations）」、「程式設計（Coding）」與「已封存（Archived）」** 的四大維度中樞控制台。

本章將帶您完整解析官方最新設定架構，特別針對 2026 最新加入的 **內建瀏覽器（Browser Use）**、**Computer use（電腦操控）**、**Appshots**、**Pets（狀態寵物）** 以及 **Git Worktrees / Environments 開發者環境** 等強大功能進行深度剖析與實用配置指引。

## 🌐 焦點一：整合篇 ——「瀏覽器（Browser）」設定全功能詳解

桌面版內建了一個完全獨立的**「內建瀏覽器（In-app Browser）」**，支援 OpenAI 最新發表的 **Browser Use（瀏覽器操作代理）** 技術。ChatGPT 不僅能讀取網頁文本，還能在瀏覽器內模擬人類點擊、滾動、填表、跨分頁比對及下載檔案。

### 1. 頂部核心開關
*   **「瀏覽器：讓 ChatGPT 控制內建瀏覽器」**：
    *   **功能意義**：總開關。開啟後，ChatGPT 即可在獨立沙盒視窗內操控瀏覽器，為您執行自動化查閱、表單填寫或本地開發除錯任務。
    *   **快速喚起**：在桌面端中隨時可透過快捷鍵 `Cmd + Shift + B`（Windows 為 `Ctrl + Shift + B`）直接打開內建瀏覽器。

### 2. 一般設定項目（General）
*   **匯入...（Import...）**：
    *   **功能**：將現有主流瀏覽器（如 Google Chrome、Safari）的登入狀態、Cookies、書籤與設定檔直接匯入到內建瀏覽器中。
    *   **公務應用**：若需要讓 ChatGPT 登入特定企業內部系統或需驗證的 SaaS 網站，可透過匯入功能無縫繼承登入狀態，省去重複手動驗證的困擾。
*   **網頁 URL 和連結開啟位置（Web URLs & Links Opening Location）**：
    *   **選項**：`預設瀏覽器（Default Browser）` 或 `ChatGPT`。
    *   **建議設定**：一般使用者建議保留為「預設瀏覽器」，避免點擊外鏈時打斷原本的工作視窗；若希望深度依賴 AI 協助閱讀與標註，則可切換為「ChatGPT」。
*   **本機 URL 開啟目標（Local URLs Opening Target）**：
    *   **選項**：`ChatGPT` 或 `預設瀏覽器`。
    *   **核心用途**：針對本機開發網頁（例如 `localhost:3000`、`127.0.0.1:8080`）。預設為「ChatGPT」，讓 AI 可以在內建瀏覽器中即時檢驗前端排版、查看主控台錯誤日誌並直接協助除錯。
*   **顯示完整網址（Show Full URL）**：
    *   **功能**：在網址列中顯示包含路徑（Path）、查詢參數（Query Strings, 如 `?id=123`）及片段錨點（Hash, 如 `#section-1`）。
    *   **建議**：進階工作者與開發者建議開啟，便於確認 AI 當前所處頁面的精確參數。
*   **瀏覽資料（Clear Browsing Data）**：
    *   **功能**：點擊「清除瀏覽資料」，可徹底抹除內建瀏覽器中的歷程記錄、網站快取、Cookie 及下載檔案，確保資安隔離與隱私安全。
*   **瀏覽歷史記錄（Browsing History）**：
    *   **功能**：點擊「管理」，可檢視並刪除 ChatGPT 在內建瀏覽器中造訪過的所有網頁歷程。
*   **註解螢幕截圖（Annotation Screenshots）**：
    *   **選項**：`一律包含（Always Include）`、`詢問（Ask）`、`從不（Never）`。
    *   **運作機制**：在內建瀏覽器中使用「註解模式」圈選網頁區塊留反饋時，系統會自動截圖傳給模型進行視覺理解。
    *   **注意事項**：介面特別標明「*會增加方案用量*」。如果帳號是免費版或用量吃緊的 Plus 方案，可考慮設為「詢問」以節省用量額度。

### 3. 自動填入和密碼（Autofill & Passwords）
*   **密碼管理工具（Password Manager）**：
    *   可新增、編輯或刪除已儲存在內建瀏覽器中的帳號密碼。讓 AI 在執行自動化表單任務時安全調用憑證，避免在聊天文字對話框中以明文輸入敏感密碼。
*   **聯絡資訊（Contact Info）**：
    *   安全儲存姓名、電話、地址與電子郵件。當指派 AI 執行例如「訂購樣品」、「活動報名表格自動填寫」時，AI 可自動帶入正確資訊。

## 🤖 焦點二：整合篇 —— Computer use 與 Appshots

除了瀏覽器，整合（Integrations）區塊還包含了兩大顛覆性的桌面 Agent 能力：

### 1. Computer use（電腦操控）
*   **功能本質**：允許 ChatGPT 透過觀察螢幕畫面、分析 UI 元素，並直接模擬操作滑鼠點擊與鍵盤輸入。
*   **適用場景**：傳統 API 或命令列無法打通的本機桌面軟體（如特定的 ERP 舊系統、影音編輯軟體、跨多個 App 的複雜資料搬運）。
*   **安全性控制**：macOS 會要求授予「輔助使用（Accessibility）」與「螢幕錄製」權限。執行過程中會以畫中畫（Picture-in-Picture）小視窗提示，關鍵敏感操作（如送出、付款、刪除）皆需人類使用者點擊核准。

### 2. Appshots（應用程式快照）
*   **功能本質**：針對當前前景（Active）視窗進行一鍵快照捕獲。
*   **優勢亮點**：不同於普通截圖只包含像素圖片，Appshots 會同時提取視窗的**「無障礙文字結構樹（Accessibility Tree）」**，讓 AI 不僅能「看見」畫面，還能精確「讀懂」文字內容、按鈕層級與結構標籤，大幅提升視覺分析精準度。

## 🛠️ 焦點三：程式設計篇 —— 開發者核心環境設定

針對程式開發者與深度自動化使用者，ChatGPT 桌面版全面整合了 Codex 與 Git 本機作業環境：

### 1. Worktrees（Git 工作樹隔離）
*   **核心痛點**：以往讓 AI 改 Code，常直接改動本機正在編輯的工作目錄，造成程式碼衝突與未暫存內容混亂。
*   **解決方案**：開啟 Worktrees 支援後，ChatGPT 在處理開發任務時，會自動在背景為新任務建立獨立的 Git Worktree 分支目錄。多個 AI 任務可以同時平行修改不同功能，完全互不干擾，驗證通過後再合併回主分支。

### 2. 環境（Environments）
*   **功能**：定義本機與雲端的開發環境配置。
*   **專案設定檔（`.codex`）**：在專案根目錄中配置設定，宣告環境依賴（如 `npm install`、`pip install`）與常用啟動腳本。當 AI 進入專案時，能自動就緒環境並執行驗證測試。

### 3. 掛勾（Hooks）
*   **功能**：生命週期自動化腳本機制。
*   **運作流程**：在特定事件觸發時（如 Session 啟動、Prompt 送出前、程式碼產生後），自動執行安全性檢查、載入環境變數、或自動執行單元測試防護網。

### 4. 連線（Connections）
*   **功能**：管理外部整合服務。支援設定遠端 SSH 主機，以及連結 GitHub、GitLab、Slack、Linear 等開發協作工具。

## 🐱 焦點四：個人篇 —— 寵物（Pets）與桌面高效互動

### 1. 寵物（Pets）—— 桌面浮動狀態指示小夥伴
最新 macOS 桌面版在「個人」設定中加入了充滿趣味卻極具實用價值的 **Pets** 模組：
*   **喚醒與收起**：在對話框輸入 `/pet` 或在設定中點擊「Wake Pet / Tuck Away Pet」。
*   **四種任務狀態即時指示**：
    *   🟡 **Running（運作中）**：背景任務或深度思考正在進行中。
    *   🔴 **Needs input（等待輸入）**：AI 遇到決策點、需要人類權限核准或回答問題。
    *   🟢 **Ready（已就緒）**：任務已完成，有未讀新訊息。
    *   ⚪ **Blocked（受阻）**：執行時遇到報錯或連線問題。
*   **自訂寵物**：可直接在設定中透過提示詞描述，讓 AI 本機生成專屬外型的動畫精靈。
*   **視窗連動**：Computer use 的畫中畫視窗可自動吸附在寵物身旁，隨寵物拖曳移動。

### 2. 組態（Configuration）與分析（Analytics）
*   **組態**：統一管理模型調度參數、本機工具調用優先順序與系統級引導提示。
*   **分析**：查看各類別功能的使用頻率與效率統計，協助評估工作流瓶頸。

## 🛡️ 公務必讀：資料控制（Data Controls）與隱私防護

無論功能多麼強大，商業情境下的**資料安全與隱私合規**永遠是第一準則：

### 1. 關閉「改善所有人的模型（Improve the model for everyone）」
*   **操作路徑**：進入 **Settings** → **個人化 / 資料控制**。
*   **關鍵設定**：將 **Improve the model for everyone** 務必**關閉（Off）**。
*   **保障**：關閉後，您的對話文字、上傳文件及程式碼將不會被 OpenAI 用於訓練下一代模型。
*   *附註*：**ChatGPT Team / Enterprise / Edu** 企業教育方案預設即遵守商業隱私協定，不會使用任何組織資料進行訓練。

### 2. 臨時對話（Temporary Chat）
*   若需進行一次性機敏算式或極敏感草稿撰寫，請點擊上方切換為「Temporary Chat」。對話不會留存於歷史紀錄、不留記憶、亦不納入模型訓練。

### 3. 多因子驗證（2FA）
*   進入 **Settings** → **帳戶 / 安全**，綁定 Google Authenticator 或 1Password 等 OTP 工具，防範帳號憑證遭受盜用。

## 📋 2026 最新設定檢查清單（Checklist）

完成以下勾選，確保您的 ChatGPT 桌面端發揮最大生產力且合規安全：

- [ ] **資料控制**：確認關閉「改善所有人的模型」（企業/團隊方案確認合規標誌）。
- [ ] **雙因子認證**：完成 2FA 安全設定。
- [ ] **瀏覽器管理**：
  - [ ] 依工作型態確認「網頁 URL」與「本機 URL」的預設開啟位置。
  - [ ] 評估是否開啟「註解螢幕截圖」（注意額度消耗）。
  - [ ] 依需求於「密碼管理工具」與「聯絡資訊」建立常用範本。
- [ ] **桌面代理與快照**：
  - [ ] 授予 macOS 輔助使用與螢幕錄製權限，以利啟用 Computer use 與 Appshots。
  - [ ] 記住全域快捷鍵（`Option + Space` 喚醒視窗、`Cmd + Shift + B` 打開內建瀏覽器）。
- [ ] （選用/趣味實用）輸入 `/pet` 喚醒桌面寵物，隨時掌握背景 Agent 任務狀態。
