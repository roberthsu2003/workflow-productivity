# 步驟三：生成門市排班 Excel 發布檔提示詞（總表 ＋ 個人專屬工作表）

> 💡 **教學情境**：班表在 Canvas 畫布微調確認無誤後，進入行政落地發布階段。如果只將文字檔貼至 LINE 群組，員工難以在手機上快速查閱個人出勤時間。透過此提示詞，可讓 ChatGPT 利用 Python 程式庫（openpyxl）自動產出具備專業視覺樣式的 `.xlsx` 試算表檔案，提供直接下載。  
> 🛠️ **適用平台**：ChatGPT（具備程式碼執行 / 檔案生成能力之對話視窗）或支援 Python 腳本生成之 AI 代理。

---

## 📋 提示詞複製專區

請將下方內容直接複製貼入剛才完成微調排班的 ChatGPT 對話框中：

```markdown
## Role

你是一位精通 Excel 資料自動化與門市營運行政管理的專家，擅長使用 Python（openpyxl / pandas）製作版面專業、易於閱讀的排班試算表。

## Task

請根據剛才最終確認的「超商門市一週排班表（2026/10/12～10/18）」，編寫 Python 程式碼直接生成一份可供直接下載的 Excel 活頁簿檔案（檔名：`便利超商_捷運站前門市_一週排班發布表.xlsx`）。

## Structure & Requirements

這份 Excel 活頁簿必須滿足下列結構，以便門市公告與員工個人查閱：

1. **工作表架構（多 Sheet 設計）**：
   - **第一個 Sheet（門市排班總表）**：
     * 工作表名稱：`門市排班總表`
     * 內容：直欄包含「日期（10/12～10/18）」與「星期（週一～週日）」，橫列包含 8 位員工姓名與當日班別（D、E、N、休），底部附上「每日各班當值人數」與「缺額檢核」。
   - **其餘獨立 Sheet（每位員工各 1 個專屬工作表）**：
     * 工作表名稱分別為：`A_店長`、`B_副店長`、`C_專職大夜`、`G_正職店員`、`D_工讀大三`、`E_工讀大四`、`H_早班兼職`、`F_假日兼職`（共 8 個 Sheet）。
     * 每個員工的專屬 Sheet 必須有清楚的個人排班明細清單，並**包含「日期」欄位**。

2. **個人 Sheet 必備欄位（每一橫列代表一天）**：
   - **日期**（如：2026/10/12）
   - **星期**（如：週一）
   - **班別代碼**（D / E / N / 休）
   - **班別名稱**（早班 / 晚班 / 大夜班 / 例休 / 特休）
   - **出勤時間**（如：07:00 – 15:00、15:00 – 23:00、23:00 – 07:00、免出勤）
   - **當日工時**（8 小時 / 0 小時）
   - **當班工作重點與注意事項**（如：通勤早餐咖啡尖峰、包裹取件高峰、大夜進貨清潔、幹部例會排休等）
   - **表尾加總列**：自動統計「本週累計總工時（小時）」與「本週出勤天數（天）」。

3. **視覺與版面美化要求**：
   - 表頭標題列使用沉穩專業背景色（如超商綠色或海軍藍），搭配白色粗體字。
   - 資料儲存格文字與數字水平置中，格線（Borders）清晰完整。
   - 班別適度加上柔和條件樣式底色（例如：早班淺藍、晚班淺橘、大夜深灰底白字、休假淺綠）。
   - 自動設定合適的欄寬（Auto-fit column width），確保在手機或電腦開啟時不會出現 `###` 或文字被截斷。

請直接執行 Python 程式產出 `.xlsx` 檔案，並在回覆中提供該檔案的直接下載連結！
```
