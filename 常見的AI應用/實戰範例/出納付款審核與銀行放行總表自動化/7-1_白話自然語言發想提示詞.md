# 7-1 白話自然語言發想提示詞（最純粹的口語表達）

> 💡 **核心思維**：在職場中，出納不需要一開始就費心手刻繁複的提示詞結構。直接用最自然、接地氣的「財務出納口吻」說明業務規則、風控門檻與套表需求，讓 AI 主動提煉出嚴謹的執行邏輯！

---

## 💬 複製即可使用之白話發想指令

```markdown
我是公司的出納，每個月底跟 16 號都要彙整應付帳款，製作「銀行付款放行總表」呈送老闆簽核後放行。

附件兩份檔案：
1. 《素材_應付明細_台幣.xlsx》：從 ERP 匯出的應付帳款清單（270 筆）。
2. 《樣板_臺企銀單筆付款放行總表.xlsx》：公司標準的銀行放行表範本（含有 {{PAY_DATE}}、{{FORM_ID}} 與動態資料列錨點 {{SEQ}}、合計列與老闆簽章欄）。

本次請幫我處理指定付款到期日為「2026/09/30」的款項，要求如下：
1. 【依傳票與廠商合併發票】：ERP 匯出的是一張發票一列，但放行表必須依「傳票號碼 + 帳款對象」進行 GroupBy 合併，計算該筆傳票總共包含幾筆發票，並加總本幣應付金額。
2. 【標準化摘要】：摘要欄位請統一格式化為：「應付 [廠商代號]（N筆發票）」，例如「應付 TB0001（5筆發票）」。
3. 【財務風控與大額警示】：
   - 請檢查有無零元、負數或重複發票。
   - 若單筆傳票金額超過 100 萬台幣，請在審核報告中列為「🚨 巨額支付警示」，提醒老闆核決權限！
4. 【雙軌交付機制】：
   - 第一階段：先在畫布（Canvas / 雙欄）產出一份結構化的「出納風控審核報告」，讓我確認筆數與金額。
   - 第二階段：使用 Python openpyxl 依照樣板的 Template Placeholder（佔位符與動態擴展錨點），動態插入資料列、繼承格線字型、更新合計 SUM 公式，並保護最底下的簽核欄位不被覆蓋，產出《出納付款放行總表_已完成.xlsx》。

請先不要寫落落長的套話，直接給我第一階段的風控審核清單；如有任何資料缺漏或疑問，請主動向我確認！
```

---

## 🎯 本提示詞三大職場防呆亮點

1. **明訂「指定付款日（批次參數）」**：
   徹底解決學生原先 Prompt 將 9/30 誤判為非固定批次異常的矛盾，讓腳本具備處理不同到期日的彈性。
2. **傳票合併發票（GroupBy 邏輯）**：
   點出出納工作最耗時的「多張發票歸戶至同一傳票」的手工痛點。
3. **Template Placeholder 樣板觀念注入**：
   要求 AI 認明樣板佔位符，嚴禁直接暴力硬寫座標，保障 Excel 版面、字型與主管簽章完整性。
