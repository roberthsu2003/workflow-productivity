# 7-1 白話自然語言發想提示詞（最純粹的口語表達）

> 💡 **核心思維**：在職場中，出納不需要一開始就費心手刻繁複的提示詞結構。直接用最自然、接地氣的「財務出納口吻」說明業務規則、風控門檻與套表需求，讓 AI 主動提煉出嚴謹的執行邏輯！

---

## 💬 實戰第一步：讓 AI 自動分析《素材_放行總表.xlsx》生成佔位符樣板

> 💡 **就像 SQE 實戰 2**：學生不需要手動打開 Excel 辛苦修改儲存格！直接將公司原有的空白放行表上傳給 AI，用以下白話發送指令，AI 就會自動產出標準佔位符樣板：

```markdown
你是一位精通 Excel 表單架構與 Python openpyxl 自動化的文件工程專家。

我上傳了一份我們公司目前出納正在使用的銀行放行表原始空白表《素材_放行總表.xlsx》。
這張表原本是人工手動填寫的（表頭有固定單號、中間有一列存款餘額、合計是寫死算式、底部是簽核欄位）。

我希望將這份文件改製為「可重複自動化套表的標準 Excel 樣板檔（.xlsx）」，請 AI 自行分析版面：
1. 【辨識固定與動態欄位】：
   - 固定欄位：例如表頭的表單代號替換為純量佔位符（{{FORM_ID}}）、備註欄替換為（{{NOTE}}）。
   - 資料列錨點：在資料輸入列（Row 4）自動填入動態資料欄位錨點（如 {{SEQ}}、{{VOUCHER_NO}}、{{PAY_DATE}}、{{SUMMARY}}、{{INCOME}}、{{UNPAID}}、{{FEE}}、{{TOTAL_PAYABLE}}、{{BALANCE}}、{{BANK_TX_NO}}）。
2. 【合計公式標準化】：合計列的各欄請設為正確的動態 SUM 算式，例如 =SUM(F4:F4)。
3. 【保護簽章區】：最底下的核准、複核、審核、經辦簽核區域必須完整保留其排版位置。

請直接產出一份排版完全零跑版的 Excel 樣板檔案，命名為《樣板_臺企銀單筆付款放行總表.xlsx》供我下載！
```

## 💬 實戰第二步：出納業務審核、風控攔截與動態套表

當取得（或直接使用）AI 產生的樣板檔後，將《素材_應付明細_台幣.xlsx》與《樣板_臺企銀單筆付款放行總表.xlsx》提供給 AI，傳送以下指令：

```markdown
我是公司的出納，每個月底跟 16 號都要彙整應付帳款，製作「銀行付款放行總表」呈送老闆簽核後放行。

附件兩份檔案：
1. 《素材_應付明細_台幣.xlsx》：從 ERP 匯出的應付帳款清單（270 筆）。
2. 《樣板_臺企銀單筆付款放行總表.xlsx》：剛剛由 AI 分析產出的標準樣板（含有 {{PAY_DATE}}、{{FORM_ID}} 與動態資料列錨點 {{SEQ}}、合計列與老闆簽章欄）。

本次請幫我處理指定付款到期日為「2026/09/30」的款項，要求如下：
1. 【依傳票與廠商合併發票】：ERP 匯出的是一張發票一列，但放行表必須依「傳票號碼 + 帳款對象」進行 GroupBy 合併，計算該筆傳票總共包含幾筆發票，並加總本幣應付金額。
2. 【標準化摘要】：摘要欄位請統一格式化為：「應付 [廠商代號]（N筆發票）」，例如「應付 TB0001（5筆發票）」。
3. 【財務風控與大額警示】：
   - 請檢查有無零元、負數或重複發票。
   - 若單筆傳票金額超過 100 萬台幣，請在審核報告中列為「🚨 巨額支付警示」，提醒老闆核決權限！
4. 【雙軌交付機制】：
   - 第一階段：先在畫布（Canvas / 雙欄）產出一份結構化的「出納風控審核報告」，讓我確認筆數與金額。
   - 第二階段：使用 Python openpyxl 依照樣板的 Template Placeholder（佔位符與動態擴展錨點），動態插入資料列、繼承格線字型、更新合計 SUM 公式，並保護最底下的簽核欄位不被覆蓋，產出《出納付款放行總表_已完成.xlsx》。

請先不要寫落落長的套話，直接給我第一階段的風控審核清單；如有任何資料缺漏或疑問，請主動向我確認！
```

## 🎯 本提示詞三大職場防呆亮點

1. **明訂「指定付款日（批次參數）」**：
   徹底解決學生原先 Prompt 將 9/30 誤判為非固定批次異常的矛盾，讓腳本具備處理不同到期日的彈性。
2. **傳票合併發票（GroupBy 邏輯）**：
   點出出納工作最耗時的「多張發票歸戶至同一傳票」的手工痛點。
3. **Template Placeholder 樣板觀念注入**：
   要求 AI 認明樣板佔位符，嚴禁直接暴力硬寫座標，保障 Excel 版面、字型與主管簽章完整性。
