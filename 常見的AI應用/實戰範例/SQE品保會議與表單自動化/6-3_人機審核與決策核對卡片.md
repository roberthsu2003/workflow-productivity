# 步驟 3：範本佔位符（Placeholders）變數映射與工程核對

> 💡 **核心精神**：  
> 在「自訂 Template Placeholder」架構下，AI 產出的是標準 JSON 鍵值對，而不是混亂的未格式化文字。  
> SQE 工程師在此步驟僅需花 30 秒核對 JSON 中的「料號、公差數字、處置判定」是否屬實。  
> 確認無誤後，即可將整包 JSON 送入自動化填充腳本，無痛產出與官方範本 100% 完全對齊的 Word 文件！

## 🛡️ SQE 品質工程師核對檢核表（Checklist）

在進行自動化產檔前，工程師僅需快速檢視以下 4 項品質紅線：
- [x] **料號與管制量**：藍機右殼 `L93XXAR1` 管制數量是否精準為 `13pcs`？（無捏造）
- [x] **公差範圍防呆**：凸輪 `92XX079` 是否明確標註「原 19° ±0.5°，以 19.5°-20° 試作 5pcs 驗證，未直接放寬」？
- [x] **試作製程完整度**：下齒板 `93XXAO2` 試作數量是否為 `80pcs`，並載明走完全製程？
- [x] **負責單位對齊**：待辦事項中之主責處室（品保、資材、二廠加工組、承化）是否權責分明？
