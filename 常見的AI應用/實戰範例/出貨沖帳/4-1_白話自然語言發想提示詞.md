# 步驟一：白話自然語言發想提示詞（最純粹的口語表達）

> 💡 **核心工作流**：**原始 Excel 檔 ➔ 轉為 Markdown 檔 ➔ AI 處理完成 Markdown 檔 ➔ 再轉為完成的 xlsx 檔**！  
> 🗣️ **一般人日常口語**：不需要生硬的提示詞工程術語，直接用日常最直白、簡單的大白話下指令！  
> 🛠️ **適用平台**：ChatGPT 任何對話視窗、Claude、Gemini。

---

## 📋 提示詞複製專區（一般人口語化自然語言）

請直接複製下方這段最簡單、最口語的指令貼給 AI，並附上轉出的 Markdown 資料：

```text
這是我從 Excel 檔（出貨沖帳.xlsx）轉出來的 markdown 表格資料：

任務：結帳單和銷貨單空白的部份，要請 AI 找到相對應品號，取有進貨數的結帳單和銷貨單，一樣的單號，填上；並計算，相同品號如進貨數+退貨數+POS銷貨數量+結清數量=0時，在巳沖完的欄位放上V。如果有什麼不知道的可以詢問我。

以下是我的 markdown 資料：
--------------------------------------------------
[請在此處貼入「出貨沖帳.md」的表格內容]
--------------------------------------------------

請幫我把這個任務轉成「RTCCF 格式」的提示詞。
⚠️ 注意：
1. 請不要太過於複雜（不要長篇大論、不要寫一堆廢話），越簡單直接越好！
2. 讓 AI 先在 Canvas 畫布幫我產出處理完成的 markdown 檔，最後再轉為完成的 xlsx 檔。
```

## 💡 兩大實戰關鍵提醒

1. **口語自然語言＋「不知道的可以問我」**：  
   不必刻意堆砌高深詞彙，一般人口語講清楚「找品號、取單號填上、四欄加總=0放V」即可。加上一句「**有什麼不知道的可以詢問我**」，AI 遇到沒進貨紀錄的品號就不會瞎猜，會主動發問！
2. **提醒 AI「不要太過於複雜」**：  
   許多 AI 聽到 RTCCF 就會開始長篇大論、寫一堆空洞理論。先提醒它「不要太過於複雜」，提煉出來的 Prompt 就會精準聚焦在資料欄位與計算規則上！
