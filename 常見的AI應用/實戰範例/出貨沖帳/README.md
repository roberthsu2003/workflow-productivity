## 🎯 案例情境與兩大核心職場心法

在零售通路與品牌電商營運中，「進銷存月結沖帳」是每個月最耗費財務與生管人員時間的繁複工作。本案例的原始資料來自連鎖超商通路每月的進退貨與銷售結帳月報表，存在兩大常見痛點：
1. **單號斷層**：後續月份有 POS 銷售或零星退貨，但 ERP 系統匯出的結帳單與銷貨單卻呈現空白，導致財務無法勾稽進貨源頭。
2. **多期銷退沖帳累加**：商品進貨為負數（入庫成本負擔），跨多個月份陸續有 POS 銷售（正數）、門市瑕疵退貨（正數）以及合約期滿結清（正數）。要驗算某一品項是否已經「沖帳完畢」，必須跨月份累加四個欄位。

### 💡 職場實戰兩大核心心法

#### 心法一：下 Prompt 時明令「不要太過於複雜」
許多學員在要求 AI「請用 RTCCF 框架產出提示詞」時，AI 常會過度展開，寫出一堆無關的宏觀經濟分析、產業背景或假大空的大道理，反而將「單號補齊」與「數量加總」等核心邏輯埋沒在廢話中。  
👉 **解決方案**：在白話 Prompt 中給予明確的負向約束——「**不要太過於複雜，去除假大空的套話，直接聚焦在欄位比對邏輯、沖帳公式與產出結果**」，產出的 RTCCF 便能精簡俐落、執行力極高！

#### 心法二：善用「有不知道的可以詢問我」（主動提問確認機制）
在真實商業世界中，資料往往不完美（例如本範例中品號 `816466` 與 `816481` 只有銷售卻查無進貨單號）。若沒有特別交代，AI 常常會「發揮想像力通靈瞎猜」，隨意複製隔壁列的單號填入，造成災難性錯帳！  
👉 **解決方案**：在 Prompt 中加上一句——「**如果有什麼不知道或資料矛盾的，請主動向我詢問確認，切勿擅自瞎猜**」。AI 就會化身為嚴謹的專業稽核員，將異常項目條列成清單回報給人類，實現最安全的人機協商核銷閉環！
