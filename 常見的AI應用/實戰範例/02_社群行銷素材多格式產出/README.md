# 範例 02 ｜ 社群行銷素材多格式整合產出

> 🟢 **適用代理平台**：ChatGPT Agent（推薦模式：專案 Projects / Work 成果交付模式）

當行銷團隊完成一場活動拍攝或新產品上市時，同一批素材必須快速轉化為不同平台的內容格式（IG、FB、官網、短影音腳本等）。本範例示範如何透過標準化提示詞，一次產出全套多格式社群素材包。

---

## 🛠️ 建議工具：專案（Projects）或 Work 模式（產內容包）+ 外部排程工具（上架）

- **ChatGPT 做得到的**：依據品牌調性與禁用詞，一次產出全格式文字草稿與分鏡腳本。
- **ChatGPT 做不到的**：❌ **自動發布到 IG / FB 平台**（ChatGPT 無法直接存取社群後台，需搭配人工排程或自動化工具如 Zapier / n8n 發布）。

---

## 📦 素材準備

| 素材 | 說明 | 必要性 | 準備技巧 / 範例 |
|---|---|---|---|
| **品牌調性描述** | 你的語氣是活潑、專業、還是溫暖？舉三個形容詞 | ★ 必備 | 例如：「親切溫暖、直率幽默、略帶生活感」。 |
| **禁用詞清單** | 不能出現的字眼（誇大用語、競品名、法規敏感詞） | ★ 必備 | 如「第一、保證有效、全網最殺」等易踩雷字眼。 |
| **表現好的貼文 3 篇** | 過去成效最好的範例，讓 AI 直接模仿其風格結構 | ★ 必備 | **這是本範例最有價值的素材**，給範例遠勝於抽象形容！ |
| **本次素材清單** | 拍了什麼照片/影片、活動主題、想傳達重點、日期 | ★ 必備 | 提供充足的事實與活動資訊。 |
| **各平台字數限制** | IG、FB、官網文章各自的長度與閱讀習慣 | 建議 | 避免 AI 在 IG 生成數千字長文。 |

---

## 💬 一次到位的多格式產出提示詞

提示詞檔案：[`社群素材多格式產出提示詞.txt`](./社群素材多格式產出提示詞.txt)

```text
以下是這次的素材資訊：
（貼上：拍了什麼、主題、想傳達的重點、活動日期）

請一次產出以下完整的行銷內容包，並請將結果儲存為結構清晰的 Markdown 檔案（.md，可供下載）：
1. IG 貼文文案（含 hashtag，繁體中文，語氣口語生動）
2. FB 貼文文案（比 IG 完整，採故事化敘事風格）
3. 官網文章標題 3 個版本（吸睛型、SEO 關鍵字型、情感共鳴型）
4. 短影音分鏡腳本（15 秒快節奏版、30 秒完整說明版各一版，含畫面描述與口播詞）
5. 封面圖建議標題文字（精簡不超過 12 字）

【語氣設定】（描述你的品牌風格）
【禁用詞清單】（列出絕對不能出現的字詞）
```

---

## 🎯 實戰要點

- **善用 Canvas 逐平台打磨**：生成 Markdown 後，在右側 Canvas 畫布中圈選 IG 文案單獨修潤 Hashtag，或圈選短影音腳本調整秒數，完全不影響其他已經寫好的 FB 與官網文案！
- **「表現好的貼文」是精髓**：與其對 AI 說「請用有質感的文青風」，不如直接貼 3 篇點讚留言最高的歷史貼文給它學習。
