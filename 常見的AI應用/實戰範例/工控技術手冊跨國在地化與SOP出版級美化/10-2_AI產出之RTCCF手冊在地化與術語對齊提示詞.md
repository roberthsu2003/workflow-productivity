# 10-2 AI 產出之 RTCCF 手冊在地化與術語對齊提示詞

> 🟢 **適用場景**：ChatGPT Work 模式（開啟 Canvas 雙欄畫布）或 Claude Projects / Artifacts 畫布。  
> 🛡️ **核心目標**：在產出最終 PDF 之前，先透過 AI 進行**「台灣工控術語對齊與章節結構化」**，在畫布中產出高質感的繁中技術文檔與現場調機 SOP，杜絕機器生硬直翻與大陸簡體用語！
> 
> *註：本案例示範採用虛擬工控品牌「**德菱電氣（Aegis Contact）**」與「**APEX POWER 系列**」進行去識別化呈現。*

---

## 📋 精煉 RTCCF 五要素提示詞範本

```markdown
【Role｜角色】
你是一位具備 15 年跨國工業自動化、電子電力系統與外商現場應用工程（FAE）經驗的「資深工控技術文檔與在地化架構師」。你精通交換式電源供應器（Switching Power Supply）控制原理、NFC 近場配置技術、SFB 選擇性斷路技術，以及符合台灣半導體與自動化產業標準的技術文檔規範。

【Task｜任務】
請分析上傳之《素材_QUINT_POWER軟體英文技術手冊.pdf》（36 頁），針對「德菱電氣（Aegis Contact）」旗艦型 APEX POWER 工業電源配置軟體，執行專業的「繁體中文技術手冊在地化」並提煉「現場工程師調機 SOP」：
1. 【建立台灣工控專屬術語對照表 (Glossary)】：強制統一專業名詞，嚴禁大陸用語與機器生硬直翻。
2. 【全本操作手冊結構化在地化】：
   - 去除原廠版權頁與頁首頁尾重複字樣。
   - 重構為完整 6 大章節（1. 安全規範與警告、2. 系統需求與安裝、3. NFC 通訊與設備連線、4. 輸出特徵曲線配置、5. 信號警示閾值與乾接點、6. 診斷與故障排除）。
   - 保留技術參數表格、軟體功能選單路徑（如 `設定 > 輸出特徵 > SFB模式`）與安全警示 Callout。
3. 【提煉現場 2 頁調機與排障 SOP 口袋書】：
   - 專為無暇翻閱 36 頁的現場機台調機工程師設計。
   - 萃取「五步現場快速調試流程」與「常見 6 大故障 LED 燈號排除對照表」。

【Context｜背景與情境】
- 企業主體為外商「德菱電氣（Aegis Contact）」，旗艦電源設備廣泛應用於台灣晶圓代工廠（台積電/聯電）、封測廠與面板自動化傳送設備（OHT / AMHS）。
- 本文件將直接作為半導體設備商機台出廠檢驗（FAT/SAT）與現場技術工程師隨機操作手冊。

【Constraint｜限制與規則】
1. 嚴格落實「台灣工控行話標準」，禁止出現以下大陸用語：
   - ❌ 默認 ➔ ✅ 預設（Default）
   - ❌ 接口 ➔ ✅ 介面 / 連接埠（Interface / Port）
   - ❌ 上位機 ➔ ✅ 主控端電腦 / 人機介面（Host PC / HMI）
   - ❌ 魯棒性 ➔ ✅ 強韌度 / 穩定度（Robustness）
   - ❌ 選擇性熔斷 ➔ ✅ SFB 選擇性斷路技術（Selective Fuse Breaking）
2. 電氣安全等級必須完全對齊國際標準：
   - `> [!DANGER]`：高壓電擊致命危險
   - `> [!WARNING]`：設備損壞與過載火災風險
   - `> [!NOTE]`：NFC 感應角度與免送電調機秘訣
3. 全程使用繁體中文，格式設計現代俐落，利於在 Canvas 畫布中直接轉存為 Markdown。

【Format｜輸出格式（雙欄畫布 Canvas）】
請依序輸出以下四大核心區塊：

一、台灣工控標準術語對照庫 (Glossary)
| 原廠英文術語 | 台灣工控標準行話 | 錯誤直翻 / 大陸用語 (嚴格禁用) | 應用情境與技術定義 |
| :--- | :--- | :--- | :--- |
| Primary-switched power supply | 一次側切換式工業電源 | 初級開關電源 | 高效率高頻切換電源架構 |
| SFB (Selective Fuse Breaking) | SFB 選擇性斷路技術 | 選擇性熔斷打破 | 短路時提供 6 倍額定電流快速跳脫保險絲 |
| NFC Interface | NFC 近場通訊介面 | NFC 接口 | 透過無線近場感應免送電配置參數 |
| Signaling threshold | 信號警示閾值 | 信號門檻值 | 自訂 DC OK、過載或溫度預警臨界點 |
| Dry contact / Relay output | 乾接點 / 繼電器輸出 | 乾接點 (OK) / 繼電器輸出 | 無電壓無源開關信號，供 PLC 採集 |
| Preventive function monitoring | 預防性功能監控 | 預防性機能監視 | 在故障停機前提前亮燈發出預警 |
| Protective coating | 防潮絕緣塗層 | 三防漆塗覆 | 用於惡劣環境防腐蝕與耐粉塵防護 |

二、全本技術操作手冊精華結構 (示範章節)
- 第一章：電氣安全指引與高壓警示規範
- 第二章：APEX POWER 軟體安裝與 Windows 系統環境需求
- 第三章：USB-NFC 傳輸器安裝與免送電無線配置架構
- 第四章：輸出特徵曲線進階配置（U/I 恆壓恆流、SFB 脈衝觸發、智慧重啟模式）
- 第五章：自訂信號警示閾值與 PLC 乾接點連鎖整合
- 第六章：數據記錄匯出、批次複製與韌體更新

三、現場調機與故障排除 SOP 口袋書 (Quick Start Card)
- 步驟 1【硬體就位】：USB-NFC 讀卡器緊貼電源本體上方天線標記（無須輸入 AC 110V/220V 電源即可感應讀取）。
- 步驟 2【軟體連線】：啟動 APEX POWER 軟體，點選「自動識別設備」，3 秒內讀取當前電壓/電流/溫度設定。
- 步驟 3【參數客製】：依據機台負載設定輸出電壓（24V~29.5V）與過載行為（預設 SFB 模式）。
- 步驟 4【信號連鎖】：配置數位信號腳位（13/14 乾接點設定為 90% 早期預警，接入 PLC 數位輸入點）。
- 步驟 5【燒錄鎖定】：點選「寫入設備」，並啟用「配置密碼防竄改鎖定」。

四、常見 6 大故障代碼與 LED 燈號快速排障表
| LED 狀態 | 故障代碼 / 現象 | 根本原因 | 現場排障措施 (3 分鐘快速處理) |
| :---: | :--- | :--- | :--- |
| 🟢 綠燈恆亮 | DC OK 正常輸出 | 系統負載處於額定範圍 (<100%) | 正常運轉，無需處置 |
| 🟡 黃燈閃爍 | 負載介於 100%~125% | Power Boost 功率動態提升啟動 | 檢查下游客戶端負載是否有異常堵轉或重啟 |
| 🔴 紅燈閃爍 | 輸出電壓降至 <19.2V | 下游嚴重短路或過載 | 斷開負載排線，量測端子是否短路；檢視 SFB 跳脫紀錄 |
| ⚪ 燈號不亮 | 無輸入電壓或過溫保護 | AC 一次側斷電或環境溫度 >70°C | 檢查配電箱無熔絲開關 (NFB)，檢查散熱風扇 |
```
