# 提示詞 10-3：生成出版級美化 PDF 發布檔提示詞 (Python + Markdown/HTML 渲染引擎)

> **使用時機**：當你已經透過 AI 將外文技術文件翻譯為繁體中文 Markdown（如 `APEX_POWER電源配置軟體_繁體中文操作手冊_已完成.md`）或提煉為現場 SOP 口袋書（如 `APEX_POWER現場調試與故障排除SOP口袋書_已完成.md`）後，若直接列印或交給客戶，純 Markdown 排版過於簡陋。本提示詞引導 AI 撰寫自動化排版與轉換腳本，套用企業級出版樣式（包含封面、高質感雙色調配色、頁首頁尾、頁碼、表格交錯底色及電氣安全 Warning/Caution 呼叫方塊），自動呼叫 Headless Chrome 引擎一鍵編譯成高解析度出版級 PDF。

---

## 複製給 AI 的提示詞（Prompt）

```markdown
你是一位具備 15 年技術文件出版（Technical Documentation Publishing）與前端列印樣式（CSS Paged Media）經驗的專家。現在我們有一份完成專業工控術語繁體在地化的技術文件（Markdown 格式），我們需要將其自動轉換為符合工業標準、具備高質感企業形象的出版級 A4 PDF 文件。

請為我設計並執行一個 Python 自動化轉換流程腳本，具體設計規範如下：

### 一、排版與視覺樣式規範（CSS Print Media Specification）
1. **版面尺寸與邊距**：
   - 標準 A4 尺寸（`size: A4 portrait;`），標準裝訂邊距（上下 18mm，左右 20mm）。
2. **字體與排版節奏**：
   - 內文字體優先採用台灣常用之清晰黑體（微軟正黑體 'Microsoft JhengHei', PingFang TC, 'Noto Sans TC', sans-serif），程式碼與接點代號採用等寬字體（'Fira Code', 'Consolas', monospace）。
   - 行距設為 1.65，字距微調增加閱讀舒適感。
3. **色彩系統（德菱電氣工控專業風格）**：
   - 主色調（Primary）：深邃電氣藍 `#0F2C59`（用於一級大標題、表格首列、頁首外框線）。
   - 輔助色（Secondary / Accent）：科技青 `#008080` 與 工控橘金 `#D97706`（用於二級標題、提示重點）。
   - 內文深灰：`#2D3748`；背景白：`#FFFFFF`。
4. **特殊呼叫方塊（Callout Boxes）**：
   - 針對 Markdown 中的 `> [!CAUTION]`、`> [!WARNING]`、`> [!IMPORTANT]`、`> [!TIP]` 進行專屬 CSS 樣式轉換：
     - **CAUTION**：深紅邊框與淺粉紅背景，標記感電致命危險。
     - **WARNING**：鮮橙邊框與淡黃橘背景，標記高溫燙傷與電氣過載。
     - **IMPORTANT**：深藍色邊框與淡藍灰背景，標記資格與規範。
     - **TIP**：翠綠邊框與淡綠背景，標記現場除錯密技與快捷流程。
5. **表格與程式碼區塊**：
   - 表格首行深藍底色白字，列與列之間加入斑馬紋淺灰交錯底色（`nth-child(even)`），外框與隔線簡潔洗鍊。
   - 程式碼或 ASCII 原理圖採用深色主題（`#1E293B`）或淺灰精緻卡片包覆，保留等寬字距且防止斷行跑版。
6. **分頁控制（Page Break Rules）**：
   - `h1` 與主要章節必須自動強制換頁（`page-break-before: always;`）。
   - 避免標題與下方內容孤行隔開（`break-after: avoid;`）。
   - 表格列內部不可被截斷換頁（`page-break-inside: avoid;`）。

### 二、轉換技術架構（Zero-Dependency Headless Engine）
- 請使用 Python 的標準生態系（例如 `markdown` 套件或正則解析）將 Markdown 解析為標準 HTML。
- 注入上述自訂 CSS `<style>` 樣式後，自動呼叫本機之 Google Chrome / Chromium 的 Headless 列印指令：
  `chrome --headless --disable-gpu --print-to-pdf=<輸出檔案.pdf> <暫存檔案.html>`
- 產出完成後，自動清理中間暫存之 HTML 檔，僅保留最終美化 PDF。

請提供可立即在終端機或 Python 環境中執行的腳本程式碼。
```

## 搭配使用的自動化轉換腳本（Python Implementation）

以下腳本已封裝完整的 CSS 排版樣式與 Headless Chrome 驅動邏輯，可直接將目錄下的 Markdown 手冊轉換為出版級 PDF：

```python
import os
import subprocess
import markdown

def convert_md_to_styled_pdf(md_file_path, output_pdf_path):
    with open(md_file_path, "r", encoding="utf-8") as f:
        md_text = f.read()

    # 1. 處理 GitHub Alert Callouts 轉換為標準 HTML 樣式 class
    md_text = md_text.replace("> [!CAUTION]", '<div class="alert alert-caution"><div class="alert-title">⚠️ 嚴正注意 / CAUTION</div>')
    md_text = md_text.replace("> [!WARNING]", '<div class="alert alert-warning"><div class="alert-title">⚡ 警示警告 / WARNING</div>')
    md_text = md_text.replace("> [!IMPORTANT]", '<div class="alert alert-important"><div class="alert-title">📌 重要規範 / IMPORTANT</div>')
    md_text = md_text.replace("> [!TIP]", '<div class="alert alert-tip"><div class="alert-title">💡 現場秘訣 / PRO TIP</div>')

    # 2. Markdown 轉 HTML
    html_body = markdown.markdown(md_text, extensions=['tables', 'fenced_code', 'nl2br'])

    # 3. 注入工業出版級 CSS 樣式
    css_style = """
    @page {
        size: A4 portrait;
        margin: 18mm 18mm 20mm 18mm;
        @bottom-right {
            content: "第 " counter(page) " 頁";
            font-size: 9pt;
            color: #718096;
        }
    }
    body {
        font-family: -apple-system, BlinkMacSystemFont, "Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif;
        color: #2D3748;
        line-height: 1.65;
        font-size: 10.5pt;
        background-color: #FFFFFF;
    }
    h1 {
        color: #0F2C59;
        font-size: 20pt;
        border-bottom: 2.5px solid #0F2C59;
        padding-bottom: 6px;
        margin-top: 24px;
        margin-bottom: 14px;
        page-break-before: always;
    }
    body > h1:first-of-type {
        page-break-before: avoid;
    }
    h2 {
        color: #1A365D;
        font-size: 14pt;
        border-left: 4px solid #008080;
        padding-left: 8px;
        margin-top: 18px;
        margin-bottom: 10px;
        break-after: avoid;
    }
    h3 {
        color: #2C5282;
        font-size: 12pt;
        margin-top: 14px;
        margin-bottom: 6px;
        break-after: avoid;
    }
    table {
        width: 100%;
        border-collapse: collapse;
        margin: 14px 0;
        font-size: 9.5pt;
        page-break-inside: avoid;
    }
    th {
        background-color: #0F2C59;
        color: #FFFFFF;
        font-weight: 600;
        text-align: left;
        padding: 8px 10px;
        border: 1px solid #0F2C59;
    }
    td {
        padding: 7px 10px;
        border: 1px solid #CBD5E0;
    }
    tr:nth-child(even) td {
        background-color: #F7FAFC;
    }
    pre {
        background-color: #1E293B;
        color: #E2E8F0;
        padding: 12px;
        border-radius: 6px;
        font-family: "Fira Code", Consolas, monospace;
        font-size: 9pt;
        overflow-x: auto;
        page-break-inside: avoid;
    }
    code {
        font-family: "Fira Code", Consolas, monospace;
        background-color: #EDF2F7;
        color: #C53030;
        padding: 2px 4px;
        border-radius: 4px;
        font-size: 9.5pt;
    }
    pre code {
        background-color: transparent;
        color: inherit;
        padding: 0;
    }
    .alert {
        padding: 10px 14px;
        margin: 12px 0;
        border-radius: 6px;
        border-left: 5px solid;
        page-break-inside: avoid;
    }
    .alert-title {
        font-weight: bold;
        font-size: 10.5pt;
        margin-bottom: 4px;
    }
    .alert-caution {
        background-color: #FFF5F5;
        border-color: #E53E3E;
        color: #9B2C2C;
    }
    .alert-warning {
        background-color: #FFFAF0;
        border-color: #DD6B20;
        color: #9C4221;
    }
    .alert-important {
        background-color: #EBF8FF;
        border-color: #3182CE;
        color: #2B6CB0;
    }
    .alert-tip {
        background-color: #F0FFF4;
        border-color: #38A169;
        color: #276749;
    }
    blockquote {
        margin: 8px 0;
        padding-left: 12px;
        border-left: 3px solid #CBD5E0;
        color: #4A5568;
    }
    """

    full_html = f"""<!DOCTYPE html>
    <html lang="zh-TW">
    <head>
        <meta charset="UTF-8">
        <title>Technical Documentation</title>
        <style>{css_style}</style>
    </head>
    <body>
        {html_body}
    </body>
    </html>"""

    temp_html_path = md_file_path.replace(".md", "_temp.html")
    with open(temp_html_path, "w", encoding="utf-8") as f:
        f.write(full_html)

    # 4. 呼叫 Headless Chrome 進行向量 PDF 渲染
    chrome_path = "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
    cmd = [
        chrome_path,
        "--headless",
        "--disable-gpu",
        f"--print-to-pdf={output_pdf_path}",
        temp_html_path
    ]
    subprocess.run(cmd, check=True)
    if os.path.exists(temp_html_path):
        os.remove(temp_html_path)

if __name__ == "__main__":
    convert_md_to_styled_pdf("APEX_POWER電源配置軟體_繁體中文操作手冊_已完成.md", "APEX_POWER電源配置軟體_繁體中文操作手冊_已完成.pdf")
    convert_md_to_styled_pdf("APEX_POWER現場調試與故障排除SOP口袋書_已完成.md", "APEX_POWER現場調試與故障排除SOP口袋書_已完成.pdf")
```
