## 🛠️ 兩種排版重製架構比較

| 方案 | 適用情境 | 核心原理 | 優點 |
| :--- | :--- | :--- | :--- |
| **方案 A：原版面文字置換重製**<br/>*(PyMuPDF / pdfplumber)* | 原廠版面極為複雜、包含多層次向量線圖、需 1:1 像素級還原原手冊 | 以原 PDF 為畫布，擦除英文文字圖層，將最新修訂繁中文字依照座標放回原版面區域 | 100% 保留原始點陣圖與向量圖，完全不破壞原始版面結構 |
| **方案 B：語意化出版級渲染**<br/>*(CSS Print Media ＋ Headless Chrome)* | 需重新編排高質感企業手冊、雙軌提煉現場 2 頁 SOP 口袋書、加入自訂封面目錄 | 將修訂後 Markdown 轉為 HTML，套用工業深海藍企業出版 CSS 樣式，呼叫無頭 Chrome 向量列印 | 具備自動頁碼、章節強制分頁、GitHub Alert 安全框（CAUTION/WARNING）、表格斑馬紋 |

## 📋 方案 A：原版面 1:1 置換重製提示詞（PyMuPDF 向量置換引擎）

若要求 100% 保留原手冊的排版與插圖，可使用以下提示詞引導 AI 撰寫 Python 重製腳本：

```markdown
你是一位具備 15 年 PDF 內部物件架構（PDF DOM & Content Streams）與 PyMuPDF (fitz) 開發經驗的專家。
請依據我們在階段二完成修訂的《APEX_POWER_全書_原文與繁中翻譯.md》與原始手冊《素材_QUINT_POWER軟體英文技術手冊.pdf》，撰寫一個高精度的 PDF 原版面文字置換腳本：

1. 核心要求：
   - 讀取原始 PDF，保留所有原始點陣圖片（Images）、向量路徑（Paths）與幾何網格。
   - 依據 Markdown 內各頁的最新繁體中文文字，比對原始文字區塊（BBoxes），以乾淨背景色覆蓋原英文字串。
   - 使用開源繁體中文字型（如思源黑體 Noto Sans TC），在對應座標寫入中文，文字必須支援文字選取（Selectable）與全文檢索（Searchable）。
   - 若中文長度超過原始區塊，自動啟用字級微調（Font Scale Down 85%~100%）與行距調整，禁止產生重疊或跑出頁面。
```

## 📋 方案 B：語意化企業出版級渲染提示詞（CSS Print Media ＋ Chrome）

若要輸出全新企業品牌視覺（如德菱電氣深海藍風格），或排版 2 頁現場 SOP 口袋書，使用以下提示詞與腳本：

```markdown
你是一位具備 15 年技術文件出版（Technical Documentation Publishing）與前端列印樣式（CSS Paged Media）經驗的專家。現在我們有一份完成專業工控術語繁體在地化的技術文件（Markdown 格式），我們需要將其自動轉換為符合工業標準、具備高質感企業形象的出版級 A4 PDF 文件。

請為我設計並執行一個 Python 自動化轉換流程腳本，具體設計規範如下：

### 一、排版與視覺樣式規範（CSS Print Media Specification）
1. 版面尺寸與邊距：標準 A4 尺寸（size: A4 portrait;），標準裝訂邊距（上下 18mm，左右 20mm）。
2. 色彩系統：深邃電氣藍 #0F2C59（一級標題、表格首列）、科技青 #008080（二級標題）、工控橘金 #D97706（警示重點）。
3. 特殊呼叫方塊（Callout Boxes）：針對 > [!CAUTION]（感電危險）、> [!WARNING]（高溫過載）、> [!IMPORTANT]（安裝資格）、> [!TIP]（除錯秘訣）轉換專屬工業風格邊框。
4. 表格與程式碼：首行深藍底白字、交錯斑馬紋、防止表格行內截斷換頁（page-break-inside: avoid;）。
5. 分頁控制：h1 強制換頁（page-break-before: always;）、標題避免孤行（break-after: avoid;）。

### 二、轉換技術架構（Headless Chrome 引擎）
- 使用 Python 將 Markdown 解析為 HTML，注入 CSS 後呼叫 Chrome：
  `chrome --headless --disable-gpu --print-to-pdf=<輸出.pdf> <暫存.html>`
```

## 💻 方案 B 完整可執行 Python 腳本（含完整 CSS 樣式庫）

```python
import os
import subprocess
import markdown

def convert_md_to_styled_pdf(md_file_path, output_pdf_path):
    if not os.path.exists(md_file_path):
        print(f"❌ 找不到來源 Markdown 檔案: {md_file_path}")
        return

    with open(md_file_path, "r", encoding="utf-8") as f:
        md_text = f.read()

    # 1. 處理 GitHub Alert Callouts
    md_text = md_text.replace("> [!CAUTION]", '<div class="alert alert-caution"><div class="alert-title">⚠️ 嚴正注意 / CAUTION (感電致命危險)</div>')
    md_text = md_text.replace("> [!WARNING]", '<div class="alert alert-warning"><div class="alert-title">⚡ 警示警告 / WARNING (高溫過載)</div>')
    md_text = md_text.replace("> [!IMPORTANT]", '<div class="alert alert-important"><div class="alert-title">📌 重要規範 / IMPORTANT (安裝資格)</div>')
    md_text = md_text.replace("> [!TIP]", '<div class="alert alert-tip"><div class="alert-title">💡 現場秘訣 / PRO TIP (調機快捷)</div>')

    # 2. Markdown 轉 HTML
    html_body = markdown.markdown(md_text, extensions=['tables', 'fenced_code', 'nl2br'])

    # 3. 工業出版級 CSS
    css_style = """
    @page {
        size: A4 portrait;
        margin: 18mm 18mm 20mm 18mm;
        @bottom-right {
            content: "第 " counter(page) " 頁";
            font-size: 9pt;
            color: #718096;
        }
    }
    body {
        font-family: -apple-system, BlinkMacSystemFont, "Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif;
        color: #2D3748;
        line-height: 1.65;
        font-size: 10pt;
        background-color: #FFFFFF;
    }
    h1 {
        color: #0F2C59;
        font-size: 18pt;
        border-bottom: 2.5px solid #0F2C59;
        padding-bottom: 6px;
        margin-top: 24px;
        margin-bottom: 12px;
        page-break-before: always;
    }
    body > h1:first-of-type {
        page-break-before: avoid;
    }
    h2 {
        color: #1A365D;
        font-size: 13pt;
        border-left: 4px solid #008080;
        padding-left: 8px;
        margin-top: 16px;
        margin-bottom: 8px;
        break-after: avoid;
    }
    table {
        width: 100%;
        border-collapse: collapse;
        margin: 12px 0;
        font-size: 9pt;
        page-break-inside: avoid;
    }
    th {
        background-color: #0F2C59;
        color: #FFFFFF;
        font-weight: 600;
        text-align: left;
        padding: 7px 10px;
        border: 1px solid #0F2C59;
    }
    td {
        padding: 6px 10px;
        border: 1px solid #CBD5E0;
    }
    tr:nth-child(even) td {
        background-color: #F7FAFC;
    }
    .alert {
        border-radius: 4px;
        padding: 10px 14px;
        margin: 12px 0;
        font-size: 9.5pt;
    }
    .alert-caution { background-color: #FFF5F5; border-left: 5px solid #E53E3E; }
    .alert-warning { background-color: #FFFAF0; border-left: 5px solid #DD6B20; }
    .alert-important { background-color: #EBF8FF; border-left: 5px solid #3182CE; }
    .alert-tip { background-color: #F0FFF4; border-left: 5px solid #38A169; }
    .alert-title { font-weight: bold; margin-bottom: 4px; }
    """

    full_html = f"""<!DOCTYPE html>
<html lang="zh-TW">
<head>
<meta charset="utf-8">
<title>工業技術手冊出版預覽</title>
<style>{css_style}</style>
</head>
<body>
{html_body}
</body>
</html>"""

    temp_html_path = output_pdf_path.replace(".pdf", "_temp.html")
    with open(temp_html_path, "w", encoding="utf-8") as f:
        f.write(full_html)

    # 4. 尋找系統 Chrome 執行檔
    chrome_paths = [
        "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
        "/usr/bin/google-chrome",
        "/usr/bin/chromium",
        "chrome"
    ]
    chrome_cmd = next((p for p in chrome_paths if os.path.exists(p)), "google-chrome")

    cmd = [
        chrome_cmd,
        "--headless",
        "--disable-gpu",
        "--no-pdf-header-footer",
        f"--print-to-pdf={output_pdf_path}",
        temp_html_path
    ]

    try:
        subprocess.run(cmd, check=True)
        print(f"✅ 成功生成出版級 PDF: {output_pdf_path}")
        if os.path.exists(temp_html_path):
            os.remove(temp_html_path)
    except Exception as e:
        print(f"⚠️ PDF 轉換過程發生問題: {e}")

if __name__ == "__main__":
    # 範例執行
    convert_md_to_styled_pdf(
        "APEX_POWER電源配置軟體_繁體中文操作手冊_已完成.md",
        "APEX_POWER電源配置軟體_繁體中文操作手冊_已完成.pdf"
    )
```
