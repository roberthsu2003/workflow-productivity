## 🎯 為什麼資訊圖表要採用「HTML/CSS 網頁渲染 ➔ 截圖」？

### ❌ 傳統生圖模型（DALL-E / Midjourney）的致命傷：
1. **中文字體崩潰**：中文會變成外星亂碼或扭曲符號。
2. **數據通靈造假**：長條圖長度與折線趨勢完全無法與 Excel 真實數字對齊。
3. **無法商業落地**：一張數字胡謅的圖，無法呈報給總經理。

### ✅ 現代 HTML/CSS 截圖黑科技的巨大優勢：
1. **結構 100% 精準對齊**：網頁的 Flexbox 與 Grid 佈局是全世界最穩健的排版工具，卡片圓角、陰影、邊界永遠整齊。
2. **數據 100% 真實可靠**：文字與圖表是由 Python 讀取真實 Excel 算出來後動態填入，完全不通靈。
3. **文字極致清晰**：瀏覽器截圖產出的是 1920×1080 高清向量渲染圖，文字邊緣銳利不模糊。
4. **手機推播體驗第一名**：產出的 PNG 圖片可直接貼在 LINE、微信、Slack 或 Email 中，主管手機點開即秒懂！

## 📋 實戰步驟指引

### 1. 步驟 1：白話自然語言發想提示詞（生成可儲存之 RTCCF 規格）
* 文件連結：[**`9-1_白話自然語言發想提示詞.md`**](./9-1_白話自然語言發想提示詞.md)
* 核心操作：學員只要上傳 5 份素材（2 個 Excel 數據檔 ＋ 3 張參考截圖），以日常生活最自然的大白話說明製作 3 張圖的需求，並指定「先產 Markdown 確認數據，確認後才截圖」的兩階段機制，引導 AI 轉化生成一份標準且可獨立儲存的 RTCCF 提示詞規格檔。

### 2. 步驟 2：AI 產出之 RTCCF 戰情資訊圖表提示詞（人機協作與執行）
* 文件連結：[**`9-2_AI產出之RTCCF戰情資訊圖表提示詞.md`**](./9-2_AI產出之RTCCF戰情資訊圖表提示詞.md)
* 核心技術：展示 AI 產出的標準 RTCCF 提示詞。學員可進行人機協作微調，修改後整段餵給 AI。AI 第一階段先產出 Markdown 數據檢核表讓人類確認數據，確認無誤後第二階段才以 HTML/CSS 渲染並透過無頭瀏覽器自動拍下 3 張 1920×1080 高清戰情圖！

### 3. 【人機協作專用】可獨立儲存之 RTCCF 提示詞規格檔
* 文件連結：[**`RTCCF_飯店訂房戰情資訊圖表提示詞.md`**](./RTCCF_飯店訂房戰情資訊圖表提示詞.md)
* 核心用途：純淨標準的 RTCCF Markdown 檔案，方便學員直接下載保存於本地、以文字編輯器隨時修改調整，修改後直接全選複製貼入 AI 對話視窗執行！
