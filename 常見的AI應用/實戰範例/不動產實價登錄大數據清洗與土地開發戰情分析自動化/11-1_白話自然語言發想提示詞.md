# 提示詞 11-1：白話自然語言發想提示詞 (土地開發大數據分析與指標工程)

> **使用時機**：當你或不動產業務/估價助理從內政部實價登錄下載了 1,700 多筆土地交易原始 Excel，面對雜亂的代碼、全筆/持分混雜的數字、以及無法直觀看出實質買賣坪數時。透過這段白話提示詞，引導 AI 釐清資料結構、定義「實質移轉坪數」計算公式，並規劃出符合土地開發部主管與投資人需求的戰情分析架構。

---

## 複製給 AI 的提示詞（Prompt）

```markdown
你好，我是不動產開發投資顧問公司的專案經理。我們剛從內政部地政司「不動產實價登錄開放資料」下載了新北市最新一期的土地交易 Excel 清冊（共 1,772 筆資料）。

目前這份原始 Excel 存在幾個讓土地開發團隊很頭痛的問題：
1. **面積與持分混雜，無法一眼看出實際買賣坪數**：
   資料中只有「土地移轉面積平方公尺（全基地）」和「權利人持分分母 / 分子」（例如基地 5,000 平方公尺，持分 100000 分之 255）。一般同仁根本看不出來這筆交易到底買了「幾坪」土地！
2. **大建商獵地 vs 散戶買屋分不清**：
   裡面有 93% 是集合住宅或預售屋的「持分移轉」（土地只有 1~3 坪），但也有 7% 是大建商或地主「全筆移轉」數百坪的大宗收購。兩種混在一起，完全無法評估各重劃區的真正土地整合熱度。
3. **都市使用分區名稱太雜**：
   欄位寫著「都市：其他:住宅區」、「都市：其他:商業區」、「都市：其他:道路用地」、「非都市：山坡地保育區...」，沒有經過分類整理。
4. **缺少「容積移轉 / 公保地」情報**：
   我們很想知道哪些熱門重劃區有投資客或建商在收購「道路用地」或「公共設施保留地」作為未來推案的容積移轉籌碼，但原始資料完全沒有標註。

請你擔任資深土地開發分析師與 Python 大數據工程專家，幫我規劃一個自動化分析流程：
1. 告訴我需要透過公式清洗出哪些核心欄位（例如：持分比例、實質移轉平方公尺、實質移轉坪數、交易型態標籤）。
2. 將交易分為三大類型：
   - 【建商大宗獵地】（全筆移轉且實質坪數 >= 30 坪）
   - 【公共設施/容積籌碼】（道路用地、機關用地、公園用地）
   - 【集合住宅持分】（微型持分買賣）
3. 規劃一個高質感的 Excel 戰情工作表，包含：
   - 頂部 4 大核心 KPI 統計卡（總移轉坪數、大宗獵地筆數、公保地筆數、持分交易筆數）。
   - 重劃區/地段交易熱度排行榜（依交易坪數與筆數排序）。
   - 土地使用分區面積分佈佔比。
   - 大宗獵地與容積用地精選清單（附上地段、地號、實質坪數、使用分區）。
4. 整理成清楚的產出規範，稍後我會請你產出完整的 Python 自動化腳本與專業報表。
```
