# 步驟三：生成多通路社群圖片尺寸提示詞（Python 自動化裁切）

> 💡 **教學情境**：在跨平台社群行銷中，企劃手邊通常只有攝影師提供的單一尺寸宣傳照（如 1:1 方形或單一橫圖）。但發布至 **Instagram、Facebook、官方網站** 時，若未依照各平台官方規範裁切，圖片將面臨被系統粗暴拉伸、關鍵主體被裁切或兩側出現黑邊的窘境。  
> 🛠️ **適用平台**：ChatGPT（具備 Python 程式碼執行能力之對話視窗）或任何支援 Python 執行之 AI Agent 平台。

---

## 📐 社群主流平台官方圖片規格標準

| 平台通路 | 應用版位 | 標準比例 | 建議解析度 (px) | 裁切與排版規範重點 |
| :--- | :--- | :---: | :---: | :--- |
| **Instagram** | 經典動態貼文 (Post) | **1:1** | `1080 × 1080` | 方形等比取樣，確保手機九宮格預覽完整。 |
| **Instagram / FB** | 限時動態 & Reels / Shorts | **9:16** | `1080 × 1920` | 直式全螢幕，主視覺置中，上下背景採微光高斯模糊擴展。 |
| **Facebook** | 橫向動態貼文 / 連結分享 | **1.91:1** | `1200 × 630` | 橫向構圖，主視覺偏中心對齊，防止手機縮圖被截斷。 |
| **官方網站** | 首頁 Hero Banner / 專欄封面 | **16:9** | `1920 × 1080` | 寬螢幕高清適配，留出空間供網頁文字標題排版。 |

```markdown
## Role
你是一位精通跨通路社群視覺設計與 Python 影像自動化處理（Pillow / OpenCV）的專家。

## Task
我已經上傳了一張新產品的宣傳情境原圖（`新品上市宣傳圖.jpg`）。請撰寫並執行 Python 程式碼，將此來源照片自動進行高品質重採樣與智慧構圖適配，一次性生成符合 Instagram、Facebook、官網 3 大通路官方標準規格的 4 款圖片，並在回覆中提供各圖片的直接下載連結：

1. **Instagram 貼文專用圖（1:1 正方形）**：
   - 檔名：`新品上市宣傳圖_IG貼文_1080x1080.jpg`
   - 解析度：`1080 × 1080 px`
   - 處理方式：等比重採樣（LANCZOS 高品質濾鏡），確保陶杯拉花與木匙茶葉細節清晰。

2. **Facebook 橫向貼文 / 連結分享專用圖（1.91:1 橫式）**：
   - 檔名：`新品上市宣傳圖_FB貼文_1200x630.jpg`
   - 解析度：`1200 × 630 px`
   - 處理方式：將寬度等比適配至 1200px，垂直以主體為核心置中智慧裁切，確保拉花陶杯與木匙茶葉落在視覺黃金區域。

3. **官方網站文章封面 / Hero Banner（16:9 寬螢幕）**：
   - 檔名：`新品上市宣傳圖_官網Banner_1920x1080.jpg`
   - 解析度：`1920 × 1080 px`
   - 處理方式：寬螢幕高解析度適配（1920px 寬），垂直對齊主體中心裁切。

4. **Instagram 限動 / Reels / Shorts 滿版專用圖（9:16 直式）**：
   - 檔名：`新品上市宣傳圖_IG限動Reels_1080x1920.jpg`
   - 解析度：`1080 × 1920 px`
   - 處理方式：滿版直式構圖（9:16），完整呈現陶杯拉花、木匙焙茶與窗邊晨光氛圍，無黑邊、無拼接感，呈現社群頂級微光氛圍感。

請直接執行程式碼產出上述 4 張圖片，並提供下載連結！
```

1. **傳統行銷痛點**：以往企劃必須打開 Photoshop 手動拉參考線裁切 4 次，容易出錯且浪費 30 分鐘以上。
2. **AI 影像自動化優勢**：透過 ChatGPT 內建的 Python 環境，只需一句話即可在 5 秒內精確輸出所有平台標準規格，並自動處理好 9:16 直式的上下氛圍延伸，真正達到「產出即發布」的職場即戰力！
