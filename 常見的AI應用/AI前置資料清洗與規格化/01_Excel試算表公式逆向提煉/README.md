# 實戰 01：Excel 試算表公式逆向提煉為「RTCCF 規格檔」

> 💡 **核心教學工作流（極簡白話 ➔ AI產出規格 ➔ 人工審核 ➔ 正式執行）**：  
> **1. 學生只講一句大白話 ➔ 2. AI 自動幫學生寫出 RTCCF.md ➔ 3. 🔍 學生當審查官檢查修改 ➔ 4. 以確認後的 RTCCF.md 當作 Prompt 正式上工**

---

## 📂 實作素材清單
1. [**`範例_業務報價與業績提成表.xlsx`**](./範例_業務報價與業績提成表.xlsx)：包含 2 張工作表、跨表參照公式（`=產品報價表!E2*D2`）與提成階梯邏輯。
2. [**`參考成果_業務報價與業績提成表_規格檔.md`**](./參考成果_業務報價與業績提成表_規格檔.md)：標準規格檔完成範本，供學員對照觀摩。

---

## 🛠️ 第一階段：學生發送大白話 Prompt（不要自己寫 RTCCF！）

一般的學生根本不會、也不可能一開始就自己寫出繁複的 RTCCF 結構。  
**學生只需要上傳 Excel，發送以下這句人人都會講的大白話即可**：

```text
我提供了這個 Excel 檔案，我要將這個 Excel 檔轉換為 Markdown 的規格檔。
請先不要直接做，請先幫我產生一個符合 RTCCF（Role, Task, Context, Constraints, Format）架構的 prompt，並儲存為獨立的【RTCCF.md】檔案交付給我。
```

> 🤖 **AI 收到後會做什麼？**  
> AI 會自動去解析這份 Excel 的工作表與儲存格，替學生撰寫出一份包含「角色、任務、背景、限制條件、輸出格式」的完整 `RTCCF.md` 提示詞規格書！

---

## 🔍 第二階段：人機協作檢核點（檢查 AI 寫出來的 `RTCCF.md`）

> ⚠️ **學員必讀核心精神**：  
> 每個 AI（Claude / ChatGPT / Gemini）甚至每一次產生的內容都不一樣！  
> 學生的真正價值不是寫 Prompt，而是**「打開 AI 幫你寫好的 RTCCF.md 檔案，進行人機協作審核」**。請學生逐一核對以下注意事項：

### ✅ 人機協作檢查清單（Checklist）

1. [ ] **【Constraints 是否有要求「公式轉白話，不可寫成死數字」？】（最常漏掉！）**  
   * **檢查重點**：看 AI 在限制條件（Constraints）裡，有沒有寫「將隱藏公式轉為白話業務公式」？
   * ❌ **NG 狀況**：AI 忘記限制公式，只寫「計算出數字」。這樣 AI 下一步就會把公式壓平成死數字（如直接寫 96,000 元）。
   * 🔧 **如何修正**：若 AI 沒寫，直接在對話框對 AI 說：  
     *「請在 Constraints 加上：嚴禁將公式算成死數字，必須將公式轉寫為白話算式（如：經銷價 ＝ 原價 × (1 - 折扣)）。」*

2. [ ] **【Task 或 Context 有沒有把「人工輸入」與「公式產出」分開？】**  
   * **檢查重點**：確認 AI 有沒有在任務或欄位字典中，標註哪些是業務手動輸入、哪些是系統公式自動算。

3. [ ] **【Token 節省限制：範例是否控制在 2~3 筆？】**  
   * **檢查重點**：檢查 AI 的 Format 要求裡，是否有規定「範例數據僅保留 2~3 筆」？如果 AI 寫「輸出所有數據」，請手動改為「僅保留 2 筆範例」，否則下一步執行會瞬間耗盡 Token！

4. [ ] **【跨工作表的關聯有沒有提到？】**  
   * **檢查重點**：銷售總額需要引用報價表的單價，AI 有沒有把這個跨表關聯寫進 Context？

---

## 🚀 第三階段：以確認後的 `RTCCF.md` 當作 Prompt 正式上工！

人機協作檢查、修改完畢後，這份 `RTCCF.md` 就是完美的生產級指令。  
在同一個對話中，學生只要對 AI 說一句話：

```text
這份 RTCCF.md 我確認無誤！
現在請你嚴格依據這份【RTCCF.md】的規範，正式將 Excel 轉換為 Markdown 規格檔交付給我！
```

---

## ⚡ 實戰重要分流：如果 Excel「沒有公式，只有純資料」怎麼辦？

如果拿到的是打卡出勤紀錄、通訊錄、發票清單等**純數據檔案（無公式）**，學生同樣只要講一句大白話：

```text
我提供了這個 Excel 檔案，裡面是純業務數據清單（沒有計算公式）。
請先不要直接做，請先幫我產生一個符合 RTCCF 架構的 prompt，要求【必須全量讀出所有資料列、去除空白列與合併儲存格雜訊】，並儲存為獨立的【RTCCF.md】檔案交付給我。
```
