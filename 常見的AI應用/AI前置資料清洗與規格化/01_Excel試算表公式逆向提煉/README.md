## 🧠 學員必背口訣：規範 AI 的「黃金五骨架」（表、欄、式、防、例）

> ⚠️ **為什麼必須嚴格規範 AI？**  
> 任何未經約束的 AI，讀取 Excel 時最常犯兩大錯誤：  
> 1. **把幾百列資料全印出來** ➔ Token 瞬間耗盡！  
> 2. **把公式算成固定數字**（例如把公式算成固定寫死 96,000 元） ➔ 商業公式全失傳！  
> 
> 👉 **請學生將以下「黃金五骨架（表欄式防例）」與「三句式提問咒語」背誦下來**（詳細解析見 👉 [**`學員必背_如何規範AI產出Excel規格書之黃金五骨架.md`**](./學員必背_如何規範AI產出Excel規格書之黃金五骨架.md)）！

```text
┌────────────────────────────────────────────────────────┐
│   規範 AI 產出 Excel 規格書口訣：【 表 ➔ 欄 ➔ 式 ➔ 防 ➔ 例 】 │
└────────────────────────────────────────────────────────┘
```
1. 🏛️ **表（工作表定位）**：這張表是幹嘛的？各表之間如何關聯？
2. 📋 **欄（欄位字典）**：【人工輸入】與【公式產出】必須分清楚！
3. 🧮 **式（白話公式）**：儲存格代號轉成白話算式，**嚴禁寫死數字**！
4. 🛡️ **防（勾稽防呆）**：防呆檢核與算錯防線。
5. 🧪 **例（精簡範例）**：**嚴禁印出全表**，只要保留 2~3 筆供驗算！

## 🛠️ 第一階段：複製白話自然語言 Prompt ➔ 叫 AI 產出規格檔

請學生開啟 Claude、ChatGPT 或 Gemini 對話視窗，上傳 [`範例_業務報價與業績提成表.xlsx`](./範例_業務報價與業績提成表.xlsx)，**直接複製並發送以下自然語言指令**：

```text
我們公司是一家軟體服務企業，未來每個月（10月、11月、12月...）都會用類似這份試算表來查詢報價、計算銷售業績與業務提成。

【任務：將 XLSX 逆向工程產出 RTCCF 商業邏輯與公式規格檔】
請先不要執行任何特定訂單的計算，也不要輸出整張龐大的表格。我現在要建立的是一套「可供未來各月份重複調用」的標準運算規格書。
請依據所附 Excel 檔案的工作表結構與儲存格公式，幫我產出【RTCCF 工作流規格書】：

1. Role（角色）：資深系統分析師與 Excel 商業邏輯逆向專家。
2. Task（任務）：定義標準計算鏈路（查詢產品經銷結算價 ➔ 計算訂單銷售總額 ➔ 依業務達標率核算個人提成）。
3. Context（背景）：定義資料結構（產品報價表、業務銷售與提成試算），跨表關聯欄位與資料來源。
4. Constraints（限制條件）：
   - 萃取公式邏輯：將隱藏在儲存格裡的公式（如 =C2*(1-D2)、=E2*F2）轉寫為白話業務公式，嚴禁寫成死數字！
   - 區分「人工輸入欄位」與「公式自動產出欄位」。
   - Token 節省原則：每個工作表僅保留 2 筆範例數據。
5. Format（輸出格式）：輸出為結構清晰的 Markdown 規格書格式。

請將這套通用的運算規格，【務必儲存為獨立的 Markdown 檔案：RTCCF_XLSX規格檔.md】交付給我！
只要產出這份 .md 規格書即可，不需要輸出其他計算內容。
```

## 🔍 第二階段：人機協作檢核點（檢查 `RTCCF_XLSX規格檔.md` 的注意事項）

> ⚠️ **學員必讀提醒**：  
> 不同的 AI（Claude / ChatGPT / Gemini）甚至同一款 AI 的每一次回答，產出的文字與排版都會有些微差異。  
> **請學員開啟 AI 產出的 `RTCCF_XLSX規格檔.md`，化身為「人工驗收員」，逐一核對以下 4 大注意事項**：

### ✅ 人機協作檢查清單（Checklist）

1. [ ] **【公式有無被壓平變死數字？】（最常見錯誤！）**  
   * **檢查重點**：檢查規格檔中的經銷價與提成，AI 有沒有把「公式邏輯」寫出來？
   * ❌ **NG 錯誤**：AI 寫出「經銷結算價為 96,000 元」（這叫死數字，下個月換產品就壞掉了）。
   * ✅ **正確標準**：AI 寫出 `經銷結算價 ＝ 原價(未稅) × (1 － 經銷商折扣率)`。

2. [ ] **【人工輸入 vs. 公式產出 有無清楚分開？】**  
   * **檢查重點**：確認 AI 在欄位字典中，有沒有標註哪些欄位是業務手動輸入（如：銷售數量、達標獎金率），哪些欄位是系統自動算出（如：銷售總額、提成金額）。

3. [ ] **【跨工作表的查找關聯有沒有交代？】**  
   * **檢查重點**：業務銷售表需要取得「產品經銷價」，AI 的任務描述裡有沒有寫清楚「依產品名稱比對產品報價表」？如果沒寫，請手動補上。

4. [ ] **【範例數據是否足夠精簡？（防 Token 浪費）】**  
   * **檢查重點**：檢查表格範例是否只有 2 ~ 3 筆？如果 AI 把幾十列歷史訂單全印出來，**請直接手動刪除多餘列，只留 2 筆即可**！

> 💡 **人機協作修正**：若發現上述缺漏，直接在對話中叫 AI 修正（例如：*「請把經銷價改為白話公式，不要寫死數字」*），確認無誤後將該檔案正式保存。

## 🚀 第三階段：以這份 `RTCCF_XLSX規格檔.md` 作為 Prompt 正式上工！

審查修改完畢後，這份規格檔就成為您企業的專屬數位資產。在同一個對話中，發送執行指令：

```text
這份 RTCCF_XLSX規格檔.md 我確認無誤！

現在請你嚴格依據這份【RTCCF_XLSX規格檔.md】的規則與公式：
1. 讀取 Excel 中的實際銷售訂單。
2. 幫我正式執行本月份的提成試算，並輸出結算報表！
```

## ⚡ 實戰重要分流：如果 Excel「沒有公式，只有純資料」怎麼辦？

> 💡 **核心鐵則**：  
> * **有公式的規格表** ➔ 用「表欄式防例」，只留 2 筆範例提煉公式（省 Token）。  
> * **無公式的純資料**（如打卡出勤、會員清單、發票流水） ➔ **【所有資料都要讀出來！】**  
>   因為後續計算要逐筆統計，漏掉一筆就全錯！

### 📢 純資料型 Excel 學生複製提示詞：
```text
【任務：純資料型 Excel 前置降噪與全量讀取】

這是一份業務原始數據清單（內部無公式）。請幫我進行前置資料清洗：
1. 資料完整性鐵則：【必須完整讀出所有資料列，嚴禁截斷、嚴禁只留範例】！
2. 格式降噪：清除所有空白列、多餘排版裝飾與合併儲存格雜訊。
3. 輸出格式：輸出為乾淨的純文字 CSV 格式（或 Markdown 全量資料表），供後續逐筆分析與運算使用。
```
