# 實戰 01：Excel 試算表公式逆向提煉為「規格檔」

> 🎯 **學習目標**：學會使用專屬 **RTCCF 提示詞**，將包含複雜公式與跨表關聯的 `.xlsx`，一鍵逆向提煉為乾淨的 **【XLSX 商業邏輯與公式規格檔】**。

---

## 📂 實作素材清單
1. [**`範例_業務報價與業績提成表.xlsx`**](./範例_業務報價與業績提成表.xlsx)：包含 2 張工作表、跨表參照公式（`=產品報價表!E2*D2`）與提成邏輯。
2. [**`參考成果_業務報價與業績提成表_規格檔.md`**](./參考成果_業務報價與業績提成表_規格檔.md)：AI 產出之標準規格檔對照範本。

---

## 🛠️ 學員操作三步曲

### 步驟 1：開啟 AI 對話視窗
開啟 Claude、ChatGPT 或 Gemini 對話框，上傳 [`範例_業務報價與業績提成表.xlsx`](./範例_業務報價與業績提成表.xlsx)。

### 步驟 2：複製貼上以下「RTCCF 逆向提煉提示詞」
```text
【任務：將 XLSX 試算表逆向工程提煉為「業務與公式規格檔」】

請依據我上傳的 Excel 檔案，分析其欄位結構、儲存格公式與工作表關聯。
【請不要輸出龐大重複的完整資料表】，我需要你幫我逆向提煉出一份標準的【XLSX 商業邏輯與公式規格檔】：

1. Role（角色）：資深系統分析師與 Excel 商業邏輯逆向工程專家。
2. Task（任務）：
   - 解析工作表中每一欄的定義與資料型態。
   - 找出藏在儲存格裡的 Excel 計算公式，將其「白話業務化」（例如：將 =C2*(1-D2) 轉寫為清晰的計算規則）。
   - 清楚區分哪些欄位是「人工輸入」，哪些是「公式自動產出」。
3. Context（背景）：這份規格檔未來是要給 AI 專案知識庫（Claude Projects）作為常駐參考標準，讓 AI 在未來每個月接手算薪或報價時能嚴格遵循。
4. Constraints（限制條件）：
   - 節省 Token 鐵則：嚴禁印出全表數據！每個工作表【僅保留 2~3 筆最具代表性的範例資料】。
   - 勾稽防呆：若有防呆邏輯（如：借貸平衡、稅額 5% 四捨五入），請明確列出。
5. Format（輸出格式）：請嚴格依據以下結構，輸出為獨立的 Markdown 文件：

   # [專案名稱] XLSX 商業邏輯與公式規格書
   ## 一、工作表概覽與業務流程
   ## 二、欄位字典（Schema）（標註：欄位名稱、資料型態、是否必填、資料來源）
   ## 三、核心計算公式與商業邏輯（以白話公式呈現）
   ## 四、防呆檢核與勾稽條件
   ## 五、代表性範例數據（Markdown 表格，僅需 2~3 筆）
```

### 步驟 3：驗收並存檔
將 AI 回傳的結果儲存為 `.md` 檔案，未來將這份 `.md` 存入 Claude Projects 專案知識庫，即可永久調用！
