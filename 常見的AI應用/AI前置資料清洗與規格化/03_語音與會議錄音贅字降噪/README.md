# 實戰 03：語音與會議錄音贅字降噪為「決議與行動清單」

> 🎯 **學習目標**：將手機錄音轉出的口語贅字生稿（大量「那個、然後、嗯」），一鍵過濾提煉為具備 **負責人 (Who)、任務 (What)、期限 (When)** 的專業 Markdown 會議紀錄。

## 🛠️ 學員操作提示詞（RTCCF 範本）

```text
【任務：將語音逐字生稿清洗提煉為「高階會議決議與行動追蹤清單」】

請閱讀這份語音辨識逐字稿，過濾所有口語廢話與贅字（如：那個、嗯、然後、大概）：
1. Role：專案管理辦公室（PMO）資深幕僚長。
2. Task：
   - 提取真正的「核心討論事項」與「拍板決議（Decision）」。
   - 將所有口頭承諾與交代整理為標準的【To-Do 行動清單表格】。
3. Context：讓團隊各部門在會後能直接依表操課。
4. Constraints：
   - 每一筆待辦事項必須明確包含【負責人】、【具體任務】與【死線 (Deadline)】。
   - 嚴禁遺漏會議中提及的具體日期（如 11/05、11/06）。
5. Format：輸出標準 Markdown，包含「一、核心決議事項」與「二、團隊行動清單表格」。
```
