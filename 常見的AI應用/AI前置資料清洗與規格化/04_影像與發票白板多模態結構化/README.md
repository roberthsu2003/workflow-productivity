## 🛠️ 學員操作提示詞（RTCCF 範本）

上傳單據照片至 AI，發送以下指令：
```text
【任務：手機發票照片多模態結構化與稅務勾稽】

請辨識我上傳的發票照片，並執行結構化提煉：
1. Role：專業財務會計審計人。
2. Task：提取發票號碼、日期、賣方統編、買受人統編、未稅金額、營業稅(5%)與總金額。
3. Context：準備作為內部費用報銷總表之輸入源。
4. Constraints：
   - 自動檢算：未稅 + 營業稅 是否等於 總金額（四捨五入）。
   - 防呆標註：若無本公司統編，必須在「可否扣抵」欄標註「❌ 不得扣抵」。
5. Format：輸出標準 Markdown 表格，欄位依照「憑證序號 | 日期 | 廠商 | 發票號 | 買受人統編 | 未稅 | 稅額 | 總金額 | 扣抵 | 會計科目」。
```
