# 🛠️ AI 前置資料清洗與規格化（多模態全素材實戰指南）

> 💡 **核心精神**：**「人讀的是排版，AI 讀的是語意。」**  
> 任何工作流在請 AI 上工前，不可或缺的第 0 步就是**「前置資料清洗」**——將臃腫的 Office、雜亂的錄音與手機照片，提煉為 AI 專屬的 Markdown 規格檔！

## 🧭 為什麼要做前置資料清洗？

| 原始素材類型 | 職場常見痛點 | 前置資料清洗效益 | 產出之 AI 規格檔 |
| :--- | :--- | :--- | :--- |
| 📊 **Excel 試算表** | 隱藏公式多、幾百行重複數據、Token 瞬間燒光 | 逆向工程萃取公式邏輯，只留 Schema ＋ 3 筆範例 | **`XLSX 商業邏輯與公式規格檔.md`** |
| 📄 **Word / PPT** | 幾萬行排版 XML 標籤、投影片圖片吃 Vision Token | 剔除排版贅肉，保留階層標題 `#` 與審核門檻 | **`業務規章與作業 SOP 規格檔.md`** |
| 🎙️ **語音音訊** | 大量口頭禪贅字（「那個、然後」）、發散無結構 | 贅字降噪，提煉明確「誰(Who)在何時(When)做何事(What)」 | **`會議決議與行動追蹤清單.md`** |
| 📸 **影像照片** | 拍照反光、發票格式雜亂、反覆上傳耗費 Token | 多模態 OCR 結構化，自動驗算稅額 5% 與統編防呆 | **`費用報銷憑證結構清單.md`** |

## 📂 四大實戰操作模組（含小範例與 RTCCF 提煉範本）

請依序進入以下子目錄，每篇均提供**實作小範例、複製即用的 RTCCF 提示詞，以及標準參考成果**供學員對照：

1. [**`01_Excel試算表公式逆向提煉/`**](./01_Excel試算表公式逆向提煉/README.md)  
   👉 **最受歡迎！** 學會將藏有 `SUM`、`VLOOKUP` 與階梯提成公式的 Excel，一鍵提煉為 AI 看得懂的商業邏輯規格檔。
2. [**`02_Word與PPT長文件降噪瘦身/`**](./02_Word與PPT長文件降噪瘦身/README.md)  
   👉 甩掉 Word 封面、頁首頁尾與 PPT 視覺圖片，將冗長合約規章轉為純淨規章表格。
3. [**`03_語音與會議錄音贅字降噪/`**](./03_語音與會議錄音贅字降噪/README.md)  
   👉 解決語音辨識逐字稿「讀不下去」的困擾，過濾廢話，提煉高階決議與 To-Do List。
4. [**`04_影像與發票白板多模態結構化/`**](./04_影像與發票白板多模態結構化/README.md)  
   👉 將手機拍下的加油發票、高鐵車票與餐飲收據，快速變成符合稅法規範的結構化 Markdown。
