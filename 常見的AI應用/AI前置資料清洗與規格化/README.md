# 🛠️ AI 前置資料清洗與規格化（多模態全素材實戰指南）

> 💡 **核心教學方法論：人機協作三部曲**  
> **1. 學生複製自然語言 Prompt ➔ 2. AI 產出 RTCCF 規格檔 ➔ 3. 🔍 人工檢核核對清單 ➔ 4. 以 RTCCF 規格檔作為 Prompt 正式執行**  
> 
> 上課時，不需要學生自己從零撰寫複雜的 Prompt。每個模組均提供**「一鍵複製的自然語言發想提示詞」**；因為每款 AI（Claude / ChatGPT / Gemini）產出的字句都不一樣，本教材的核心重點是引導學生在**「人機協作檢核點」**進行嚴謹審查！

## 🧭 為什麼要做前置資料清洗？

| 原始素材類型 | 職場常見痛點 | 前置資料清洗效益 | 產出之 AI 規格檔 |
| :--- | :--- | :--- | :--- |
| 📊 **Excel 試算表** | 隱藏公式多、幾百行重複數據、Token 瞬間燒光 | 逆向工程萃取公式邏輯，只留 Schema ＋ 2 筆範例 | **`RTCCF_XLSX規格檔.md`** |
| 📄 **Word / PPT** | 幾萬行排版 XML 標籤、投影片圖片吃 Vision Token | 剔除排版贅肉，保留階層標題 `#` 與授權門檻 | **`RTCCF_業務規章規格檔.md`** |
| 🎙️ **語音音訊** | 大量口頭禪贅字（「那個、然後」）、發散無結構 | 贅字降噪，提煉明確「誰(Who)在何時(When)做何事(What)」 | **`RTCCF_會議決議規格檔.md`** |
| 📸 **影像照片** | 拍照反光、發票格式雜亂、反覆上傳耗費 Token | 多模態 OCR 結構化，自動驗算稅額 5% 與統編防呆 | **`RTCCF_憑證審核規格檔.md`** |

## 📂 四大實戰操作模組（自然語言 Prompt ＋ 人機協作檢核點）

請依序進入以下子目錄，每篇均提供**實作小範例、一鍵複製的自然語言發想 Prompt、嚴格的人機審查 Checklist，以及標準參考成果**供學員對照：

1. [**`01_Excel試算表公式逆向提煉/`**](./01_Excel試算表公式逆向提煉/README.md)（★ 內含**學員必背「表欄式防例」黃金五骨架**）  
   
   👉 **最受歡迎！** 學會發送自然語言，叫 AI 將藏有公式的 Excel 轉為規格檔；著重審查「公式有無被壓平變死數字」。
2. [**`02_Word與PPT長文件降噪瘦身/`**](./02_Word與PPT長文件降噪瘦身/README.md)  
   👉 甩掉 Word 封面贅字與排版雜訊；著重審查「金額門檻與天數是否 100% 精準」。
3. [**`03_語音與會議錄音贅字降噪/`**](./03_語音與會議錄音贅字降噪/README.md)  
   👉 過濾逐字稿廢話口頭禪；著重審查「每項待辦是否有點名負責人（Who）與死線（When）」。
4. [**`04_影像與發票白板多模態結構化/`**](./04_影像與發票白板多模態結構化/README.md)  
   👉 將手機拍下的加油、高鐵與餐飲發票轉為結構表；著重審查「統編數字 OCR 有無誤判、稅額 5% 驗算」。
