# 實戰 02：Word 與 PPT 長文件降噪提煉為「RTCCF 規格檔」

> 💡 **核心教學工作流（極簡白話 ➔ AI產出規格 ➔ 人工審核 ➔ 正式執行）**：  
> **1. 學生只講一句大白話 ➔ 2. AI 自動幫學生寫出 RTCCF.md ➔ 3. 🔍 學生當審查官檢查修改 ➔ 4. 以確認後的 RTCCF.md 當作 Prompt 正式上工**

---

## 📂 實作素材清單
1. [**`範例_企業採購與合約簽核規範.docx`**](./範例_企業採購與合約簽核規範.docx)：含有大量行政套話、段落排版的原始規章 Word 檔。
2. [**`參考成果_企業採購與合約簽核規範.md`**](./參考成果_企業採購與合約簽核規範.md)：標準規格檔完成範本，供學員對照觀摩。

---

## 🛠️ 第一階段：學生發送大白話 Prompt（不要自己寫 RTCCF！）

一般的學生不會自己寫繁雜的 RTCCF 結構。學生只要上傳 Word 或 PPT 檔，發送以下這句大白話即可：

```text
我提供了這份 Word/PPT 規章文件，我要將它轉換為 Markdown 的規章規格檔。
請先不要直接做，請先幫我產生一個符合 RTCCF（Role, Task, Context, Constraints, Format）架構的 prompt，並儲存為獨立的【RTCCF.md】檔案交付給我。
```

> 🤖 **AI 收到後會自動幫學生做什麼？**  
> AI 會自動去讀取文件，替學生把「Role（角色）、Task（任務）、Context（背景）、Constraints（限制條件）、Format（格式）」整套規格書寫好，並存成 `RTCCF.md` 給學生！

---

## 🔍 第二階段：人機協作檢核點（檢查 AI 寫出來的 `RTCCF.md`）

> ⚠️ **學員必讀提醒**：  
> 每個 AI（Claude / ChatGPT / Gemini）產出的字句都不一樣！請學生開啟 AI 寫好的 `RTCCF.md`，化身「內控稽核員」，逐一核對以下 3 大注意事項：

### ✅ 人機協作檢查清單（Checklist）

1. [ ] **【金額門檻與天數是否 100% 精準？】**  
   * **檢查重點**：看 AI 在 Constraints（限制條件）裡，有沒有嚴格鎖定原始 Word 中的金額數字：
     * 小於 10 萬（一般採購 / 部門主管）
     * 10 萬至 100 萬（專案採購 / CTO+COO 會簽 ➔ 總經理）
     * 超過 100 萬（重大資產 / 董事會）
   * ❌ **常見錯誤**：AI 有時會漏掉「會簽」或漏掉一個 0，學生必須用肉眼核對抓出！

2. [ ] **【比價規則與例外條款是否齊全？】**  
   * **檢查重點**：確認是否有註明「5 萬元以上需 3 家比價」以及「獨家專利免比價之單一來源簽呈」例外流程。

3. [ ] **【行政套話是否徹底被削掉？（防 Token 浪費）】**  
   * **檢查重點**：檢查 AI 的 Task 要求裡，是否有註明「清除開頭客套話、封面宣告與頁首頁尾」，只留下純粹的規則表格。

---

## 🚀 第三階段：以確認後的 `RTCCF.md` 當作 Prompt 正式上工！

審查修改確認後，在同一個對話中，學生只要對 AI 說一句話：

```text
這份 RTCCF.md 我確認無誤！
現在請你嚴格依據這份【RTCCF.md】的規範，正式將 Word/PPT 規章降噪轉換為 Markdown 規格檔交付給我！
```
