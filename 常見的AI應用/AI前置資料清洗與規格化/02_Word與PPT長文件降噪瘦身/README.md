# 實戰 02：Word 與 PPT 長文件降噪提煉為「RTCCF 規格檔」

> 💡 **核心教學工作流**：  
> **學生發送白話自然語言 ➔ AI 產出 RTCCF 規章規格檔 ➔ 🔍 人機協作審查修改 ➔ 以 RTCCF 規格檔作為 Prompt 正式執行**

---

## 📂 實作素材清單
1. [**`範例_企業採購與合約簽核規範.docx`**](./範例_企業採購與合約簽核規範.docx)：含有大量行政套話、段落排版的原始規章 Word 檔。
2. [**`參考成果_企業採購與合約簽核規範.md`**](./參考成果_企業採購與合約簽核規範.md)：標準規格檔完成範本，供學員對照觀摩。

---

## 🛠️ 第一階段：複製白話自然語言 Prompt ➔ 叫 AI 產出規格檔

請學生開啟 AI 對話視窗，上傳 [`範例_企業採購與合約簽核規範.docx`](./範例_企業採購與合約簽核規範.docx) 或公司的規章 PPT，**直接複製並發送以下自然語言指令**：

```text
我們公司是一家注重內控合規的企業，未來同仁提出各類請購與簽核時，AI 代理人都必須依據公司的採購規章進行自動化審核。

【任務：將長篇 Word/PPT 規章降噪提煉為 RTCCF 業務規章規格檔】
請先不要審核任何特定的採購申請單。請閱讀這份規章，剔除所有公文套話、排版代碼與封面贅字，幫我產出【RTCCF 工作流規格書】：

1. Role（角色）：資深法務合規主任與內部控制稽核專家。
2. Task（任務）：定義標準審核作業鏈路（判斷採購金額級距 ➔ 檢驗三家比價單據 ➔ 檢查簽核權限層級 ➔ 判定核准或退件）。
3. Context（背景）：定義適用的規章標準與授權矩陣，適用於全公司日常請購。
4. Constraints（限制條件）：
   - 關鍵數據絕對精準：金額門檻（如 10 萬、100 萬）、廠商數量（如 3 家）嚴禁簡略或遺漏。
   - 矩陣化呈現：將文字敘述的金額權限轉為清晰的 Markdown 表格。
5. Format（輸出格式）：輸出為獨立的 Markdown 規格書格式。

請將這套通用的審核規格，【務必儲存為獨立的 Markdown 檔案：RTCCF_採購審核規格檔.md】交付給我！
只要產出這份 .md 規格書即可，不需要輸出其他審核內容。
```

---

## 🔍 第二階段：人機協作檢核點（檢查 `RTCCF_採購審核規格檔.md` 的注意事項）

> ⚠️ **學員必讀提醒**：  
> 請開啟 AI 產出的 `RTCCF_採購審核規格檔.md`，化身為「內控稽核員」，逐一核對以下 3 大注意事項：

### ✅ 人機協作檢查清單（Checklist）

1. [ ] **【金額門檻與天數是否 100% 精準？】**  
   * **檢查重點**：核對原始 Word 中的金額數字：
     * 小於 10 萬（一般採購 / 部門主管）
     * 10 萬至 100 萬（專案採購 / CTO+COO 會簽 ➔ 總經理）
     * 超過 100 萬（重大資產 / 董事會）
   * ❌ **常見錯誤**：AI 有時會漏看「會簽」或是漏掉一個 0，必須由人工複核抓出！

2. [ ] **【比價規則與例外條款是否齊全？】**  
   * **檢查重點**：確認是否有註明「5 萬元以上需 3 家比價」以及「獨家專利免比價之單一來源簽呈」例外流程。

3. [ ] **【行政套話是否徹底被削掉？（防 Token 浪費）】**  
   * **檢查重點**：檢查文件開頭是否有殘留「為健全本公司之內部營運架構、促進採購效率...」等客套廢話。若有，手動刪除，只留純粹的規則表格。

---

## 🚀 第三階段：以這份規格檔作為 Prompt 正式執行

審查修改確認後，未來只要有員工提出採購申請，直接發送：
```text
請嚴格依據【RTCCF_採購審核規格檔.md】的授權矩陣與比價規則，審查以下請購單：
[貼上請購金額 15 萬元、附 2 家報價單的申請]
```
AI 就會 100% 依據內控標準精準回覆退件理由（金額達 15 萬需 3 家比價且需總經理核決）！
