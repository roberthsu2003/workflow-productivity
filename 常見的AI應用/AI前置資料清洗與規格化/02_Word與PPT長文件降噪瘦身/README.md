# 實戰 02：Word 與 PPT 長文件降噪為「純淨 Markdown」

> 🎯 **學習目標**：學會將充斥著花俏封面、頁首頁尾與繁雜表格的 `.docx` 與 `.pptx`，降噪為 AI 最喜歡讀的乾淨結構標題與清單。

---

## 📂 實作素材清單
1. [**`範例_企業採購與合約簽核規範.docx`**](./範例_企業採購與合約簽核規範.docx)：含有大量行政套話、段落排版的原始規章 Word 檔。
2. [**`參考成果_企業採購與合約簽核規範.md`**](./參考成果_企業採購與合約簽核規範.md)：清洗後的精準規則對照表。

---

## 🛠️ 學員操作提示詞（RTCCF 範本）

上傳 Word 或 PPT 檔至 AI，貼上以下提示詞：
```text
【任務：將 Word/PPT 長文件降噪提煉為「AI-Ready 業務規章規格檔」】

請閱讀我上傳的文件，剔除所有版面排版雜訊（如：封面、頁首頁尾、免責宣告、客套話）：
1. Role：資深法務合規與行政流程分析師。
2. Task：將內文的核心規則、金額級距、簽核權限與例外流程，提煉為結構化純文字 Markdown。
3. Context：供未來 AI Agent 執行自動化審核時作為底層規則依據。
4. Constraints：
   - 數字、金額、天數必須 100% 精準保留。
   - 能用 Markdown 表格呈現的門檻，一律轉為表格。
5. Format：輸出標準 Markdown，使用 #、##、條列 (-) 與表格 (|)。
```
