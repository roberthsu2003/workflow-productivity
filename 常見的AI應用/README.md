### 📊 辦公室全能應用（Word / Excel / PPT / PDF 商務文件生成）
👉 **[進入章節總覽](./辦公室全能應用/README.md)**：**從零生成**，用口語條列 ＋ `RTCCF.md` 一問一答，讓 AI 產出全新的商務文件。通用於 Claude.ai、ChatGPT、Gemini 與 Antigravity。

本章包含：
- **Word 與 PDF 文件的生成**：企劃公文、SOP 規章與研究指南，先審核 `.md` 內文，確認後再轉成 `.docx` 與 `.pdf`。
- **Excel 試算表的生成**：前導心法＋五大階梯，從基礎建表、防呆警示、髒資料清洗、跨表關聯一路到商業儀表板，規格確認後直接交付 `.xlsx`。
- **PowerPoint 簡報的生成**：AI 先提煉每頁大綱，審核通過後直接交付 `.pptx`。

### 📐 Office 辦公室應用進階對齊（DOCX / XLSX / PPTX / PDF 四大格式）
👉 **[進入章節總覽](./office辦公室應用進階的對齊/README.md)**：**既有範本套印**，保護公司原本的版面，大量填入資料也不跑版。每個單元都是「課前導讀 ➔ 實戰主頁 ➔ 練習題」。

本章包含：
- **Word (.docx)**：結業證明書套印，鎖定置中／靠左／靠右、固定表格欄寬、長文字自動折行不爆頁。
- **Excel (.xlsx)**：xltpl 商業報價單，動態品項列增減、數值型別寫入、保護原生 `=SUM()` 公式與合併儲存格。
- **PowerPoint (.pptx)**：兩大主軸，固定佔位符例行報告（Run 層級替換、長文字縮字防溢出），以及企業母片＋大綱動態分頁生成。
- **PDF (.pdf)**：A4 向量報銷單，繁中防豆腐字、千分位右對齊、跨頁自動重複表頭與簽核防撕裂。
