# 現代職場的 AI 應用全指南與實戰範例庫

本目錄集中收納現代職場中最常見、高頻使用的 Generative AI 核心應用情境與實戰模組。從純文字協同編輯、會議自動化，到商務簡報圖表與個人知識庫，提供完整的提示詞架構、素材檢核表與工作流指南。

## 🧭 應用主題分類導覽

### 📑 職場實戰範例庫（Practical Examples）
- **[現代職場實戰範例庫](./實戰範例/README.md)**  
  收錄 11 大現代職場高階落地實戰案例，涵蓋四大人機協作核心領域，聚焦「核心觀念與人機協商工作流」，一套思維通用於三大主流代理平台（Claude.ai、ChatGPT、Google Antigravity），提供完整的白話發想提示詞、嚴謹 RTCCF 提示詞、企業級素材與一鍵生成發布成果：
  - **營運排程與規則稽核**：便利超商 24 小時三班制排班與勞基法檢核、進銷存出貨四欄平帳沖帳。
  - **行銷傳播與多媒體生成**：社群行銷活動多格式產出（IG/FB/短影音分鏡腳本）、GA4 與社群廣告跨平台數據交叉漏斗分析。
  - **多模態現場與嚴謹審查**：工程監造白板現場照片多模態辨識與驗收報告、SQE 品保會議逐字稿提煉與 Human-in-the-loop 會簽表單自動化。
  - **大數據分析與戰情報表自動化**：企業出納百萬付款審核與銀行放行總表（Template Placeholder）、星嵐大飯店大數據月報與 16:9 PPT 簡報自動化、電子被動元件 39 家同業競業情資矩陣與市場地圖、工控技術手冊跨國在地化與現場 SOP 口袋書出版級美化、新北市不動產實價登錄 1,772 筆大數據清洗與土地開發戰情分析。
