# 現代職場的 AI 應用全指南

本目錄集中收納現代職場中最常見、高頻使用的 Generative AI 核心應用情境與實戰模組。從純文字協同編輯、會議自動化，到商務簡報圖表與個人知識庫，提供完整的提示詞架構、素材檢核表與工作流指南。

## 🧭 應用主題分類導覽

### 📊 辦公室全能應用（Word / Excel / PPT / PDF 商務文件生成）
- **[四大商務交付格式總覽手冊](./辦公室全能應用/README.md)**  
  通用於 Claude.ai、ChatGPT、Gemini 與 Antigravity，一站式產出職場必備商務文件格式。
- **[Word 與 PDF 文件的生成](./辦公室全能應用/Word與PDF文件的生成/README.md)**  
  企劃公文、SOP 規章與研究指南，人機協作審核確認後匯出或下載為 `.docx` 與 `.pdf`。
- **[Excel 試算表的生成](./辦公室全能應用/Excel試算表的生成/README.md)**  
  非結構文字、採購與會議清單自動結構化，通過數據風控審核卡片後一秒匯出或下載為 `.xlsx`。
- **[PowerPoint 簡報的生成](./辦公室全能應用/簡報的生成/README.md)**  
  結合 AI 提煉結構化簡報大綱、科技風格配色並快速成型為 `.pptx`。

### 📐 Office 辦公室應用進階對齊（Advanced Alignment & Precision Templates）
- **[Office 辦公室應用進階的對齊（Docx 證書與 Xlsx 報價單套印）](./office辦公室應用進階的對齊/README.md)**  
  解決排版跑版、公式覆蓋與資料錯位：從既有正式 Word 證書與 Excel 報價單出發，經 AI 逆向提煉為鎖定排版、相容 Python xltpl 動態迴圈與保護動態公式的「佔位符樣版」，再搭配結構化資料庫實現精準對齊批次套印，提供完整原始檔、樣版、測試資料與示範成果一鍵下載。
