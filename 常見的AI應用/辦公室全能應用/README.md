# 辦公室全能應用：五大商務交付格式生成手冊
## 🚀 AI Agent 人機協作實戰

> **本模組簡介**：本專題專為現代職場與辦公室非技術人員量身設計，徹底擺脫對單一工具的依賴。核心工作流通用於各類主流 AI Agent。
> 
> 針對初學者「不會寫 Prompt、擔心 AI 產出不可控、格式無法直接交付」的三大痛點，同時避免單一任務流程過於繁瑣，本教學全面導入 **單點審核 Markdown 閉環機制（RTCCF 任務與預檢規格書二合一，Human-in-the-Loop）**：
> 1. **零門檻口語／素材輸入**：學員輸入日常口語（或上傳 PDF、Word、Excel、CSV、白板照片等素材），要求 AI 先產出「RTCCF 規格＋預檢卡片」，不直接吐出長文或成品。
> 2. **AI 一次產出二合一「RTCCF 任務與預檢規格書」➔ 儲存為單一 `RTCCF規格書.md`（單點審核）**：AI 在同一回合輸出上半部 **RTCCF 任務條件**（角色、背景、限制）與下半部 **架構／數據預檢卡片**（章節、欄位、平帳驗算、分頁大綱）。使用者**只需審核這一次**，即可存為單一 `.md` 檔兼具當下防呆驗收基準與日後可重用的 SOP 範本。
> 3. **人類核准放行 ➔ 生成最終商務產品**：經使用者單次確認「確認無誤，可以生成」，AI Agent 才正式匯出 **Word (.docx)**、**Excel (.xlsx)**、**PowerPoint (.pptx)**、**PDF (.pdf)** 以及 **全自動資訊圖表（Infographic）**！

## 🧭 AI Agent 辦公室人機協作全景架構（Human-in-the-Loop）

![辦公室人機協作全景圖](./images/辦公室人機協作全景圖.svg)

本手冊全面導入 **單點審核 Markdown 閉環機制（三步閉環）**，把兩次煞車合併為一次精準把關，確保 AI 產出完全受控、不跑版、符合企業實務標準：
1. **零門檻輸入 (Input Layer)**：支援日常口語交辦，以及 PDF、Word、Excel、CSV、白板照片（OCR）等 7 大多模態實體素材。
2. **AI 一次產出二合一 `RTCCF規格書.md` (Merged Spec)**：AI Agent 一次將需求規格化為 **RTCCF 任務條件 ＋ 預計產出骨架預檢（章節、欄位、金額平帳、版面動線）**，**統一存為單一 `.md` 檔**。
3. **人類單點審核放行 (Single Review Gate)**：使用者只需審核這一次，核對條件與預檢骨架無誤後回覆「確認無誤，可以生成」。
4. **正式生成最終產品 (Deliverables Hub)**：放行後正式產出 Word、Excel、PPT、PDF、資訊圖表與進階對齊樣版。

## 📌 關鍵核心原則：為什麼人機協作的「二合一 RTCCF 任務與預檢規格書」必須儲存為 Markdown (.md) 檔案？

在與 AI Agent 進行深度人機協作時，**「將二合一的 RTCCF 任務條件與架構預檢規格書儲存為單一 Markdown 檔案 (`.md`)」是兼顧效率與品管的最佳實踐**：

| 評估面向 | 儲存為 Markdown (`.md`) | 存為一般記事本 (`.txt`) | 存為 Word (`.docx`) |
| :--- | :--- | :--- | :--- |
| **語意結構保真度** | 🟢 **100% 原生解析**：保留 `#` 標題、`\| 表格 \|`、代碼區塊與縮排層級，AI Agent 精準理解任務角色、欄位邊界與約束條件。 | 🟡 **結構模糊**：僅有平鋪文字，複雜的交辦步驟、參數對齊容易錯位，AI Agent 容易漏看約束。 | 🔴 **格式污染**：夾帶大量二進位與 XML 富文本標籤，複製到對話介面時引發格式錯亂與雜訊。 |
| **AI Agent 相容性** | 🟢 **完美通用**：主流 AI Agent 原生皆以 Markdown 渲染與解析，直接讀取 `.md` 規格書能做到**零幻覺精準執行**。 | 🟡 段落切分較生硬，跨段落檢索容易斷層。 | 🟡 檔案體積大，上傳與解析耗時較久，部分平台解析表格易變形。 |
| **人機協作與版本控管** | 🟢 **最佳數位資產**：支援 Git、VS Code、Obsidian，一份檔案同時保存 RTCCF 提示詞與預檢標準，團隊可多人修訂並作為下次一鍵套用的 SOP 資產庫。 | 🔴 缺乏結構化，難以建立可追蹤、可擴充的規格資產庫。 | 🔴 難以進行純文字 diff 版本比較與自動化管道調用。 |

> 💡 **單點審核操作原則**：
> 1. **一次看齊「任務規則＋預檢骨架」**：在單一任務中，你不需要先審一次 RTCCF、存一個檔，再貼回去審一次規格書。AI 會在同一則回覆中幫你整理好 **RTCCF 條件（上半部）** 與 **章節／欄位／金額預檢卡片（下半部）**。
> 2. **單檔保存即資產（`RTCCF規格書.md`）**：檢視無誤後，可將這份二合一規格書儲存為單一 `.md` 檔案（例如：`採購單據清洗_RTCCF規格書.md`），既能當作當下生成的防呆基準，未來遇到類似任務也能直接複製整份 `.md` 一鍵套用！
