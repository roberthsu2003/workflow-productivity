# 辦公室全能應用：五大商務交付格式生成手冊
## 🚀 跨平台人機協作實戰（Claude.ai × ChatGPT × Gemini × Antigravity）

> **本模組簡介**：本專題專為現代職場與辦公室非技術人員量身設計，徹底擺脫對單一工具的依賴。核心工作流通用於目前四大主流生成式 AI 平台：
> - **Claude (Claude.ai)**：超強邏輯推理、精準長文本分析與 Artifacts 即時視覺預覽。
> - **ChatGPT**：通用自然語言互動、進階數據分析（Advanced Data Analysis）與 Canvas 畫布編輯。
> - **Gemini**：多模態 OCR 視覺辨識、長上下文理解與一鍵匯出 Google 文件／試算表。
> - **Google Antigravity**：自主代理 Coding Agent，支援專案工作區本機檔案讀寫與全自動化腳本。
> 
> 針對初學者「不會寫 Prompt、擔心 AI 產出不可控、格式無法直接交付」的三大痛點，本教學全面導入 **人機協作（Human-in-the-Loop）四步閉環機制**：
> 1. **零門檻自然語言輸入**：學員只需輸入日常口語，AI 自動轉化為專業 **RTCCF 格式**。
> 2. **強制儲存為 Markdown (.md) 檔案**：**核心守則——必須儲存為 `.md` 檔案**！Markdown 是 LLM 原生語意結構語言，唯有儲存為 `.md` 才能跨平台無損保留角色、表格、階層與約束，達到真正的人機協同與重複調用。
> 3. **強制「審核卡片（Review Card）」機制**：在產生任何實體檔案前，AI 必須先產出審核卡片供人類快速核對，**待使用者確認「可以了 / 審核通過」才正式生成**。
> 4. **實體交付格式匯出**：無縫產出 **Word (.docx)**、**Excel (.xlsx)**、**PowerPoint (.pptx)**、**PDF (.pdf)** 以及 **全自動資訊圖表（Infographic）**！

## 📌 關鍵核心原則：為什麼人機協作對話「一定要儲存為 Markdown (.md) 檔案」？

在與 Claude、ChatGPT、Gemini 或 Antigravity 進行深度人機協作時，**「將 Prompt 與溝通成果儲存為 Markdown 檔案 (`.md`)」是跨平台協作不可妥協的最佳實踐**，原因如下：

| 評估面向 | 儲存為 Markdown (`.md`) | 存為一般記事本 (`.txt`) | 存為 Word (`.docx`) |
| :--- | :--- | :--- | :--- |
| **語意結構保真度** | 🟢 **100% 原生解析**：保留 `#` 標題、`| 表格 |`、代碼區塊與縮排層級，AI 精準理解角色任務與邊界條件。 | 🟡 **結構模糊**：僅有平鋪文字，複雜的表格、參數對齊容易錯位，AI 易漏看約束。 | 🔴 **格式污染**：夾帶大量的二進位與 XML 富文本標籤，複製到對話框時常引發格式錯亂與雜訊。 |
| **跨平台 AI 相容性**<br>(Claude / ChatGPT / Gemini / Antigravity) | 🟢 **完美通用**：四大平台原生皆以 Markdown 渲染，上傳或複製 `.md` 內容均能無縫解析，達到**零幻覺精準輸出**。 | 🟡 段落切分較生硬，跨段落檢索容易斷層。 | 🟡 檔案體積大，上傳與解析耗時較久，部分平台解析表格易變形。 |
| **人機協作與版本控管** | 🟢 **最佳數位資產**：支援 Git、VS Code、Obsidian、GitHub，團隊可多人協作、審核修訂與永久複用。 | 🔴 缺乏結構化，難以建立大型企業級 Prompt 資產庫。 | 🔴 難以進行純文字 diff 版本比較與自動化調用。 |

> 💡 **操作原則**：每次 AI 將你的口語需求改寫為 RTCCF 格式後，**請第一時間複製並在本地或專案中新增 `.md` 檔案（例如：`採購單據清洗_Prompt.md`）儲存**。

## 🧭 雙軌生成工作流（Dual-Track Workflow）

每一個專案與格式，皆提供兩種操作模式，並附上**可一鍵複製的自然語言 Prompt** 與**多元實體教學偽資料**：

```
【軌道一：直接使用 Prompt 生成（Prompt 協作軌）】
在任何 AI 平台輸入自然語言 ➔ 轉化為 RTCCF 並儲存為 .md 檔案 ➔ 通過「審核卡片」核可 ➔ 產出標準格式 ➔ 下載 Word / Excel / PPT / PDF / 資訊圖表

【軌道二：以企業實體素材為依據生成（素材 Grounding 協作軌）】
直接將隨附的「實體偽資料檔案（PDF/Word/Excel/白板照片）」作為附件上傳給 AI ➔ 輸入自然語言 ➔ 轉化為 RTCCF 並儲存為 .md 檔案 ➔ 通過「審核卡片」核對事實 ➔ 一鍵生成零幻覺報告、試算表、投影片與視覺資訊圖表
```
