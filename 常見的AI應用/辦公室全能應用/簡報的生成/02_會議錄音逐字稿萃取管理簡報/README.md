# 實戰範例 02：會議錄音逐字稿萃取管理簡報（PowerPoint）

> 🟢 **適用範圍**：通用於各主流 AI Agent（Web 對話介面與 Coding Agent）  
> 🛠️ **核心工作流**：**雙階段 Markdown 審核閉環**（上傳逐字稿附件 ➔ 存為 `工作流.md` 初審 ➔ 產出 `規格書.md` 終審 ➔ 正式生成高階管理簡報）

---

## 📥 學員實戰素材與交付成品

- **必載輸入素材**：
  - [**`素材_數位轉型專案啟動會議音訊逐字稿.docx`**](./素材_數位轉型專案啟動會議音訊逐字稿.docx) *(長篇會議逐字稿，亦可使用 [純文字檔](./素材_數位轉型專案啟動會議音訊逐字稿.txt))*
- **核心交付成品**：
  - [**`數位轉型專案啟動會議_管理簡報大綱.md`**](./數位轉型專案啟動會議_管理簡報大綱.md) *(由 AI 去蕪存菁提煉之 6 頁高階管理決策投影片大綱，可一鍵轉為 `.pptx`)*

---

## 🏆 案例情境與業務痛點

高階主管會議動輒開 2 小時，產生數萬字音訊逐字稿：
1. **逐字稿又長又雜**：充滿口語助詞、跨部門發散討論，老闆沒時間閱讀全文。
2. **缺乏結構化決策點**：無法快速提煉出「總經理指示、各部需求、資安防線、培訓時程」。
3. **AI 隨意歸納容易漏看**：若未經人機協作審核規格書查核，容易遺漏關鍵交辦事項。

## 🛠️ 實戰演練：自然語言 ➔ RTCCF 交辦事項 ➔ 規格書 ➔ 實體簡報

學員不必在多個檔案間切換，以下完整展示從白話日常口語到生成最終管理簡報的完整流程：

### 步驟 1：日常自然語言輸入（零門檻口述需求）

在對話介面上傳 [`素材_數位轉型專案啟動會議音訊逐字稿.docx`](./素材_數位轉型專案啟動會議音訊逐字稿.docx)，並輸入日常白話：

```text
幫我把這份數位轉型會議逐字稿做成一份給老闆報告的精華簡報大綱，大概 6 頁。把總經理講的話、各部門要什麼、資安怎麼管、什麼時候上課跟最後結論寫出來。
請先幫我把這段需求改寫成標準的 RTCCF 交辦事項（工作流），讓我儲存為 Markdown (.md) 檔案；並且先產出「管理簡報審核規格書」給我確認，不要直接輸出全部內容。待我確認 Markdown 內容與架構後，請再依照該檔為我正式生成 6 頁精華大綱。
```

---

### 步驟 2：AI Agent 轉化為 RTCCF 交辦事項（⚠️ 強制儲存為 `工作流.md`）

AI Agent 接收口語與附件後，自動結構化出標準交辦事項。**請學員第一時間將此內容儲存為 `逐字稿管理簡報_工作流.md` 檔案**：

```markdown
## Role
資深企業幕僚兼決策簡報顧問。

## Task
以已上傳之《數位轉型專案啟動會議音訊逐字稿》為客觀依據，提煉出 6 頁高階管理決策簡報大綱。

## Context
供總經理與各部門主管查閱，著重會議決議、部門權責與行動方針。

## Constraint
1. 嚴格依據逐字稿客觀事實，去除發散對話與口語贅字。
2. 提煉總經理致詞重點、四部需求、資安原則、訓練時程與三大決議。
3. 執行限制：【第一步必須先產出審核規格書】，待使用者核准後再輸出全文。
4. 語言：繁體中文，精準洗鍊。

## Format
6 頁結構、每頁核心標題與 3 點決策綱要。
```

> 👤 **人類初審**：使用者在本地或專案中檢視 `工作流.md`，確認 6 頁主題涵蓋關鍵會議內容後傳給 AI 執行。

---

### 步驟 3：傳遞工作流 ➔ AI Agent 輸出「管理簡報審核規格書」（⚠️ 亦存為 `規格書.md`）

AI Agent 接獲交辦事項後，先輸出 6 頁決策簡報規格書供人類查核：

![決策簡報審核規格書](./images/決策簡報審核規格書.svg)

---

### 步驟 4：人類終審放行 ➔ 正式生成 PowerPoint 內容與套版

使用者人眼核對 6 頁骨架與會議三大決議無遺漏後，發送放行指令：

```text
審核通過，請產出完整投影片。
```

AI Agent 立即依循規格書輸出完整 6 頁管理簡報大綱：
- 📄 **完整示範成果**：請直接點閱參閱 [**`數位轉型專案啟動會議_管理簡報大綱.md`**](./數位轉型專案啟動會議_管理簡報大綱.md)。
- 📥 **匯出方式**：可直接套用現成 PPT 母片模板或貼入 Gamma 匯出高品質 `.pptx` 投影片交付長官！
