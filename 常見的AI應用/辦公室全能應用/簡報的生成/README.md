# PowerPoint (.pptx) 簡報生成模組
## 🚀 AI Agent 商業簡報大綱萃取與 PPTX 實戰（Claude × ChatGPT × Gemini × Antigravity）

> **模組目標**：非技術人員常為製作高階主管報告、業務提案投影片耗費大量時間排版與構思。因為 **`RTCCF.md` 內就已包含完整每頁大綱**，本模組示範如何透過**「6 個口語條列重點 ➔ AI 儲存含每頁大綱的 `RTCCF.md` 並以 5~6 題一問一答確認方向（Human-in-the-Loop）➔ 大綱審核通過 ➔ 直接交付 PowerPoint (.pptx)」**，無須多繞一圈即可產出高品質投影片！

本模組收錄兩大核心商業實戰範例，提供完整 6 大口語重點起手、5~6 題問答流程、素材與產出範本：

1. [**實戰範例 01：科技商務提案簡報企劃**](./01_科技商務提案簡報企劃/README.md)
   - **情境類型**：白話口語直接發想
   - **核心業務**：零門檻口語發想，在含 8 頁大綱的 `RTCCF.md` 中通過 5~6 題問答定案，直接產出「企業導入生成式 AI 效益」科技商務簡報（含色票與演講備忘錄）。
   - **交付成品**：`RTCCF.md`（含 8 頁每頁大綱）➔ 直接交付 `.pptx`（模板 [`ptt簡報模版.pptx`](./01_科技商務提案簡報企劃/ptt簡報模版.pptx) ／ 範例 [`商業科技簡報範例.pptx`](./01_科技商務提案簡報企劃/商業科技簡報範例.pptx)）

## 🎨 科技商務配色與設計原則

- **深邃科技風**：主色深藍 `#1E2761`、強調色冰藍 `#CADCFC` 或青綠 `#00FFD0`。
- **閱讀黃金法則**：**一頁一重點（One Slide, One Idea）**，切忌將長段落文字直接複製到簡報上。
- **排版技巧**：文字盡量採用「**粗體關鍵字** + 簡要短語」，讓台下主管在 3 秒內抓住核心論點。
- **跨平台統一字型（直接寫入 `RTCCF.md`）**：因為 `.pptx` 是在 `RTCCF.md` 通過後直接交付，務必在 `RTCCF.md` 的格式規範鎖定繁體中文（`zh-TW`）字型——中文字型統一為 **`Microsoft JhengHei`（微軟正黑體）**（或台灣版思源黑體 **`Noto Sans TC` / `Noto Sans CJK TC`**，避免誤抓簡體 `SC` 字庫）、英數字型統一為 **`Arial`**，且要求 AI 在每個文字框與表格儲存格底層 XML 同時寫入**東亞字型 `<a:ea>`**、**拉丁字型 `<a:latin>`** 與 `lang="zh-TW"`，避免在 Mac / Windows 退回新細明體或簡體筆畫。
