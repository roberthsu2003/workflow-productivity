## 🏆 案例情境與業務痛點

企業非技術同仁在撰寫專案企劃書時，常面臨三大困擾：
1. **指令空泛，AI 產出不知所云**：直接告訴 AI「幫我寫企劃」，產出往往缺少推動對象、分階段時程與資安規範。
2. **缺乏審查機制，直接長篇大論**：AI 一口氣產生數千字，若方向偏差必須整篇重寫，浪費時間。
3. **沒有保存結構化提示詞**：沒有將 Prompt 儲存為 `.md` 檔案，下次換工具或微調時無法重複調用。
