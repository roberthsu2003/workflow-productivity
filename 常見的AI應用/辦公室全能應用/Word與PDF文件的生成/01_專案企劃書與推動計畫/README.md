# 實戰範例 01：專案企劃書與推動計畫（Word / PDF）

> 🟢 **適用範圍**：通用於各主流 AI Agent（Web 對話介面與 Coding Agent）  
> 🛠️ **核心工作流**：**單點審核 Markdown 閉環**（口語發想 ➔ AI 一次產出二合一 `RTCCF規格書.md` 單點審核 ➔ 正式生成 Word/PDF）

---

## 📥 學員實戰素材與交付成品

- **核心交付成品**：
  - [**`2026年度辦公室AI賦能推動計畫書_範本.md`**](./2026年度辦公室AI賦能推動計畫書_範本.md) *(由 AI 完整產出之 1,500 字標準公文格式企劃書，可一鍵轉為 Word (.docx) 或 PDF (.pdf))*

---

## 🏆 案例情境與業務痛點

企業非技術同仁在撰寫專案企劃書時，常面臨三大困擾：
1. **指令空泛，AI 產出不知所云**：直接告訴 AI「幫我寫企劃」，產出往往缺少推動對象、分階段時程與資安規範。
2. **缺乏審查機制，直接長篇大論**：AI 一口氣產生數千字，若方向偏差必須整篇重寫，浪費時間。
3. **沒有保存可重用規格資產**：缺少結構化的 `RTCCF規格書.md` 範本，下次做類似企劃又得從頭描述需求。

## 🛠️ 實戰演練：自然語言 ➔ 二合一 RTCCF 任務與預檢規格書 ➔ 實體文件

學員不必在多個檔案間反覆複製貼上，以下完整展示「三步單點審核閉環」的實戰流程：

### 步驟 1：日常自然語言輸入（零門檻口述需求）

學員完全不需要先學會寫複雜的提示詞，只要在 AI Agent 對話框中輸入日常白話：

```text
我想寫一份公司今年推動非技術同仁使用 AI 辦公室工具的專案計畫書給主管看，希望大概包含計畫緣由、目標、推動步驟、資安跟預算，字數大概 1500 字，口吻要專業正式。
請先幫我一次產出二合一的「RTCCF 任務與計畫架構預檢規格書」，並直接儲存為 Markdown 檔案（專案計畫書_RTCCF規格書.md）交付給我審核：上半部整理這項任務的 RTCCF 條件，下半部直接列出 6 大章節骨架與字數預檢卡片。先不要直接輸出完整企劃長文，待我對這份 .md 規格書單次確認無誤後，再為我正式生成完整文件。
```

---

### 步驟 2：AI 產出並儲存 `專案計畫書_RTCCF規格書.md`（單點審核）

AI Agent 接收口語後，會將上半部「RTCCF 任務條件」與下半部「架構預檢卡片」直接儲存為單一 **`專案計畫書_RTCCF規格書.md`** 交付人類進行 Human-in-the-Loop 單點審核（同時作為本次驗收基準與日後重用範本）：

**【上半部：RTCCF 任務定義】**

```markdown
## Role
你是一位資深企業營運規劃師，擅長撰寫結構嚴謹、條理分明的正式公務企劃書。

## Task
請幫我撰寫一份完整的「2026 年度辦公室 AI 賦能推動計畫書」，準備提交給高階主管核閱。

## Context
- 核心目標：引進主流 AI Agent 辦公室工具，協助非技術同仁處理公文、試算表、簡報與資訊圖表，節省 40% 行政工時。
- 推動對象：全體非技術同仁（約 80 人）。

## Constraint
- 必須包含：計畫緣起、KPI 目標、分階段時程、資安與去識別化規範、預算配置、預期成效。
- 語言：繁體中文，公務正式口吻，字數約 1,500 字。
- 執行限制：先將本規格書與【6 大章節骨架預檢卡片】二合一儲存為 `專案計畫書_RTCCF規格書.md` 檔案交付審核，待我確認後再輸出全文。

## Format
- 階層標題（Markdown #、##、###）、標準三欄表格。
```

**【下半部：計畫架構預檢卡片】**

![專案計畫書架構規格書](./images/專案計畫書架構規格書.svg)

> 👤 **人類單點審核（Human-in-the-Loop）**：使用者只需打開這份已儲存的 `專案計畫書_RTCCF規格書.md` 核對這一次！確認上方 RTCCF 條件（對象、字數、必含項目）與下方 6 大章節骨架皆符合預期，若有微調直接修改 `.md` 檔或告訴 AI；無誤後即可放行，這份 `.md` 檔也能作為日後重複使用的標準範本。

---

### 步驟 3：人類確認放行 ➔ 正式生成 Word (.docx) 與 PDF (.pdf)

使用者核對無誤後，直接發送放行指令（不需再貼回 RTCCF）：

```text
確認無誤，可以生成。
```

AI Agent 立即依循規格書輸出完整 1,500 字企劃長文：
- 📄 **完整示範成果**：請直接點閱參閱 [**`2026年度辦公室AI賦能推動計畫書_範本.md`**](./2026年度辦公室AI賦能推動計畫書_範本.md)。
- 📥 **匯出方式**：可直接在 AI Agent 對話介面匯出至線上文件另存為 Word/PDF，或由 Coding Agent 自動化編譯輸出為標準實體 `.docx` 或 `.pdf` 檔案交付主管！
