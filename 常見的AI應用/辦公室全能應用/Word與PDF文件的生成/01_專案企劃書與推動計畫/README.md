## 🏆 案例情境與業務痛點

企業非技術同仁在撰寫專案企劃書時，常面臨三大困擾：
1. **指令空泛，AI 產出不知所云**：直接告訴 AI「幫我寫企劃」，產出往往缺少推動對象、分階段時程與資安規範。
2. **缺乏審查機制，直接長篇大論**：AI 一口氣產生數千字，若方向偏差必須整篇重寫，浪費時間。
3. **沒有保存可重用規格資產**：缺少結構化的 `RTCCF.md` 範本，下次做類似企劃又得從頭描述需求。

## 🛠️ 實戰演練：口語條列 ➔ AI 儲存 `RTCCF.md` ＋ 輕量一問一答 ➔ 實體文件

學員不需要背誦複雜提示詞，只要用日常口語條列需求，交由 AI 自動補齊細節並透過 2~3 題「一問一答」確認大方向：

### 步驟 1：日常口語條列輸入（零門檻起手）

學員只要在 AI Agent 對話框中用最自然的條列式寫法輸入需求（最後加上「先存成 `RTCCF.md`、小細節你填好、大方向問 2~3 題就好」）：

```text
1. 我想寫一份給主管看的專案計畫書，主題是「公司今年推動非技術同仁使用 AI 辦公室工具」。
2. 內容希望包含計畫緣由、目標、推動步驟、資安跟預算，大概 1500 字，口吻要專業正式。
3. 先不要直接寫完整長文！請先幫我整理成 RTCCF 規格書，並直接儲存為 Markdown 檔案（RTCCF.md）。
4. 小細節請你直接用專業經驗幫我規劃好，只要針對大方向（例如章節大綱或重點指標）用「一問一答」跟我確認（一次問 1 題並給建議選項，不要問太細，最多問 2~3 題就好），每確認一題就幫我更新儲存 RTCCF.md！
```

---

### 步驟 2：AI 儲存 `RTCCF.md` ＋ 輕量一問一答（只問 2~3 題大方向）

AI Agent 接收口語條列後，會自動填妥字數分配與格式細節，直接儲存 **`RTCCF.md`** 交付審核，並拋出 2~3 題附帶選項的大方向問題（例如確認章節骨架與核心 KPI），每回答一題即自動更新儲存 `RTCCF.md`：

**【AI 產出並儲存的 `RTCCF.md` 範例】**

```markdown
## Role
你是一位資深企業營運規劃師，擅長撰寫結構嚴謹、條理分明的正式公務企劃書。

## Task
請幫我撰寫一份完整的「2026 年度辦公室 AI 賦能推動計畫書」，準備提交給高階主管核閱。

## Context
- 核心目標：引進主流 AI Agent 辦公室工具，協助非技術同仁處理公文、試算表、簡報與資訊圖表，節省 40% 行政工時。
- 推動對象：全體非技術同仁（約 80 人）。

## Constraint
- 必須包含：計畫緣起、KPI 目標、分階段時程、資安與去識別化規範、預算配置、預期成效。
- 語言：繁體中文，公務正式口吻，字數約 1,500 字。
- 執行限制：小細節依專業慣例自動補齊，僅針對章節大綱與核心指標透過「一問一答（一次 1 題、附選項、最多 2~3 題）」確認，確認後同步更新本 `RTCCF.md` 再產出全文。

## Format
- 階層標題（Markdown #、##、###）、標準三欄表格。
```

**【AI 透過一問一答確認的大方向預檢總覽】**

![專案計畫書架構規格書](./images/專案計畫書架構規格書.svg)

> 👤 **輕量 Human-in-the-Loop（不問太細）**：AI 主動附上建議選項（如 A/B/C），學員只要花 30 秒回答 2~3 題確認 6 大章節骨架與推動對象等大方向，AI 即會把確認結果寫回 **`RTCCF.md`**；日後要寫同類企劃時，直接套用這份 `.md` 即可！

---

### 步驟 3：人類確認放行 ➔ 正式生成 Word (.docx) 與 PDF (.pdf)

一問一答完成且打開確認定稿後的 `RTCCF.md` 無誤，直接發送放行指令：

```text
RTCCF.md 規格確認無誤，請正式生成完整企劃書！
```

AI Agent 立即依循規格書輸出完整 1,500 字企劃長文：
- 📄 **完整示範成果**：請直接點閱參閱 [**`2026年度辦公室AI賦能推動計畫書_範本.md`**](./2026年度辦公室AI賦能推動計畫書_範本.md)。
- 📥 **匯出方式**：可直接在 AI Agent 對話介面匯出至線上文件另存為 Word/PDF，或由 Coding Agent 自動化編譯輸出為標準實體 `.docx` 或 `.pdf` 檔案交付主管！
