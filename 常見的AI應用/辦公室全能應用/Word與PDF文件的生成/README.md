# Word (.docx) 與 PDF (.pdf) 文件生成模組
## 🚀 AI Agent 公文、企劃與報告實戰

> ### 🎯 模組核心目標
> 
> 非技術同仁常面臨公文排版、專案企劃書與法規指引撰寫的繁瑣流程。本模組全面導入 **雙階段 Markdown 審核閉環機制**：
> 
> 1. **零門檻日常口語交辦**：白話口述需求或直接上傳內部規章 PDF。
> 2. **AI 規格化工作流**：AI 自動生成 RTCCF 任務結構（**強制存為 `工作流.md`**，人類初審確認後傳遞）。
> 3. **文件架構規格書**：AI 預檢章節骨架、字數規劃與合規防線（**強制存為 `規格書.md`**，作為終審驗收基準）。
> 4. **正式生成實體文件**：人類確認「審核通過」放行後，AI Agent 正式匯出 **Word (.docx)** 與 **PDF (.pdf)**！

## 📥 AI Agent 匯出 Word (.docx) 與 PDF (.pdf) 指南

1. **對話介面匯出**：在各主流 AI Agent 對話介面，點選匯出至線上文件或直接複製 Markdown，貼入 Word 保留完整階層排版，並可另存為 PDF。
2. **自主代理 Coding Agent**：可指示 AI Agent 直接讀取工作區內的 `.md` 檔案，透過自動化腳本編譯輸出為標準排版之 `.docx` 或 `.pdf` 實體檔案。
