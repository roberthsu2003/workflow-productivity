# Word (.docx) 與 PDF (.pdf) 文件生成模組
## 🚀 AI Agent 公文、企劃與報告實戰

> **模組目標**：非技術同仁常面臨公文排版、專案企劃書與法規指引撰寫的繁瑣流程。本模組示範如何透過**「白話自然語言 ➔ RTCCF 提示詞（強制存為 `.md`）➔ 文件審核卡片（人機協商）➔ 正式匯出 Word (.docx) 或 PDF (.pdf)」**，建立高嚴謹度、高效率的公務文件產出閉查。

---

## 🧭 人機協作標準工作流（Human-in-the-Loop）

```mermaid
flowchart LR
    A["① 學生日常口語\n(自然語言輸入)"] --> B["② AI Agent 轉化為\nRTCCF Prompt\n(強制儲存為 .md 檔)"]
    B --> C["③ 輸出【文件審核卡片】\n(章節骨架/字數/合規防線)"]
    C --> D{"④ 人類核准確認\n(回覆：審核通過)"}
    D -->|核准後| E["⑤ 產出完整公文\n➔ 匯出 .docx / .pdf"]
```

## 📥 AI Agent 匯出 Word (.docx) 與 PDF (.pdf) 指南

1. **對話介面匯出**：在各主流 AI Agent 對話介面，點選匯出至線上文件或直接複製 Markdown，貼入 Word 保留完整階層排版，並可另存為 PDF。
2. **自主代理 Coding Agent**：可指示 AI Agent 直接讀取工作區內的 `.md` 檔案，透過自動化腳本編譯輸出為標準排版之 `.docx` 或 `.pdf` 實體檔案。
