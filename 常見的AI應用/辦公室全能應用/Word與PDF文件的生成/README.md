# Word (.docx) 與 PDF (.pdf) 文件生成模組
## 🚀 AI Agent 公文、企劃與報告實戰

> ### 🎯 模組核心目標
> 
> 非技術同仁常面臨公文排版、專案企劃書與法規指引撰寫的繁瑣流程。由於長篇文件與條款細節無法僅靠大綱確認，本模組全面導入 **「`RTCCF.md` 輕量問答 ＋ 先交付完整內文 `.md` 審核（Human-in-the-Loop）＋ 最後轉為 `.docx`/`.pdf`」四步閉環機制**：
> 
> 1. **口語條列交辦**：用簡單的 `1. 2. 3. 4.` 口語條列需求（或附上內部規章 PDF），要求 AI 先存為 **`RTCCF.md`** 並以一問一答確認大方向。
> 2. **AI 儲存 `RTCCF.md` ＋ 輕量一問一答（最多 2~3 題）**：AI 自動填妥細節並儲存為 **`RTCCF.md`**，只針對章節大綱或關鍵標準向人類確認 2~3 題（附建議選項），每確認一題就更新 `RTCCF.md`。
> 3. **先交付完整內文 `.md`（Human-in-the-Loop 內容審核）**：確認 `RTCCF.md` 後，AI **必須先將完整文件內文交付為 Markdown 檔案（`.md`）**，讓使用者逐段審核 AI 產出的文字與法規條款是否正確；若有偏差就持續透過對話進行 Human-in-the-Loop 編修直到定稿。
> 4. **轉換為正式實體文件**：`.md` 完整內文審核無誤後，才正式轉換並匯出 **Word (.docx)** 與 **PDF (.pdf)**！

本模組收錄兩大核心商業實戰範例，提供完整口語條列起手、輕量一問一答收斂流程與產出範本：

### 📄 01. 專案企劃書與推動計畫
- **範例連結**：[**01_專案企劃書與推動計畫/**](./01_專案企劃書與推動計畫/README.md)
- **實戰情境**：**口語條列直接發想**（零門檻日常白話）
- **業務場景**：口語條列交代重點，由 AI 規劃 1,500 字「2026 年度辦公室 AI 賦能推動計畫書」
- **人機協作交付成果**：
  - 口語條列輸入 ➔ AI 儲存 `RTCCF.md` 並以 2~3 題輕量一問一答確認大綱 ➔ **先交付 [`2026年度辦公室AI賦能推動計畫書_範本.md`](./01_專案企劃書與推動計畫/2026年度辦公室AI賦能推動計畫書_範本.md) 審核內文** ➔ 定稿轉檔 `.docx` / `.pdf`

### 📘 02. 企業差旅規章萃取員工指南
- **範例連結**：[**02_企業差旅規章萃取員工指南/**](./02_企業差旅規章萃取員工指南/README.md)
- **實戰情境**：**企業規章萃取**（上傳內部規章 PDF）
- **業務場景**：上傳內部 3 頁差旅管理辦法 PDF，零幻覺提煉差旅報銷標準與加班換休權益指南
- **人機協作交付成果**：
  - 上傳規章 PDF ＋ 口語條列 ➔ AI 儲存 `RTCCF.md` 並以 2~3 題輕量一問一答確認條款範圍 ➔ **先交付 [`員工差旅報銷與加班權益指南_範本.md`](./02_企業差旅規章萃取員工指南/員工差旅報銷與加班權益指南_範本.md) 核對條文與頁碼** ➔ 定稿轉檔 `.docx` / `.pdf`

> 💡 **進階延伸**：若手邊已有一份正式排版之 `.docx` 文件（如結業證書、聘書、公函），需要保護其既有格式、防止字數過長跑版並進行大量批次套印，請參考專案專題：👉 [**Word (.docx) 進階對齊與範本套印**](../../office辦公室應用進階的對齊/docx/README.md)。

## 📥 AI Agent 匯出 Word (.docx) 與 PDF (.pdf) 指南

1. **對話介面匯出**：在各主流 AI Agent 對話介面，點選匯出至線上文件或直接複製 Markdown，貼入 Word 保留完整階層排版，並可另存為 PDF。
2. **自主代理 Coding Agent**：可指示 AI Agent 直接讀取工作區內的 `.md` 檔案，透過自動化腳本編譯輸出為標準排版之 `.docx` 或 `.pdf` 實體檔案。
