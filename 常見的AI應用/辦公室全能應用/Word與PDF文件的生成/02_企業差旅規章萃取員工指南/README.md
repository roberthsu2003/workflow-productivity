# 實戰範例 02：企業差旅規章萃取員工指南（Word / PDF）

> 🟢 **適用範圍**：通用於各主流 AI Agent（Web 對話介面與 Coding Agent）  
> 🛠️ **核心工作流**：**口語條列 ＋ `RTCCF.md` 輕量問答 ＋ `.md` 內文審核 ➔ Word/PDF**（上傳規章 PDF ＋ 口語條列 ➔ `RTCCF.md` 2~3 題問答定案 ➔ **先交付完整內文 `.md` 核對條款** ➔ 定稿才轉為 `.docx`/`.pdf`）

## 🏆 案例情境與業務痛點

許多公司的人資規章長達數十頁、文字艱澀，同仁出差報銷或加班時經常：
1. **找不到關鍵規定**：搞不清楚高鐵搭乘資格、住宿上限是多少、出差幾天內要報銷。
2. **詢問人資造成負擔**：重複問題天天問，耗費人資大量答覆時間。
3. **AI 隨意回答產生幻覺**：若沒有上傳真實規章 PDF，AI 會自行瞎掰外部法規，造成內部違規風險。

## 🛠️ 實戰演練：口語條列 ➔ AI 儲存 `RTCCF.md` ＋ 輕量一問一答 ➔ 實體文件

學員不需要背誦複雜提示詞，只要上傳 PDF 並用日常口語條列需求，交由 AI 整理細節並透過 2~3 題「一問一答」確認大方向：

### 步驟 1：日常口語條列輸入（零門檻起手）

在 Claude、ChatGPT、Gemini 點選「**＋ 上傳檔案**」上傳 [`素材_企業內部規章_差旅與加班管理規範.pdf`](./素材_企業內部規章_差旅與加班管理規範.pdf)（Antigravity 則直接指定檔案路徑），並輸入日常條列式需求：

```text
1. 請根據我上傳的差旅規範 PDF，幫我寫一份給全體員工看的「出差報銷與加班權益指南」Word 檔草案。
2. 裡面要把大家最常問的交通、住宿、膳雜費上限、幾天內要報銷、還有加班換休規定寫清楚，並且一定要照 PDF 內容寫、不能自己亂編。
3. 先不要直接寫出整篇指南！請先幫我整理成 RTCCF 規格書，並直接儲存為 Markdown 檔案（RTCCF.md）。
4. 小細節請你直接依 PDF 幫我規劃好，只要針對大方向（例如指南章節結構與萃取出的津貼標準）用「一問一答」跟我確認（一次問 1 題並給建議選項，不要問太細，最多問 2~3 題就好），每確認一題就幫我更新儲存 RTCCF.md！
```

---

### 步驟 2：與 AI 進行 2~3 題輕量一問一答（動態收斂 `RTCCF.md`）

因為每份規章重點與現場需求不同，後續對話內容由現場互動決定，學員只需把握兩個重點：
1. **AI 自動建立首版 `RTCCF.md`**：送出後 AI 會依 PDF 補齊「嚴禁臆測外部法規、標註頁碼」等規範，並將規格儲存為 `RTCCF.md`。
2. **回答 2~3 題大方向問題**：AI 會每次問 1 題（附建議選項 A/B/C，例如確認指南章節架構與津貼標準），學員只需選擇或簡單補充，AI 即同步更新儲存 `RTCCF.md`。

---

### 步驟 3：確認 `RTCCF.md` 定案 ➔ 先交付完整內文 `.md`（Human-in-the-Loop 核對條款）

回答完 2~3 題並打開確認定稿後的 `RTCCF.md` 無誤，**先要求 AI 交付完整員工指南的 Markdown 檔案**，用來核對 AI 萃取的規章金額與頁碼對不對：

```text
RTCCF.md 規格確認無誤，請先依規格產出完整員工指南並儲存為 Markdown 檔案讓我審核！
```

- 📄 **示範產出參考**：[**`員工差旅報銷與加班權益指南_範本.md`**](./員工差旅報銷與加班權益指南_範本.md)
- 🔍 **審核重點**：打開 `.md` 檔逐項比對車資上限、住宿費、報銷時效與 PDF 頁碼；若有疏漏或幻覺，直接透過對話請 AI 修改 `.md` 檔直到確認無誤。

---

### 步驟 4：Markdown 內文審核完成 ➔ 轉換為 Word (.docx) 與 PDF (.pdf)

當 `.md` 內文與法規條款核對無誤後，才正式轉換為實體文件：

```text
Markdown 內文審核通過，請正式幫我轉換為 Word (.docx) 與 PDF (.pdf) 檔案！
```

- 📥 **匯出方式**：可在對話介面將定稿內容匯出至線上文件另存為 Word / PDF，或直接請 Coding Agent 依定稿 `.md` 編譯輸出標準實體 `.docx` / `.pdf` 檔案！
