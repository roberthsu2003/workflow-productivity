# 步驟 3：視覺設計審核卡片與視覺代碼生成提示詞

## 🛡️ 人機協商閘門：AI 產出的「資訊圖表視覺設計審核卡片」

在生成完整設計規格前，AI 主動呈現審核卡片：

```markdown
📋【資訊圖表視覺設計審核卡片 (Review Card)】—— 請使用者確認

【圖表規格概要】
• 圖表主題：傳統公務辦公 vs. 生成式 AI 協作賦能
• 排版風格：便當盒排版法 (Bento Box Grid)
• 閱讀動線：Z 型動線（由左至右、由上至下流暢閱讀）
• 推薦色票：高對比科技冷色（深藍底 `#0F172A` + 數據螢光綠 `#10B981` + 重點琥珀黃 `#F59E0B`）

【4 大模組方塊預覽】
┌────────────────────────┬────────────────────────┐
│ 模組 1：大數據量化成效 │ 模組 2：工作流程縮減   │
│ • 節省 70% 行政工時    │ • 傳統 5 步 ➔ AI 2 步  │
├────────────────────────┼────────────────────────┤
│ 模組 3：五大格式全覆蓋 │ 模組 4：資安三大信任防線│
│ • Word/Excel/PPT/PDF   │ • 查核、分流、責任確認 │
└────────────────────────┴────────────────────────┘

👉 請確認此版面格局與內容模組是否符合您的需求。若確認可以，請回覆：【審核通過，請展開設計規格】，或回覆修改指示。
```

---

## 💬 人類核准指令

```text
審核通過，請展開設計規格。
```

---

## 📥 落地產出

確認後，AI 輸出完整版面規格書，並產出 HTML/SVG 代碼或 Canva 排版文字：
- **Claude.ai**：Artifacts 面板即時渲染互動卡片。
- **ChatGPT / Gemini**：產出 SVG 向量代碼或複製文案至 Canva / Gamma。
- **Google Antigravity**：直接編譯為本機 HTML 檔案。

完成成果展示請開啟：[**`便當盒視覺卡片_已完成.html`**](./便當盒視覺卡片_已完成.html)。
