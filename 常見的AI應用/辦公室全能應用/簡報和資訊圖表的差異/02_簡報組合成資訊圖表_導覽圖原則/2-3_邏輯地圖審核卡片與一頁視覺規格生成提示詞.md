# 步驟 3：邏輯地圖審核卡片與一頁視覺規格生成提示詞

## 🛡️ 人機協商閘門：AI 產出的「邏輯地圖審核卡片」

在展開詳細視覺規劃前，AI 呈現審核卡片：

```markdown
📋【簡報濃縮資訊地圖審核卡片 (Review Card)】—— 請使用者確認

【濃縮規格概要】
• 原簡報來源：20 頁「企業智慧辦公室賦能」投影片
• 濃縮目標：單頁 Bento Box 便當盒網格懶人包（讀者 30 秒吸收）
• 提煉之四大核心板塊：
  ┌────────────────────────────────────────────────────────┐
  │ 板塊 1（核心數據）：節省 40% 行政工時、0 元軟體授權    │
  ├────────────────────────────────────────────────────────┤
  │ 板塊 2（落地路徑）：法規防線 ➔ 種子培訓 ➔ 全員推廣     │
  ├────────────────────────────────────────────────────────┤
  │ 板塊 3（工具矩陣）：Word / Excel / PPT / 圖表 四合一   │
  ├────────────────────────────────────────────────────────┤
  │ 板塊 4（資安守則）：查核 Grounding、分流脫敏、責任確認  │
  └────────────────────────────────────────────────────────┘

👉 請確認此四大板塊是否涵蓋原簡報核心。若確認可以，請回覆：【審核通過，請產出視覺規格】。
```

---

## 💬 人類核准指令

```text
審核通過，請產出視覺規格。
```

---

## 📥 落地產出

確認後，AI 輸出具備色票與排版規格的 Markdown 規範書，亦可產出 HTML/SVG 代碼或貼入 Canva 製作精美單頁宣傳海報。
