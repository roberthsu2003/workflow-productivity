**白板照片 OCR 練習**：把 `實體白板專案討論與待辦筆記.png` 上傳到 Claude、ChatGPT 或 Gemini，輸入「*請辨識這張白板上的手寫待辦清單，依人員與日期整理成 Markdown 表格，並轉為試算表*」。

> 💡 **使用方式**：在 Claude.ai、ChatGPT、Gemini 對話框點「**＋ 上傳檔案**」附上素材；在 Google Antigravity 則直接指定檔案路徑。
