## 🚀 如何在課堂與自學中使用這些素材？

1. **上傳附件至 AI 平台（Claude / ChatGPT / Gemini）**：
   - 點選上方表格中欲練習的檔案名稱進行下載（例如 `.pdf`、`.docx` 或 `.xlsx`）。
   - 開啟 [Claude.ai](https://claude.ai/)、[ChatGPT](https://chatgpt.com/) 或 [Google Gemini](https://gemini.google.com/)，在對話框點選「**＋ 上傳檔案／迴紋針圖示**」附帶該檔案。
   - 依照各教學手冊中的 Prompt 進行人機協作練習。
2. **在 Google Antigravity 中使用**：
   - 直接於對話中指定專案目錄下的檔案路徑（例如：`常見的AI應用/辦公室全能應用/範例素材與偽資料/...`），Agent 會自動讀取並執行清洗與轉換。
3. **在多模態 AI 中上傳圖片 OCR**：
   - 下載 [實體白板專案討論與待辦筆記.png](./實體白板專案討論與待辦筆記.png)。
   - 在 AI 對話輸入框點選「**＋ 上傳檔案／圖片**」，選擇該圖檔。
   - 輸入指令：「*請辨識這張白板上的手寫待辦清單，依人員與日期整理成 Markdown 表格，並轉為試算表*」。
