# 步驟 3：數據風控審核卡片與正規 Excel 匯出提示詞

> 🛡️ **人機協作關鍵防線（Human-in-the-Loop）**：  
> 當處理真實商業數據（特別牽涉採購預算與金額）時，直接產生檔案極易發生「單價漏乘、品項漏列、數量判讀錯誤」。  
> 透過「數據風控審核卡片」，能在 5 秒內以肉眼完成驗證，建立絕對可靠的零失誤內控閉環。

---

## 🔍 一、AI 產出之「數據風控審核卡片」（預期展示）

```markdown
### 📋 【數據風控審核卡片】
- **處理檔案 / 來源**：通訊軟體零碎採購需求留言串（共 5 則訊息）
- **清洗成果**：已拆解為 **7 筆獨立明細資料**（多品項已拆分獨立列）
- **各部門採購小計核算**：
  1. `業務部` (王大明)：微軟藍牙滑鼠 × 2 = NT$ 1,700
  2. `行銷處` (小美)：咖啡豆 × 5 + 濾紙 × 3 = NT$ 2,100 + NT$ 360 = NT$ 2,460
  3. `人資處` (陳主任)：新人講義 × 30 = NT$ 2,550
  4. `IT 資訊處` (張工程師)：網路線 × 10 + 轉接頭 × 4 = NT$ 1,800 + NT$ 1,400 = NT$ 3,200
  5. `總經理室` (林秘書)：高山烏龍茶 × 2 = NT$ 2,400
- **全案採購預算總計**：`NT$ 12,310`（公式 `=SUM(G4:G10)`）
- **異常與風險提醒**：
  - 🚨 `IT 資訊處` 兩項物料標記為「非常緊急」，需求到貨日為明日（2026-04-10），建議優先發包！
  - ⚠️ 行銷處與人資處需求屬常態備品與定期培訓，建議合併於下週發票報支。
```

## 📋 二、【可一鍵複製提示詞】人類審核核准指令

```markdown
審核通過，金額與拆分品項完全正確！
請為我生成符合企業財務標準的 Excel 活頁簿：
1. 包含微軟正黑體、深藍色標題底紋、淺灰格線、斑馬交錯底色與千分位數值格式。
2. 小計必須保留公式 `=E{row}*F{row}`，底部合計保留 `=SUM(...)`。
3. 急迫度為「非常緊急」與「緊急」項目，請使用淺橘紅底色特別醒目標記。
4. 請輸出可直接下載之 .xlsx 檔案或生成 Python openpyxl 建立代碼。
```

## 🚀 三、四大 AI 平台實體 Excel (.xlsx) 取得方式

| 平台 | 匯出操作方式 |
| :--- | :--- |
| **Claude.ai** | Claude Artifacts 會即時渲染表格，點擊右上角「下載按鈕」即可存為 Excel；或在提示詞要求產出 Python openpyxl 代碼執行。 |
