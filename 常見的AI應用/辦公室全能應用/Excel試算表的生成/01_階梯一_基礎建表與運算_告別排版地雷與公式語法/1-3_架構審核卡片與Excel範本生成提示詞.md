# 🛡️ 步驟 1-3：架構審核卡片與 Excel 範本生成提示詞

> **核心機制**：  
> 人機協作的精髓在於「人類負責決策與驗收，AI 負責繁瑣生成」。  
> 在生成最終 `.xlsx` 之前，先透過「審核卡片」確認沒有合併儲存格、沒有純文字干擾數值運算、且小計與總計皆為動態公式。

---

## 🔍 審核卡片預檢重點（學員自我查核）

| 稽核項目 | 正確標準 | 常見人為/AI 錯誤 | 檢查結果 |
| :--- | :--- | :--- | :---: |
| **合併儲存格** | 明細資料列完全不合併，每列獨立一筆 | 為了美觀把同一個部門合併，導致無法篩選 | ✅ 通過 |
| **金額格式** | 純數值 + Excel 千分位標記 `#,##0` | 單元格填入 `NT$ 5,000` 或 `5000元` 導致公式失靈 | ✅ 通過 |
| **小計公式** | 儲存格內容為 `=G5*H5` 動態乘積 | 人工算好填入純數字 `10000`，改數量不會變動 | ✅ 通過 |
| **總計公式** | 儲存格內容為 `=SUM(I5:I14)` 動態加總 | 硬編碼或遺漏部分列範圍 | ✅ 通過 |

---

## 📋 發送確認核准指令給 AI（產出 .xlsx 活頁簿）

```markdown
審核卡片核對無誤！我確認：
1. 資料庫結構合格（完全無合併儲存格）。
2. 金額欄位已設定純數值與千分位。
3. 小計與總計皆配置正確公式。

請為我生成最終的標準 Excel 活頁簿（.xlsx 格式），請提供以下任一種產出方式：
1. 【ChatGPT / Claude / Gemini】提供可直接點擊下載的 .xlsx 檔案連結。
2. 【Antigravity / 本地端】提供完整的 Python openpyxl 生成腳本。
```

## 💾 各 AI 平台操作指南

1. **Claude**：點擊右側 Artifacts 面板，點選「Download」按鈕即可取得 `.xlsx`。
2. **ChatGPT (Plus / Team / Enterprise)**：ChatGPT 會啟用 Python 沙盒環境（Advanced Data Analysis），直接點擊輸出方塊中的「下載費用報銷核銷表.xlsx」連結。
3. **Gemini**：可要求 Gemini 匯出為 Google 試算表（Google Sheets），或提供 Python openpyxl 產生腳本。
4. **Antigravity**：自動執行 Python 腳本生成實體檔案，檔案直接存放於：
   - `01_階梯一_基礎建表與運算_告別排版地雷與公式語法/部門差旅與專案費用報銷表_已完成.xlsx`
