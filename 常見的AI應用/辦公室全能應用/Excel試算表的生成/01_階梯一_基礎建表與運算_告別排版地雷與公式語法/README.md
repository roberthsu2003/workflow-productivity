## 🏆 案例情境與業務痛點

非技術同仁在製作報銷表或各類清單時，最常踩入三大地雷被會計退件：
1. **隨意合併儲存格**：為了美觀把同部門合併，導致後續無法使用「資料篩選」與「排序」。
2. **文字干擾數值運算**：填入「NT$ 3,500 元」或夾帶「個/台/包」，導致 `=SUM()` 加總永遠是 0。
3. **計算機算死值硬編碼**：手動算好小計打上去，改了單價或數量，金額完全不會連動更新。

## 🛠️ 實戰演練：自然語言 ➔ RTCCF 交辦事項 ➔ 規格書 ➔ 實體 Excel

學員不必在多個檔案間切換，以下完整展示從白話日常口語到生成最終標準 Excel 表格的完整流程：

### 步驟 1：日常自然語言輸入（零門檻口述需求）

學員完全不需要背任何複雜函數，只要在對話框中輸入日常白話：

```text
你好，我是專案行政人員。主管請我做一份「2026 年度部門差旅與專案費用報銷核銷表」，讓同仁填寫並給會計審查。
我對 Excel 只有最基本概念，但我知道以前大家做表常犯毛病：亂合併儲存格導致不能篩選、金額填文字導致不能加總、小計用計算機算死值不會連動。
請扮演資深 Excel 顧問，幫我規劃符合資料庫標準（絕不合併明細儲存格）的欄位清單，設定純數值與千分位格式，配置小計乘積與 SUM 動態公式，並擬定 10 筆示範資料。
請先幫我把這段需求改寫成標準的 RTCCF 交辦事項（工作流），讓我儲存為 Markdown (.md) 檔案；並且先產出「架構審核規格書」給我確認，不要直接輸出 Excel。待我確認 Markdown 內容與架構後，請再依照該檔為我正式生成標準 .xlsx 檔案。
```

---

### 步驟 2：AI Agent 轉化為 RTCCF 交辦事項（⚠️ 強制儲存為 `工作流.md`）

AI Agent 接收口語後，自動結構化出標準交辦事項。**請學員第一時間將此內容儲存為 `費用報銷表_工作流.md` 檔案**：

```markdown
## Role
資深財務報銷顧問兼 Excel 資料庫架構師。

## Task
建立一份符合會計稽核標準的「2026 年度部門差旅與專案費用報銷核銷表」。

## Context
供全體專案成員填報、主管與會計審核，必須具備動態連動與資料庫二維純淨度。

## Constraint
1. 【嚴禁合併儲存格】：明細資料列每筆記錄獨立一行，確保可進行資料篩選與多重排序。
2. 【純數值與千分位】：單價、數量、小計必須為純整數數值，貨幣呈現設定為 `#,##0`。
3. 【動態公式連動】：小計配置公式 `=單價*數量`（`=G5*H5`），總計配置 `=SUM(I5:I14)`。
4. 執行限制：【第一步必須先產出審核規格書】，待使用者核准後再輸出 .xlsx。
5. 語言：繁體中文，專業規範。

## Format
欄位清單、格式定義、公式設定、10 筆示範資料。
```

> 👤 **人類初審**：使用者在本地或專案中檢視 `工作流.md`，確認欄位與防呆約束無誤後傳給 AI 執行。

---

### 步驟 4：人類終審放行 ➔ 正式生成標準 Excel (.xlsx)

使用者人眼核對 4 大會計稽核標準無誤後，發送放行指令：

```text
審核卡片核對無誤，請產出 .xlsx 活頁簿。
```

AI Agent 立即依循規格書輸出標準 Excel 檔案：
- 📄 **完整示範成果**：請直接點閱參閱 [**`部門差旅與專案費用報銷表_已完成.xlsx`**](./部門差旅與專案費用報銷表_已完成.xlsx)。
- 📥 **取得方式**：Claude 可由右側 Artifacts 面板下載、ChatGPT 可直接點選下載連結，或由 Coding Agent 自動透過 Python openpyxl 產出實體活頁簿！
