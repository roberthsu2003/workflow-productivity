# 步驟 3：架構審核卡片與 Excel 範本生成提示詞

> 🛡️ **人機協作關鍵防線（Human-in-the-Loop）**：  
> AI 絕不能擅自直接輸出檔案！必須先出具「架構審核卡片」，由人類肉眼 10 秒核對「欄位名稱」、「資料型別」、「公式連動」與「示範數值」，確認無誤後再下達生成指令。

---

## 🔍 一、AI 產出之「試算表架構審核卡片」（預期展示）

```markdown
### 📋 【試算表架構審核卡片】
- **專案名稱**：2026 數位轉型專案里程碑與預算進度管控表
- **規劃工作表數**：1 頁（專案總表）
- **欄位架構設計（共 12 欄）**：
  1. `任務編號` [文字, 自動對齊置中]
  2. `所屬部門` [文字, 支援篩選]
  3. `任務名稱` [文字, 左對齊]
  4. `負責人` [文字, 置中]
  5. `預計開始日` [日期, YYYY-MM-DD]
  6. `預計完成日` [日期, YYYY-MM-DD]
  7. `編列預算` [純數值, 格式: #,##0]
  8. `實際支出` [純數值, 格式: #,##0]
  9. `預算差異` [公式: =編列預算 - 實際支出]
  10. `進度` [百分比, 格式: 0%]
  11. `執行狀態` [文字, 下拉清單: 未開始/進行中/已完成/卡關延遲]
  12. `風險備註` [文字]
- **底部統計列規則**：
  - 總編列預算：`=SUM(G4:G9)` ➔ NT$ 930,000
  - 總實際支出：`=SUM(H4:H9)` ➔ NT$ 600,000
  - 總結餘差異：`=SUM(I4:I9)` ➔ NT$ 330,000
  - 全案平均進度：`=AVERAGE(J4:J9)` ➔ 55%
  - 預算執行率：`=H10/G10` ➔ 64.5%
- **異常與風控警示**：
  - TSK-02 核心資料庫遷移實際支出 (295,000) > 編列預算 (280,000)，差異為 -15,000，標記紅字並列為「卡關延遲」。
```

## 📋 二、【可一鍵複製提示詞】人類審核核准指令

```markdown
審核通過！請根據上述審核卡片的規劃架構：
1. 為我生成標準的 Excel 試算表（包含專業表頭深色底紋、白色粗體字、斑馬紋交錯底色、千分位數值格式與自動計算公式）。
2. 請提供可用 Python openpyxl 建立標準 .xlsx 的代碼，或直接提供試算表下載連結／可直接複製到 Excel 的結構化表格。
```

## 🚀 三、四大 AI 平台實體 Excel (.xlsx) 取得方式

| 平台 | 匯出操作方式 |
| :--- | :--- |
| **Claude.ai** | Claude 會透過 **Artifacts** 產生即時表格預覽，或點擊代碼區塊右上角的下載圖示即可下載 `.xlsx`；亦可要求執行 Python 腳本產出。 |
| **ChatGPT (Plus)** | ChatGPT 會自動啟動 **Advanced Data Analysis (Code Interpreter)**，直接產出藍色可點擊的 `下載 專案進度與預算追蹤管理表.xlsx` 檔案連結。 |
| **Google Gemini** | Gemini 支援表格右上方「**匯出至試算表 (Export to Sheets)**」按鈕，可一鍵開啟 Google 試算表並另存為 `.xlsx`。 |
| **Google Antigravity** | 本地 Coding Agent，會自動執行 Python `openpyxl` 腳本，直接於工作區目錄中產生實體 `.xlsx` 檔案！ |
