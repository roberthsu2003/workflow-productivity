# 步驟 2：AI 產出之 RTCCF 單據清洗提示詞

> 💾 **【人機協作第一步：請學員將此 RTCCF Prompt 強制儲存為 `.md` 檔案備用】**  
> *（⚠️ 切勿存為 Word 或一般記事本，唯有 `.md` 能在跨平台協作中保全跨來源勾稽約束與數值純數字規範）*

```markdown
## Role
資深財務審計分析師。

## Task
以上傳之《各部門2026年Q2辦公耗材與IT設備採購申請彙整清單》為唯一單一事實依據，全面提取所有採購項目，建立零死角的財務預算審核表。

## Context
來源為已上傳之採購單據與多格式跨部門紀錄，避免財務部門手工謄寫造成漏筆或匯率換算錯誤。

## Constraint
1. 嚴格依據上傳內容提取，嚴禁虛構數值。
2. 數值欄位（單價、數量、總額）必須全為純數字，不可夾雜符號或中文單位。
3. 外幣品項必須標註匯率換算依據。
4. 產出前必須提供【數據風控審核卡片】，列出數據總筆數、預估總預算與異常品項。
5. 經人類回覆「確認無誤」後才產出完整 Markdown 表格。

## Format
審核卡片 ➔ 人機確認 ➔ 匯出用 Markdown 表格 ➔ 匯出 Excel 指引。
```
