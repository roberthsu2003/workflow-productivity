# 步驟 3：數據風控審核卡片與採購總表匯出提示詞

## 🛡️ 人機協商閘門：AI 產出的「數據萃取審核卡片」

在產出 Excel 表格前，AI 主動呈現卡片供人類查核：

```markdown
📋【數據萃取審核卡片 (Review Card)】—— 請使用者確認

【資料來源摘要】
• 涵蓋來源：2026年Q2採購申請彙整清單（含 Excel、CSV、單據對話）
• 提取項目數：共 8 筆部門提報（涵蓋人體工學椅、雙螢幕支架、伺服器硬碟、碎紙機等）
• 估算總金額：NT$ 98,400 元整

【核心財務數值預檢】
• 資訊技術部：3 項，合計 NT$ 54,900 元
• 行政總務部：1 項，合計 NT$ 19,200 元
• 行銷公關處：1 項，合計 NT$ 2,500 元
• 人力資源處：1 項，合計 NT$ 6,500 元
• 財務會計處：1 項，合計 NT$ 14,500 元
• 業務發展部：1 項，合計 NT$ 6,900 元

【⚠️ 匯率與風控提醒】
• 資訊部提報之「伺服器備用硬碟 4TB」單價為 USD 200，已依公司規定以匯率 32 換算為 NT$ 6,400 元。

👉 若數據無誤，請回覆：【審核通過，請生成試算表表格】。
```
