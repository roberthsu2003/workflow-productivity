# 🛡️ 步驟 2-3：防呆審核卡片與 Excel 範本生成提示詞

> **核心機制**：  
> 在生成最終包含下拉選單與色彩格式的 `.xlsx` 檔案前，先透過審核卡片確認驗證清單與顏色條件規則，避免格式跑版或條件式格式互相衝突。

---

## 🔍 審核卡片預檢重點（學員自我查核）

| 稽核項目 | 正確標準 | 常見人為/AI 錯誤 | 檢查結果 |
| :--- | :--- | :--- | :---: |
| **資料驗證 (下拉清單)** | 鎖定在 K 欄，包含「未開始,進行中,已完成,卡關延遲」 | 漏設防呆，允許使用者隨意輸入自由文字 | ✅ 通過 |
| **超支條件格式** | `預算差異 < 0` 時自動標註淡紅底深紅字 | 顏色過深導致文字看不清楚，或公式參照欄位錯誤 | ✅ 通過 |
| **完成/延遲顏色** | 「已完成」綠色、「卡關延遲」黃色 | 多重條件式格式覆蓋順序混亂，導致顏色不顯示 | ✅ 通過 |
| **動態預算差異** | 儲存格內容為 `=G4-H4` 動態相減 | 人工手動計算死值填入 | ✅ 通過 |

---

## 📋 發送確認核准指令給 AI（產出含防呆特性的 .xlsx）

```markdown
防呆與警示審核卡片核對無誤！我確認：
1. 資料驗證下拉選單設定完整（4 種合法狀態）。
2. 超支、完成、延遲之條件式格式設定規則正確。
3. 預算差異與彙總公式配置無誤。

請為我生成最終的標準 Excel 活頁簿（.xlsx 格式），請確保在 Excel 打開時能直接看到下拉箭頭與條件變色效果！
提供可直接下載的 .xlsx 檔案或 Python openpyxl 完整腳本。
```

## 💾 本地端與平台交付成果路徑

- 實體 Excel 檔案位置：
  - `02_階梯二_資料防呆與自動警示_告別手動檢查與眼花抓漏/專案里程碑與預算進度管控表_已完成.xlsx`
- 打開檔案後之檢驗要點：
  1. 點擊 K 欄（執行狀態）儲存格，右上角會出現**下拉選單箭頭**。
  2. 觀察 I 欄（預算差異），TSK-02（核心資料庫遷移）因超支 15,000 元（-15,000），自動以**淡紅底深紅粗體字**警示！
  3. 觀察 K 欄（執行狀態），TSK-01「已完成」自動顯示為**淡綠底深綠字**，TSK-02「卡關延遲」自動顯示為**淡黃底深黃字**！
