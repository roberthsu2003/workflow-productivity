# 🟡 階梯二：資料防呆與自動警示（告別手動檢查與眼花抓漏）
## 🎯 從手動看漏到智慧自動化：專案時程與預算超支警示表

> **核心學習定位**：  
> 當表格要發給多人填報時，最令人頭痛的就是「每個人填寫內容不一致」與「主管必須用肉眼一行行找誰超支、誰進度落後」。  
> 過去要在 Excel 設定「下拉選單」與「條件式格式化」，步驟繁瑣且常因參照鎖定 `$A1` 錯誤導致全表亂跳色。  
> **現在，你只要告訴 AI 管理的規則（限定狀態有哪些、超支多少要亮紅燈），AI 一鍵幫你把驗證防呆與色彩預警直接寫入 Excel！**

---

## ⚡ 學員有感痛點對比表（手動 vs. AI 協作）

| 檢驗維度 | 傳統手動痛點（以前好痛苦 😭） | AI 協作新體驗（現在好輕鬆 ✨） |
| :--- | :--- | :--- |
| **輸入格式混亂** | 同事填寫狀態五花八門（「OK」、「差不多」、「卡住」），後續完全無法分類統計。 | AI 自動配置**資料驗證（Data Validation）下拉選單**，只能點選限定選項，杜絕輸入錯誤。 |
| **超支與延遲檢查** | 主管拿紅筆或黃色螢光筆在螢幕上一行行看數字，眼花看漏導致預算失控。 | AI 自動設置**條件式格式化（Conditional Formatting）**，超支自動亮紅燈、延遲亮黃燈、完工亮綠燈。 |
| **條件格式設定難度** | 條件式格式介面層級極深，稍微選錯公式範圍或沒鎖定欄位，全表格式大崩潰。 | 只要口語描述「小於 0 變淺紅底深紅字」，AI 精準配置底層規則與配色色碼。 |
| **管理回報效率** | 週會前要手動花半小時把異常項目標黃標紅，費時又沒價值。 | 數據一更新，警示燈號自動即時切換，專案狀態一目了然！ |
