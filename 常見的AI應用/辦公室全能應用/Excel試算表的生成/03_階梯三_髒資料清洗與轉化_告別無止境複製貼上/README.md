## 🏆 案例情境與業務痛點

真實世界中的資料往往殘缺不全：
1. **非結構文字轉表格耗時**：收到主管在通訊軟體丟來的採購清單，只能一格格複製貼上。
2. **夾帶單位無法計算**：資料夾帶「15 包」、「3,500 元」，導致 Excel 無法運算。
3. **日期格式五花八門**：民國年、斜線、中文月日混雜，無法正常排序與篩選。

## 🛠️ 實戰演練：自然語言 ➔ RTCCF 交辦事項 ➔ 規格書 ➔ 實體 Excel

學員不必在多個檔案間切換，以下完整展示從非結構文字到生成乾淨 Excel 表格的完整流程：

### 步驟 1：日常自然語言輸入（零門檻口述需求）

學員將雜亂文字貼入對話框，並輸入日常白話：

```text
這是一段大家在通訊軟體留言的零散採購清單，裡面日期格式亂七八糟（有民國年、有中文月日），數量和金額還夾帶「包、台、元」等文字單位，導致不能算數。
請扮演資料清洗專家，幫我把雜質字元剔除還原為純數字，日期全部轉成西元標準 YYYY-MM-DD，自動補上標準流水單號 PR-2026-001，並加上預設「待審核」狀態欄。
請先幫我把這段需求改寫成標準的 RTCCF 交辦事項（工作流），讓我儲存為 Markdown (.md) 檔案；並且先產出「清洗轉換審核規格書」讓我檢查前後對比，不要直接輸出 Excel。待我確認 Markdown 內容與架構後，請再依照該檔為我正式生成標準 .xlsx 檔案。
```

---

### 步驟 2：AI Agent 轉化為 RTCCF 交辦事項（⚠️ 強制儲存為 `工作流.md`）

AI Agent 接收口語與資料後，自動結構化出標準交辦事項。**請學員第一時間將此內容儲存為 `資料清洗_工作流.md` 檔案**：

```markdown
## Role
資深資料工程師兼資料庫清洗規範顧問。

## Task
將提供的非結構化採購文字與髒 CSV，清洗並轉化為符合二維資料庫標準的「各部門採購需求規範審核表」。

## Context
整合各部門零星採購需求，供採購部審批與會計核銷。

## Constraint
1. 【去除文字雜質】：剔除「包、台、元」等字元，單價與數量還原為純整數值。
2. 【日期標準化】：統一轉換為國際標準 ISO-8601（`YYYY-MM-DD`）。
3. 【補齊流水單號】：依序編列標準單號（PR-2026-001...）並新增審核狀態欄。
4. 執行限制：【第一步必須先產出審核規格書】，待使用者核准後再輸出 .xlsx。
5. 語言：繁體中文，清楚明確。

## Format
清洗前後對比、欄位清單、正規化範例。
```

> 👤 **人類初審**：使用者在本地或專案中檢視 `工作流.md`，確認清洗規則符合公司規範後傳給 AI 執行。

---

### 步驟 3：傳遞工作流 ➔ AI Agent 輸出「清洗轉換規則審核規格書」（⚠️ 亦存為 `規格書.md`）

AI Agent 接獲交辦事項後，先輸出清洗規則前後對比規格書供人類查核：

![階梯三清洗轉換規則審核規格書](./images/階梯三_清洗轉換規則審核規格書.svg)

---

### 步驟 4：人類終審放行 ➔ 正式生成乾淨 Excel (.xlsx)

使用者人眼核對數值還原與標準日期格式無誤後，發送放行指令：

```text
審核卡片核對無誤，請產出 .xlsx 活頁簿。
```

AI Agent 立即依循規格書輸出標準 Excel 檔案：
- 📄 **完整示範成果**：請直接點閱參閱 [**`各部門採購需求規範審核表_已完成.xlsx`**](./各部門採購需求規範審核表_已完成.xlsx)。
- 📥 **取得方式**：Claude 可由右側 Artifacts 面板下載、ChatGPT 可直接點選下載連結，或由 Coding Agent 自動透過 Python openpyxl 產出實體活頁簿！
