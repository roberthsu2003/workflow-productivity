# 🛡️ 步驟 3-3：數據清洗審核卡片與正規 Excel 匯出提示詞

> **核心機制**：  
> 資料清洗最怕「洗錯數字」或「欄位對錯」。透過審核卡片對比清洗前後的樣貌，確認無誤後再匯出標準 Excel。

---

## 🔍 資料清洗審核卡片（清洗前後對照範例）

| 原始髒資料樣貌（Source） | AI 清洗後標準欄位（Sanitized） | 轉換重點與風控 |
| :--- | :--- | :--- |
| 「羅技無線滑鼠 15 支，單價大概 650 元」 | 數量：`15` ｜ 單價：`650` ｜ 小計：`=F4*G4` (9,750) | 剝離「支」與「元」，建立乘積公式 |
| 「每台 NT$ 13,500」 | 單價：`13500`（格式為 `#,##0`） | 移除貨幣前綴與文字，保留純數值 |
| 「民國115年4月12日」 | 交付日期：`2026-04-12` | 校正民國年與中文格式為 ISO-8601 |

---

## 📋 發送確認核准指令給 AI（產出清洗後 .xlsx）

```markdown
資料清洗前後對比審核無誤！我確認：
1. 文字雜訊與單位符號已徹底剔除。
2. 數值與日期格式皆已標準化。
3. 預估總金額已正確套用乘積公式。

請為我生成最終清洗完畢的標準 Excel 活頁簿（.xlsx 格式）：
提供可直接下載的 .xlsx 檔案或 Python openpyxl 完整腳本。
```

## 💾 本地端與平台交付成果路徑

- 實體 Excel 檔案位置：
  - `03_階梯三_髒資料清洗與轉化_告別無止境複製貼上/各部門採購需求規範審核表_已完成.xlsx`
- 打開檔案後之檢驗要點：
  1. 數量與單價皆為乾淨整數，顯示千分位。
  2. 點擊 H 欄（預估總金額），公式為 `=F4*G4`。
  3. 底部有 `=SUM(H4:H13)` 動態合計總申購金額。
