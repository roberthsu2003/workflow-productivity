## 🏆 案例情境與業務痛點

面對董事會、總經理與跨部門副總，上班族常踩入三大匯報雷區：
1. **滿螢幕呆板數字無人想看**：主管只有 10 秒時間，不想看一格格密密麻麻的小表格。
2. **圖表配色刺眼沒有商務感**：只會直接按預設插入圖表，紅配綠非常突兀，缺乏專業水準。
3. **缺乏高階經營洞察**：做完圖表答不出「所以這張圖代表什麼？」，無法給出經營決策建議。

## 🛠️ 實戰演練：自然語言 ➔ RTCCF 交辦事項 ➔ 規格書 ➔ 實體 Excel 看板

學員不必在多個檔案間切換，以下完整展示從白話日常口語到生成最終主管級商業看板的完整流程：

### 步驟 1：日常自然語言輸入（零門檻口述需求）

學員只要在對話框中輸入日常白話：

```text
我要向總經理與各部門副總報告第一季全通路營運表現。
請不要給我密密麻麻的數字，幫我規劃一個像麥肯錫那樣沉穩深藍科技風的「C-Level 商業儀表板（Dashboard）」。
最上面要放 4 張獨立的 KPI 大數字卡片（總營收、總毛利、平均客單價、最佳通路），中間放通路營收與毛利率圖表，底下直接幫我寫出「3 大業績亮點與 2 大風控建議」，讓我報告時可以直接當講稿。
請先幫我把這段需求改寫成標準的 RTCCF 交辦事項（工作流），讓我儲存為 Markdown (.md) 檔案；並且先產出「儀表板審核規格書」給我確認，不要直接輸出 Excel。待我確認 Markdown 內容與架構後，請再依照該檔為我正式生成標準 .xlsx 商業看板。
```

---

### 步驟 2：AI Agent 轉化為 RTCCF 交辦事項（⚠️ 強制儲存為 `工作流.md`）

AI Agent 接收口語後，自動結構化出標準交辦事項。**請學員第一時間將此內容儲存為 `商業儀表板_工作流.md` 檔案**：

```markdown
## Role
麥肯錫等級高階商業智慧顧問兼 Excel 視覺化架構師。

## Task
建立三層式結構（視覺看板層 ➔ 彙總層 ➔ 明細層）之「2026 全通路營運績效與銷售分析儀表板」。

## Context
供總經理與董事會審閱，要求 10 秒內掌握全局，具備高階決策自明性。

## Constraint
1. 【三層式結構】：視覺展示層（Dashboard）完全獨立，不與原始數據混雜。
2. 【4 大 KPI 卡片】：頂部獨立配置營收、毛利、客單價、最佳通路卡片。
3. 【高階經營洞察】：自動生成 3 大業務亮點與 2 大風險防範建議。
4. 執行限制：【第一步必須先產出審核規格書】，待使用者核准後再輸出 .xlsx。
5. 語言：繁體中文，專業俐落。

## Format
三層工作表規劃、KPI 卡片佈局、圖表形式、高階洞察摘要。
```

> 👤 **人類初審**：使用者在本地或專案中檢視 `工作流.md`，確認 KPI 定義與匯報風格後傳給 AI 執行。

---

### 步驟 3：傳遞工作流 ➔ AI Agent 輸出「儀表板佈局審核規格書」（⚠️ 亦存為 `規格書.md`）

AI Agent 接獲交辦事項後，先輸出看板佈局規格書供人類查核：

![階梯五儀表板佈局審核規格書](./images/階梯五_儀表板佈局審核規格書.svg)

---

### 步驟 4：人類終審放行 ➔ 正式生成商業儀表板 Excel (.xlsx)

使用者人眼核對 4 大 KPI 卡片與高階洞察摘要無誤後，發送放行指令：

```text
審核卡片核對無誤，請產出 .xlsx 活頁簿。
```

AI Agent 立即依循規格書輸出標準 Excel 檔案：
- 📄 **完整示範成果**：請直接點閱參閱 [**`2026全通路營運績效與銷售分析儀表板_已完成.xlsx`**](./2026全通路營運績效與銷售分析儀表板_已完成.xlsx)。
- 📥 **取得方式**：Claude 可由右側 Artifacts 面板下載、ChatGPT 可直接點選下載連結，或由 Coding Agent 自動透過 Python openpyxl 產出實體活頁簿！
