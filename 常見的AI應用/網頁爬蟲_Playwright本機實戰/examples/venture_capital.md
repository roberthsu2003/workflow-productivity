# 💼 創投（VC）實務範例：本機 Playwright 動態網頁調研與截圖存證

> 🛠️ **核心工具**：桌面版 AI（Claude Desktop / ChatGPT 桌面版 / Antigravity）＋ 本機 **Playwright**  
> 📌 **適用情境**：突破雲端白名單限制、抓取無公開 API 的新創官網、動態 JS 渲染網頁截圖、關鍵技術情報蒐集

---

## 💡 創投調研痛點與本機 Playwright 解法

1. **新創官網無公開 API**：大量採用 React / Vue / Webflow 動態渲染，傳統靜態抓取只會拿到空白骨架。
2. **雲端防爬阻擋**：海外雲端 AI IP 經常被 Cloudflare 擋下，改用本機真實電腦 IP 即可正常瀏覽。
3. **網頁即時存證**：利用 Playwright `page.screenshot(full_page=True)` 自動滾動並保留高解析度全頁截圖作為 DD 紀錄。

---

## 📝 實作驗證任務（直接貼給桌面版 AI 使用）

### 🔹 任務 A：動態產業新聞爬取與重點整理
```text
請使用本機 Playwright 開啟科技新報（https://technews.tw）：
1. 搜尋過去一週關於「半導體封裝」或「CPO 矽光子」的新聞報導。
2. 擷取前 3 筆資料的「標題」、「發布日期」與「摘要重點」。
3. 將結果整理成 Markdown 表格輸出，並給出 2 點投資人關注重點分析。
```

---

### 🔹 任務 B：新創官網 JS 滾動載入與視覺截圖存證
```text
請使用本機 Playwright 開啟指定的新創公司官網（例如 https://example.com）：
1. 開啟網頁並自動向下滾動頁面，確保所有動態 JavaScript 區塊與圖片完全載入。
2. 讀取頁面完整文字，並將首頁儲存為高解析度全頁截圖（startup_snapshot.png）。
3. 提煉出該公司的「核心產品/技術」、「應用市場」與「團隊優勢」。
4. 依據上述資訊，列出 3 個訪談創辦團隊時建議詢問的 DD 關鍵問題。
```

---

### 🔹 任務 C：雙標的競品快速橫向對比（DD 初階比對）
```text
請使用本機 Playwright 分別造訪以下兩家公司官網：
- 標的 A 官網：[貼入標的 A 網址]
- 標的 B 官網：[貼入標的 B 網址]

任務要求：
1. 分別擷取兩家公司的「核心產品訴求」、「目標客群（B2B / B2C）」與「定價／商業模式」。
2. 製作 Markdown 橫向對比表格。
3. 點評兩者在市場定位上的差異與潛在競爭護城河。
```
