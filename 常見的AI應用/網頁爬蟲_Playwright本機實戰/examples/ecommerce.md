# 🛒 電商與零售實戰範例：本機 Playwright 爬蟲、競品比價與登入互動

> 🛠️ **核心工具**：桌面版 AI（Claude Desktop / ChatGPT 桌面版 / Antigravity）＋ 本機 **Playwright**  
> 📌 **適用情境**：公開牌告查詢、動態電商商品比價、競品規格矩陣分析、需會員登入之受保護頁面存取

---

## 💡 為什麼電商爬蟲一定要用「桌面版 AI ＋ 本機 Playwright」？

多數電商平台（如 momo、PChome、蝦皮）擁有複雜的前端 JavaScript 渲染與防爬蟲機制，雲端網頁版 AI 幾乎都會被阻擋。透過您電腦本機的 **Playwright 真實瀏覽器**：
- **動態模擬人類瀏覽**：自動在搜尋框輸入關鍵字、等待商品清單載入、解析價格與規格。
- **人機協作安全登入**：遇到需要帳號密碼或手機 2FA 驗證的會員頁，可先由人工在彈出的瀏覽器視窗登入，再交由 Playwright 接續抓取訂單或會員專屬價格。

---

## 📝 實作演練範例（直接貼給桌面版 AI 使用）

### 🔹 範例一：公開金融表格爬取（台灣銀行牌告匯率）
```text
請使用本機 Playwright 開啟台灣銀行牌告匯率網頁（https://rate.bot.com.tw）：
1. 查詢今日美金 (USD)、日圓 (JPY) 與歐元 (EUR) 對新台幣的「現鈔買入」與「現鈔賣出』匯率。
2. 將結果整理成 Markdown 表格輸出。
```

---

### 🔹 範例二：動態搜尋與商品比價（momo 購物網）
```text
請使用本機 Playwright 開啟 momo 購物網（https://www.momoshop.com.tw）：
1. 在搜尋框中輸入「毛寶洗碗精」並進行搜尋，等待商品列表渲染完成。
2. 收集搜尋結果前 5 筆商品的「商品名稱」與「促銷價格」。
3. 將結果整理成 Markdown 表格輸出。
```

---

### 🔹 範例三：競品市場調查與交叉對比分析
```text
請使用本機 Playwright 開啟 momo 購物網（https://www.momoshop.com.tw）：
1. 搜尋「毛寶 小蘇打洗碗精 無香精」，記錄我方產品的促銷價格與規格。
2. 重新搜尋「小蘇打洗碗精」，尋找其他競品（例如橘子工坊、茶籽堂、淨毒五郎等）。
3. 收集前 5 筆競品的「品牌名稱」、「商品名稱」、「容量」與「促銷價格」。
4. 製作 Markdown 交叉對比表格，並針對價格競爭力提供建議。
```

---

### 🔹 範例四：登入型網站操作（人機協作半自動登入）

> ⚠️ **關鍵設定提示**：必須保持預設的**有頭模式（不可加上 `--headless`）**，瀏覽器視窗才會顯示在螢幕上讓您手動輸入帳密與驗證碼。

```text
請使用本機 Playwright 前往 momo 購物網登入頁（https://www.momoshop.com.tw/member/Login.jsp）：
1. 開啟頁面後停在登入畫面，提示我手動進行登入。
2. 當我在對話框回覆「我已完成登入」後，前往「會員中心 -> 訂單查詢」。
3. 收集最近 3 筆訂單的「訂單編號」、「訂購日期」與「訂單金額」，整理成 Markdown 表格輸出。
```
