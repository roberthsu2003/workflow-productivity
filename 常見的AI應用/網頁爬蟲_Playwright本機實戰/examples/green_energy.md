# 🌿 綠能與政府公開資訊實戰：台電即時電力與法規動態爬取

> 🛠️ **核心工具**：桌面版 AI（Claude Desktop / ChatGPT 桌面版 / Antigravity）＋ 本機 **Playwright**  
> 📌 **適用情境**：台電即時電力資訊爬取、能源署／氣候變遷署動態公告追蹤、無 API 儀表板截圖存證

---

## 💡 為什麼政府與電力網站特別需要「本機 Playwright」？

| 比較維度 | 雲端網頁版 AI / 靜態爬蟲 | 桌面版 AI ＋ 本機 Playwright |
| :--- | :--- | :--- |
| **動態圖表渲染** | 抓不到前端 JS 繪製的發電量與負載數據 | 啟動真實 Chromium，完整渲染動態儀表板 |
| **政府網站防火牆** | 海外雲端伺服器 IP 易被國內公部門網站阻擋 | 直接以台灣本機真實網路 IP 發送請求，暢行無阻 |
| **瞬時數據存證** | 缺乏視覺存證，瞬時備轉容量隨時變動 | 支援 `full_page=True` 截圖存證，數據眼見為憑 |

## 📝 三階段實作演練任務（直接貼給桌面版 AI 使用）

### 🔹 任務 A：台電即時電力供需與再生能源佔比監控
```text
請使用本機 Playwright 開啟台電「今日電力資訊」頁面（https://www.taipower.com.tw/d006/loadGraph/loadGraph/load_briefing3.html 或台電官網即時用電資訊頁）：
1. 等待頁面上的動態電力負載數據與圖表渲染完成。
2. 擷取「目前用電量」、「尖峰負載預測」、「預估最高備轉容量率」與「供電燈號」。
3. 將該頁面截圖存檔為 `taipower_status.png`，並將數據整理成 Markdown 摘要報告。
```

---

### 🔹 任務 B：主管機關淨零政策與碳費法規追蹤
```text
請使用本機 Playwright 前往經濟部能源署或環境部氣候變遷署最新公告頁面：
1. 擷取最新 5 筆關於「再生能源」、「儲能」或「碳費」的法規／公告標題與發布日期。
2. 整理成 Markdown 追蹤清單，並標註需要法規幕僚優先研讀的重點項目。
```

---

### 🔹 任務 C：儲能設備商官網動態規格解析與截圖
```text
請使用本機 Playwright 開啟指定的儲能／電池製造商官網產品頁：
1. 滾動頁面確保動態規格表（Datasheet）完整載入並截圖存證。
2. 擷取電池容量（kWh）、充放電倍率（C-Rate）、循環壽命與安全認證（如 UL 9540A）等關鍵參數。
3. 整理成標準化技術審查表格，方便後續匯入 Excel 評估。
```
