# 📑 PDF (.pdf) 進階對齊與向量文件套印

> 🚧 **專區建置狀態**：本資料夾為 **`.pdf` 文件進階對齊** 專用分類目錄（範例檔案建置中）。

---

## 🎯 未來收錄核心對齊重點

1. **官方表單與憑證精準排版（ReportLab / WeasyPrint / PyPDF）**：
   - 以向量格式產出不失真 PDF，精準控制頁邊距、表格線條對齊與中文字型嵌入（避免方塊亂碼）。
2. **長篇報表跨頁表頭與分頁防斷裂**：
   - 確保跨頁表格自動重複表頭、簽核欄位不被硬生生切分在兩頁之間。
3. **多文件合併、頁尾流水號與階層書籤對齊**：
   - 整合封面目錄、傳票與憑證掃描圖，統一頁面尺寸（A4）、自動壓印頁尾頁碼與左側目錄跳轉書籤。
