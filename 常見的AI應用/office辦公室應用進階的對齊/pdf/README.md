## 🛠️ 實戰兩階段：先定排版規格書，再寫向量生成腳本

### 階段 0：將舊版 PDF 整理成「向量排版規格書」（若你只有舊 PDF 範本）

> 💡 **先別急著複製！請先學會提示詞裡的 4 個「關鍵字」**  
> 學員在請 AI 幫忙分析 PDF 並產出規格書或生成程式時，必須看懂這 4 個核心指令，才不會做出跑版又亂碼的 PDF：
> 1. **「註冊繁體中文字型（`TTFont`）」**：明確指定註冊系統內的 TrueType 字型，徹底杜絕中文字變成 `□□□` 豆腐字。
> 2. **「固定欄寬總和 + `Paragraph` 自動折行」**：先算好 `A4 寬度 - 左右邊界 = 174mm` 的總寬，且長摘要欄必須包進 `Paragraph` 才會自動斷行。
> 3. **「跨頁重複表頭（`repeatRows=1`）+ `KeepTogether`」**：確保超過 1 頁時第 2 頁頂端自動補上表頭，且底部簽核區絕不被頁尾切斷。
> 4. **「雙遍掃描頁碼（`NumberedCanvas`）」**：普通寫法只能印出「第 1 頁」，必須使用兩階段 Canvas 才能準確印出 `第 1 頁 / 共 2 頁`。

📋 **Prompt 0（複製使用）**：
```text
請閱讀這份 `報銷核銷單_原始範例.pdf`，幫我歸納出一份給 Python ReportLab 使用的排版規格書 `pdf_layout_spec.md`：
1. 量測並固定 A4 頁面邊界，確保所有表格欄寬總和嚴格等於可用內容寬度（174mm）。
2. 標註每一欄的對齊規則：項次/日期/類別置中、摘要說明靠左且必須包進 Paragraph 支援自動折行、張數與金額千分位靠右對齊。
3. 明確規定必須註冊系統繁體中文 TTFont 字型（防豆腐字），並加入跨頁自動重複表頭（repeatRows=1）與簽核區防撕裂（KeepTogether）規則。
4. 定義頁尾水平分隔線與靠右對齊的「第 X 頁 / 共 Y 頁」規格。
```

### 階段 1：依據規格書與資料檔，產出跨頁不跑版的向量 PDF

📋 **Prompt 1（複製使用）**：
```text
請嚴格依照 `pdf_layout_spec.md` 的排版規格，讀取 `expense_data.md` 中的 Case 1 與 Case 2 資料，幫我寫一支使用 `reportlab` 的 Python 腳本，分別產出兩份 A4 向量 PDF：
1. 註冊繁體中文字型（macOS 使用 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`），確保所有中文與標點清晰顯示。
2. 表格必須設定 `repeatRows=1` 與固定的 `colWidths`，金額欄位統一靠右對齊並加上千分位逗號。
3. 底部三欄簽核區塊必須使用 `KeepTogether` 包裝，防止跨頁時被切開。
4. 實作雙遍掃描的 `NumberedCanvas`，在每頁右下角精準對齊顯示「第 X 頁 / 共 Y 頁」。
```

#### 💻 核心 Python 實作範例（`reportlab` 跨頁防斷裂精華）
```python
from reportlab.platypus import Table, KeepTogether

# 1. 設定 repeatRows=1，跨頁時自動在第 2 頁頂端重複表頭
tbl = Table(rows, colWidths=col_w, repeatRows=1)

# 2. 使用 KeepTogether 包住簽核表，避免標題與簽名線被分在兩頁
story.append(tbl)
story.append(KeepTogether([sign_tbl]))
```
