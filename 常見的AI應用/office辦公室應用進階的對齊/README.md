# 📐 Office 辦公室應用進階對齊（DOCX / XLSX / PPTX / PDF 四大格式）

> **本章定位**：手邊已經有一份公司正式排版的範本（證書、報價單、簡報母片、核銷單），要用 AI ＋ Python **大量套印資料，又不能跑版**。
> 本章四個單元都在解決同一件事：**名字變長、品項變多、文字溢出、跨頁斷裂時，版面依然對齊。**
