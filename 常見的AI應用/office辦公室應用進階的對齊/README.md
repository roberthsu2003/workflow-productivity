## 🧭 通用兩階段對齊工作流

```text
[⓪ 既有正式文件] ──(階段 0：AI 逆向提煉)──▶ [① {{佔位符}} 通用樣版]
                                                      │
[② 結構化測試資料] ────(階段 1：AI 批次對齊套印)────────┴──▶ [③ 精準對齊批次成品]
```

1. **階段 0（轉為佔位符樣版）**：把過去做好的正式檔案交給 AI，將動態資料轉成 `{{變數}}` 佔位符，並 100% 鎖定原始字型、段落對齊、欄寬與公式。
2. **階段 1（批次套印與驗收）**：搭配結構化資料（`.txt` / `.md`），由 AI 或 Python 腳本精準灌入樣版，並檢查無殘留 `{{...}}` 與公式計算正確。

## 🛠️ 支援執行環境
* **ChatGPT / Claude 網頁版**：上傳各資料夾內的「佔位符樣版 ＋ 資料檔」與對應 `README.md` 內的提示詞即可直接產出下載。
* **Google Antigravity / 本機 Python**：直接讀取各資料夾內檔案，透過 `python-docx`、`xltpl`、`python-pptx`、`reportlab` 離線海量批次產出。
