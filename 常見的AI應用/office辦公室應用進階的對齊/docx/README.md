## 🔄 實戰操作兩階段

### 階段 0：將原始檔案轉換為「佔位字符樣版」
上傳 [`結業證明書.docx`](./結業證明書.docx) 給 AI，發送以下提示詞即可產出 [`結業證明書_佔位符範本.docx`](./結業證明書_佔位符範本.docx)：

```markdown
請讀取我上傳的原始正式文件《結業證明書.docx》，將其轉換為可重複套印的「標準佔位字符樣版（Template Placeholder）」。

【任務目標】：
1. 自動識別變動欄位，將實體文字替換為雙大括號佔位符：
   - 學員姓名 ➔ `{{學員姓名}}`、學員編號 ➔ `{{學員編號}}`
   - 課程名稱 ➔ `{{課程名稱}}`、訓練時數 ➔ `{{訓練時數}} 小時`
   - 上課期間 ➔ `{{開始日期}} ～ {{結束日期}}`、結業成績 ➔ `{{結業成績}}`
   - 授課講師 ➔ `{{授課講師}}`、學習評語 ➔ `{{學習評語}}`
   - 發證單位 ➔ `{{發證單位}}`、證書編號 ➔ `{{證書編號}}`、發證日期 ➔ `{{發證日期}}`
2. 【嚴格排版與對齊鎖定】：
   - 100% 保留原始 XML 結構、字型（微軟正黑體）、字體大小與頁面邊距。
   - 段落對齊不變：標題置中（Center）、發證單位靠左（Left）、發證日期靠右（Right）。
   - 表格左欄寬度鎖定，僅替換右欄為佔位符，確保長文字自動換行不跑版。
3. 請產出轉換後的樣版檔，命名為《結業證明書_佔位符範本.docx》。
```

### 🎯 階段 1：批次套印與進階對齊

上傳 [`結業證明書_佔位符範本.docx`](./結業證明書_佔位符範本.docx) 與 [`student_data.txt`](./student_data.txt)，發送以下提示詞：

```markdown
請讀取我上傳的 DOCX 範本（結業證明書_佔位符範本.docx）與學員資料（student_data.txt），依據每位學員資料各產生一份獨立的 DOCX 結業證明書。

【嚴格對齊要求】：
1. 替換佔位符：將範本中所有 `{{欄位名稱}}` 精準替換為對應學員內容，共同資料套用至所有學員。
2. 保留版面設定：嚴格保留原始範本的頁面邊距、段落靠左/置中/靠右對齊設定與字型大小。
3. 表格穩定性：表格欄位寬度不可變形；遇長文字（如學員 2 的長課程名稱與長評語）請於儲存格內自動換行，維持單頁排版。
4. 交付檢核：產出前確認文檔內無任何殘留之 {{...}} 標籤，並提供 3 份可供下載的 DOCX 檔案。
```
