## 🔄 實戰操作兩階段

### 階段 0：將原始報價單轉換為「xltpl 動態樣版」

> 💡 **先別急著複製！請先學會提示詞裡的 4 個「關鍵字」**（日後回公司製作自己的 Excel 動態樣版時，務必放進這 4 項要求）：
> 1. **指定引擎語法 `xltpl / Jinja2 動態擴展樣版` ＋ `{% for it in items %}`**：明確要求使用 `xltpl` 標籤包裹示範列，否則 AI 只會寫死固定 3 列，未來品項變多時就會把下方合計公式蓋掉！
> 2. **防公式破壞關鍵字 `嚴禁覆蓋公式（保留原生動態公式）`**：必須特別叮嚀保留小計、`=SUM()` 與營業稅公式，避免 AI 直接把計算結果寫成沒有公式的「死數字」。
> 3. **型別對齊關鍵字 `數值型別（Number）` ＋ `千分位 #,##0`**：套印階段務必強制數量與單價寫入為數值而非文字，否則公式會回傳錯誤或變成 `0`。
> 4. **合併格防跑版關鍵字 `保留合併儲存格與自動換行`**：鎖定底部備註欄的跨欄合併與 `wrap_text` 折行設定，讓列數增加後備註欄自動往下順延且不破版。

上傳 [`報價單.xlsx`](./報價單.xlsx) 給 AI，發送以下提示詞即可產出 [`報價單_xltpl樣版.xlsx`](./報價單_xltpl樣版.xlsx)：

```markdown
請讀取我上傳的原始商業試算表《報價單.xlsx》，將其轉換為符合 Python xltpl / Jinja2 語法規範的「動態擴展佔位符樣版」。

【任務目標】：
1. 表頭變數標籤化：`{{客戶名稱}}`、`{{聯絡窗口}}`、`{{報價單號}}`、`{{報價日期}}`、`{{專案名稱}}`。
2. 動態品項區塊導入 xltpl 迴圈：
   - 在品項明細起始列上方加入 `{% for it in items %}`，下方加入 `{% endfor %}`。
   - 品項列改為佔位符：`{{ it.no }}`、`{{ it.name }}`、`{{ it.qty }}`、`{{ it.unit }}`、`{{ it.price }}`。
   - 保留該列之原生小計公式 `=IF(AND(ISNUMBER(D13),ISNUMBER(F13)),D13*F13,"待填資料")`。
3. 彙總公式與備註保留：
   - 嚴禁覆蓋公式：保留未稅合計 `=SUM(...)`、營業稅 5% 與含稅總計動態公式。
   - 備註欄替換為 `{{付款條件與備註}}`，有效期限替換為 `{{報價有效期限}}`。
   - 100% 保持千分位格式（`#,##0`）、儲存格框線、底色與自動換行。
4. 請產出樣版檔，命名為《報價單_xltpl樣版.xlsx》。
```

### 🎯 階段 1：批次套印與進階對齊

上傳 [`報價單_xltpl樣版.xlsx`](./報價單_xltpl樣版.xlsx) 與 [`quotation_data.md`](./quotation_data.md)，發送以下提示詞：

```markdown
請以我提供的《報價單_xltpl樣版.xlsx》為結構範本，並讀取 quotation_data.md 內的客戶資料，為每位客戶各產生一份 .xlsx 商業報價單。

【嚴格對齊要求】：
1. xltpl 迴圈展開：品項區塊以 `{% for it in items %}` 展開，無論品項數量多寡，自動延展新列並向下推移合計與備註欄。
2. 數值型別對齊：{{ it.qty }} 與 {{ it.price }} 必須寫入為「數值型別（Number）」，絕不可寫入文字字串，確保觸發原版 `=IF(AND(ISNUMBER()))` 動態小計公式。
3. 公式與樣式保留：嚴禁覆蓋任何計算公式為死值；保留千分位格式（`#,##0`）與合約備註欄位的跨欄合併與自動折行。
4. 交付檢核：產出 3 份可供下載的 .xlsx 檔案，且含稅總計需與 quotation_data.md 內的預期金額精確相符。
```

#### 💻 Python xltpl 本機執行參考（10 行極致簡潔）
```python
from xltpl.writerx import BookWriter

payload = {
    "客戶名稱": "星河創意有限公司",
    "聯絡窗口": "林怡君",
    "報價單號": "Q20261021-001",
    "報價日期": "2026/10/21",
    "專案名稱": "企業形象網站建置專案",
    "items": [
        {"no": 1, "name": "網站視覺設計", "qty": 1, "unit": "式", "price": 28000},
        {"no": 2, "name": "響應式網站開發", "qty": 1, "unit": "式", "price": 48000},
        {"no": 3, "name": "網站維護服務", "qty": 6, "unit": "月", "price": 2500},
    ],
    "付款條件與備註": "簽約後支付總價 50%，網站驗收後支付尾款 50%；包含一次操作教學。",
    "報價有效期限": "2026/11/20",
}

writer = BookWriter("報價單_xltpl樣版.xlsx")
writer.render_sheet(payload)
writer.save("報價單_示範成果_客戶1_星河創意.xlsx")
```
