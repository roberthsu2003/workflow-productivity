## 💡 AI 生圖與職場視覺化的 3 大落地原則

1. **結構優先於裝飾**：在下達生圖指令前，先以 Markdown 定出資訊層級、區塊權重與動線，避免 AI 隨機生成導致畫面凌亂。
2. **規格書審核把關**：將色彩主題、字型尺寸、Icon 象徵與模組邊界先沉澱為可審查的文字規格書，降低重工成本。
3. **場景決定格式**：口頭報告需逐頁引導（選簡報）；非同步傳閱、社群貼文或 SOP 張貼（選單頁資訊圖表）。
