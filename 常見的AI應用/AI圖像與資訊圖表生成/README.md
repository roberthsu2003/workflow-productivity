# 🎨 AI 圖像與資訊圖表生成（Image & Infographic Generation）

## 🧩 兩大模組特色說明

### 🍱 01. 全自動資訊圖表的生成
- **10 大主流設計風格**：便當盒法（Bento Box）、教學風（Explanatory）、專業風（Professional）、積木風（Blocks）等。
- **3 大黃金視覺動線**：Z 型動線（橫向瀏覽）、S-Curve 蛇形動線（流程步驟）、垂直瀑布動線（因果階梯）。
- **雙階段人機協作機制**：學員口語發想 ➔ 產出視覺排版與色票 `規格書.md` ➔ 審核核准 ➔ 自動生成 HTML / SVG 高保真資訊圖表與視覺發布檔。

### 🔍 02. 簡報和資訊圖表的差異
- **核心思維對比**：徹底釐清「演講用投影片（局部放大鏡）」與「單頁資訊圖表（全景導覽圖）」在受眾專注力、資訊密度與閱讀情境的本質差異。
- **雙向轉化工作流**：
  - **放大鏡原則**：資訊圖表拆解為簡報（由大到小）。
  - **導覽圖原則**：簡報組合成資訊圖表（由小到大）。

## 💡 AI 生圖與職場視覺化的 3 大落地原則

1. **結構優先於裝飾**：在下達生圖指令前，先以 Markdown 定出資訊層級、區塊權重與動線，避免 AI 隨機生成導致畫面凌亂。
2. **規格書審核把關**：將色彩主題、字型尺寸、Icon 象徵與模組邊界先沉澱為可審查的文字規格書，降低重工成本。
3. **場景決定格式**：口頭報告需逐頁引導（選簡報）；非同步傳閱、社群貼文或 SOP 張貼（選單頁資訊圖表）。
