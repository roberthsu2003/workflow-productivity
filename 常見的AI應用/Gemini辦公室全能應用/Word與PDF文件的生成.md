# Word (.docx) 與 PDF (.pdf) 文件的雙軌人機協作生成指南
## 🚀 Google Gemini × 原生筆記本（NotebookLM）公文、企劃與報告實戰

> **本篇重點**：非技術人員往往不知道如何撰寫精準的 AI 指令。本指南建立**「自然語言 ➔ RTCCF 轉換存檔 ➔ 審核卡片確認 ➔ 正式生成 Word/PDF」**的標準人機協作（Human-in-the-loop）工作流。
> 
> 🛡️ **核心資安與品質守則**：AI 嚴禁未經確認直接產出正式檔案！在生成 `.docx` 與 `.pdf` 前，**必須先產出「審核卡片」**，待使用者覆核確認「可以了」，才執行格式匯出。

---

## 🧭 人機協作四步標準工作流

```
步驟 1：學生自然語言發想 ➔ 步驟 2：AI 轉化為 RTCCF Prompt 並存檔 ➔ 步驟 3：AI 產出審核卡片（人機覆核） ➔ 步驟 4：確認後正式生成 Word/PDF
```

| 協作階段 | 執行角色 | 關鍵任務 |
| :--- | :--- | :--- |
| **1. 初始指令** | 學生 / 同仁 | 用平常講話的**自然語言（白話）**描述想要寫的公文或企劃需求。 |
| **2. 提示詞工程** | AI 輔助 | 將自然語言擴充為具備角色、背景、限制與格式的 **RTCCF 格式 Prompt**，**並要求同仁複製存檔**以利日後重複調用。 |
| **3. 安全審核** | AI + 人類 | AI 先輸出 **Markdown「文件審核卡片」**（大綱架構、法規依據、關鍵章節）。**人類審閱確認「可以了」**。 |
| **4. 格式生成** | 系統匯出 | 確認無誤後，一鍵「匯出至 Google 文件」並下載為 **Word (.docx)** 或 **PDF (.pdf)**。 |

---

## 🛠️ 軌道一：直接使用 Prompt 產出 Word/PDF（純 Prompt 協作）

### 💬 步驟 1：學生輸入「自然語言 Prompt」（平常講話即可）
學生往往不會寫 Prompt，可以直接在 [Google Gemini](https://gemini.google.com/) 貼入這段白話文：

```text
我想寫一份公司今年推動非技術同仁使用 AI 辦公室工具的專案計畫書給主管看，希望大概包含計畫緣由、目標、推動步驟、資安跟預算，字數大概 1500 字，口吻要專業正式。
請先幫我把這段需求改寫成標準的 RTCCF 格式 Prompt，讓我存檔；並且先產出「計畫審核卡片」給我看，不要直接輸出完整長文。
```

---

### 📋 步驟 2：AI 自動產出的 RTCCF 格式 Prompt（【請務必存檔備用】）
AI 會將學生的白話轉化為以下專業 Prompt。**請學員務必將此 Prompt 複製並儲存為檔案（如 `AI推動計畫書_Prompt.md`）**：

```markdown
## Role
你是一位資深企業營運規劃師，擅長撰寫結構嚴謹、條理分明的正式公務企劃書。

## Task
請幫我撰寫一份完整的「2026 年度辦公室 AI 賦能推動計畫書」，準備提交給高階主管核閱。

## Context
- 核心目標：引進 Google Gemini 及其原生筆記本，協助非技術同仁處理公文、試算表、簡報與資訊圖表，節省 40% 行政工時。
- 推動對象：全體非技術同仁（約 80 人）。

## Constraint
- 必須包含：計畫緣起、KPI目標、分階段時程、資安與去識別化規範、預算配置、預期成效。
- 語言：繁體中文，公務正式口吻。
- 執行限制：【第一步必須先產出審核卡片】，待我確認後再輸出全文。

## Format
- 階層標題（Markdown #、##、###）、標準三欄表格。
```

---

### 🛡️ 步驟 3：AI 產出的「Word/PDF 文件審核卡片」（人機協作確認）
在輸出全文前，Gemini 會先呈現此卡片供人類核對：

```markdown
┌─────────────────────────────────────────────────────────────┐
│               📑 專案計畫書架構審核卡片 (Review Card)         │
├─────────────────────────────────────────────────────────────┤
│ 專案名稱：2026 年度辦公室 AI 賦能推動計畫書                     │
│ 預計產出格式：Word (.docx) / PDF (.pdf)                     │
│ 預估字數：約 1,500 ~ 1,800 字 ｜ 排版：標準公文 6 大章節       │
├─────────────────────────────────────────────────────────────┤
│ 【章節骨架預覽】：                                           │
│ 1. 計畫緣起：當前行政文書 3 大痛點與工時浪費分析              │
│ 2. 推動目標：三大核心 KPI（例行行政提速 40%、零資安違規）       │
│ 3. 實施階段：4月資安檢測 ➔ 5月中旬種子培訓 ➔ 6月全面推廣       │
│ 4. 資安防護：三大原則（查核、分流、負責）與個資脫敏規範         │
│ 5. 資源預算：零軟體授權成本（採用免費方案）+ 教育訓練場地費   │
│ 6. 預期效益：投資報酬率 (ROI) 預估與總結                      │
├─────────────────────────────────────────────────────────────┤
│ ⚠️ 待確認事項：                                              │
│ - 上述 6 大章節結構與 KPI 設定是否符合您的需求？             │
│ - 若確認無誤，請回覆【確認無誤，可以生成】，我將為您產出正式全文│
└─────────────────────────────────────────────────────────────┘
```

---

### 📥 步驟 4：確認後生成並匯出 Word (.docx) 與 PDF (.pdf)
當學員在對話框回覆：**「確認無誤，可以生成」**：
1. Gemini 立即產出結構完整、標題分明的正式企劃長文。
2. 滾動至回覆最下方，點選右下角「**分享與匯出**」圖示 ➔ 選擇「**匯出至 Google 文件**」。
3. 在 Google 文件中點選上方選單：
   - **下載 Word**：**「檔案」➔「下載」➔「Microsoft Word (.docx)」**。
   - **下載 PDF**：**「檔案」➔「下載」➔「PDF 文件 (.pdf)」**。

## 📑 軌道二：以 Notebook 資料為範本產出 Word/PDF（知識庫協作）

當手上有現成的公司規章（如出差辦法），需要萃取成「員工常見問答與指南」時，使用筆記本能保證條文零幻覺。

### 📂 步驟 1：下載並上傳教學偽資料
- 練習素材：[**企業內部規章_差旅與加班管理規範.pdf**](./範例素材與偽資料/企業內部規章_差旅與加班管理規範.pdf)（亦可使用 [純文字檔](./範例素材與偽資料/企業內部規章_差旅與加班管理規範.txt)）
- 操作方式：在 Gemini 側邊欄點選「**＋ 新增筆記本**」，點擊「新增來源」上傳該檔案。

### 💬 步驟 2：學生在筆記本輸入「自然語言 Prompt」
```text
請根據我剛才上傳的差旅規範 PDF，幫我寫一份給全體員工看的「出差報銷與加班權益指南」Word 檔草案。
請先幫我轉成 RTCCF 格式讓我存檔，並先列出「審核卡片」讓我看有哪些條文重點，我確認可以了再寫正式內容。
```

### 📋 步驟 3：AI 轉化之 RTCCF Prompt（【複製存檔備用】）
```markdown
## Role: 人資法規專家
## Task: 依據上傳來源產出「員工差旅報銷與加班權益指南」
## Context: 來源為星雲數位科技股份有限公司內部差旅辦法（文件編號 HR-SOP-2026-003）
## Constraint:
1. 先產出審核卡片（包含交通標準、住宿上限、加班規則對照）。
2. 每項結論嚴格附帶上傳 PDF 頁碼與條款引文標註。
3. 待確認後再輸出完整 Markdown 正式公文。
## Format: 審核卡片 ➔ 確認後輸出結構化 Markdown
```

### 🛡️ 步驟 4：審核卡片確認 ➔ 匯出 Word / PDF
1. 筆記本先產出【差旅法規重點審核卡片】（高鐵資格、每晚 2,800 元上限、10 天核銷期限）。
2. 學員回覆：**「可以了，請產出正式指南」**。
3. 產出後點選「**儲存為筆記**」➔ 點選筆記右上角「**匯出至 Google 文件**」。
4. 於 Google 文件下載為 **Word (.docx)** 或 **PDF (.pdf)**！
