# 全自動資訊圖表 (Infographic) 的雙軌生成指南
## 🚀 Google Gemini × 原生筆記本（NotebookLM）10 大視覺風格 × 3 大閱讀動線全攻略

> **本篇重點**：非技術人員如何運用 **Google Gemini** 與 **Gemini 原生筆記本（NotebookLM）**，透過「**直接 Prompt 設計**」與「**以 Notebook 範本資料鉛筆指令生成**」兩種工作流，免用任何繪圖軟體，即可自動產出一頁式高密度、高質感的 **商務資訊圖表（Infographic）**。

---

## 🧭 雙軌生成模式選擇指南

| 模式 | 適用時機 | 工作流核心 | 產出型態 |
| :--- | :--- | :--- | :--- |
| **軌道一：直接使用 Prompt** | 從文字構思版面佈局、設計跨部門宣傳懶人包草案 | 在 Gemini 對話框直接輸入動線與模組化 Prompt | 資訊圖表版面規格書、各區塊文案與排版指南 |

## 🛠️ 軌道一：直接使用 Prompt 規劃資訊圖表架構

直接在 [Google Gemini](https://gemini.google.com/) 對話框輸入以下提示詞。請直接複製使用：

### 📋 一鍵複製 Prompt（便當盒排版法 Bento Box 資訊圖表設計）：

```markdown
## Role
你是一位頂尖的資訊設計師（Information Designer），擅長將複雜數據與文字流程轉化為易讀的一頁式資訊圖表（Infographic）。

## Task
請幫我規劃一張「傳統公務辦公 vs. Gemini AI 協作賦能」的對比資訊圖表版面架構，採用「便當盒排版法 (Bento Box)」風格。

## Constraint
- 必須包含四大模組區塊（如 Bento Box 方格）：
  1. 【核心指標區】行政工時與產出速度對比（大數字量化）。
  2. 【工作流對照區】傳統 5 步驟 vs AI 一站式 2 步驟。
  3. 【五大格式輸出區】Word、Excel、PPT、PDF、資訊圖表之能力展示。
  4. 【資安防護區】三大守則（查核、分流、負責）安全徽章。
- 閱讀動線：Z 型動線（左上 ➔ 右上 ➔ 左下 ➔ 右下）。
- 附上各區塊文字標題、說明文案（30字內）、建議圖示（Icon）與視覺配色建議。
```

## 🎨 軌道二：以 Notebook 資料為範本產出全自動資訊圖表

Google NotebookLM 於近期升級了資訊圖表（Infographic）功能，將風格與動線的選擇權交還給使用者。透過**10 種視覺風格**與**3 種閱讀動線**的搭配，共可創造出 30 種不同的圖表變化！

### 📂 步驟 1：下載並上傳教學偽資料
- 練習素材：[**新進同仁到職七天SOP指南.md**](./範例素材與偽資料/新進同仁到職七天SOP指南.md)（亦可使用 [純文字檔](./範例素材與偽資料/新進同仁到職七天SOP指南.txt)）
- 操作方式：在 Gemini 側邊欄點選「**＋ 新增筆記本**」，點擊「新增來源」，將上述檔案上傳。

### ✏️ 步驟 2：在資訊圖表生成處下達「鉛筆指令」（一鍵複製）

在 NotebookLM 介面中選擇產生「資訊圖表」，並在**鉛筆圖示**處輸入下列任一指令：

#### 範例 A：多步驟 SOP（蛇形流程動線 S-Curve + 教學風格）
```text
請使用「教學風格 (Explanatory)」，搭配「蛇形動線 (S-Curve)」，將上傳的新進同仁到職 6 大步驟製作為直式資訊圖表，清楚標示每個階段的任務與負責窗口。
```

#### 範例 B：企業正式報告（垂直動線 + 專業風格）
```text
請使用「專業風格 (Professional)」，搭配「垂直線性動線 (Vertical)」，以冷色調與高對比網格呈現這份新人指引的各項核心里程碑。
```

## 📐 10 大視覺風格與 3 大閱讀動線速查表

### 3 大閱讀動線：
1. **垂直線性動線 (Vertical)**：由上往下延伸，適合列表類內容、SOP 單一拆解。
2. **Z 型動線 (Z-Pattern)**：左上 ➔ 右上 ➔ 左下 ➔ 右下，適合方案對比與四象限分析。
3. **蛇形流程動線 (S-Curve)**：蛇行前進，適合超過 5 步以上的長條型步驟與時間軸。

![](./images/三種視覺閱讀動線.png)

### 10 大視覺風格：

| 風格名稱 | 核心視覺特色 | 最合適場景 |
| :--- | :--- | :--- |
| **便當盒法 (Bento Box)** | 模組化方格、規整分類 | 功能清單、產品規格與成效對比 |
| **專業風 (Professional)** | 冷色調、乾淨網格、高對比 | 商務會議、正式年度報告 |
| **教學風 (Explanatory)** | 簡約線條、流程導向 | 員工培訓手冊、SOP 流程圖解 |
| **社論風 (Editorial)** | 雜誌排版感、文字圖表交錯 | 專案觀點評論、趨勢專題 |
| **積木風 (Blocks)** | 幾何方塊、模組化立體視覺 | 系統架構、組織圖、專案階段 |
| **手繪風 (Hand-drawn)** | 不規則線條、類筆觸感 | 創意發想、具溫度的品牌故事 |
| **可愛風 / 黏土風 / 動漫風 / 科學風** | 依情境與目標受眾親和力靈活切換 | 活動海報、生活指南、科普宣導 |
