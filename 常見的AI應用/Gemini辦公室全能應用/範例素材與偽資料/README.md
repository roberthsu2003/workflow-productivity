## 🚀 如何在課堂與自學中使用這些素材？

1. **上傳至 Gemini 筆記本（NotebookLM）**：
   - 點選上方表格中欲練習的檔案名稱進行下載（例如 `.pdf`、`.docx` 或 `.txt`）。
   - 開啟 [Google Gemini](https://gemini.google.com/)，在左側功能選單點選「**＋ 新增筆記本**」。
   - 點擊「**新增來源**」上傳該檔案，即可依照各教學手冊中的 Prompt 進行練習。
2. **在 Gemini 多模態中上傳圖片**：
   - 下載 [實體白板專案討論與待辦筆記.png](./實體白板專案討論與待辦筆記.png)。
   - 在 Gemini 對話輸入框點選「**＋ 上傳檔案／圖片**」，選擇該圖檔。
   - 輸入指令：「*請辨識這張白板上的手寫待辦清單，依人員與日期整理成 Markdown 表格，並匯出至試算表*」。
