# 工研院綠能與環境研究所
## 🚀 Claude AI 與 Skills 工作流程自動化實作

> **專案簡介**：本課程專為工研院**綠能與環境研究所（綠能所）**團隊量身打造，旨在建立一套自動化「綠能情報與數據蒐集 → 關鍵洞察與分析 → 報告與簡報交付」的數位工作助理流程。

---

## 📌 課程概覽

| 項目 | 說明 |
| :--- | :--- |
| **總時數** | **14 小時（共 4 天，每天 3.5 小時模組化設計）** |
| **授課形式** | 實體工作坊（觀念解說 + 實務上機操作） |
| **適合對象** | 綠能所研發研究員、專案管理、技術推廣及產學合作相關人員（無需程式背景） |
| **課程特色** | 結合綠能淨零技術與能源數據實例、零代碼/低維護原生架構、文字情報與數據分析雙軌並重 |

### 🎯 課程四大核心目標
1. **自動化工作流**：獨立設計 Claude Skill，自動完成日常綠能情報、技術文獻與數據分析。
2. **團隊知識庫**：建立與維護 Projects 知識庫，將綠能專案規範與研究成果轉化為專屬 AI 助理。
3. **數據與圖表交付**：運用 Code Execution 與 PPTX Skill，快速解析能源數據並產出高質感技術簡報。
4. **自主排程與協作**：掌握 Cowork 與 Scheduled 排程架構，實現定期法規監控與專案管考自動化。

### 💡 預期效益
- ⏱️ **效率大幅提升**：每日國際綠能新知、政策法規與能源監測數據判讀時間縮短，聚焦高價值研發與決策。
- 📊 **產出標準化**：產出統一格式的技術評估報告、產學簡報與碳排分析，提升溝通效率。
- 🔧 **靈活可擴充**：學員課後可自行新增綠能技術主題與維護自訂分析規則。

##### 範例 1：基礎版 — 本週行程時間軸整理（搭配 Google Calendar Connector）
```markdown
## Role
你是一位個人行程管理助理，擅長精準整理日程與時間規劃。

## Task
請讀取我在 Google Calendar 上的行程，整理出「本週（週一至週五）」的時間軸行程清單。

## Context
- 我已開啟 Google Calendar Connector 連結。
- 本週日期為本工作週（週一至週五）。

## Constraint
- 僅讀取本週一至週五的公開與個人行程。
- 依時間先後順序排列，標註開始與結束時間、會議名稱及地點/會議連結。
- 若當天無行程，請註明「當天無排定行程」。
- 嚴格依據日曆實際資料，不可捏造行程。

## Format
- 以 Markdown 日期標題分段（例如：`### 8/3 (週一)`）。
- 每個行程使用格式：`[時間範圍] 會議名稱 | 地點/連結 | 與會人員`。
```

##### 範例 2：進階版 — 綠能技術研發與產學合作簡報製作（使用 Anthropic PPTX Skill）
```markdown
## Role
你是一位綠能與永續科技領域的技術簡報設計助手，擅長將技術研發成果與合作要點轉化為結構清晰的簡報大綱，並運用 Anthropic PPTX Skill 製作專業 PowerPoint 簡報。

## Task
請依我提供的綠能技術主題與要點，先規劃一份簡報大綱與投影片結構，與我討論確認後，再使用 PPTX Skill 製作成 PowerPoint 簡報檔案 (.pptx) 供我下載。

## Context
- 簡報主題：2026 智慧微電網與儲能系統技術應用與產學合作提案
- 報告對象：產學合作企業與技術審查委員
- 主要要點：
  1. 技術背景：再生能源高滲透率下的電網調度與儲能需求。
  2. 核心技術：分佈式能源管理系統（EMS）、雙向充放電控制演算法。
  3. 實證效益：示範場域削峰填谷成效、節能率達 18%、降低契約容量超約罰款。
  4. 合作模式：技術移轉、場域實證與共同研發。

## Constraint
- 語言：繁體中文
- 簡報設計配色：指定使用綠能科技風格配色（森林翡翠綠 `0F5132` / 活力淺綠 `D1E7DD` / 深灰文字 `212529` / 白底 `FFFFFF`）。
- 固定 5 頁簡報結構：封面 → 產業痛點與背景 → 核心技術突破 → 示範場域成果 → 合作推廣模式
- 每頁重點條目不超過 4 條。
- **工作流程限制**：
  1. **第一步（討論階段）**：請先使用 Claude Artifacts 功能，呈現每頁投影片的標題與內容大綱草稿。
  2. **第二步（討論階段）**：詢問我是否需要修改，在此時**不要**呼叫 PPTX 產生工具。
  3. **第三步（製作階段）**：待我確認大綱「可以製作」後，呼叫內建 PPTX Skill 將此大綱內容製作成實體 .pptx 簡報檔案。

## Format
- 使用內建 Anthropic PPTX Skill 建立並套用指定配色，匯出 PowerPoint 簡報檔案 (.pptx)。
- 完成後提供簡報檔案下載連結，並列出每頁的標題與大綱摘要。
```

##### 範例 3：完整版 — 近 7 天 Email 檢查與重要性分類（配合 Gmail Connector）
```markdown
## Role
你是一位行政與郵件管理助理，擅長資訊過濾、優先級排序與郵件分類整理。

## Task
請檢查我近 7 天（最近一週）在 Gmail 上的收件匣郵件，依據重要性與類別進行整理，並產出高優先待處理事項與郵件分類報告。

## Context
- 我已開啟 Gmail Connector 連結。
- 近期專案與技術合作郵件繁多，需要快速掌握近 7 天累積的重要資訊與待辦事項。

## Constraint
- 僅讀取最近 7 天內的信件。
- 依照重要性標示等級：`🔴 高優先`（需立即處理/回覆）、`🟡 中優先`（本週內處理）、`🟢 低優先`（僅供參考/例行通知）。
- 郵件類別須歸類為：`[專案管考/審查]`、`[產學合作/技轉]`、`[行政簽核/通知]`、`[研討會/學術動態]`。
- 若信件包含附件（如：合約、技術規格書、簡報、評審意見），請特別標註 `📎 含附件`。
- 嚴格基於郵件實際內容整理，不可捏造；無相關信件時註明「無相關郵件」。

## Format
1. **近 7 天郵件總覽摘要**（總信件數、高優先待辦數）。
2. **🔴 高優先緊急待辦區**（列表包含：`寄件者` | `郵件主旨` | `日期` | `建議行動` | `建議回覆期限`）。
3. **郵件分類總覽表**（Markdown 表格：`重要性` | `類別` | `寄件者` | `主旨` | `日期` | `重點摘要與附件`）。
```

## 🌱 綠能所專屬應用情境與案例建議方向

針對**工研院綠能與環境研究所（綠能所）**的核心研發領域與業務性質，建議在 14 小時的課程實作中，融入以下 5 大代表性情境範例：

### 1. 🌍 國際淨零法規與能源政策情報監控（Day 3 爬蟲與情報 Skill）
* **背景情境**：全球淨零趨勢演進迅速，研究團隊需定期追蹤歐盟 CBAM、美國 IRA、RE100 最新標準、國內碳費制度及能源署最新公告。
* **推薦實作範例**：
  * 使用 **Playwright MCP / Claude in Chrome** 爬取能源署、環境部氣候變遷署及 IEA / IRENA 最新報告。
  * 打造「綠能法規情報監控 Skill」，自動摘要最新法規草案、對國內能源產業之衝擊、法規生效時程，並輸出為團隊週會簡報。

### 2. ⚡ 綠能專案技術白皮書與專利知識庫（Day 1 & Day 2 Projects 知識庫）
* **背景情境**：所內累積大量地熱探勘、CCUS（碳捕捉與再利用）、氫能燃料電池、儲能安全規範等研究報告與專利文件。
* **推薦實作範例**：
  * 在 **Claude Projects** 建立「綠能核心技術知識庫」，上傳歷年研發白皮書、法規手冊與測試規範。
  * 實作技術問答助理：快速比對不同儲能材料（鋰鐵/鈉離子/液流電池）之安全標準，或針對產學合作廠商的技術規格進行初審比對。

### 3. 📊 場域能耗監測與碳盤查數據自動化分析（Day 4 Code Execution 整合者 Skill）
* **背景情境**：研究員經常需處理示範場域之電力需量（kW）、用電量（kWh）、太陽光電/風力即時發電數據，以及廠區溫室氣體（範疇一/範疇二）盤查 Excel 報表。
* **推薦實作範例**：
  * 設計「能源與碳排分析 Skill」，讓 Claude 透過 **Code Execution（Python）** 自動讀取 Excel 數據。
