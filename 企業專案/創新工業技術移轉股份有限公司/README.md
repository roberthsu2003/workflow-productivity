# 創新工業技術移轉股份有限公司

## Claude AI 和 Skills 工作流程自動化實作
- **總時數**：12 小時（共 3 天，每天 4 小時）
- **授課形式**：實體課程

---

## 課程目標

1. 讓學員能獨立設計並建立一套完整的 Claude Skill 工作流，自動完成「資料與數據收集 → 重點摘要與分析 → 彙整交付」的日常任務
2. 培養學員撰寫、測試、修正 Claude Skill 與 Projects 知識庫的能力，將團隊經驗轉換為可重複使用的數位工作助理
3. 建立一套可持續維護、可依投資組合與營運需求自行擴充的市場情報與數據分析自動化系統

## 課程特色

- **結合 ITIC 實際情境**：以投資組合公司追蹤、產業新聞監控、Excel 營運資料分析等實務工作為教學案例，學完即可上線使用
- **三天 12 小時模組化設計**：每天 4 小時（共 3 天），課程環環相扣，課後帶回一套完全可運作的自動化流程與專屬 Skill 檔案
- **原生零代碼/低維護**：不需 n8n 等外部工具，全程採用 Claude 原生功能（Projects 知識庫、Skills、排程、檔案輸出），降低後續維護與跨系統依賴的門檻
- **文字與數據雙軌並重**：同時涵蓋非結構化文件（簡報、報告、新聞）的摘要洞察，以及結構化表格（Excel 業績、營運資料）的趨勢判讀與報表整理
- **實戰範例導向**：每單元皆有實作練習與範例 Prompt，當堂即可帶回可使用的 Skill 檔案

## 適合對象

ITIC 投資研究、營運管理及業務相關人員（具備基礎電腦操作能力即可，不需要程式設計背景）

## 預期效益

- **作業效率提升**：每日新聞蒐集、資料整理與 Excel 數據判讀時間大幅縮短，人力可轉投入分析判斷而非資料蒐集
- **產出標準化**：建立統一格式的分析報告與每日彙整簡報，便於主管與團隊快速掌握重點、風險與關鍵洞察
- **系統可擴充性**：專案知識庫與 Skill 規則可彈性維護，未來新增投資標的或調整分析準則時，學員可自行擴充維護

## 備註

- 各單元練習皆建議使用 ITIC 實際投資組合公司與營運資料作為範例，以提高學員上完課後直接沿用的可行性
- 建議上課前先確認 ITIC 現有的資料交付管道（內部信箱、共用雲端硬碟等），以便 Day 3 的實作能對接實際使用情境
