# 創新工業技術移轉股份有限公司

## Claude AI 和 Skills 工作流程自動化實作
- **總時數**：12 小時（共 3 天，每天 4 小時）
- **授課形式**：實體課程

---

## 課程目標

1. 讓學員能獨立設計並建立一套完整的 Claude Skill 工作流，自動完成「資料與數據收集 → 重點摘要與分析 → 彙整交付」的日常任務
2. 培養學員撰寫、測試、修正 Claude Skill 與 Projects 知識庫的能力，將團隊經驗轉換為可重複使用的數位工作助理
3. 建立一套可持續維護、可依投資組合與營運需求自行擴充的市場情報與數據分析自動化系統

## 課程特色

- **結合 ITIC 實際情境**：以投資組合公司追蹤、產業新聞監控、Excel 營運資料分析等實務工作為教學案例，學完即可上線使用
- **三天 12 小時模組化設計**：每天 4 小時（共 3 天），課程環環相扣，課後帶回一套完全可運作的自動化流程與專屬 Skill 檔案
- **原生零代碼/低維護**：全程採用 Claude 原生功能（Projects 知識庫、Skills、排程、檔案輸出），降低後續維護與跨系統依賴的門檻
- **文字與數據雙軌並重**：同時涵蓋非結構化文件（簡報、報告、新聞）的摘要洞察，以及結構化表格（Excel 業績、營運資料）的趨勢判讀與報表整理
- **實戰範例導向**：每單元皆有實作練習與範例 Prompt，當堂即可帶回可使用的 Skill 檔案

## 適合對象

ITIC 投資研究、營運管理及業務相關人員（具備基礎電腦操作能力即可，不需要程式設計背景）

## 預期效益

- **作業效率提升**：每日新聞蒐集、資料整理與 Excel 數據判讀時間大幅縮短，人力可轉投入分析判斷而非資料蒐集
- **產出標準化**：建立統一格式的分析報告與每日彙整簡報，便於主管與團隊快速掌握重點、風險與關鍵洞察
- **系統可擴充性**：專案知識庫與 Skill 規則可彈性維護，未來新增投資標的或調整分析準則時，學員可自行擴充維護

## 課程大綱

### 第一章：Claude 核心操作、Projects 知識庫與關注清單 Skill

#### 使用內建的skill

**課程內容綱要：**
- [**生成式AI模型基本概念**](../../生成式AI模型基本概念/README.md)：解析 LLM 底層模型核心能力（文字理解與生成）與上層應用程式（檔案讀取、搜尋、外掛 API 串接）的演進與職場應用觀念

- [**Prompt的技巧(實作)**](../../prompt/README.md)：掌握自然語言/YAML/Markdown 內容格式、System Prompt 角色規則設定與進階提示詞工程設計技巧

- [**claude官方skill介紹(連結介紹)**](https://github.com/anthropics/skills)

- [**討論的方式的內容生成Artifact(實作)**](../../Claude_ai/Artifacts/README.md)：透過獨立預覽視窗（Canvas）生成長文案、數據圖表與互動原型，實現即時渲染、版本控制與介面隔離

- [**連結的技巧**](../../Claude_ai/Connectors/README.md)
- [**使用現有的Skill-Google Works(實作)**]:設定 Connectors 串接 Google Workspace（Drive、Gmail、Calendar、Sheets），無須手動複製貼上即可讓 Claude 直接存取與整合雲端資料


### 第二章：自動化新聞情報蒐集、Excel 數據分析與重點摘要 Skill

- [**網路爬蟲技巧-playwright**](../../Claude_ai/Local_MCP/README.md)：相較於內建 Web Fetch 僅能讀取簡單靜態網頁且受限於雲端白名單，Playwright 可在本機操控真實瀏覽器，支援動態 JS 渲染、點擊與輸入等頁面互動，並能存取公司內網與登入型網站

**課程內容綱要：**
- **每日產業新聞/情報蒐集 Skill**：web search 搜尋策略設計（關鍵字組合、時間範圍控制），讀取 Day 1 關注清單作為搜尋依據，輸出結構化結果
- **上傳 Excel 業績與營運資料**：上傳 Excel 業績、專案或營運資料，進行趨勢判讀、異常提醒、重點摘要與報表整理
- **新聞與情報重點摘要 Skill**：摘要 Prompt 設計技巧（濃縮 2-3 句重點），依「利多/利空/中性」或「產業影響程度」分類，符合版權安全原則
- **實作練習**：針對投資公司與 Excel 營運資料實測自動化蒐集與摘要整理流程

### 第三章：每日彙整簡報產出、排程自動化與交付實作

**課程內容綱要：**
- **每日彙整簡報產出 Skill**：串接文件產出能力（Word/PDF），將摘要與數據分析整合為「主管一眼看懂」的正式簡報與報告範例
- **排程自動化**：以 Claude 原生排程功能取代 n8n，設定固定時間自動執行 Day 1-2 的完整流程
- **例外處理與交付管道對接**：自動化流程的例外處理與失敗提醒設計，規劃交付管道（Email、共用資料夾等，依 ITIC 現有系統調整）
- **綜合演練與成果發表**：完整跑通「蒐集 → 摘要/分析 → 彙整 → 交付」全流程，並設定每日自動執行，最後進行課程總結與維護建議

---

## 備註

- 各單元練習皆建議使用 ITIC 實際投資組合公司與營運資料作為範例，以提高學員上完課後直接沿用的可行性
- 建議上課前先確認 ITIC 現有的資料交付管道（內部信箱、共用雲端硬碟等），以便 Day 3 的實作能對接實際使用情境
