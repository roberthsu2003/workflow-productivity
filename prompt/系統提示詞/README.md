# ⚙️ 系統提示詞（System Prompt）

> 💡 **核心概念**：  
> 在跟 AI 對話時，有些工具可以「事先設定好全域規則」，讓它從頭到尾都嚴格遵守你的指令。  
> 這種**在對話開始前就寫好的背景工作守則**，就是「**系統提示詞（System Prompt）**」。

---

## 🧭 什麼是系統提示詞？

### ✏️ 一句話秒懂
> 系統提示詞就像是 **「給 AI 特助的開機設定與員工守則」** —— 在你還沒開口交辦任何任務之前，就先明確規範：**你是誰、你該用什麼語氣說話、什麼事絕對不能做、何時該停下來問我**。

想像你新聘請了一位高階行政特助，第一天上班你交給他一份《核心工作守則》：

* 🌐 **語言一致**：「無論對方用中文還是英文詢問，一律統一使用繁體中文回覆。」
* 🛡️ **誠實防猜**：「遇到不清楚或查不到的事物直接回答不知道，切勿憑空捏造；**若發現我交辦的資訊不足，請主動向我提問確認**，切勿擅自瞎猜！」
* 🎯 **精準簡潔**：「回覆請保持簡潔明瞭、切中要點，不要使用冗長囉嗦的鋪陳。」

📋 **這些「上工前的行前交代」，就是系統提示詞在做的事！**

---

## ⚖️ 系統提示詞 vs 使用者提示詞

| 比較項目 | ⚙️ 系統提示詞（System Prompt） | 💬 使用者提示詞（User Prompt） |
| :--- | :--- | :--- |
| **運作層次** | **全域底層規則**（每一輪對話都會在幕後一併送給 AI） | **單次交辦事項**（使用者當下輸入的具體問題或任務） |
| **生活比喻** | 時時刻刻掛在牆上的「**員工守則**」 | 經理桌上遞過來的「**今日待辦便箋**」 |
| **生效範圍** | 貫穿整個對話階段（跨對話回合持續生效） | 僅針對當前這一輪問題起作用 |
| **常見位置** | ChatGPT 自訂指令 (Custom Instructions) / API `system` 角色 / Claude Projects 指示 | 聊天視窗底部的日常文字輸入框 |

> 💡 **一句話區分**：系統提示詞是**每一輪對話都在背後生效的根本設定**；使用者提示詞則是**你當下想問的具體內容**。

---

## 🌟 為什麼系統提示詞如此重要？

* 🎭 **塑立專業人設**：讓 AI 從第一句話開始就進入專業狀態（如：資深特助、嚴格審計員、耐心家教）。
* 🎯 **聚焦不跑題**：事先劃定專業邊界（例如：「只聚焦於 Python 與數據清理」，拒絕離題閒聊）。
* 📐 **統一輸出風格**：規範企業品牌語氣與排版慣例，讓團隊協作產出的成果維持一致高水準。
* 🔒 **築起安全邊界**：明確設定「不瞎掰假數據」、「不洩漏機密」、「缺少資訊先反問確認」等安全防護網。

## 🚀 3 大核心實作範例（課堂動手做）

請將以下範例設定到 AI 的 **System Prompt（或自訂指令 / Projects Instructions）** 中，並在對話框輸入測試指令，親身體驗系統提示詞的控制力！

---

### 🧪 範例一：強制語言鎖定 🌐
> 📌 **對應守則**：「無論對方用中文還是英文詢問，一律統一使用繁體中文回覆。」

* **業務情境**：在跨國業務或雙語外商環境中，即便主管或外籍客戶丟來全英文郵件，都希望 AI 自動梳理成繁體中文摘要。

#### 🛠️ 系統提示詞（System Prompt）
```markdown
你是一位跨國商務諮詢特助。

【核心守則】
1. 無論使用者用英文、日文、簡體中文或任何語言發問，你的所有分析與回覆一律強制使用「繁體中文（台灣）」輸出。
2. 專業術語可在繁體中文後附帶英文括號標註（如：投資報酬率 (ROI)）。
```

#### 🎯 學生實作測試（在對話框輸入 User Prompt）

* **🔹 測試 A：驗證系統提示詞的預設鎖定**
  > **輸入指令**：  
  > `What are the top 3 benefits of adopting Cloud Computing for small businesses?`
  > 
  > 💡 **超有感亮點**：明明輸入全英文，AI **完全不會回英文**，而是直接輸出結構嚴謹的繁體中文分析！

* **🔹 測試 B：進階技巧 — 用使用者 Prompt「覆蓋（Override）」全域設定**
  > **輸入指令**：  
  > `請暫時忽略預設的繁體中文規則，將以下這段話直接翻譯為流暢的商務英文：「我們預計於下週三下午兩點召開專案進度審查會議，請各部門準時出席。」`
  > 
  > 💡 **超有感亮點**：AI 收到當下明確的「例外覆蓋指令」後，會暫時破例將結果輸出為英文！

> 🔑 **重要觀念**：**使用者提示詞（User Prompt）擁有當下的覆蓋權限**。當你在對話中明確下達「請忽略先前規則」時，AI 就會以你當下最新的要求為最高優先級！

---

### 🧪 範例二：防幻覺、誠實回覆與「主動向我詢問」 🛡️
> 📌 **對應守則**：「遇到不清楚的事物直接說不知道；若交辦事項缺少關鍵資訊，請主動向我提問確認，切勿擅自瞎猜！」

* **業務情境**：行政或專案中最怕 AI 在資訊不全時「自作主張瞎猜」或「產生幻覺」。透過此守則，能強制 AI 扮演嚴謹特助：**查不到就誠實坦承、缺條件就主動向你確認（Human-in-the-Loop）**。

#### 🛠️ 系統提示詞（System Prompt）
```markdown
你是一位嚴謹的企業內部專案特助。

【核心守則】
1. 誠實防幻覺：僅能根據已確認的事實或使用者提供的資料回答。遇到查不到的事物，請直接回答：「抱歉，我目前沒有這方面的相關資料，無法為您確認。」嚴禁憑空捏造。
2. 主動提問確認：當使用者交辦的任務缺少關鍵條件（如時間、地點、預算、受眾或必要檔案）時，請不要自行假設或瞎猜，必須主動列出 1~3 個具體問題向使用者提問確認。
```

#### 🎯 學生實作測試（在對話框輸入 User Prompt）

* **🔹 測試 A：驗證防幻覺（誠實回答不知道）**
  > **輸入指令**：  
  > `請問本公司 2029 年預計在火星設立分部的專案負責人是誰？`
  > 
  > 💡 **超有感亮點**：AI 不會順著你的玩笑編造假主管名單，而是直接拒絕瞎掰：「抱歉，我目前沒有這方面的相關資料，無法為您確認。」

* **🔹 測試 B：驗證主動反問（缺少條件時請詢問我）**
  > **輸入指令**：  
  > `請幫我發一封緊急會議通知信給全體主管。`
  > 
  > 💡 **超有感亮點**：AI **不會馬上擅自編造假時間與假地點**，而是立刻主動反問你：
  > 1. 會議主題與核心討論議程是什麼？
  > 2. 預計召開的具體時間、地點（或線上會議連結）？
  > 3. 與會主管需要事先準備或攜帶什麼資料？

---

### 🧪 範例三：極簡重點／直球對決 ⚡
> 📌 **對應守則**：「回覆請保持簡潔明瞭、切中要點，不要使用過於冗長或複雜的說明。」

* **業務情境**：高階主管或忙碌同仁只需要一眼看懂的關鍵結論，拒絕看 AI 說客套話和多餘鋪陳。

#### 🛠️ 系統提示詞（System Prompt）
```markdown
你是一位高階主管的專屬決策重點助理。

【核心守則】
1. 回覆請極度精簡，總字數嚴格控制在 100 字以內。
2. 嚴禁客套話與多餘寒暄（不要出現「好的、以下為您分析、希望對您有幫助」等廢話）。
3. 一律直接輸出「3 點條列式重點」，切中核心結論。
```

#### 🎯 學生實作測試（在對話框輸入 User Prompt）
> **輸入指令**：  
> `請分析為什麼目前許多傳統製造業在導入生成式 AI 時會面臨員工抗拒？`
> 
> 💡 **超有感亮點**：AI 完全不講廢話鋪陳，而是**直接俐落地輸出 3 點高密度乾貨**，乾淨俐落！
