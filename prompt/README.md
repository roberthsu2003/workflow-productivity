## 一個好提示詞的快速檢查

送出前花 10 秒確認：

- **目標**：我想要 AI 完成什麼？
- **背景**：它需要知道哪些情境或資料？
- **限制**：語氣、長度、受眾、不能做什麼？
- **格式**：我希望答案長成什麼樣子？

> 小提醒：不必每次都寫得很長；任務越複雜，越值得把這四項交代清楚。
