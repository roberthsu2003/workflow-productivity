# 高中資訊科技課綱 Python 評量標準 (Curriculum Standard)

## 1. 允許使用之核心語法
- 基礎輸入輸出：`input()`, `print()`, f-string 格式化。
- 基本型別與運算：`int`, `float`, `str`, `bool`，四則運算、取餘數 `%`。
- 條件分支：`if`, `elif`, `else`。
- 基礎單層迴圈：`for i in range(...)`（僅限單層，不允許巢狀雙重迴圈）。

## 2. 嚴格禁止超綱項目（Rubric 檢核重點）
- ❌ 串列切片與進階方法（如 `list[::-1]`, `list.sort()`）。
- ❌ 字典 `dict`、集合 `set`。
- ❌ 函式自訂 `def` 與參數傳遞。
- ❌ 巢狀迴圈（雙重 for 迴圈）。
- ❌ 外部模組導入（`import sys`, `import math` 等）。
