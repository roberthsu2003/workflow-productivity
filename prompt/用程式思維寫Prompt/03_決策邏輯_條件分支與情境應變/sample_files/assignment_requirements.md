# 作業題目：階梯式電費計算器 (Homework Requirements)

## 題目說明
請撰寫一個 Python 程式，讓使用者輸入用電度數（`kwh`），並依據以下階梯電價計算總電費：
1. **第一級（120 度以下含 120 度）**：每度 1.6 元
2. **第二級（超過 120 度至 330 度含 330 度）**：前 120 度每度 1.6 元，超過部分每度 2.4 元
3. **第三級（超過 330 度）**：前 120 度每度 1.6 元，121~330度每度 2.4 元，超過 330 度部分每度 3.5 元

## 預期輸入與輸出範例 (Test Cases)
- 測試案例 1（第一級）：
  - 輸入：`100`
  - 預期輸出：`總電費為 160.0 元`
- 測試案例 2（第二級邊界）：
  - 輸入：`200`
  - 預期計算：`120 * 1.6 + (200 - 120) * 2.4 = 192 + 192 = 384.0`
  - 預期輸出：`總電費為 384.0 元`
- 測試案例 3（負數防呆）：
  - 輸入：`-10`
  - 預期輸出：`用電度數不可為負數！`
