# 團隊協作工具使用者意見訪談與痛點筆記 (Feature Request Notes)

- **產品名稱**：WorkSync SaaS (專案看板與工作卡片管理工具)
- **收集來源**：客服工單、ZenDesk 報修紀錄與 5 位企業付費用戶訪談摘要

## 痛點彙整
1. **行銷主管 Karen**：「我們在卡片底下的留言串交代組員『請補齊宣傳圖檔』，但因為沒有 @通知功能，被指派的人根本不知道有這則留言，常常拖了三天才發現！」
2. **工程師 Leo**：「如果有人在卡片裡打 `@leo`，我希望手機 App 能跳推播通知，或在網頁右上角的鈴鐺出現紅點未讀。現在只能一直手動刷新瀏覽器看有沒有人找我。」
3. **專案經理 David**：「有時候同一個卡片裡大家隨便亂 tag，或者打錯字打成不存在的帳號，系統直接卡死或者沒任何提示，很不友善。」

## 期待功能
- 在卡片留言輸入 `@` 時，能浮現成員選單（彈出 Autocomplete）。
- 送出留言後，被提及者能即時收到通知（通知中心鈴鐺紅點 + 點擊直達該留言）。
- 需防範邊界情境：連續 tag 多人、tag 已離職員工或不存在的使用者時該如何處理。
