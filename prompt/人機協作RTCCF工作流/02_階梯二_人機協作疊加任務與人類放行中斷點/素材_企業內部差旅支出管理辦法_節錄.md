# 企業內部差旅與公務支出管理辦法（節錄規範）

## 第三條：差旅經費支用標準與核決門檻
1. **常規核決標準**：同仁出差住宿、交通與餐費，單筆支出於新台幣 3,000 元（含）以下者，經直屬主管核准後得辦理核銷。
2. **大額支出專案簽呈**：
   - 單筆支出超過新台幣 3,000 元者，視為大額支出項目。
   - 報銷時必須具備專案簽呈字號（如總經理簽呈 `#GM-XXXX` 或副總經理簽呈 `#VP-XXXX`）。
   - 若未檢附專案特批字號，財務部應依合規程序予以【退件補正】，待簽核補齊後方得撥款。
3. **單據完整性要求**：所有請款必須具備有效統一發票或收據號碼，且金額需明確載明；缺漏者列為異常暫緩受理。
