# 生成式AI全面探索:技術、應用與未來趨勢

## 🎯 目標

### 思維升級：Copilot ≠ Autopilot

![思維升級：Copilot ≠ Autopilot；Human-in-the-loop](./assets/Human-in-loop.png)

> **核心觀念：Human-in-the-loop（人類參與決策循環）**  
> **Copilot**：人是機長，AI 負責輔助導航與草稿，**人保留最終決策權**。  
> **Autopilot**：在公務與職場情境中，若**完全放手**交給 AI、不審閱、不負責，將帶來**極高風險**。

✔ 把 AI 當成**每天並肩工作的副駕（Copilot）**，而不是取代你思考的「全自動」

✔ 用 AI **減少重複、瑣碎、低價值工作**（AI 協助約 80%，你聚焦約 20% 的方針、取捨與責任）

✔ 知道如何把 AI **嵌入既有流程，而不是額外負擔**

✔ 具備 AI 素養：**會下指令、會檢核、會修正**，不被新工具牽著走

✔ **使用免費方案**，零成本學習 AI 應用（有大量**需求**可再訂閱付費方案）

## 80/20 原則的應用（仍由人類負責最後一哩）

1. **讓 AI 做可重複、可驗證的基礎工作**：格式、結構、初稿與彙整
2. **你負責創意與決策**：方向、風格、合規與風險判斷、**最終品質與交付責任**
3. **持續優化 Prompt**：指令越清楚，副駕越能對齊你的意圖；產出後仍要**人類審閱**再對外使用

## 🤖 三大主流 AI 代理平台實戰全指南

深入解析現代職場最具代表性的三大主流 AI 代理平台（Agent Platforms），從日常生產力代理副駕到工程級自主代理引擎，剖析其核心架構、工具調用、自動化工作流與實務落地指引：

### 🟣 [Claude.ai 智慧代理平台實戰全指南](./Claude_ai/README.md)
Anthropic 旗艦級 AI 代理平台，以頂級邏輯推理、超長脈絡窗口與卓越的中文理解著稱。作為高階認知與分析型代理人，核心優勢在於能直接透過對話自主編寫與執行程式碼並產出 Word、Excel、PPT、PDF 等正式商務檔案，並具備 Artifacts 成果畫布、Projects 知識庫沙盒、自訂 Skills 技能體系，以及能跨應用程式自主操作的 Computer Use 進階代理能力，特別適合高複雜度的長文深度分析、規章稽核與專業公務自動化。

### 🟢 [ChatGPT 多模態代理平台實戰全指南](./chatGPT/README.md)
OpenAI 旗艦級多模態 AI 代理平台，專為日常知識工作者打造的全能型生產力代理副駕。全篇聚焦於 Web 與桌面版圖形介面的代理協作能力（完全免寫程式、免用 CLI 終端機）：透過 Canvas 雙欄畫布人機協同精修長文與公文、免本機環境由進階數據分析代理（Advanced Data Analysis）自動清洗 Excel 並產出商務圖表與 Office 下載檔、零程式碼打造垂直領域的專屬 Custom GPTs 專案代理人與內部規章知識庫、委託 Deep Research 代理人自主規劃多步驟深度產業調研、Advanced Voice Mode 進階口說演練，以及 Google Drive 雲端硬碟直連，是跨領域企劃、行政管理、數據洞察與日常多工協作的強大代理助手。

### 🔵 [Google Antigravity 自主代理平台實戰全指南](./antigravity/README.md)
Google DeepMind 旗艦級 AI-First 自主代理平台與執行引擎生態系（**核心為強大的自主代理架構、CLI `agy` 與擴展生態，非僅限於 Antigravity IDE 編輯器介面**）。具備工程級規劃模式（Planning Mode）、子代理派工（Subagents）與背景長效任務（Background Tasks），原生支援本機終端指令執行、受控檔案精準變更、無頭瀏覽器自動化操作與 MCP 協定工具串接；搭配模組化的 Skills 技能、Rules 規範與 Hooks 機制，能自主形成「分析 ➔ 規劃 ➔ 執行 ➔ 自我驗證」的閉環工作流，專為複雜專案架構、深層自動化與工程級高產能交付而生。
